# 게임 결함 보고 (QA → 사용자)

> QA가 발견했지만 **고치지 않은** 게임 쪽 문제. 사용자 결정 2026-07-28:
> "AI 버그를 수정하는 건 자체적으로 해도 되는데, 시스템 버그는 나에게 정리해서 말해주고 고쳐야 해."
>
> QA/AI 쪽(`Assets/Scripts/QA/`, `tools/`)은 자체 수정. 그 외 게임 코드·씬·데이터는 **여기 적고 대기**.

## [2026-07-28] 안전가옥에 창고(Stash) 상호작용 대상이 없다

- **증상**: `goto NOT_PLACED: 'Stash' 상호작용 대상이 이 씬(Safehouse)에 배치돼 있지 않음` — 3개 런에서 재현.
- **근거**: Systems 씬에 `MainStash` 매니저는 정상 존재. 즉 시스템은 살아 있는데 **플레이어가 다가가 E를 누를 대상이 Safehouse 씬에 없다.**
- **원인 추정**: `SafehouseGreyboxLayout`에 `InteractType.Stash` 오브젝트 배치 누락.
- **제안 수정**: 안전가옥 레이아웃 빌더에 Stash 상호작용 오브젝트 추가 후 씬 재빌드.
- **영향**: **창고 접근 불가 → 인벤토리 정리 루프 자체가 성립하지 않음.** 레이드에서 가져온 물건을 보관할 수 없다.

## [2026-07-28] 사망해도 사망 화면이 뜨지 않는다

- **증상**: 플레이어가 죽었는데 "죽었다"는 창·연출이 나오지 않는다(사용자 화면 관찰).
- **근거**: QA 로그에 `DEATH — 사망 — (87, 119)` 기록됨(봇은 `Health.IsDead`로 감지). 즉 **사망 자체는 발생**하는데 UI가 없다.
- **원인 추정**: 사망 → 결과/재시작 UI 배선 누락. `Health.OnDeath` 구독자가 플레이어 쪽에 없을 가능성.
- **제안 수정**: 플레이어 사망 시 사망 화면(사망 원인·잃은 물품·재시작) 표시. 약탈자 회수 루프(docs/raid.md)와 연결되는 지점이므로 그 흐름과 함께 설계 필요.
- **영향**: 죽어도 아무 피드백이 없어 **플레이어가 무슨 일이 일어났는지 모른다.** 타르코프식 손실 규칙의 체감이 전혀 전달되지 않는다.

## [2026-07-28] 플레이어·적 체력바가 보이지 않는다

- **증상**: 전투 중 플레이어와 적 **양쪽 다** 체력바가 화면에 없다(사용자 화면 관찰).
- **근거**: `EnemyController`는 HP/그로기 바를 SpriteRenderer로 그리도록 돼 있다(CLAUDE.md 기술). 실제 화면에는 안 보임.
- **원인 추정 (미확인)**: ① 2026-07-28 `VisionDarkness` 오버레이가 바 스프라이트를 덮음(sortingOrder 문제) ② 바 오브젝트 비활성 ③ 플레이어 HUD 미배치.
  - ①이 유력하다 — 어둠 오버레이가 같은 시기에 들어왔고 화면 전체를 덮는 메시다.
- **제안 수정**: `VisionDarkness` 메시의 sortingLayer/Order를 체력바보다 **뒤로** 두거나, 바를 UI 캔버스로 올린다.
- **영향**: **전투 피드백이 전혀 없다.** 내가 얼마나 깎였는지, 적이 죽어가는지 알 수 없어 교전 판단이 불가능하다.

## [2026-07-28] ★최우선★ 플레이어 근접공격이 적에게 **전혀 맞지 않는다**

전투가 아예 성립하지 않는다. 5개 런 연속 `KILL 0`, 매번 플레이어만 죽는다.

- **증상**
  ```
  combat CHAIN          클릭 17 → 발동 17 (거부: 없음) → 적중 0 → 데미지 0
  combat ATTACK_MISSES  발동 17회가 전부 헛스윙 — 명중 0
                        평균 거리 1.4m · 평균 각도차 1도
  combat TRADE          적 HP 40→40 (준 피해 0) · 내 체력 100%→32% (받은 피해 68%p)
  ```

- **근거 — 봇 문제가 아님이 배제됨**
  | 배제 항목 | 실측 |
  |---|---|
  | 공격이 발동 안 됨? | **클릭 17 → 발동 17.** 쿨다운·스태미너 거부 0건 |
  | 조준이 틀림? | **평균 각도차 1도** (정확히 정면) |
  | 사거리 밖에서 휘두름? | **평균 1.4m**, 히트박스 도달 범위 0.3~1.5m 안 |
  | 무기 미장착 탓? | 데미지는 `Stat.lightDamage`(8) — 맨손도 적용 (`TopDownPlayer.cs:220`) |
  | 스윙 중 뒤로 빠져서? | `TopDownPlayer.cs:306-310` — 공격 중 `linearVelocity = 0`으로 **이동 자체가 봉쇄**됨 |
  | 적이 인식을 못 해서? | **적 인식률 100%** (4기 중 4기). 적은 정상적으로 다가와 때린다 |

- **히트박스 기하는 정상** (`TopDownPlayer.cs:238-252`, `StatDB.asset` lightRange=1.2)
  ```
  offset  = BodyRadius(0.3) + range(1.2)*0.5 = 0.9
  boxSize = (1.2, 0.7)
  → 정면 0.3m ~ 1.5m 를 폭 0.7m 로 덮는다. 공격 거리 1.4m는 이 안.
  적은 scale 2 라 콜라이더가 커서 더 잘 맞아야 한다.
  ```

- **원인 추정 — 판정 대상(레이어/콜라이더)이 안 잡힌다**
  `AttackPerformer.ScanWindow`는 `Physics2D.OverlapBox(center, size, angle, filter, _buf)`로 `targetMask`에 걸리는 콜라이더만 찾는다.
  1. **`TopDownPlayer.enemyMask`가 실제로 적 레이어를 포함하지 않을 가능성** — 선언 기본값은 `~0`(전부)이지만 `[SerializeField]`라 **PlayerRig.prefab에 직렬화된 값이 실제로 쓰인다.** 프리팹에서 `Nothing` 또는 잘못된 레이어로 저장돼 있으면 영원히 0히트.
  2. **적 `Hurtbox` 콜라이더 문제** — `EnemyController.cs:498`에서 `GetComponentInChildren<Hurtbox>()`로 참조. 그 오브젝트의 **레이어**가 `enemyMask`와 안 맞거나, 콜라이더가 없거나 비활성일 가능성.
  3. 필터가 `useTriggers = true`라 트리거도 잡으므로 트리거 여부는 원인이 아님.

- **확인 방법 (가장 빠른 순서)**
  1. `PlayerRig.prefab` → `TopDownPlayer` 컴포넌트의 **Enemy Mask** 인스펙터 값 확인. 적 레이어가 체크돼 있는가?
  2. 런타임에 적 프리팹의 `Hurtbox` 자식 GameObject **레이어** 확인 — `enemyMask`에 포함되는가?
  3. `AttackPerformer.ScanWindow`에 `Debug.DrawCube`/기즈모로 히트박스를 그려 적 콜라이더와 실제로 겹치는지 눈으로 확인.

- **영향**
  **게임의 핵심 루프가 성립하지 않는다.** 적을 죽일 수 없으므로 전투·시체 파밍·퀘스트(처치형)·레벨업이 전부 막힌다. 플레이어는 일방적으로 맞다가 죽는 것만 가능하다.
  이것이 해결되기 전에는 **전투 밸런스 측정 자체가 무의미**하다.

## [2026-07-28] 도망쳐도 적에게서 벗어날 수 없다

- **증상**: `flee · CANNOT_ESCAPE — 12초 도망쳤는데도 체력이 계속 깎임 (32%→0%)`. 2개 런에서 재현, 둘 다 도주 중 사망.
- **근거**: QA 봇이 적 반대 방향으로 12초간 연속 이동(`safeDist` 18m 목표)했는데 거리가 벌어지지 않았다. 그동안 체력은 32%→12%, 다른 런에선 32%→0%.
- **원인 추정**: 적 이동속도가 플레이어와 같거나 빠름 / 추격 포기 거리(`loseRange`)가 너무 멀거나 작동 안 함. `StatDB` 기준 `bandit_melee_1`은 `moveSpeed 2.5`, 플레이어는 `moveSpeed 4`인데 실제로는 안 벌어진다 → **플레이어 이동이 무언가에 막히거나(피격 경직?) 적이 설정보다 빠르다.**
- **제안 수정**: 피격 시 이동 제약(경직·넉백) 확인, `loseRange` 동작 확인. 그리고 위 "공격이 안 맞는다" 결함과 겹치면 **교전 = 확정 사망**이 된다.
- **영향**: 타르코프식 "손실을 감수하고 빠진다"가 성립하지 않는다. 적을 만나면 죽는 것 외에 선택지가 없다.

## 조사 중 (증거 부족 — 아직 결함으로 단정 못 함)

### 적이 플레이어를 인식하지 못하는 경우가 있다
- 사용자 관찰. QA 계측 추가함(`enemy · NOTICED` / `AWARENESS`).
- 2026-07-28 런: **인식률 100%(표본 1기, 인식거리 6.3m)** — 이번엔 정상 동작.
- 표본이 더 필요하다. 반복 관측되면 여기로 승격.

### 전투에서 한 마리도 못 잡는다
- 4개 런 연속 `KILL 0`, 매번 체력 20~30%까지 깎이고 도주/사망.
- **아직 원인 미확정**: 명중이 안 되는 것(배선)인지, 맞는데 못 죽이는 것(밸런스)인지.
- QA 계측(`combat · TRADE` — 적 HP 변화)을 넣었으나 도주 경로에서 기록이 누락되는 버그가 있어 데이터 미수집. QA 쪽 수정 후 재측정 예정.
