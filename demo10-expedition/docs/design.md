# Demo 10: 원정대 (Expedition) — 기획 문서

## 컨셉
좀보이드/타르코프식 맵 탐색 + 워테일즈식 격자 턴제 전투 + 안전가옥 귀환 루프

## 핵심 루프
안전가옥 → 구역 선택 → 맵 탐색 (루팅/적 조우) → 전투 (격자 턴제) → 귀환

## 검증 질문
"탐색의 긴장감과 전투의 전술적 깊이가 공존하는가?"

---

## 시스템 설계

### 맵 탐색
- 절차적 생성 타일맵 (방 + 복도 구조)
- 시야 제한 (포그 오브 워)
- WASD 이동, E 상호작용
- 루트 상자, 적 조우, 탈출구
- 긴급 철수 시 보급품 절반 손실

### 전투
- 12x8 격자 턴제 전술
- AP(행동력) 기반: 이동 + 공격/스킬
- SPD 순서로 턴 진행
- AI 유형: melee_rush, balanced, ranged_kite, aggressive

### 안전가옥
- 원정대 편성 확인
- 보급품 관리
- 구역 선택 (난이도별)
