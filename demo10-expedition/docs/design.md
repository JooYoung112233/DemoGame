# Demo 10: 원정대 (Expedition) — 기획 문서

## 컨셉
좀보이드/타르코프식 맵 탐색 + 실시간 액션 전투 + 안전가옥 경영 루프

## 핵심 루프
안전가옥 (장비/상인/의뢰/제작) → 구역 선택 → 맵 탐색 (루팅/적 조우) → 실시간 전투 → 탈출구 도달 → 귀환

## 검증 질문
"탐색의 긴장감과 생존의 쾌감이 공존하는가?"

---

## 시스템 설계

### 캐릭터
- **1인 모험자** (단독 원정)
- 장비 슬롯: 무기, 방어구, 소모품 3칸
- HP, ATK, DEF, SPD 스탯
- 장비에 따라 스탯 변동

### 맵 탐색
- 절차적 생성 타일맵 (직사각형/정사각형 건물)
- 건물 = 벽+바닥+문 구조, 모든 건물은 반드시 출입 가능
- 시야 제한 (포그 오브 워)
- WASD 이동, E 상호작용
- 루트 상자, 적 조우, 탈출구
- **탈출구**: ~500칸 이동 후 출현 (미니맵에 표시)
- 긴급 철수 시 보급품 전부 손실

### 적 조우
- 적이 플레이어 시야 내 접근 → **느낌표(!) 표시** + 추적 시작
- 적 감지 범위: 5칸 (시야 내)
- 전투는 맵 위에서 실시간 진행 (별도 씬 없음)

### 전투 (실시간 액션)
- 맵 위에서 직접 클릭/키로 공격
- 무기 사거리 내 적 클릭 → 공격 (쿨다운)
- 적도 실시간 추적 + 공격
- HP바 표시, 피격 시 넉백 효과
- 적 처치 시 드롭 아이템

### 안전가옥
- **보관함**: 아이템 보관 (초기 20칸, 업그레이드 가능)
- **장비 장착**: 무기/방어구/소모품 슬롯 세팅
- **상인**: 아이템 매매, 신뢰도에 따라 품목 해금
- **의뢰 게시판**: 퀘스트 수락/완료 → 보상
- **작업대**: 재료 조합 → 장비 제작
- **시설 업그레이드**: 골드+재료로 각 시설 레벨업
