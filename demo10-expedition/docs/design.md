# Demo 10: 밤에만 열리는 도시 (Opening City) — 기획 문서

## 컨셉
> 낮엔 폐허를 준비하고, 밤엔 도시가 열린다.

현실의 폐도시를 탐험하며 장비를 준비하고,
밤이 되면 현실에 존재하지 않던 건물과 구역이 열리는 도시에서
루팅과 생존, 경쟁 원정대를 상대하는 2D 생존 루팅 게임.

## 핵심 감정
> "한 집만 더 털까?"

## 검증 질문
"낮/밤 전환의 긴장감과 루팅의 쾌감이 공존하는가?"

---

## 세계관

세상은 멸망하지 않았다. 정부도 있고 도시도 존재한다.
하지만 특정 폐도시들은 밤이 되면 현실과 겹쳐지며 '열림(Open)' 현상이 발생한다.
낮에는 단순한 폐허처럼 보이는 건물이, 밤이 되면 존재하지 않던 내부 구조와 구역을 드러낸다.

사람들은 이를 **"개장(Open)"**이라 부르고, 이곳을 탐험하는 사람들을 **"원정꾼"**이라 부른다.

---

## 핵심 루프

안전가옥 (장비/상인/수리/정보) → 폐도시 진입 → 낮(폐허 탐색/자원 수집) → 밤 전환(도시 개장) → 밤 루팅(시간 제한) → 도시 닫힘 전 탈출 → 귀환

---

## 시스템 설계

### 캐릭터 (원정꾼)
- **1인 원정꾼** (단독 탐험)
- 장비 슬롯: 무기, 방어구, 소모품 3칸
- HP, ATK, DEF, SPD 스탯
- 장비에 따라 스탯 변동
- **손전등**: 배터리 소모, 시야 핵심

### 맵 구조 (하나의 맵에서 낮/밤 전환)
- 절차적 생성 타일맵
- **낮**: 폐허 건물(벽+바닥+문), 기본 루트, 밴딧/야생동물
- **밤 전환**: 특정 건물이 "개장" → 새로운 내부 구조 출현, 희귀 루트 생성
- 같은 맵에서 시간이 흐르며 낮→밤 전환

### 낮/밤 사이클
- **낮**: 폐허 탐색, 자원 수집, 밴딧/야생동물 조우
- **밤 전환**: 화면 어두워짐 + "개장" 연출, 건물 내부 변경
- **밤**: 핵심 루팅 단계, **시간 제한** 존재
- **도시 닫힘**: 시간 초과 시 강제 탈출 (전리품 손실 위험)

### 시간 제한 (밤)
- 밤 진입 후 타이머 시작 (예: 5분)
- 시간 경과에 따라 UI 경고
- 시간 초과 시 도시가 "닫히며" 강제 귀환 (전리품 일부 손실)
- 탈출구에 도달하면 안전 귀환

### 시야 시스템 (부채꼴)
- **낮**: 넓은 원형 시야 (기존과 유사)
- **밤**: 부채꼴 시야 (이동 방향 기준)
  - 전방: 넓고 먼 시야 (손전등)
  - 측면: 좁은 시야
  - 후방: 매우 좁은 시야
- **손전등 배터리**: 시간에 따라 소모, 꺼지면 매우 좁은 시야
- 목표: 호러가 아닌 **긴장감**

### 적 구조

#### 낮 (70% 인간)
- **밴딧**: 약탈자, 총격전
- **경쟁 원정대**: 장비 좋음, 루트 경쟁
- **야생 들개**: 빠르지만 약함

#### 밤 (50% 인간 + 50% 도시 존재)
- **밤 밴딧**: 밤에도 활동하는 약탈자
- **경비원**: 개장된 건물 순찰, 발견 시 공격
- **순찰자**: 도로/통로 순찰
- **관리자**: 특정 구역 수호, 강력
- *도시 존재는 좀비가 아님. 도시 역할을 수행하는 존재. 현실 80% / 이상함 20%*

### 장소 (개장 구역)
- **폐백화점**: 가방, 고급 장비, 식량 / 경비원+경쟁 원정대
- **병원**: 의약품, 응급키트, 희귀약물 / 이상한 환자+보안
- **중앙역**: 희귀 장비, 군용 상자 / 제한 시간 짧음
- **학교**: 공구, 제작 재료 / 확장되는 교실

### 안전가옥
- **보관함**: 아이템 보관
- **장비 장착**: 무기/방어구/소모품 슬롯
- **상인**: 아이템 매매
- **수리대**: 장비 수리, 손전등 정비
- **정보판**: 오늘 밤 어디가 열리는지 힌트
