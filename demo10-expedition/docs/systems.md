## 1. 파밍 시스템 (Tarkov-Style Slot Search)

### 개요
컨테이너를 수색하면 슬롯 그리드가 열리고, 프로그레스바 진행에 따라 아이템이 하나씩 공개된다.  
탐색 중에는 이동/공격 불가 (무방비 상태).

### 수색 흐름
```
E키로 상호작용 → 슬롯 UI 오픈 → 프로그레스바 진행 →
슬롯 순차 공개 (? → 아이템/빈칸) → 클릭으로 회수 → ESC 또는 완료 후 닫기
```

### 슬롯 표시 방식
| 상태 | 표시 | 설명 |
|------|------|------|
| 미탐색 | `?` (어두운 칸) | 슬롯은 보이지만 내용물 숨김 (잠금 아이콘 아님) |
| 공개 - 아이템 있음 | 아이콘 + 이름 + 무게 | 희귀도 색상 테두리, 클릭 가능 |
| 공개 - 빈칸 | `비어있음` | 회색 어두운 칸 |
| 회수 완료 | `✓ 획득` | 비활성, 회색 |

### 컨테이너 종류별 사양
| 컨테이너 | 타일 | 슬롯 수 | 탐색 시간 | 루트 풀 |
|-----------|------|---------|-----------|---------|
| 드럼통 | BARREL | 4칸 | 3.0초 | barrel |
| 사물함 | LOCKER | 6칸 | 5.0초 | locker |
| 보급상자 | CRATE | 6칸 | 5.0초 | crate |
| 의료함 | MEDICAL | 6칸 | 4.0초 | medical |
| 컴퓨터 | COMPUTER | 4칸 | 6.0초 | computer |
| 루트 | LOOT | 4칸 | 3.5초 | common_crate |

### 희귀도 시스템 (공개 순서 & 연출)

아이템마다 희귀도가 지정되어 있으며, **커먼 → 에픽 순서로 공개**된다.  
높은 희귀도일수록 공개 연출이 길고 화려하다.

| 희귀도 | 색상 | 테두리 | 공개 연출 시간 | 발광 효과 |
|--------|------|--------|---------------|-----------|
| Common | #aaaaaa (회색) | 0x666666 | 300ms | ✗ |
| Uncommon | #44ff88 (초록) | 0x44ff88 | 500ms | ✗ |
| Rare | #4488ff (파랑) | 0x4488ff | 900ms | ✓ 펄스 발광 |
| Epic | #aa44ff (보라) | 0xaa44ff | 1400ms | ✓ 펄스 발광 |

### 아이템 희귀도 분류

**Common** — 고철, 천 조각, 못, 전선, 붕대, 생수, 통조림, 권총탄, 산탄

**Uncommon** — 덕트테이프, 전자부품, 화학약품, 진통제, 에너지드링크, 전투식량, 소총탄, 배터리, 랜턴 연료, 락픽, 의약품, 손전등 부품, 인식표, 헬멧

**Rare** — 의료킷, 조준경, 방탄판, 백팩, 회로기판, USB, 도시 지도, 낡은 열쇠

**Epic** — 금목걸이, 택티컬 조끼, 기밀문서, 야시경, 희귀 소재

### 공개 순서 로직
1. 빈 슬롯 & Common 아이템 → 먼저 공개
2. Uncommon → 중간
3. Rare → 후반
4. Epic → **가장 마지막에 공개** (드라마틱 연출)

같은 희귀도 내에서는 랜덤 순서. 공개 타이밍은 프로그레스바 진행률에 비례하여 분배.

### 수색 중 규칙
- 이동, 공격, 인벤토리, 맵 열기 **모두 불가**
- ESC로 중도 취소 가능 — **이미 회수한 아이템은 유지**, 미회수 아이템은 소실
- 적이 공격해도 수색 UI는 자동으로 닫히지 않음 (플레이어 판단)

## 2. 무게 시스템

### 기본 수치
| 항목 | 값 |
|------|-----|
| 최대 무게 | **30kg** |
| 최대 슬롯 | 20칸 |

### 아이템별 무게 (발췌)
| 아이템 | 무게 | 비고 |
|--------|------|------|
| 고철 | 1.0kg | 재료 |
| 천 조각 | 0.5kg | 재료 |
| 의료킷 | 1.0kg | 소모품 |
| 붕대 | 0.3kg | 소모품 |
| 배터리 | 0.3kg | 소모품 |
| 방탄판 | 2.0kg | 장비 |
| 택티컬 조끼 | 2.0kg | 장비 |
| 백팩 | 1.0kg | 장비 |
| 금목걸이 | 0.3kg | 귀중품 |
| USB | 0.1kg | 귀중품 |
| 희귀 소재 | 1.0kg | 귀중품 |

### 과적 (Overweight) 패널티
- 현재 무게 > 30kg 시 **과적 상태**
- **이동속도 1.8배 감소** (MOVE_DELAY × 1.8)
- HUD에 무게 텍스트가 빨간색으로 변경
- 인벤토리에 `⚠ 과적! 이동속도 감소` 경고 표시

### 무게 제한 적용 시점
- **수색 UI에서 아이템 회수 시**: 현재 무게 + 아이템 무게 > 30kg이면 회수 거부 + 경고 메시지
- **인벤토리 슬롯 20칸 제한**은 별도로 유지 (무게와 슬롯 이중 제한)

### UI 표시
| 위치 | 표시 내용 |
|------|-----------|
| HUD (상시) | `🎒 3/20  ⚖12.5/30kg  💰 245` |
| 인벤토리 패널 | 무게바 (파랑→주황→빨강) + kg/G 수치 |
| 수색 UI 하단 | `인벤: 3/20  ⚖12.5/30kg` |

### 무게바 색상
| 구간 | 색상 |
|------|------|
| 0~80% | 파랑 (0x44aaff) |
| 80~100% | 주황 (0xffaa44) |
| 100%+ | 빨강 (0xff4444) |

## 3. 인벤토리 시스템

### TAB키로 열기/닫기

### 정렬 순서
1. Epic (보라) — 가장 위
2. Rare (파랑)
3. Uncommon (초록)
4. Common (회색) — 가장 아래

같은 희귀도 내에서는 알파벳순.

### 표시 항목 (아이템 행)
```
● 🔩 고철 x3                    3.0kg  15G
```
- 희귀도 색상 점(●)
- 아이콘 + 이름 + 수량
- 총 무게 + 총 가격 (우측 정렬)

### 상단 요약
- 무게바 (시각적 게이지)
- `⚖ 12.5 / 30kg  |  💰 245G`
- 과적 시 경고 문구

## 4. 시야 안개 (Fog of War)

### 개요
플레이어의 현재 시야 범위만 선명하게 보이며, 탐색했지만 시야 밖인 타일은 반투명 안개로 덮인다.  
미탐색 타일은 완전한 검정 안개.

### 안개 상태별 투명도
| 상태 | alpha | 설명 |
|------|-------|------|
| 미탐색 | 0.85 | 완전 가림 (최초 생성값) |
| 탐색 완료 + 현재 시야 내 | 0.00 | 완전히 보임 |
| 탐색 완료 + 시야 밖 (낮) | **0.55** | 반투명 — 지형은 보이나 흐릿 |
| 탐색 완료 + 시야 밖 (밤) | **0.75** | 짙은 안개 — 거의 안 보임 |

### 낮 시야
- 원형, 반경 = `PLAYER_DATA.visionRadius` (6칸)
- 시야 내 타일: 즉시 alpha 0
- 시야 밖 탐색 완료 타일: alpha 0.55로 페이드 (300ms)

### 밤 시야
- 기본 원형: `nightVisionRadius` (2칸) — 손전등 없어도 바로 앞은 보임
- 손전등 ON: 부채꼴 `flashlightRange` (7칸) × `flashlightArc` (90°)
  - Bresenham LOS 체크로 벽 뒤는 차단
- 손전등 OFF / 배터리 0: 기본 2칸만 보임
- 시야 밖 탐색 완료 타일: alpha 0.75로 페이드

### 가로등 효과
- `STREETLIGHT` 타일 반경 2칸 내 → 밤에도 시야 밖 re-fog 면제
- 가로등 근처는 항상 밝게 유지

### 성능
- 매 프레임 플레이어 주변 `activeRadius + 5` 범위만 스캔
- `discovered` 배열로 탐색 여부 추적 (O(1) 조회)
- 이미 적절한 alpha인 타일은 트윈 생략

## 7. UI 렌더링 원칙

### Phaser Container 미사용
모든 UI는 씬에 직접 추가 + `setDepth()` 로 레이어링.  
Phaser Container는 depth 정렬 문제로 **사용 금지**.

### Depth 계층
| Depth | 용도 |
|-------|------|
| 0 | 타일맵 |
| 1 | 크롬 배경 (SafeHouse) |
| 2 | 타일 아이콘 |
| 5 | SafeHouse 제목/탭 |
| 10 | 탭 컨텐츠, 플레이어 |
| 50 | 안개 (Fog) |
| 100 | HUD, 상시 UI |
| 150 | 인터랙션 프롬프트 |
| 200 | 인벤토리/풀맵 오버레이 |
| 250 | 수색 UI |
| 260 | 수색 아이템 획득 팝업 |

### 씬 전환 패턴
```js
this.cameras.main.fadeOut(600, 0, 0, 0);
this.time.delayedCall(650, () => {
    game.scene.stop('CurrentScene');
    game.scene.start('TargetScene', data);
});
```
- `game.scene.stop/start` 사용 (this.scene.start 금지 — 블랙스크린 원인)
- `time.delayedCall` 사용 (setTimeout 금지)
