`demo13-flashlight` **게임 시스템 빌드**를 한 단계 이어서 진행한다. (요약은 짧게 — 파일 덤프 금지.)

## 1. 핸드오프 로드 (먼저)
- `demo13-flashlight/docs/dev-handoff.md` — **마지막 작업 상태 / 다음 할 일**(여기부터).
- `demo13-flashlight/docs/dev-roadmap.md` "빌드 순서 — 코어 루프부터 1단계씩" 표 — 현재 Phase.
- `git log --oneline -5` + `git status` — 최근 커밋·미커밋 변경.

## 2. 요약 후 진행
- 현재 어디까지 됐고 **다음 한 단계가 뭔지 2~3줄**로 요약.
- 다음 단계를 진행:
  - 코드면 → 작성 + **정적 컴파일 감사**(타입 충돌·API 실재·using 정합). Unity 못 돌리니 여기까지가 내 몫.
  - 씬/그레이박스면 → 돌릴 빌더(`Tools ▸ TopDown ▸ 빌드 ▸ …`)와 테스트 절차를 사용자에게 안내.

## 3. 고정 원칙
- **리소스(아트)만 제외, 그 외 전 게임 시스템을 그레이박스로 한 단계씩 제작+테스트.**
- **Unity 실행/테스트는 사용자** → 결과(특히 컴파일 에러=0순위) 받고 다음 단계.
- 플레이어 경험 순서로: **타이틀 → 안전가옥 → 레이드 → 루팅 → 전투 → 시스템.** 진행/경제 레이어는 맨 마지막.
- 기획 결정은 즉시 해당 `docs/` md에 기록. `main` 직접 push 금지(브랜치→PR). 커밋은 사용자 요청 시에만.

## 4. 마무리
- 단계 끝나면 `dev-handoff.md`의 "지금 위치 / 다음 할 일"을 갱신해 다음 핸드오프를 남긴다.
