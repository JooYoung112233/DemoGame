`demo13-flashlight`의 **세계관·스토리 작업을 이어서** 진행한다. 먼저 캐논 현재 상태를 복원한 뒤, 사용자가 지정한 초점으로 계속한다. (요약은 짧게 — 파일 덤프 금지.)

## 1. 현재 상태 복원 (먼저 수행)
- **세계관 캐논(SSOT)**: `demo13-flashlight/docs/gdd-core.md §5` 읽기 — 시대·무대 / 짙은현상 / 빛의역설 / 루디 / 시간왜곡.
- **스토리 설계**: `docs/story.md` — §2(기원·진실/표층 대조)·§4(지역별)·§5(엔딩) 구조 훑기. **1지역 본선 진실 = `docs/story-script.md`(S-000~S-018)**.
- **최근 결정**: `story.md`·`gdd-core.md` 하단 "기획 결정 로그" **최신 2~3개**.
- **미결 스캔**: 문서에서 `TBD` · `⚠️` · "남은 정합 / 후속 / 재작성 대기" 표기를 훑는다.
- **git**: `git log --oneline -6` + `git status` — 최근 커밋과 **미커밋/병렬(Unity) 변경분**을 구분.

## 2. 룰 (항상 준수)
- **세계관 로어 SSOT = `gdd-core.md §5`.** 타 문서는 로어를 **재서술하지 말고 §5로 링크.** 충돌 시 §5 우선.
- **1지역 데모 본선의 진실 = `story-script.md`** — `story.md`와 충돌 시 script 우선.
- **기획 결정은 즉시 해당 `docs/` md에 기록**(날짜·질문·결정·근거 + 변경 로그). "현 상태 = 진실" — 바뀐 결정은 덮어쓰고 폐기분은 변경 로그/배너로 남김. (모호하면 [design-keeper], 정합 점검은 [doc-consistency] 활용)
- **현재 핵심 캐논**(놓치지 말 것): 동생 「노을」 = **알파가 심은 가짜 기억**(실존 X) · 새벽 기억상실 = **죽음→시간역행 부활** · 시계 = 알파 면역체+능력 · 엔딩 **2종**(①진엔딩 진실 / ②굿엔딩 거짓 동생). 빛의 역설 = 루디 외 모든 빛 위험. 루디 = 충전·방전·마모 활성 자원.
- **git**: `main` 직접 push 금지 → 브랜치 후 PR. 커밋/푸시는 **사용자 요청 시에만**. **손대지 않은 병렬/Unity 변경분은 임의 커밋 금지.**

## 3. 이어서 진행
1. **"마지막으로 멈춘 지점 + 미결 항목"**을 3~5줄로 요약해 사용자에게 보여준다.
2. 사용자가 준 초점: **$ARGUMENTS**
   - 있으면 → 룰을 지키며 바로 그 작업 진행.
   - 비어 있으면 → 미결 항목을 우선순위로 제시하고 "무엇부터 할지" 묻는다(멋대로 큰 변경 시작 금지).
