# QA ↔ 개발 자동 루프 (유기적 시스템)

```
 ┌─────────────────────────────────────────────────────────┐
 │  qa-runner ──판정+문제목록──▶ dev-fixer ──수정──┐        │
 │      ▲                                          │        │
 │      └────────── 재검증 ◀────────────────────────┘        │
 │                     │                                     │
 │                     └──▶ 라운드마다 사용자에게 중간 보고   │
 └─────────────────────────────────────────────────────────┘
        게임(-qa-serve) ◀──파일──▶ 에이전트    외부 GUI: tools/qa-dashboard.ps1
```

## 사전 조건 (없으면 사용자에게 요청)

1. **게임이 명령 대기 모드로 떠 있어야 한다**
   ```bash
   game.exe -qa-serve -qa-instance=A -qa-minutes=10
   ```
   (에디터라면 Play + F9는 1회 실행만 되므로, 루프에는 빌드 + `-qa-serve` 권장)

2. **대시보드(선택)** — 사용자가 눈으로 보려면
   ```bash
   powershell -ExecutionPolicy Bypass -File tools\qa-dashboard.ps1
   ```
   → http://localhost:8787

`qa-status.json`을 Glob으로 찾아 게임이 떠 있는지 먼저 확인할 것.

## 라운드 진행

**한 라운드 = QA 1회 + 수정 1회 + 사용자 보고 1회.** 기본 3라운드, 사용자가 지정하면 그만큼.

### 1) QA 실행
`qa-runner` 에이전트에 위임. 이번 라운드의 **검증 목표**를 명시해 보낸다.
- 1라운드: 루프가 도는가(cycles 2~3, 전 스텝)
- 2라운드: 직전 수정이 실제로 고쳐졌는가 + 새 축 하나 추가
- 3라운드~: 반복성·맵 밸런스(cycles 5+, wander)

> **매 라운드 검증 축을 하나씩 늘린다.** 같은 것만 반복 확인하지 말 것.

### 2) 수정
QA 보고의 "dev-fixer에게 넘길 것"을 그대로 `dev-fixer`에 위임.
- **고칠 게 없으면 이 단계를 건너뛰고** 다음 검증 축으로 넘어간다.
- dev-fixer가 "사용자 결정 필요"를 올리면 **루프를 멈추고** 사용자에게 물어본다.

### 3) 중간 보고 (매 라운드 필수)

```
## 라운드 N/M — <검증 목표>
판정: PASS → FAIL → PASS 처럼 추이를 보인다
고친 것: <한 줄씩>
남은 것: <한 줄씩>
다음 라운드: <무엇을 검증할지>
```

짧게. 파일 덤프 금지. 사용자가 흐름만 따라올 수 있게.

## 멈춰야 할 때

- 같은 문제가 **2라운드 연속 안 고쳐짐** → 원인 미상. 사용자에게 판단 요청.
- dev-fixer가 **기획 결정 필요**를 올림 → 사용자에게 선택지 제시.
- 게임 프로세스가 죽음(`qa-status.json` 10초 이상 갱신 없음) → 재실행 요청.
- **PASS가 2라운드 연속** → 현재 검증 축은 충분. 새 축을 제안하고 사용자에게 계속할지 확인.

## 병렬 실행

여러 각도를 동시에 보려면 인스턴스를 나눈다.
```bash
game.exe -qa-serve -qa-instance=A   # 경제 검증용
game.exe -qa-serve -qa-instance=B   # 맵/길찾기 검증용
```
`qa-runner`를 인스턴스별로 동시에 띄우고, 결과를 합쳐 보고한다.
대시보드는 인스턴스를 자동으로 구분해 보여준다.

## 원칙

- **QA는 고치지 않고, 개발은 판정하지 않는다.** 역할을 섞지 말 것.
- 커밋·푸시는 **사용자가 요청할 때만**.
- 라운드마다 실제 데이터(JSON)를 근거로 말한다. 추측 금지.
