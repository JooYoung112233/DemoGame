에이전트 루프 & 하네스 🟢 공식

Workflow vs Agent

Workflow: 사전정의된 코드 경로로 오케스트레이션

Agent: LLM이 스스로 프로세스·도구 사용을 동적으로 지휘

에이전트 루프

"환경 피드백을 받아 도구를 루프에서 쓰는 LLM". 매 단계 환경의 ground truth로 진척 평가

하네스(scaffold) = 모델을 에이전트로 작동시키는 시스템. Claude Agent SDK는 여러 컨텍스트 윈도우에 걸친 루프로 동작.

학술 뿌리 🔵: ReAct(2210.03629) · Reflexion(2303.11366) · Toolformer · Generative Agents — 마케팅 신조어가 아님

코드↔문서 정합성 — stale 방지 🟡

코드가 바뀌면 분석문서는 낡는다(stale). 어떻게 추적하나?

  • docs-as-code — 문서를 코드처럼: 평문·git·PR 리뷰·같은 repo
  • 심볼+git diff stale 감지 — frontmatter source_refs: "file::symbol" → git log --since=<updated>로 바뀐 문서 플래그
⚠️ 한계: 파일 단위 diff는 오탐 많음(4400줄 한 줄 바뀌어도 전 문서 플래그) → 심볼 단위로 좁히고 report-only
권고: 감지·플래그는 자동, 갱신은 사람 승인. "AI가 완전 자동 동기화" 🟠 미성숙
