# 플레이어 B 만화풍 텍스처 — 2026-09-12

사용자 선택: A/B/C 중 **B의 진한 만화 선**. 후속으로 **텍스처에 직접 그리는 그림자도 허용**했다. 이 선택은 스타일 승인이고 실제 연결본의 최종 외형 승인은 별도다.

## 변경과 실제 연결

- 몸/장비 Base Color를 `Textures/Player_Comic_B.png`, `PlayerGear_Comic_B.png`로 제작했다. 모자 패널·재킷 포켓·지퍼·소매/바지 끝·가방 덮개·버클의 선을 강화하고, 2~3단 색면과 각진 그림자로 표현했다.
- Unity MCP로 `Assets/ChibiSurvivor/Player/Painted62/Textures`에 임포트하고 기존 `Player_Painted.mat`, `PlayerGear_Painted.mat` 두 재질의 BaseMap만 변경·개별 저장했다. 원본 V1/V2 텍스처는 유지했다.
- 현재 플레이어의 17개 스킨 재질 슬롯이 B 텍스처를 참조한다. 모델/UV/리그/애니메이션/셰이더/씬 파일 변경 없음. 화면 외곽선 셰이더는 추가하지 않았다.

## 제작·자체 검수

- 내장 image_gen 사용. 현용 V2 아틀라스를 편집 대상으로, `../PlayerCartoonConcept62/Player_Texture_ABC.png`의 B를 스타일 참고로 사용했다. 전체 프롬프트는 `Prompts.json`.
- 첫 몸 아틀라스의 검은 UV 조각 테두리가 불필요한 피부 경계선을 만들 수 있어 제거하는 편집을 거쳤다. 실제 봉제/주름선은 유지하고 결과를 다시 확인했다.
- 검수 도중 Unity가 편집 모드가 되어 기존 스크립트가 런타임 플레이어를 찾지 못했다. 플레이 전제 가드를 추가하고 상태 조회의 Vector3 직렬화를 숫자 배열로 수정했다. 다시 플레이에 진입하여 모델 생성을 확인했다.
- 초기 시작 위치는 건물에 가려 기존 `PlayerPainted62/Unity/prepare.json` 절차로 마을 (52, .02, 12) 검수 위치에 이동했다. 검수 카메라는 플레이어의 현재 방향을 기준으로 정후면을 맞추도록 수정했다. 플레이어 방향이나 게임 카메라 설정 자체는 변경하지 않았다.
- `Unity/A_Previous_*`와 `B_Comic_*`는 동일 호출의 V2/B A/B 렌더: 정면, 양측면, 후면, pitch 62° 정후면. 텍스처 배치와 피부 경계, 모자/주머니/가방 선을 확인했다. 현재 마을 조명에서 검수했으며 모든 시간대 검증을 뜻하지 않는다.
- `Unity/GameCamera.png`는 최종 적용 후 실제 메인 카메라와 동일한 위치/회전/줌/해상도로 만든 렌더다. 화면 오버레이 UI는 포함하지 않는다. 작은 크기에서 모자와 의복 색 구분, 굵은 봉제선 가독성을 확인했다.
- `Unity/Applied.json`: 17슬롯 연결 참, 셰이더 오류 없음. 최종 MCP 콘솔 오류 0·경고 0 (`Unity/ConsoleValidation.json`). 앞서 발생한 검수 스크립트 실패는 위에 별도 기록했으며 게임 코드 오류로 숨기지 않았다.

## 재현·복원

- `Unity/review.json`: 저장된 현재 재질과 B 후보 6방향씩 촬영 후 원래 참조로 복원. B 적용 후에는 A/B가 같은 B이므로 V2 비교를 재현하려면 두 재질을 먼저 V2에 돌려야 한다.
- `Unity/apply.json`: 준비된 B 텍스처 두 장을 재질에 연결·저장하고 현재 런타임 17슬롯 검증.
- `Unity/game.json`: 현재 메인 카메라 기준 렌더. `Unity/inspect.json`: 씬/플레이어 상태 조회.
- 이전 스타일로 복원하려면 BaseMap 두 개를 각각 `Player_Painted_V2.png`, `PlayerGear_Painted_V2.png`로 Unity MCP에서 변경·저장한다.

현재 Unity는 플레이 중이며 B 텍스처 연결이 저장되어 있다. 다른 캐릭터와 환경은 아직 이 스타일로 일괄 변경하지 않았다.
