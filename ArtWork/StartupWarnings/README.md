최종 새 실행 Systems → 실제 저장 로드 → Safehouse → Hideout: **경고 0, 오류 0**. 최종 상태 Hideout 플레이 실행 중, 안개 검색 미실행·안개 쿼드 없음.

before-mcp.json은 원인 확인용 최초 원본 로그, startup-mcp.json 및 after-town-mcp.json은 단계별 추가 원인 기록이다. final-* 파일이 최종 결과다. missing-shader-regression.json의 1회 경고는 의도적으로 안개를 강제 요청한 별도 회귀 검사 결과이며 최종 일반 플레이 로그와 구분한다.

삭제된 안개/시야 어둠 셰이더 아트는 복구하지 않았다. 사용 가능한 표현만 초기화하며, 실제 누락 기능을 명시적으로 요청하면 진단을 남긴다. 경고 필터를 비활성화하거나 로그를 전역 억제하지 않았다.

Verify.cs는 Assets 외부의 MCP run_script 검수 도구다. save-test.json은 기존 저장 파일을 읽어 메모리에서만 왕복하며 파일을 쓰지 않는다.
