# 마을 상점 내부 — 62° 모델 검토 패키지

**이 패키지는 전체 매장 초안 이력이다.** 과도한 크기 피드백 이후 외곽을 유지하고 영업 공간/잠긴 추가 방으로 나누었다. 최신 시안은 `../TownInteriorsPartition62/README.md`를 참조한다. 이 패키지의 가구·재질은 최신 시안에서도 원본 크기로 재사용한다. 아래 검수는 표면/배치 오류 검수이며 전체 매장 크기의 사용자 승인을 뜻하지 않는다.

2026-09-11 사용자 요청: 마을 건물 내부 제작. 기존 하이드아웃은 유지하며 전당포·수리점·의료소·가구점·암시장 5채를 제작했다. 모든 결과는 오프라인 모델이다. 진행 중 Unity 플레이·씬·실행 에셋은 변경하지 않았다.

60개 FBX = 신규 가구/소품 25개 + 기존 프랍 재사용 15개 + 건축/검토용 모듈 20개. 라이브러리 65,770 삼각형, 방 5개에 104개 배치다. 실제 렌더러 수/장면 삼각형 수는 Unity 통합 시 달라진다.

## 파일

- `BlenderSource~/TownInteriors62.blend`: 편집 가능한 가구 부품, 재사용 원본, 건물별 `*_Assembly62` 컬렉션. PBR 텍스처를 패킹했다.
- `Models/*.fbx`: 독립 모델. `Reuse_*`는 승인된 Hideout02/TownProps02를 재사용한 것이다. 재사용 원본은 변경하지 않았다.
- `KitManifest.json`: 미터 단위 크기/로컬 배치/원화/재질과 기존 건물의 월드 위치·회전. Blender 좌표 = (-Unity X, -Unity Z, Unity Y).
- `ModelValidation.json`: UV0·표면·원본 해시와 보수적인 평면 통행 검사.
- `FBXValidation.json`: 대표 가구/천/재사용 모델 6개 재임포트의 UV·크기 확인.
- `*62.png`: 건물별 실제 Blender 렌더. 각 자산의 입구가 아래를 향하는 62° 정면이다. 가구점/암시장의 실제 마을 yaw 90° 방향 결과는 Unity 연결 시 추가 검수한다.

## 구성/통행

현재 Town02 면적과 중앙 1.6m 입구를 따른다. 전당포 NPC 로컬 (0,0,2.4), 카운터 z=1.5와 양옆 접근을 보존한다. 가구 배치를 통한 외형 제안이며 현재 NPC나 상점 기능이 이 가구에 연결됐다는 뜻은 아니다.

통행 검사는 반경 0.35m 보행자를 가정하고 가구 평면을 팽창시킨 0.15m 격자에서 입구부터 접근 지점까지 검사한다. 실제 플레이어 콜라이더/물리·NavMesh 검증을 대체하지 않는다.

## Unity 연결 시

1. 전투 테스트가 종료된 뒤 **Unity MCP**로만 작업한다.
2. 전용 재질을 현재 GameLit 정책에 맞춰 연결한다. Blender의 혼합/유리 노드가 Unity에서 자동 재현되지는 않는다. 새 재질 값은 manifest에 기록했다.
3. 기존 Town02 외벽과 지붕을 유지하고 실내 바닥·가구·내장만 배치한다. `PreviewCutaway62`는 미리보기 전용으로 실제 씬에 겹쳐 배치하지 않는다.
4. `TallLining62`와 필요 시 기존 외벽도 가림 대상에 함께 묶는다. 지붕만 숨기면 현재 높은 외벽 때문에 내부 시야가 달라진다.
5. 기존 회색 카운터/소품은 시각 요소만 교체하고 전당포 NPC·상호작용·해금·문/충돌을 보존한다. 새 가구의 콜라이더와 진입/복귀·카운터 접근을 실제 확인한다.

재사용/신규 가구는 시각 모델이며, 금고 열기·치료·물건 판매 같은 새 기능을 구현하지 않았다. 자체 검수 완료와 사용자 최종 승인은 별개다.
