# World Comic B + Town Life (2026-09-12)

승인된 실제 플레이어 Comic B를 현용 캐릭터·환경에 확장하고, 그 다음 마을 생활 프랍 배치를 보강했다. Unity MCP로 임포트·저장·검수 완료. 새 결과의 사용자 최종 미감 승인은 별도다.

## 텍스처 적용

- 내장 image_gen으로 14개 Base Color 제작. `Textures/` 제작본과 `Assets/Art/WorldComic62/Textures/` 런타임 파일은 동일 이미지다. 셰이더 소스·캐릭터 메시·UV·리그·애니메이션 변경 없음.
- 캐릭터 전용 아틀라스 6개: 전당포 주인, 구역 관리인, 베테랑 수집가, 떠돌이 상인, 현용 SimpleBandit, BanditClub.
- 공용 표면 8개: 목재, 금속, 천, 미장/콘크리트, 벽돌, 아스팔트, 흙, 종이. 기존 재질의 재료별 색과 광택을 바탕으로 적용한다. 지붕·건물·실내·마을 생활 도구·무기·보관함까지 공유 재질로 연결된다.
- 기존 독립 재질 136개 저장, FBX 내부 재질 슬롯 114개를 외부 재질로 연결, 씬의 인라인/내부 참조 70개 Renderer를 지속되는 재질 자산으로 교체했다. 슬롯 수와 모델 수는 다르다. 정확한 경로는 `Unity/MaterialApply.json`, 최종 표면 연결은 `Unity/Coverage.json`.
- 승인된 Player/Painted62의 B 텍스처는 그대로 사용한다. 원래 이미지 파일과 원본 모델은 보존했다. 구형 Bandit01·SimpleHero 저작용 원본은 현용 모델과 구분해 보존했다. UI, VFX, 발광, 지도 선, 풀잎·균열 등 의도적인 단색 표현은 그림을 억지로 덮지 않는다.
- UV0가 없는 메시 2개는 구형 FBX에 남아 있는 옛 Bandit_Bat이다. 현용 무기는 UV가 있는 독립 BanditClub 프리팹을 사용한다(`Unity/MissingUV.json`).
- 최초 목재의 검은 줄/옹이와 미장 균열 반복을 자체 검수에서 발견해 재생성했다. 도로의 미터 UV에 중복된 반복 배율은 0.25로 교정했다. 비벽돌 표면의 과도한 이전 노멀 강도는 0.12로 완화했다. 전당포 앞 포장의 밝기도 주변 도로와 맞췄다.

## 검수와 이미지 구분

- 캐릭터 4방향+62°, 현용 적/무기 30°+62°, 하이드아웃 실내 30°+62°를 확인했다. 얼굴·봉제선·접힌 천·장비 면을 확인한 후 채택했다.
- 62° 마을 8구역 캡처 후 눕는 프랍, 색 기본값, 벤치/텃밭 겹침, 집에 가려진 생활 프랍을 수정하고 재검수했다.
- 최종 `Unity/Validation.json`: 기존 건물과 충돌 겹침 0, 신규 프랍끼리 0, 과대 충돌 0, 주요 입구 6곳 반경 1.2m 침범 0, 누락 스크립트 0, 오류 셰이더 0. 이는 배치/물리 검사이며 전투·레이드 전체 QA를 수행했다는 뜻은 아니다.
- 최종 콘솔 오류 0/경고 0. Unity 플레이 재실행 후 저장된 결과를 확인했다.
- `Unity/GameCamera.png`: 실제 런타임 메인 카메라의 월드 렌더. 화면 오버레이 UI는 포함하지 않는다.
- `Unity/Applied_*.png`: 실제 저장 자산/씬의 검수 카메라 캡처. `Asset_*.png`는 실제 Unity 모델의 별도 검수 조명이다.
- `Night_*.png`: 게임 WeatherData의 야간 조명 적용 검사. 시간·게임 페이즈 이벤트는 변경하지 않고 렌더 상태를 복원했다. 캐릭터 근접 컷은 검사 카메라의 near clip/fog 간섭을 피하려고 안개를 일시 제외한 **표면 검사**다. 마을 와이드 컷은 안개 포함. 실제 밤 전체 플레이의 승인 이미지와 구분한다.

## 재현 자료

프롬프트: `Prompts.json`, `EnvironmentPrompts.json`, `RevisionPrompts.json`. 모두 내장 image_gen 사용. 임포트/연결/배치/검수에 사용한 일회성 C#과 MCP 요청 JSON은 `Unity/`에 있다. 배치 명령을 기존 씬에 중복 실행하지 않는다. 프로젝트를 열면 이미 저장된 자산과 프리팹으로 결과를 볼 수 있다.
