# 전당포 보행·입구 수정 검수 — 2026-09-13

대상 프로젝트: `E:/personalProject/Demo/demo13-flashlight`. Unity 조작·저장·임포트·검증은 프로젝트에 고정된 공식 Unity MCP로 수행했다.

## 원인과 수정

플레이어 Rigidbody는 Y=0에 고정되어 있다. 실내 바닥 충돌체는 Y=0.06까지, 입구 앞 도로 장식 충돌체는 Y=0.02까지 올라와 있었다. 캡슐이 바닥에 관통된 상태의 마찰 때문에 낮은 이동 속도가 상쇄되었다.

실내 걷기 2.5초에 약 0.024m 이동하던 현상을 재현했다. 실내 바닥 충돌만 조정하면 내부 걷기는 정상화됐지만 입구의 도로 장식 마찰은 남았다. 둘을 수정한 뒤 같은 시간 약 2.994m로 정상화되었다. 출입 조건에 달리기를 요구하는 코드는 원인이 아니었다.

마을 바닥 5개와 도로 장식 4개의 중복 충돌체를 비활성화했다. 9개 모두 기존 Y=0 Ground가 아래를 덮는지 먼저 확인했다. 실내 기본 바닥의 시각 상면은 Y=0.005로 조정했다. 벽·가구·셔터 등 장애물과 상호작용 연결은 저장 전후 동일함을 검사했다. `Safehouse3DLayout` 빌더도 같은 설정으로 수정했다.

전당포의 차양 널판 14개·지지대 2개를 Blender 원본에서 제거했다. 목재 간판과 중앙 문틀을 유지하고 낮은 돌 바닥 표시를 추가했다. 첫 표시가 포장 바닥에 가려져 상면을 포장보다 1cm 높은 Y=0.055로 보정한 뒤 다시 검수했다. 이 표시는 물리 충돌을 만들지 않는다.

## 근거와 검증 범위

- `Before.json`: 걷기/달리기 진입·실내 횡이동·퇴장 실측. 정지 또는 속도 손실을 재현했다.
- `Candidate.json`, `CandidateRoads.json`: 실내 바닥만 수정한 후보와 도로까지 수정한 후보를 비교한다.
- `After.json`: 저장 후 재실행한 최종본에서 걷기·달리기·앉기 × 진입·내부 이동·퇴장 9/9 통과. 각 경로는 약 3m다.
- `Regression.json`: 지붕 진입/퇴장 전환, 9개 장식 충돌 비활성화, Y=0 Ground 지지, 전면 벽 충돌 유지, 중앙 출입 통로 확보, 새 아트에 물리 문턱 없음의 7/7 통과.
- `Applied.json`: 변경한 9개 충돌체 목록, 기존 장애물·상호작용 보존, 누락 스크립트 0, 임포트한 메시와 재질 연결 확인.
- `BlenderValidation.json`: 차양 제거 16개, 외벽 1,996삼각형, 기존 UV 채널과 재질 이름 유지, 유효한 정점/면 검사.
- `Final_Entrance.png`: 실제 게임 화면. `Final_Overview62.png`와 `Final_Overview30.png`는 현재 Unity 마을을 검수용 카메라로 렌더한 화면이며 게임 카메라 설정을 바꾸지 않았다.
- `ErrorsFinal.json`, `WarningsFinal.json`: 최종 재검증의 Unity 로그. 앞서 지원되지 않는 진단 명령이 남긴 도구 오류는 `ToolDiagnostic.json`에 별도 보존했다.

62도 게임 시점 및 30도 보조 시점에서 형태·입구 가시성·재질을 자체 검수했다. 사용자의 최종 미감 승인과 구분한다. 다른 상점의 거래·잠금 해금 흐름 전체를 플레이한 검수는 아니다.

## 재현 도구

`demo13-flashlight/tools/unity_mcp_call.py run_script <요청.json>`으로 `Movement.cs`, `Regression.cs`, `Apply.cs`, `Capture.cs`, `Overview.cs`의 정적 진입점을 실행한다. `Apply.cs`는 플레이 종료 상태에서만 저장한다. 나머지는 마을 플레이 상태에서 실행한다. 이동 검사는 가상 입력을 사용하고 종료 시 원래 입력 모드와 플레이어 위치를 복원한다.

`refine_pawnshop_entry.py`는 설치된 Blender의 background Python으로 실행한다. 기존 Town02 원본의 전당포만 편집하고 `Pawnshop_Shell.fbx`를 내보낸다. 전체 재생성용 `build_town02.py`에도 차양 제거와 입구 표시를 반영했다.
