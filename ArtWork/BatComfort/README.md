# 방망이·장비 편의성 검수 (2026-09-13)

- `Before.json`: 실제 플레이어 소켓/메시/공격 데이터 읽기. 원래 메시 축은 (-.1, y, -.025), 손 소켓 축은 (0, y, 0)이었다.
- `Apply.cs`: Unity MCP Edit mode에서 프리팹 로컬 위치와 공격 fps만 수정. 새로운 모델·텍스처는 만들지 않았다.
- `Sample.cs` / 자세 PNG / `GripSamples.json`: 현용 모델과 클립을 임시 복제해 20°/62°에서 검수. 샘플마다 BakeMesh(true)로 스킨 행렬·FBX 스케일을 반영한다. 메시에 수정 없이 소켓과 축을 비교한다. 캡처 초기 RenderTexture 해제 순서 오류는 카메라 targetTexture 해제 후 정리하도록 수정했으며 재실행으로 확인했다.
- `TimingAfter.json`: 약공 .8초 / 강공 1초 / 풀차지 1.2초. 타격 프레임 17~21/48 유지, 애니메이션 재생 속도도 기존 런타임 경로에서 동일 비율로 반영.
- `Probe.cs` / `Validation.json`: 실제 UI 버튼 클릭 콜백과 공격 실행 경로를 통해 23개 항목 통과. 일시정지 UI 더블클릭, 오인 더블클릭 방지, 가득 찬 휴대 격자에서 무기 해제 취소, 숫자키 등록 회귀, 양손 대기/걷기/공격 그립, 공격 길이·타격 시점·애니메이션 동기화 포함.
- `InGameGrip62.png`: 임시 테스트 방망이 장착 상태의 실제 62° 게임 화면. 자동 시험은 디스크 저장을 억제하며 장비/소지품/퀵슬롯/플레이어 위치를 복원한다.
- 자체 검수 완료. 최종 미감과 조작감에 대한 사용자 승인은 별도다. 새 적을 대상으로 피해량/그로기를 측정하는 레이드 전투 시험은 이번 검증에 포함하지 않았다.
