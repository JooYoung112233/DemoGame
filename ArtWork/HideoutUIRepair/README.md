# 2026-09-12 출입·UI·이동·마을 외관 수정 검수

Unity 6000.6.0f1, 공식 Unity MCP stdio 연결로 에디터 조작·에셋 저장·Play 검증.

## 반영

- 하이드아웃 출구 UI가 이전 Safehouse 씬 언로드 때 파괴되던 부모/씬 소유권 오류 수정.
- 확인창 모달 입력, ESC 닫기 순서, 폐기된 파견 바로가기와 플레이어 HP 바 정리.
- 인벤토리 제목/경험치 분리, 장비 셀 가독성, 한국어 필터/정렬, 삭제된 부위 상태의 옛 베이크 제거. 수분/포만감 유지.
- 인벤토리의 퀵슬롯 등록 타깃 유지. 일반 하이드아웃과 메뉴에서는 전투 바 숨김.
- 설정 슬라이더·텍스트·화살표 행 겹침 수정, 현재 단축키 안내, 일시정지 패널 정리.
- 문/출전 준비 지점의 가까운 입장 표기 복구.
- 이전에 결정했지만 미적용된 원본 모션 기준 속도를 StatDB/PlayerRig/Systems에 저장. 대각선 Vector2 속성 복사본 정규화 버그 수정.
- 마을 컨테이너 3곳을 박공지붕 집·목재 자재 보관소·반개방 작업장으로 대체. 기존 충돌체와 서쪽 출입 트리거 유지.

## 검증 증거

- `SpeedRegression.json`: 0.3초 가속 후 1초간 실제 XZ 거리/게임 시간 측정. 걷기 0.44999, 대각선 0.44996, 달리기 2.29502, 앉기 0.22502 m/s. 4항목 통과.
- `KeyboardRegression.json`: GameInput의 1프레임 가상 키를 사용해 ESC 확인/취소, Tab 열기, ESC로 인벤토리만 닫기 검증. 4항목 통과.
- 출구와 확인 버튼: EventSystem 최상단 Raycast 대상 일치와 Button.onClick 실행 후 Safehouse 복귀 확인.
- `EntranceRegression.json`: 외관 교체 후 실제 이동 입력으로 기존 SceneDoor3D 입구 통과, Hideout 진입 통과(약 1.38초).
- `ModelAudit.json`: 3종 메시의 UV/노멀 수, 삼각형 수, bounds 검사. 건축 정적 메시이므로 스킨 리그 없음.
- `*-Review62.png`, `Replacements-All62.png`: 실제 Unity 카메라 62° 렌더. 검수 후 카메라 원래 상태 복구.
- `*-current.png`: 실제 게임 UI 스크린 캡처. 하이드아웃/인벤토리/마을 입장 표기/지도/메뉴/설정 확인.
- 최종 C# 컴파일 오류 0, Unity 콘솔 error 0. Unity 직렬화 파일의 빈 `m_Name:` 줄 후행 공백은 에디터 출력 그대로 유지; 소스/문서 diff 공백 검사는 통과.

## 아트 검수

제작 전 GPT 안전구역 집 `06_59_09.png`, 수리점 `06_59_29.png`를 열어 확인. 낮은 채도·목재/미장/철판 조합과 생활용 문/창을 반영. 기존 컨테이너 골판 외장은 대체.

첫 검수에서 옛 창문 중복과 작업대 가림을 찾아 수정하고 재검수했다. 메시 갱신 시 CopySerialized의 렌더 버퍼 잔재를 피하도록 기존 Mesh의 정점/삼각형을 직접 갱신한다. 새 결과는 Unity 적용·자체 검수 완료이며 사용자 최종 아트 승인을 뜻하지 않는다.

## 재현

`tools/*.json`은 `demo13-flashlight/tools/unity_mcp_call.py run_script <json>`의 인수. BuildReplacements.Build는 메시/프리팹, Install은 정지 상태에서 Safehouse 배치를 저장한다. 변경 전 씬/에셋 상태를 먼저 확인하고 사용한다.

거래·제작·퀘스트 보상 지급과 모든 레이드의 전체 플레이를 완료한 보고서는 아니다. 그 기능 데이터는 이 정리에서 변경하지 않았다.
