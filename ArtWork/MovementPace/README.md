# 이동 속도·모션·방향 검수 — 2026-09-12

사용자가 맵 규모에 맞는 속도 인상과 애니 배속 조정, 대각선 가속 방지를 요청했다. 이전 원본 배속 고정 결정을 대체한다.

| 모드 | 이전 m/s | 변경 m/s | 실제 8방향 m/s | Animator 배속 |
|---|---:|---:|---|---:|
| 걷기 | 0.45 | 1.2 | 1.19934~1.19980 | 2.6667 |
| 달리기 | 2.295 | 3.6 | 3.59941~3.60108 | 1.5652 |
| 앉아 이동 | 0.225 | 0.6 | 0.59990~0.60120 | 1.3333 |

- Unity MCP로 StatDB·PlayerRig 저장, 컴파일 후 Systems에서 재실행. 입력 합을 카메라 변환 전에 길이 1로 제한하고 직교 단위축을 사용한다. 약한 아날로그 입력 길이는 보존한다.
- 검수는 마을 플레이에서 임시 충돌 바닥 위에 실제 플레이어 Rigidbody를 놓고 GameInput 가상 축으로 움직였다. 가속 후 고정 시간과 실제 위치 차이를 측정했다. 종료 후 임시 바닥 제거, 원위치·입력·앉기·시간 상태 복원.
- 각 모드 8방향과 길이 0.5 입력 총 27건 통과. 최종 결과는 **validated-movement.json**, 요약은 summary.json이다. 직선/대각선 차이 0.3% 이내이며 반입력은 반속도다.
- after.json의 최초 앉기 9건은 검수 도구가 가상 C키 Down을 프레임 종료 때 해제하지 않아 반복 토글된 실패 기록이다. 도구 프레임 처리를 고치고 앉기만 재검수한 crouch.json이 최종 값이며, validated-movement.json은 최초 걷기/달리기와 재검수 앉기를 합친 것이다.
- 기존 코드에도 변환 후 ClampMagnitude는 있었다. 현재 62° 카메라에서 기존 대각선 1.414배 증가를 재현한 것으로 주장하지 않는다. 이번에는 카메라 축 투영까지 보강하고 실제 8방향 동일 속도를 검증했다.
- 추가로 Hideout 퇴장 시 플레이어 disabled/kinematic 상태가 복구되지 않는 버그를 수정했다. 왕복 결과는 hideout-state.json/returned-town-state.json. 최종 마을 플레이에서 경고 0·오류 0.
- 전용 앉아 걷기 클립은 없어 기존 Walk를 사용한다. 속도와 재생 배속을 검증했으며 새 모션 아트를 제작한 것은 아니다.
