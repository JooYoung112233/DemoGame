# 마을 표현 기준 — 2026-09-11

사용자 “진행해보자”로 승인된 전당포 실내·야외 NPC 조명/색감/재질 개선. Unity 에디터 작업은 MCP만 사용했다. 고정 62°/0° 게임 카메라에서 기존 낮 시간대로 비교한다.

## 적용

- WeatherData 낮 햇빛 RGB `(1,.90,.79)`, 세기 `.8`; 주변광 RGB `(.34,.35,.37)`. 햇빛은 따뜻하게 유지하고 주변광의 갈색 겹침을 줄였다. 기존 태양 각도와 밤 WeatherData는 유지했다.
- PlayerRigVolume3D: 기존 Neutral 톤매핑 유지, 대비 `10`, 채도 `-8`, 노출 `0`, 블룸 강도 `.18`/임계 `1.1`, 그레인 `.06`, 비네트 `.20`. 기존 공용 프로필을 조정했으므로 다른 게임플레이 씬도 같은 후처리 기준을 사용한다.
- GameLit에 선택적으로 사용하는 `_GAMELIT_PACKED_MASK`를 추가했다. `_MetallicGlossMap`의 R=금속성, A=매끄러움을 기존 스칼라와 곱한다. 켜지 않은 재질은 이전 계산과 같다. 모든 패스의 상수버퍼는 공통 Input을 사용한다.
- NPC 4명의 제작된 마스크를 연결했다. 피부·천·가죽·금속은 아틀라스의 표면 값으로 구분한다. 노멀 `.35`, 때 `.12`, 그림자 탈색 `.20`, 림 `.045`. 새 마스크 속성을 shader reimport와 같은 호출에서 설정했을 때 참조가 누락된 문제를 발견해 재연결하고 직렬화를 확인했다.
- 전당포 단색 임시 재질을 기존 Town02의 콘크리트/목재 기반 변형으로 교체했다. 바닥 UV 반복 `8×6`, 카운터 `4×1`; 마을 전체 지면 `20×14`, 도로는 약 4m마다 반복한다. 신규 이미지 생성이나 모델 수정은 하지 않았다.
- 전당포 기존 Bulb는 강도 `4`, 범위 `9`, 색 `(1,.88,.74)`; 기존 PracticalLight 6개는 강도 `6`, 범위 `6`, 색 `(1,.86,.70)`로 조정했다. 야간 시험에서 전구 강도 8은 낮 캐릭터에 과노출이 있어 4로 낮췄다.

## 검수 자료

최종 PNG는 실제 Main Camera 렌더이며 URP 후처리가 켜져 있다. Screen Space Overlay HUD는 포함하지 않는 캡처 방식이다. Blender 결과나 합성 이미지가 아니다.

- `Before_*`: 수정 전 기준.
- `Lighting_*`: 조명·후처리만 조정한 중간 비교.
- `Final_*`: 최종 저장·재시작 후 낮 검수. `Night_*`: 거리 조명 6/전당포 전구 8의 중간 야간 검수. 전구를 최종 4로 낮춘 뒤 낮을 재검수했고, 최종 야간 재촬영 도중 Zone1로 전환되어 현재 전투 플레이를 보존했다. **전구 4의 최종 밤 화면 재확인은 남아 있다.**
- `Validation.json`: shader compiler, 카메라/HDR/볼륨, 마스크 직렬화/선형 임포트, 애니메이션, 조명 저장 상태.
- `BeforeFiles/`: 작업 시작 상태의 로컬 백업, Git에는 포함하지 않는다.

표현 자체의 내부 검수와 사용자 최종 컨펌은 구분한다. 건물 형태·실내 가구 배치·전투 기능은 이번 범위가 아니다. 최종 Unity shader compiler/콘솔 오류는 0이며, 11개 마스크 참조·Linear 임포트·NPC 단일 루프와 공용 프로필 값은 파일/에셋 검증을 통과했다. 실시간 NPC 최종 검사 실패는 당시 씬이 Zone1로 바뀌어 마을 NPC가 로드되지 않은 데 따른 것으로 구분했다.
