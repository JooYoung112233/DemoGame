# 걷기 템포 완화 — 2026-09-12

사용자 “걷는 게 너무 경박스럽다” 피드백으로 StatDB의 플레이어 walk.animSpeed만 1→0.5로 조정했다. 새 PlayerStatData 기본값도 일치시켰다.

Unity MCP로 저장·컴파일·재실행 후 실제 Rigidbody 속도 및 Animator를 측정했다.

- 걷기: 1.19934m/s, Animator 1.33333배(이전 2.66667의 절반).
- 달리기: 3.60108m/s, Animator 1.56522배 유지.
- 이동 입력·대각선 제한·공격·앉기 수치 불변. 경고 0건.

Probe.cs는 앞선 MovementPace 회귀 도구를 걷기/달리기 각 한 방향으로 좁힌 검사다. 모션 배속을 확인했으며 사용자의 최종 체감 승인은 별도다. 원본 보폭을 바꾸지 않아 접지 미끄러짐을 완전히 제거한 것으로 주장하지 않는다.
