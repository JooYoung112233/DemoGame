# 가방 과조명 — 2026-09-11

사용자: “다좋은데 주변광? 가방에 빛이 너무나네”. Unity MCP에서 실제 플레이어와 같은 위치의 조명을 분리 비교했다. 가방 재질 emission=검정, smoothness=.08. BodyGlow를 끈 화면에서도 얼룩이 남고 LampSpill을 끄면 사라졌다.

`Before_*`, `NoGlow_*`, `NoSpill_*`: 기존값과 광원별 제거 비교. `Tuned_*`: 세기만 낮춘 초기 후보(BodyGlow .04, Spill 낮.08/밤.25). 밤의 밝은 가방 윗면이 남아 폐기. `LowSpill_*`: BodyGlow 원래값 유지, 퍼짐광을 월드 아래 .65m로 내리고 낮.08/밤.136으로 줄인 채택 후보. `Saved_*`: 코드·PlayerRig 저장 및 재실행 후 같은 실제 런타임 플레이어로 재촬영.

62°/0°·임시 확대 카메라(ortho1.7)·960×720 렌더로 가방을 확인한다. 메인 카메라 URP/HDR/Volume 설정을 복사했다. 테스트 중 모델의 Character3D 방향과 빔 방향을 함께 돌려 앞뒤 비교하며 환경/조명/방향은 종료 시 복원한다. Screen Space Overlay HUD는 포함하지 않는다. 낮밤 환경과 착용등은 같은 페이즈로 설정한다. `diagnose.json`은 현재 런타임값을 비교하므로 적용 후 실행하면 역사적 Before를 덮어쓴다.

적용: WornLamp spillHeightOffset=-.65, spillFloor=.08, spillRatio=.04. 등 회전 후 월드 수직 오프셋을 갱신하여 빔의 기울기에 따라 퍼짐광이 가방 높이로 돌아오지 않게 한다. 전방 빔·BodyGlow·퍼짐 반경/그림자·가방 재질/리그/모델·날씨/Volume 유지.

검증: 재컴파일 성공, 저장 후 재실행 낮밤 앞뒤 자체 검수, 실제 낮밤 이벤트·실내.15배·등급2배·월드 위치·신규 등 검사 통과(`Validation.json`). 하이드아웃 실제 화면·연속 이동 및 모든 장비 등급을 시각 검수한 것은 아니다. 플레이어 없는 보조 씬의 경로는 코드 검토만 했다. 자체 검수 완료와 사용자 최종 외형 승인은 별개다.
