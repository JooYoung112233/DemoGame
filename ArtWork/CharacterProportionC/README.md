# C 비례 — 플레이어·밴딧 공통 적용 준비본

2026-09-11 사용자 선택: “밴딧도 수정해야 할 텐데 그럼 일단 나도 C”.

머리/모자·밴딧 후드와 마스크를 90%로 줄이고, 몸 높이를 108%, 몸통 깊이를 112% 방향으로 맞췄다. 플레이어 모자/스카프/가방과 밴딧 후드/복면/의상은 유지한다. 밴딧의 조끼/팔 등 골격에 따라 섞이는 몸통 정점은 몸통 뼈 가중치만큼 깊이 조정을 적용한다.

## 파일

- `BlenderSource~/Player_C.blend`, `Models/Player_C.fbx`: 플레이어 기본/검 모션.
- `BlenderSource~/PlayerBat_C.blend`, `Models/PlayerBat_C.fbx`: 플레이어 양손 방망이 모션.
- `BlenderSource~/Bandit_C.blend`, `Models/Bandit_C.fbx`: 공통 밴딧 본체. 현재 권총·소총 밴딧도 이 본체 계열을 사용한다.
- `BlenderSource~/BanditCombat_C.blend`, `Models/BanditCombat_C.fbx`: 밴딧 근접 모션 준비본.
- `Validation.json`: 원본 파일 해시, 골격/모션/표면 보존 해시, 프레임별 손/발/소켓의 리그 내부 행렬 검사.
- `FBXValidation.json`: Blender에서 FBX를 재임포트한 골격·액션·UV·크기 검사.

## 적용 방식과 검증 한계

새 뼈나 경로를 추가하지 않았다. `SimpleHero_Rig` 모델 루트의 Blender Z 스케일만 1.08로 두고 머리 메시의 높이를 미리 보상했다. Unity에서는 높이 축이 Y다. 뼈의 rest 좌표와 애니메이션 키를 재작성하지 않아 기존 클립을 재사용할 수 있는 구성을 유지한다. 루트가 비균일 스케일이므로 같은 시각 루트 아래의 무기와 부착물도 같은 공간 변환을 받는다. 이를 **애니메이션·총기 검증까지 완료된 게임 적용본으로 간주하지 않는다.**

내보낸 스케일을 한 번만 적용해야 한다. 모델에 이미 높이 보정이 들어 있으므로 프리팹 루트에 1.08을 다시 곱하지 않는다. 스킨 메시만 떼어 기존 bind pose/변환과 섞지 말고 모델의 스킨·바인드·시각 루트 설정을 함께 검토한다. 물리/이동을 담당하는 플레이어·적 최상위 루트를 임의로 늘리지 않는다.

Unity 플레이 중이므로 이 폴더는 `Assets` 밖에 두었고, 실행 중인 원본 FBX·프리팹·애니메이션·재질은 교체하지 않았다. 플레이 종료 후 Unity MCP로 전용 임포트 경로에서 다음을 확인해야 한다.

1. 현재 GameLit 재질 연결, 모델 높이, 바닥 접지와 머리/후드·목 경계.
2. 기존 대기/걷기/달리기/방망이 모션. 애니메이션이 모델 루트 스케일을 덮어쓰거나 높이를 중복 적용하지 않는지 확인.
3. `Bandit_Pistol.prefab`, `Bandit_Rifle.prefab`의 조준·발사·이동·다리/등 수납. 두 Aim 클립의 `m_ScaleCurves`는 비어 있는 것을 파일로 확인했다. 전체 런타임 상태/IK/다른 클립이 보존된다는 실증은 아직 아니다.
4. 플레이어 총기와 달릴 때 수납, 양손 그립, 총구 방향/위치. 무기와 소켓은 같은 시각 루트 안에 유지한다. 무기만 다른 루트로 옮겨 스케일을 상쇄하면 그립 관계가 달라질 수 있다.
5. 피격/래그돌 콜라이더와 모델 높이, 통행. 플레이어 장비 착용은 기존 인벤토리 기반 흐름을 유지한다.

실행 대상은 `Resources/Characters/Bandit01`, `BanditPistol`, `BanditRifle`다. 이름이 Bandit01이어도 현재 Resource 프리팹은 GUID `5cdb07e86e1bc5040a5ab767e9540d43`의 SimpleBandit 프리팹을 참조한다. 구형 `Bandit/Bandit01/Bandit01.blend`를 잘못 교체하지 않는다. 플레이어 가방끈·스카프·장식도 두꺼워진 몸통 표면을 따라 깊이를 조정해 옷 안에 묻히지 않도록 했다.

미리보기는 Blender 렌더다. Unity 화면이나 총기 검증 결과가 아니다. C 선택 이전의 원형은 각 원본 경로에 그대로 남아 있다.
