# 장착 무기 퀵슬롯 등록 검수 — 2026-09-13

- 대상: `CharacterPanelUI`, Unity 6000.6.0f1, Demo/demo13-flashlight.
- `Probe.cs`: Unity MCP run_script로 실행. 임시 무기 실물을 장착하고 실제 UI 클릭 처리/컨텍스트 버튼/숫자키 입력 처리 경로를 검증한다. OS 입력 자동화는 사용하지 않는다.
- `Validation.json`: 9/9 통과. 일반 좌클릭 선택, 원래 슬롯의 실물 유지, 단일 선택 강조, 보조 무기 넘패드 등록, 보관 후 선택 취소, 같은 itemId의 다른 실물로 교체 후 선택 취소, 메뉴 등록, 기존 격자 등록, Ctrl 착용해제.
- 테스트 중 SaveManager.SuppressWrites=true이며 finally에서 장비/소지품/퀵슬롯/입력 모드를 복원한다. 실제 세이브 파일을 쓰거나 읽어 덮어쓰지 않는다. 창고는 수정하지 않는다.
- 첫 검증에서는 같은 프레임에 여러 가상 키를 넣어 이전 Down이 남았다. 게임 입력 코드를 변경하지 않고 검증 키를 프레임별로 분리한 뒤 모두 통과했다.
- `EquipmentMenu.png`: 테스트 무기 장착 상태의 게임 화면. 추가한 메뉴 문구가 잘리지 않고 읽히는 것을 자체 확인했다. 실제 사용자 장비 구성이 아니며, 새 모델/텍스처 작업 또는 사용자 외형 승인을 뜻하지 않는다.
