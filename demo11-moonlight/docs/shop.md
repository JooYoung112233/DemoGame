# 상점 시스템 (Shop System)

## 현 상태

### 핵심 컨셉
- 플레이어는 **제작자 겸 상점 주인**. 직접 모험은 안 함.
- 모험가에게 의뢰 → 재료 수령 → 제작 → 판매의 루프
- **검증 포인트**: 의뢰-제작-판매 루프에서 판단과 긴장감이 생기는가?

### 상점 영업
- 진열대에 제작한 아이템 배치 + 원재료도 판매 가능
- 손님이 방문하여 구매/흥정/떠남
- 가격 책정이 핵심 — 바가지 쓰면 평판↓

### 손님 AI
- 5종 유형: 일반, 부자, 구두쇠, 수집가, 모험가
- 원하는 카테고리가 없으면 구경만 하고 감
- 가격 > 체감가치이면 흥정 or 떠남
- 예산 초과면 무조건 떠남

### 흥정 시스템 (주사위 기반)
- 손님이 흥정을 제안하면 → 주사위 미니게임 발동
- 손님마다 "흥정 점수"가 있음 (예: 구두쇠 80, 일반 40, 부자 20)
- 플레이어가 주사위 굴림 → 나온 눈 × 보정값(아이템 품질, 장인등급, 평판)
- 플레이어 점수 > 손님 흥정 점수 → 원래 가격에 판매 성공
- 플레이어 점수 < 손님 흥정 점수 → 깎인 가격 수락 or 거절

### 제작 시스템
- 프로그레스바(2초) + 타이밍 클릭 미니게임
- Perfect(정중앙 10%): 2개 생산 / Good(중앙 40%): 1개 / Miss: 1개
- 자동 스킵 → Good 판정, 1개
- 장인 등급 올라가면 Perfect 구간 확대 + 상위 아이템 해금

### 알바생 시스템 (규모 확장)
- 매출 일정 이상이면 고용 가능
- 알바생: 자동 판매(마진 낮음) or 제작 보조(제작 슬롯 +1)
- 인건비 매일 자동 차감

### 평판
- 적정가 → +1, 바가지(130%+) → -2, 흥정 실패(떠남) → -1
- 높을수록 손님 수↑, 부자↑, 특별 주문↑
- 단계: 무명 → 골목상점 → 인기가게 → 왕실납품처 → 전설의 상점

## 추가 시스템 기획

### 모험가 성장/부상 시스템
- 의뢰 성공 → 경험치 획득 → 레벨업 시 성공률↑, 전리품↑
- 의뢰 실패 → 부상 (2~3일 고용 불가)
- 특정 모험가 호감도 → 개인 퀘스트 해금
  - 예: "사냥꾼 레나: 아버지의 유물 찾기" → 폐허 의뢰 3회 → 완료 시 영구 강화
- 모험가는 "성장하는 자산" — 잃으면 아픔

### 랜덤 이벤트 시스템
- 아침/밤 전환 시 랜덤 이벤트 발생 (확률 30%?)
- 종류:
  - 축제 → 손님 2배, 특정 카테고리 수요 폭증
  - 도적 출현 → 의뢰 실패율↑, 보상 드랍↑
  - 상인 길드 → 희귀 레시피 해금 기회
  - 왕실 납품 요청 → 큰 보상, 빡빡한 기한
  - 폭풍 → 의뢰 불가, 기존 재고로 버텨야
  - 흑시장 상인(밤) → 희귀 재료 비싸게 or 훔친 물건 싸게 (리스크)

### 날씨 시스템
- 맑음: 기본
- 비: 손님↓, 포션류 수요↑
- 맑은 날: 모험가 성공률 +10%
- 폭풍: 의뢰 불가

### 레시피 연구/발견
- 재료 조합 실험 → 성공하면 새 레시피 발견 (실패하면 재료 낭비)
- 힌트 시스템: "이 재료들로 뭔가 만들 수 있을 것 같다..."
- 발견한 레시피는 영구 해금

### 확장/투자 시스템
- 진열대 슬롯 추가 구매 (비용 증가)
- 제작대 업그레이드 → Perfect 구간 확대
- 창고 확장 → 재고 보관 한계
- 알바 고용

### 장인 등급 시스템
- 카테고리별 제작 경험치 (포션, 장비, 장신구 등)
- 등급: 견습 → 숙련 → 장인 → 명장 → 거장
- 등급 효과: Perfect 구간↑, 재료 절약 확률, 상위 레시피 해금
- "체력 포션+" 같은 강화 버전 해금

### 연출 강화
- 시간대별 배경색/분위기 변화 (아침 주황, 낮 밝음, 밤 어두움)
- 모험가 귀환 애니메이션 (성공: 보따리, 실패: 절뚝)
- 손님 감정 연출 (만족/화남/흥정 이모지 + 대사)
