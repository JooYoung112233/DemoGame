# 상점 시스템 (Shop System)

## 현 상태

### 핵심 컨셉
- 밤에 상점을 운영하여 낮에 획득한 재료/아이템을 판매
- 손님이 자동으로 방문하며, 가격 책정과 진열이 핵심 메커니즘
- **검증 포인트**: 가격 책정과 손님 대응 자체가 재밌는가?

### 상점 메커니즘
- **진열대**: 최대 6칸, 아이템을 드래그하여 배치
- **가격 책정**: 아이템별 기본 시세 대비 ±50% 범위에서 자유 설정
- **영업 시간**: 밤 시간 = 고객 10~15명 방문 (날짜/평판에 따라 변동)

### 손님 AI
- 손님 유형: 일반, 부자, 구두쇠, 수집가, 모험가
- 각 유형별 예산, 선호 아이템, 흥정 성향이 다름
- **구매 판정**: 가격 ≤ 체감가치 → 즉시 구매 / 가격 > 체감가치 → 흥정 or 떠남
- **흥정**: 손님이 역제안 → 수락/거절 선택 (2회까지)

### 평판 시스템
- 적정가 판매 → 평판 +1
- 바가지(시세 130%+) → 평판 -2
- 흥정 실패(손님 떠남) → 평판 -1
- 평판 높을수록: 손님 수 ↑, 부자 손님 비율 ↑, 단골 등장

### 가공/제작 (Phase 2)
- 원재료 조합 → 고급 상품 (약초+약초→포션, 광석+광석→무기)
- 가공품은 원재료 대비 2~3배 가격
- 레시피 해금 시스템 (모험에서 발견)
