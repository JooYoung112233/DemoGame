# 경제 시스템 (Economy)

## 현 상태

### 화폐
- **골드(Gold)**: 유일한 화폐. 상점 매출로 획득, 장비/가게 확장에 사용

### 아이템 카테고리 & 시세
| 카테고리 | 아이템 예시 | 기본 시세 | 출처 |
|----------|-----------|----------|------|
| 약초 | 치유초, 독초, 빛꽃 | 5~15G | 숲 |
| 광석 | 철광석, 은광석, 마석 | 10~30G | 광산 |
| 가죽 | 늑대가죽, 곰가죽 | 8~20G | 들판 |
| 몬스터 드랍 | 고블린 이빨, 슬라임 젤리 | 3~12G | 모든 구역 |
| 보석 | 루비, 사파이어 | 40~80G | 광산(희귀) |
| 포션(가공) | 체력포션, 해독제 | 25~40G | 제작 |
| 무기(가공) | 단검, 도끼 | 50~100G | 제작 |

### 수요 변동
- 3일 주기로 특정 카테고리 수요 ↑↓
- 수요 높은 날: 해당 카테고리 체감가치 1.5배
- 수요 낮은 날: 해당 카테고리 체감가치 0.7배
- 화면에 "오늘의 트렌드" 표시

### 투자 딜레마
- **장비 강화**: 모험 효율 ↑ (더 깊은 구역, 더 좋은 재료)
- **가게 확장**: 진열대 ↑, 창고 ↑, 인테리어 → 손님 수/질 ↑
- **제작대 해금**: 가공품 제작 가능 → 고부가가치

### 초기 자금
- 시작 골드: 100G
- 시작 재료: 랜덤 약초 3개 + 광석 2개
