# 낮/밤 루프 시스템 (Day-Night Loop)

## 현 상태

### 하루 흐름
1. **아침** → 원정 구역 선택 (낮 파트)
2. **낮** → 자동 원정 진행 (결과 표시)
3. **저녁** → 원정 결과 확인 + 상점 준비
4. **밤** → 상점 영업 (핵심 게임플레이)
5. **새벽** → 일일 정산 + 다음 날

### 낮 파트 (자동 원정) — Phase 1
- 구역 선택 UI → 버튼 하나로 "원정 보내기"
- 원정 시간 = 즉시 (결과만 표시)
- 결과: 획득 아이템 목록 + 간단한 로그
- 구역별 드랍 테이블이 다름

### 구역 목록
| 구역 | 난이도 | 주요 드랍 | 해금 조건 |
|------|--------|----------|----------|
| 마을 근처 숲 | ★ | 약초, 목재 | 시작 |
| 들판 | ★★ | 가죽, 몬스터 드랍 | Day 3+ |
| 광산 | ★★★ | 광석, 보석(희귀) | Day 7+ |
| 폐허 | ★★★★ | 유물, 레시피 | Day 12+ |

### 밤 파트 (상점 영업)
- → shop.md 참조

### 날짜 시스템
- Day 1부터 시작
- 날짜가 올라갈수록: 구역 해금, 손님 다양성 ↑, 수요 변동
