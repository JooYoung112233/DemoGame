# 온보딩 & UI 단계별 확장

> 최종 수정: 2026-05-19

## 설계 원칙
- 퀘스트 가이드 방식: 화면 좌측 상단에 "다음 할 일" 미션 목록 (1~2줄) 고정 표시
- 클릭하면 해당 시설/화면으로 이동
- 길드 레벨에 따라 UI 자체가 확장 (처음엔 심플, 나중에 풀 UI)

## UI 확장 단계 (5단계)

### Lv.1 (입문)
- 용병 모집소
- Blood Pit 구역
- 로스터
- 장비 착용

### Lv.2
- 보관함
- 제작소 (forge)

### Lv.3
- Cargo 구역
- 경매장

### Lv.5
- Blackout 구역
- 훈련소
- 신전

### Lv.7
- 정보소
- 고급 모집소
- 길드 회관
- 자동화

## 퀘스트 가이드 시스템

### 표시 위치
- 화면 좌측 상단 고정
- 항상 1~2개 활성 미션 표시
- 클릭 시 해당 시설/화면으로 자동 이동

### 퀘스트 체인 (예시)
1. "첫 용병을 고용하세요" → 모집소
2. "장비를 착용하세요" → 장비 화면
3. "Blood Pit에 출전하세요" → 출발 게이트
4. "첫 전투를 승리하세요" → (자동 체크)
5. "길드 레벨 2 달성" → (자동 체크)
6. "제작소를 해금하세요" → 시설 해금
7. ...단계별로 새 시설/구역 해금 유도

### 퀘스트 데이터 구조
```javascript
QUEST_GUIDE = [
    { id: 'hire_first', text: '첫 용병을 고용하세요', target: 'RecruitScene', check: gs => gs.roster.length >= 1 },
    { id: 'equip_first', text: '장비를 착용하세요', target: 'EquipmentScene', check: gs => /* 장비 장착 여부 */ },
    { id: 'first_deploy', text: 'Blood Pit에 출전하세요', target: 'DeployScene', check: gs => /* 첫 출전 */ },
    ...
]
```
