# TownProps02 — 안전구역 마당·골목 프랍

2026-09-11. GPT 원화를 대조한 오프라인 모델 18종. `KitManifest.json`은 각 모델의 원화 경로, 미터 단위 크기, 배치 예시, 선택적 충돌체 제안을 담는다.

- `Models/`: 개별 FBX. 각 모델은 한 개의 결합 메시이며 여러 재질 슬롯을 사용한다.
- `BlenderSource~/TownProps02.blend`: 부품별 편집 컬렉션과 세 구역의 배치 예시. 재질 이미지는 원본 파일에도 패킹했다.
- `ModelValidation.json`: Blender의 UV0, 유한한 좌표, 퇴화 면, 표면 노멀, 참조 파일, PBR 이미지 연결 검사 결과. Unity 임포트·탄젠트·게임 화면·충돌 검증 결과가 아니다.
- `ArtWork/TownPropsReview/`: 별도 Blender 스튜디오 미리보기. 실제 게임 화면이 아니다.

## 재질과 후속 적용

16개 재질의 `textureFolder`와 `family`를 조합하여 기존 Hideout02/Town02의 `{family}_Base.png`, `_Normal.png`, `_Mask.png`를 재사용한다. Blender에는 연결되어 있으나 FBX만 드래그한다고 프로젝트용 재질 설정이 완성되는 것은 아니다. `palette.color`는 선형 색상 기준이다. 별도 비트맵을 복제하거나 현재 공용 재질을 수정할 필요가 없다.

전투 테스트 중이므로 Unity MCP 호출, 씬 조작, 명시적 리프레시, 프리팹 생성은 수행하지 않았다. 테스트가 끝난 뒤 다음 순서로 진행한다.

1. Unity MCP로 현재 셰이더/머티리얼 정책을 확인하고 전용 재질을 만들며 FBX의 `TownProps_*` 슬롯을 연결한다. 기존 공용 재질을 덮어쓰지 않는다.
2. 모델 노멀 임포트, Mikk 탄젠트 계산, 필요한 보조 UV를 설정하고 누락 재질 및 표면 채널을 검사한다.
3. 미리보기 씬에서 개별 프리팹을 구성한다. `colliders`는 아직 적용하지 않은 제안이다. 작은 바닥 소품은 보행을 막지 않도록 우선 시각용으로 둔다. 배전함은 벽에 거는 모델이므로 하단 배관이 원점 아래로 내려간다.
4. 마을의 생활 공간·수리점 앞·골목 가장자리에 배치하면서 입구, NPC, 귀환 스폰과 통행을 확인한다. 빨랫줄은 기둥만 충돌 대상으로 검토한다.

이 모델들은 시각용이다. 자전거 탑승, 급수, 조리, 개봉/루팅, 발전 기능은 추가하지 않았다. `reviewGroups`의 장소 이름은 아트 배치 예시이며 새 게임 시스템을 의미하지 않는다.
