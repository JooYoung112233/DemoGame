# 맵 빌더 사용 가이드

> Play 모드에서 동작하는 런타임 맵 에디터.
> 아이소메트릭 3D 공간(XZ 평면)에 타일/벽/프롭/건물/오브젝트를 배치하고 JSON으로 저장/불러오기.

---

## 1. 시작하기

1. **메뉴**: `Tools > Dev Tools > Map > Open Map Builder`
   - 카탈로그(SO)가 없으면 자동 생성
   - MapBuilder 전용 씬이 없으면 자동 생성
   - 씬이 열림
2. **Play 버튼** 클릭 → 맵 에디터 시작 (64×64 기본 그리드)

### 에셋 등록 (타일/벽/프롭/건물)
- **메뉴**: `Tools > Dev Tools > Map > Catalog Editor`
- 4개 탭 (Tiles / Walls / Props / Buildings)에서 에셋 생성 & 카탈로그 등록
- 또는 `Create > Isometric Map > Tile Definition` 등으로 SO를 직접 만든 뒤 카탈로그에 수동 추가

---

## 2. 조작법

### 도구 선택
| 키 | 도구 | 설명 |
|----|------|------|
| `1` | Tile | 바닥 타일 배치 |
| `2` | Wall | 벽 배치 |
| `3` | Prop | 프롭(소품) 배치 |
| `4` | Building | 건물 배치 (멀티셀 풋프린트) |
| `5` | Object | 맵 오브젝트 (스폰포인트, 추출지점 등) |
| `6` | Eraser | 지우개 |

### 배치 & 삭제
| 입력 | 동작 |
|------|------|
| **좌클릭** | 선택한 도구로 배치 (드래그 가능) |
| **우클릭** | 현재 도구 타입에 맞는 것만 삭제 (Tile→타일만, Wall→벽만, Prop→프롭만...) |
| `6`번(Eraser) + 좌클릭/우클릭 | 종류 무관하게 가장 가까운 오브젝트 삭제 |
| **우측 Hierarchy 패널 X 버튼** | 특정 오브젝트 지정 삭제 |
| **우측 Hierarchy 패널 이름 클릭** | 해당 오브젝트로 카메라 포커스 |

### 회전 & 스냅
| 키 | 동작 |
|----|------|
| `Q` | 반시계 회전 (N→W→S→E) |
| `E` | 시계 회전 (N→E→S→W) |
| `G` | 그리드 스냅 토글 (Free ↔ Snap) |

> **Free 모드 (기본)**: 프롭/건물이 마우스 위치에 자유 배치  
> **Snap 모드**: 프롭/건물이 그리드 중앙에 정렬

### 카메라
| 입력 | 동작 |
|------|------|
| `WASD` / 방향키 | 카메라 이동 |
| `Shift` + 이동 | 빠른 이동 (2.5배) |
| **휠 클릭 드래그** | 카메라 패닝 |
| **마우스 휠** | 줌 인/아웃 |

### 파일
| 단축키 | 동작 |
|--------|------|
| `Ctrl+N` | 새 맵 (크기 지정 다이얼로그) |
| `Ctrl+S` | 저장 (JSON) |
| `Ctrl+L` | 불러오기 |
| `Ctrl+Z` | 되돌리기 (최대 30단계) |

## 3. 도구별 상세

### Tile (바닥)
- 좌측 팔레트에서 타일 선택 → 좌클릭으로 배치
- 드래그하면 연속 배치
- 같은 셀에 다시 배치하면 덮어씀

### Wall (벽)
- Q/E로 방향 회전 후 배치
- 높이/두께는 TileDefinition SO에서 설정

### Prop (소품)
- 프리팹 기반, 풋프린트 크기 설정 가능
- `blocksWalkability` 옵션으로 이동 차단 여부 결정
- **기본 Free 배치** — 마우스 위치에 정확히 배치 (G키로 그리드 스냅 전환)

### Building (건물)
- 풋프린트(예: 2×2, 3×4) 범위를 차지
- 프리팹이 없으면 큐브 플레이스홀더로 표시
- 겹치는 위치에 배치 불가
- **기본 Free 배치** — G키로 그리드 스냅 전환 가능

### Object (맵 오브젝트)
- SpawnPoint, ExtractionPoint 등 게임 로직 마커
- 시각적으로 색깔 큐브로 표시

### Eraser (지우개)
- 좌클릭/우클릭으로 커서 위치의 **가장 가까운** 오브젝트 1개 삭제 (종류 무관)
- 다른 도구에서 **우클릭**하면 해당 도구 타입만 삭제

### Hierarchy 패널 (우측)
- 배치된 건물/프롭/맵오브젝트 목록 표시
- **이름 클릭** → 해당 오브젝트로 카메라 이동
- **X 버튼** → 해당 오브젝트 삭제 (Undo 지원)

---

## 4. 저장 & 불러오기

- 저장 형식: JSON (`Assets/Maps/` 폴더)
- `Ctrl+S` → 파일명 입력 → OK
- `Ctrl+L` → 파일 목록에서 선택 또는 파일명 입력 → OK
- 저장 데이터: 타일, 벽, 프롭, 건물, 맵 오브젝트, 그리드 설정 포함

---

## 5. 에셋 생성 (Catalog Editor)

`Tools > Dev Tools > Map > Catalog Editor` 에서:

| 탭 | 생성 시 필요한 정보 |
|----|---------------------|
| Tiles | ID, 스프라이트, 머티리얼, 크기(셀), 이동가능 여부 |
| Walls | ID, 스프라이트, 머티리얼, 벽 높이, 벽 두께 |
| Props | ID, 표시이름, 프리팹, 아이콘, 풋프린트, 이동차단 |
| Buildings | ID, 표시이름, 프리팹(선택), 아이콘, 풋프린트, 진입가능 |

생성된 SO는 `Assets/Resources/MapBuilder/` 하위에 자동 저장.

---

## 6. 좌표 시스템

- **3D 공간**: XZ 평면(Y=0)에 타일 배치
- **카메라**: 3D Orthographic, `Euler(45, 45, 0)` 아이소메트릭 뷰
- **GridToWorld**: `Vector3(cell.x * tileSize, 0, cell.y * tileSize)`
- **WorldToGrid**: XZ 좌표에서 `Mathf.RoundToInt`로 역산
