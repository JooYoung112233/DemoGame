# 레이드 후 이벤트 시스템

## 시스템 개요
추출 성공 후, 안전가옥 귀환 직전 랜덤 이벤트가 팝업으로 발생.
텍스트 기반 선택지 시스템 (낙원 스타일).

---

## 1. 이벤트 흐름

```
추출 성공 → Safehouse 씬 로드
  → PostRaidEventManager 이벤트 체크
    → 조건 충족 이벤트 풀에서 랜덤 선택
    → PostRaidEventUI 팝업 표시
      → 선택지 2~3개
      → 선택 → 결과 텍스트 + 보상/페널티 적용
      → 닫기
  → RaidResultUI 표시 (기존 정산)
```

## 2. 이벤트 발생 확률
- 기본 발생 확률: **40%** (레이드당)
- 조건별 가중치로 확률 조정 가능
- 같은 이벤트 연속 방지 (최근 2회 제외)

## 3. 이벤트 데이터 (ScriptableObject: PostRaidEventData)

```
PostRaidEventData
├── eventId: string
├── title: string                    // 이벤트 제목
├── description: string              // 상황 설명 (2~3줄)
├── choices: EventChoice[]           // 선택지 배열
│   ├── text: string                 // 선택지 텍스트
│   ├── resultText: string           // 선택 결과 설명
│   ├── rewards: EventReward[]       // 보상 목록
│   │   ├── type: RewardType         // Item / Currency / Heal / Affinity
│   │   ├── itemId: string           // (Item일 때)
│   │   ├── amount: int
│   │   └── npcId: string            // (Affinity일 때)
│   └── penalties: EventPenalty[]    // 페널티 목록
│       ├── type: PenaltyType        // LoseItem / LoseCurrency / Damage / LoseTime
│       └── amount: int
├── conditions: EventCondition       // 발생 조건
│   ├── minRaidTime: float           // 최소 생존 시간
│   ├── requiredRegion: string       // 특정 지역에서만
│   ├── minLootCount: int            // 최소 획득 아이템 수
│   ├── requiredQuestActive: string  // 특정 퀘스트 진행 중일 때
│   └── timeOfDay: DayNight          // 밤/낮 조건
├── weight: float                    // 선택 가중치 (높을수록 자주)
└── oneShot: bool                    // true면 1회만 발생
```

## 4. 이벤트 예시

### 이벤트 1: 귀환길의 상인
> "안전가옥으로 돌아가는 길에 초라한 행상을 만났다. 그가 짐 속을 뒤적이더니 무언가를 꺼낸다."

- **① 거래하기** → 소량 화폐 소모, 랜덤 아이템 획득
- **② 무시하고 지나가기** → 아무 일 없음
- **③ 위협하기** → 아이템 획득, 떠돌이 상인 호감도 -2

### 이벤트 2: 매복
> "좁은 골목을 지나는데 인기척이 느껴진다. 무장한 그림자가 길을 막는다."

- **① 싸운다** → 체력 소모, 추가 전리품
- **② 도망친다** → 아이템 일부 드랍
- **③ 협상한다** → 화폐 소모, 무사 통과

### 이벤트 3: 부상자 발견
> "건물 잔해 사이에서 신음 소리가 들린다. 다리에 피를 흘리는 사람이 보인다."

- **① 의료품으로 치료** → 의료품 소모, 의사 NPC 신뢰도 +3
- **② 물자를 주고 떠나기** → 소모품 소모, 호감도 소폭 상승
- **③ 무시하기** → 아무 일 없음
