## 상호작용 — 디오라마 (2026-09-08 확정)

은신처는 **걸어다니지 않는다.** 2D판의 타르코프식 클릭 방식을 유지한다.
다만 2D판처럼 캐릭터를 **숨기지 않는다** — 클릭한 시설로 캐릭터가 가서 자세를 잡는 **디오라마**다.

| 시설 | 캐릭터 자세 | UI 자리 |
|---|---|---|
| (대기) 의자 | **앉아 있음** | — |
| 침대 | **눕는다** | **하단** — 화면을 가리지 않는 바 또는 시간 표기 |
| 요리대 | 앞에 선다 | **우측 패널** |
| 작업대·의료대·창고·라디오·파견·발전기 | 앞에 선다 | **우측 패널** |

### 원칙: UI가 캐릭터를 가리지 않는다

캐릭터가 시설에서 자세를 잡는 것이 이 화면의 요점이므로, 그 위에 패널을 덮으면 의미가 없다.
- UI는 **우측 도킹** 또는 **하단 바**로 붙인다. 전체화면 패널 금지.
- 시설을 누르면 **카메라가 부드럽게 이동해** 캐릭터를 반대쪽(위/왼쪽)으로 밀어 UI 자리를 비운다.
  순간이동이 아니라 스무딩 이동이다.

### 구현

| 구성 | 파일 | 역할 |
|---|---|---|
| 시설 앵커 | `Scripts/TopDown/HideoutFacilityAnchor.cs` | 시설별 **캐릭터가 설 자리·자세(Stand/Sit/Lie)·UI 도킹(Right/Bottom/None)**. `moduleKey`는 `HideoutUI.Show(module)` 값과 일치해야 한다 |
| 카메라 연출 | `CameraFollow.SetFocus(focus, screenBias, orthoSize)` | 피사체를 화면 비율만큼 밀어 UI 자리를 비운다. `ClearFocus()`로 복귀. 도킹에서 편향 자동 산출(우측→캐릭터 왼쪽, 하단→캐릭터 위) |

### ⚠️ 아직 안 된 것

- **앵커를 읽어 실제로 캐릭터를 옮기고 자세를 재생하는 오케스트레이터가 없다.**
  `HideoutController`(2D판, 캐릭터 숨김 전제)를 디오라마 기준으로 다시 써야 한다.
- **자세 애니메이션이 없다.** 치비는 idle/walk/run 3종뿐 — 앉기·눕기·작업 자세 미제작
  ([3d-migration.md](3d-migration.md) Stage 4). 그전까지는 위치·방향만 맞고 자세는 idle이다.
- **기존 UI 패널들이 전체화면 전제**다. 요리·수면·창고 등을 우측/하단 도킹으로 재배치해야 한다.

## 소품 목록 — 모델 제작용

치수는 **가로(X) × 높이(Y) × 세로(Z)**, 미터. 위치는 바닥 기준 `(x, z)` — 빌더가 높이 절반만큼 띄워 바닥에 앉힌다.
현재는 전부 **단색 박스 그레이박스**다. 아래 "형태 메모"가 실제 모델 제작 지시다.

### 구조물

| 이름 | 치수 | 위치 | 형태 메모 |
|---|---|---|---|
| `Floor` | 14 × 0.1 × 9 | 중앙 | 골판 금속 바닥. 긁힘·녹·기름때. 가운데가 닳아 색이 옅어진 동선 |
| `Wall_S` / `Wall_N` | 14.6 × 2.6 × 0.3 | 남/북 | 컨테이너 측벽 |
| `Wall_W` / `Wall_E` | 0.3 × 2.6 × 9 | 서/동 | 동벽 = 컨테이너 **양문**(경첩·잠금바). 서벽 = 막힌 면 |
| `Rib_S` / `Rib_N` | 0.18 × 2.4 × 0.10 | 1.2 m 간격 | **골판 리브**. 콜라이더 없음(장식). 실제 컨테이너의 세로 주름 |

> 리브는 지금 얕은 박스를 덧댄 것이다. 실제 모델에서는 **벽 메시 자체에 주름을 넣어** 드로우콜을 줄일 것.

## 아직 안 된 것

- **시설 클릭 판정이 아직 없다.** 앵커(`HideoutFacilityAnchor`)는 붙었지만 마우스 클릭 →
  캐릭터 이동 → UI 열기로 잇는 오케스트레이터가 없다(위 §디오라마 참조).
- **컨테이너 문 없음.** 동벽이 막혀 있다. 진출입 연출(문 열림/씬 전환)은 후속.
- **재질이 단색**이다. 텍스처·노멀은 3D 아트 패스에서.
- 캐릭터 가독성 — 어두운 팔레트가 배경에 묻힌다. 아웃라인/접지 링 검토(3d-migration.md Stage 0 함정 ③).
