## 0. 문서 목적

이 문서는 현재까지 확정된 **다녀올게** 게임의 스토리, 전투, 루팅, 낮/밤 출전, 안전가옥, NPC 호의도 구조를 하나의 시스템 문서로 정리한 2차 초안이다.

기존에 검토했던 슬롯/카드/턴제 구조는 제외한다.  
총기는 초기 버전에서 제외하고, 추후 확장 요소로 보류한다.

현재 게임의 중심은 다음과 같다.

> **기억을 잃은 주인공이 낮에는 정보를 모으고, 밤에는 짙은 현상 지역에 들어가 루디를 회수하며, 근접 전투와 루팅/탈출을 통해 안전가옥을 성장시키고 잃어버린 동생의 진실을 추적하는 생존 루팅 액션 게임.**

## 1. 게임 한 줄 정의

> **낮과 밤이 나뉜 도시에서, 15분 안에 파밍하고 살아서 탈출하는 근접 생존 루팅 액션 게임.**

플레이어는 안전가옥에서 출격을 준비하고, 전체맵에서 지역을 선택한다.  
같은 지역이라도 낮과 밤의 목적이 다르다.

- 낮: 정보 수집, NPC, 쪽지, 준비
- 밤: 루디 회수, 밴딧/몬스터 전투, 이상현상, 고위험 파밍

## 4. 스토리 도입

### 4.1 시작 상황

플레이어는 낯선 타운에서 깨어난다.

- 기억 없음
- 이름도 확실하지 않음
- 몸에는 상처가 있음
- 가진 것은 낡은 옷, 작은 가방, 손목에 찬 오래된 시계뿐

당장 먹고 잘 방법이 없기 때문에, 플레이어는 손목시계를 전당포에 맡기려 한다.

---

### 4.2 전당포 첫 만남

> ⚠️ **아래는 세계관 도입 예시(초기 드래프트).** 실제 인게임 대사·진행 = [story-script.md S-002~S-003](story-script.md)이 진실. 데모에선 강무진의 **인식을 의도적으로 보류**한다 — S-002는 시계에 대한 충격("어디서 났어")·거절·쫓아냄까지만, "너, 살아 있었냐?"식 직접 인식은 서사 단계(§10) 공개 전까지 노출하지 않는다.

전당포 주인은 시계를 보자마자 플레이어를 알아본다.

```text
전당포 주인:
“시계라… 요즘 이런 걸 맡기러 오는 사람은 드문데.”

그는 시계를 받아 들고 뒷면을 확인한다.
순간, 그의 손이 멈춘다.

전당포 주인:
“…너, 살아 있었냐?”

플레이어:
“날 압니까?”

전당포 주인:
“아는 정도가 아니지. 그런데 정보는 공짜가 아니야.”
```

전당포 주인은 플레이어에게 말한다.

- 세상이 망한 건 아니다. **정부는 멀쩡히 돌아간다** — 단, 여기엔 없다.
- 이 도시가 **짙은 현상**에 잠겼고, 정부는 도시를 **봉쇄**하고 존재 자체를 **은폐**했다.
- 봉쇄선 안쪽은 시간과 무관하게 낮에도 밤처럼 어두워진다. 괴물, 밴딧, 이상한 물건이 나타나고, 안쪽 전기는 끊겼다.
- 우리가 있는 이 바깥은 정부 통제에서 밀려난 **무법지대**다. 회수꾼·밴딧·상인이 흘러든다.
- 봉쇄선 안에서만 얻을 수 있는 **루디**가 현재 가장 중요한 자원이다.
- 루디를 가져오면 플레이어의 이름과 과거에 대한 정보를 조금씩 알려주겠다고 한다.

### 4.3 컨테이너 안전가옥

전당포 주인은 플레이어에게 작은 컨테이너 하나를 소개한다.

표면상 이유:

> “당장 잘 곳도 없을 테니 여기서 지내라.”

이 컨테이너가 게임의 기본 안전가옥이다.

> **🌐 세계관 단일 출처(SSOT).** 게임 세계의 설정·로어는 **이 §5가 진실**이다. 다른 문서(story.md·anomaly.md·world-map.md 등)는 세계관을 **재서술하지 말고 여기로 링크**한다. 충돌 시 §5 우선.
>
> | 하위 | 내용 |
> |---|---|

> | **§5.1** | 짙은 현상 — 빛·공간 침식 (시간 무관) |

> | **§5.3** | 루디 — 안전한 광원·미래 자원·암시장 + **충전·방전·마모 활성 자원**(형성=시간/기억 응결, 부분 충전) |
> | **§5.4** | 시간 왜곡 — 현상 안 비선형 시간 + "믿을 수 없는 시계" |

### 5.0 시대와 무대 — 봉쇄된 도시, 무법의 변두리

> **아포칼립스가 아니다.** 세계는 멀쩡하고, 정부도 사회도 정상 작동한다. 무너진 것은 **이 도시 하나**다.

- **사건**: 어느 도시에서 **짙은 현상**이 발생했다. 정부 산하 특수 현상 연구소가 원인을 연구하다 위험성이 정치 문제로 번지자, 정부는 **현상의 존재 자체를 은폐**하고 도시를 **봉쇄**했다. (연구원 제거·기록 말소 작전 → [story.md](story.md) §2)
- **봉쇄선 안 (봉쇄구역)**: 짙은 현상에 잠긴 폐도시. 전기가 끊기고, 낮에도 밤처럼 어둡고, 괴물·밴딧·이상현상·**루디**가 있다. **레이드 무대.**
- **봉쇄선 밖 (무법지대 / 완충지대)**: 정부 통제에서 밀려난 변두리. 회수꾼·밴딧·떠돌이 상인·생존자가 흘러든다. 여기에 **타운·전당포·컨테이너 안전가옥**이 있다. **거점/허브.** 아포칼립스는 아니지만 치안은 없다.
- **정부**: 무대에 직접 등장하지 않는다(흔적만). 하지만 봉쇄는 단순 격리가 아니다 — **현상을 이용하고, 미래 자원 루디를 독점 채굴**하는 작전이다. 은폐는 그 채굴을 가리는 명분이기도 하다.
  - **루디 = 미래 자원**: 전기가 죽은 세계에서 불꽃 없이 안정된 동력을 내는 유일 자원(§5.3). 정부는 그 전략 가치를 알고 도시를 **자원작전으로 봉쇄**했다.
  - **빛의 제약(빛의 역설 §5.2)**: 정부조차 **빛·화력을 함부로 못 쓴다.** 루디 외 빛으로(특히 대규모 조명으로) 캐려 들면 침식이 폭주한다 → **어둠 속에서 루디 빛만으로 조심스럽게** 캘 수밖에 없다 → 채굴이 느리고 비효율적.
  - **그래서 회수꾼**: 어둠을 직접 누비는 인간 회수꾼의 손이 정부 채굴보다 유효하다. 정부는 루디를 **독점·통제**하려 하고, 회수꾼·전당포·블랙마켓은 그 틈을 빼먹는 **비공식 공급망(암시장)**이다. → 플레이어가 캐온 루디가 이 암시장을 흐른다.
  - **무대 표현 = 오프스테이지 + 흔적**: 정부 마크가 찍힌 채굴 장비 잔해, 비워진 채굴 케이지, 회수 흔적, 문서뿐. 직접 등장은 없다. 접점은 **블랙마켓 내부자**(전직 공무원의 옛 동료) 서사. [→ story.md §7](story.md)

```text
        [정상 사회 / 정부]
              │ (봉쇄 + 은폐, 무대 밖)
   ───────────┼─────────── 봉쇄선
   봉쇄선 밖   │   봉쇄선 안
   무법지대    │   봉쇄구역 (짙은 현상)
   ─ 거점/허브 │   ─ 레이드 무대
   타운·전당포 │   폐도시·루디·괴물·이상현상
   안전가옥    │
              ▲
        플레이어: 바깥 거점 → 봉쇄선 넘어 안으로 레이드 → 회수 후 귀환
```

> 핵심 한 줄: **정부가 봉쇄한 짙은 현상 도시 — 그 봉쇄선 바깥 무법지대에서 살아남으며, 안으로 루디를 회수하러 들어가는 회수꾼.**

### 5.1 짙은 현상

짙은 현상은 **빛과 공간을 침식하는 현상**이다. **시간(밤)과 무관하다** — 시간상 한낮이어도, 짙은 현상이 발생한 지역에는 햇빛이 제대로 닿지 않는다.

- 멀리 있는 사물부터 **색과 윤곽이 흐려진다.**
- 침식이 심한 곳은 **바로 앞도 보이지 않을 만큼** 어두워진다.
- 공간도 어긋난다 — 길 구조가 바뀌고, 없던 문·골목이 생기고, 같은 장소가 반복되고, 탈출구가 바뀐다.
- 그 안에서 밴딧·몬스터가 움직이고, 원래 없던 귀중품과 **루디**가 나타난다.
- 주인공의 기억·시계·동생 단서와 연결된다.

> **밤이 되어 현상이 강해지는 게 아니라, 현상이 발생해 주변이 밤처럼 보이는 것**이다.
> 게임상 "어두운 지역"은 시간대가 아니라 **침식 정도**다.

---

### 5.2 빛의 역설 — 빛이 어둠을 부른다

> **한 줄: 빛으로 어둠을 밀어내려 할수록, 어둠이 그 빛에 이끌려 더 짙어진다. 안전한 빛은 루디뿐.**
> 루디를 제외한 **모든 빛**(손전등·랜턴·플레어·차 헤드라이트, 그리고 그중 **최악인 불**)은 현상을 밀어내지 못하고 오히려 **자극한다.**

#### 왜 — 메커니즘
- **일반 빛 = 먹이·유인 신호.** 짙은 현상은 빛을 **포식·침식**한다(§5.1). 외부의 평범한 빛은 현상이 먹을 수 있는 먹이이자 "여기 빛이 있다"는 신호 → 현상 잔재가 그 빛으로 **모여든다.**
- **루디 빛 = 예외(안전).** 루디는 현상이 시간·기억을 갈아낸 **부산물**(§5.3·§5.4)이라 **현상과 같은 결**의 안정광 → 현상이 먹지도, 끌리지도 않는다(중립).
- **불 = 최악의 빛.** 불은 빛에 더해 **열·연기·출렁임**까지 내어 신호가 가장 강하다 → 같은 비루디 빛 중에서도 침식을 가장 빨리 부른다.
- **누적과 임계.** 약하게·잠깐은 무시할 수준. 같은 자리에서 **밝게·반복·오래** 켜면 잔재 농도가 올라가 임계를 넘으면 **자가 지속** → 햇빛이 흐려지고 그림자가 짙어져 **영구 짙은 구역**으로 굳는다.

#### 게임 메커닉 — 장소별 빛 침식 누적 〔확정 방향 · 수치 TBD〕
- 현상권/근처에서 **루디 외 광원(비루디 빛 전부)**을 켜면 그 지점에 **침식 게이지**가 쌓인다. **밝기 × 지속 × 반복**에 비례. **불 계열은 가중치 최대.** (확정 2026-06-16)
- 단계별 악화: ① 국소 시야 축소·몬스터 스폰↑ → ② **안전 구간이 짙은 현상으로 전환** → ③ **영구 짙은 구역화**(통행·루팅 불리, 회복 불가).
- **루디 광원(탐지등) = 게이지 0(안전).** → 플레이어 **기본 광원은 루디**. 비루디 빛(플레어·횃불·발견한 전등·화염무기)은 즉효(넓은 시야·온기·화염 전투)지만 그 자리를 갉는 **양날** → "지금 밝힐까 vs 아껴둘까".
- **회복**: 영구화(③) 임계 전이면 게이지는 시간 경과로 천천히 옅어진다. (회복 속도·임계 = `GameTuning` TBD)
- **거점 적용**: 비루디 조명·난방·조리는 거점권 침식 위험 → 거점 광원·시설을 **루디 기반으로 전환**하는 안전가옥 강화 동기. [→ safehouse.md]

#### 세계 표현 — 환경 스토리텔링
- **빛으로 망한 자리**: 버려진 모닥불·랜턴·밴딧 캠프 주변이 유독 짙은 현상으로 굳어 있다. "여기서 불 켠 놈들은 안 돌아왔다."
- **회수꾼 수칙**: "**루디 말곤 켜지 마. 불은 절대.**" — 신참에게 가장 먼저 가르치는 규칙.
- **밴딧 대비**: 밴딧은 이 규칙을 모르거나 무시 → 점거지 주변이 위험 구역(플레이어가 역이용할 여지).

#### 스토리·세력 연결
- **정부 자원작전이 비효율인 진짜 이유**: 대규모 조명으로 캐려다 **침식 폭주 → 채굴장 자멸.** → 어둠을 직접 누비는 인간 **회수꾼**이 더 유효한 근거(§5.0). 〔지역3 「묻힌 정비창」 = 정부가 **대규모 조명으로 캐다 망해 묻어버린 현장** 후보 → [story.md §4](story.md)〕
- **연구소 단서**: 빛의 역설은 연구소가 발견한 **핵심 경고**다 → 강무진/연구 기록 단서로 연결([story.md](story.md) §2·§10).

> **결정 (2026-06-16)** — 「불의 역설」 → **「빛의 역설」로 재정의.** 위험의 본질은 불이 아니라 **루디를 제외한 모든 빛**(불은 그중 최악). 게임 메커닉 = **장소별 빛 침식 누적**(밝기·지속·반복 비례, 불 가중치 최대). **침식 대상 범위 = 비루디 빛 전부(확정).** 누적/회복속도·영구화 임계 수치 = `GameTuning` TBD. **지역3 정부 채굴장 자멸 = 빛의 역설 물증**으로 스토리 연결.

### 5.3 루디 — 현상이 굳힌 빛 (안전 광원·동력·자원)

루디는 **단순한 발광 보석이 아니다.** 현상 에너지를 머금은 **결정**으로 — 빛을 내며 서서히 **방전**되고, 현상 안에서 **다시 충전**할 수 있는 **활성 자원**이다. 빛의 역설(§5.2)의 **유일한 예외**(불꽃 없는 안정광, 침식 X)라 전기 죽은 세계의 유일하게 **안전한** 빛·동력이다.

**미래 자원**으로서 모든 세력이 루디를 원한다 — **정부는 독점 채굴(은폐된 자원작전)**, 회수꾼·전당포·블랙마켓은 그 틈을 빼먹는 **비공식 공급망(암시장)**. 단, 누구도 §5.2 빛의 역설을 피할 수 없어 **루디 외 빛은 못 쓰고 저광량 채굴**만 가능하다. [→ §5.0]

#### 다른 조건 — 충전·방전이 있는 활성 자원 〔확정 방향 · 수치 TBD〕
- **충전·방전.** 빛/전력으로 쓰면 머금은 현상 에너지가 줄어든다 → 충전량 0이면 빛이 꺼져 **「죽은 루디」**(둔탁한 돌)가 된다. → 탐지등·시설은 무한이 아니라 **관리 자원**(빛의 역설과 맞물려 "루디를 아껴 써야 하는" 긴장).
  - **(확정 2026-06-16)** 탐지등은 레이드 중 **약하게 방전** → **여분 루디로 교체**하며 운용(가혹하지 않은 광원 관리 긴장). 방전 속도·여분 용량 = `GameTuning`.
- **현상에 반응.** 현상권에 가까울수록 더 밝고 안정적으로 빛난다(제 집). 멀어질수록(안전구간·거점) 천천히 식는다 → 거점 상시조명은 "큰 루디 + 보충" 구조.
- **시간 동조(미약).** 시계처럼 비선형 시간(§5.4)에 약하게 동조 — 임박 시 미세하게 진동·명멸(보조 예고).

#### 왜 생기나 — 형성 이유 〔신규〕
- 루디는 현상이 **시간과 기억을 갈아낸 부산물이 응결**한 결정이다(§5.4). 시간이 뒤섞이고 과거가 겹치는 곳에서만 **맺힌다** → 그래서 **현상권 안에서만** 발견.
- 현상이 **짙고 오래 머문 자리**(잔영·반복 구역)일수록 크고 순도 높은 결정이 맺힌다 → **큰 결정 = 더 많은 기억·시간이 갈린 곳**(용량↑·고가), 조각 = 작음.
- (떡밥) 순도 높은 루디엔 **갈려나간 기억의 잔향**이 남아, 만지면 장면·소리가 스친다(오르골?) → 동생·기억 단서로 연결. [→ story.md](story.md)

#### 회복(충전) 구조 — 일정 한도까지 〔확정 방향 · 수치 TBD〕
- **부분 회복(전부는 아님).** 방전·죽은 루디를 다시 머금게 한다. **충전 위치 = 둘 다(확정)**:
  - **현장 — 현상 노드**: 현상권 활성 잔재에 노출 → **빠르지만 위험**(재진입 리스크/보상). "캐기" 외에 "충전"이라는 재진입 이유 추가.
  - **거점 — 루디 충전/가공대**: **느리지만 안전**. 안전가옥 강화로 해금/효율↑. [→ safehouse.md, crafting.md]
- **마모(확정).** 충전을 반복할수록 **최대 용량이 조금씩 줄어든다** → 결국 영구히 죽는다 → **신선한 루디 회수가 계속 필요**(경제·레이드 동기 유지). 마모율 = `GameTuning`.
- **가공(거점, 선택).** 작은 루디를 갈아 큰 루디를 소폭 보충하거나, 안정화로 마모를 늦추는 강화. [→ crafting.md]

| 사용처 | 설명 |
|---|---|
| 안전 광원 | 거점·통로·창가 랜턴의 상시 조명 (빛의 역설 예외) |
| 전력 공급 | 안전가옥 발전기·조명·시설 가동 |
| 거래 | 전당포·NPC의 핵심 거래 자원 (고액; 충전 상태·순도가 가치에 영향) |
| 안전가옥 강화 | 작업대·의료대 등 강화 + **루디 충전/가공대** |
| 미션 | NPC가 요구하는 주요 회수품 |
| 스토리 | 짙은 현상·기억 상실의 진실, 갈려나간 기억의 잔향 단서 |

루디는 단순 화폐가 아니라, 플레이어가 짙은 현상 지역에 **반복해서** 들어가야 하는 이유다(회수 + 충전).

> **핵심 차이 요약**
> ① 밤이 되어 현상이 강해지는 게 아님 → 현상이 발생해 밤처럼 보이는 것
> ② 루디 외 빛(불 등) 반복 사용 → 지역 침식 진행 → 자연광까지 차단 → 낮에도 어두워짐 (빛의 역설 §5.2)
> ③ 루디 빛 = 침식을 일으키지 않는 안전한 광원 — 단, **충전·방전·마모**가 있는 활성 자원

> **결정 (2026-06-16)** — 루디를 단순 발광체 → **충전·방전·마모가 있는 활성 자원**으로 심화. **형성 이유**(현상이 시간·기억을 갈아낸 부산물의 응결, 순도=갈린 양) + **부분 회복** 추가. **확정**: ① 탐지등 **약하게 방전**(여분 교체) · ② 충전 위치 = **현장(현상 노드)+거점(가공대) 둘 다** · ③ **마모 있음**(반복 충전 시 최대 용량↓ → 영구 사망). 방전/충전/마모율 등 수치 = `GameTuning` TBD.

### 5.4 시간 왜곡 — 현상 안에선 시간이 다르게 흐른다

짙은 현상은 빛과 공간만 침식하는 게 아니다. **시간의 순서마저 무너뜨린다.** 현상 구역 안에서 시간은 선형으로 흐르지 않는다 — 느려지고, 빨라지고, 되감기고, **과거와 현재가 한 공간에 겹친다.**

- **과거의 재생**: 떠난 사람·죽은 사람의 잔상이 그 자리에 남아 움직인다. 없는 열차 소리, 기도하는 그림자, 옛 장면이 유령처럼 재생된다.
- **반복**: 같은 복도·같은 골목이 계속 되돌아온다. 빠져나온 줄 알았는데 처음 그 자리다.
- **비틀린 생존**: 현상 안에선 "그 순간"이 아직 끝나지 않았을 수 있다. 바깥에서 사라진 자가 안에선 **시간이 비틀린 채 멈춰 있거나 살아 있을 수** 있다. → 동생 생존(엔딩 C)·기억 재현의 근거. [→ story.md](story.md)
- **시계의 동조**: 주인공의 손목시계(=현상 측정기, [→ navigation.md](navigation.md))는 이 비선형 시간에 **동조해 반응한다.** 멈춘 초침이 떨리고, 임박·왜곡을 디제틱하게 예고한다.
- **루디와의 연결**: 루디는 현상이 **기억과 시간을 갈아낸 부산물**이다(§5.3). 시간이 뒤섞이는 곳에서만 루디가 맺히는 이유.

> **게임 메커닉 — 믿을 수 없는 시계** (확정 2026-06-11, 수치 TBD)
> 짙은 현상 구역에 머무는 동안 **레이드 15분 타이머가 불안정해진다.** 일정하게 흐르지 않고 출렁인다 — 한동안 느리게 가다(여유) 갑자기 훅 줄어든다(시간 도둑맞음). 깊이 들어갈수록·오래 머물수록 왜곡이 커진다.
> - **위험/보상 강화**: 안전 구간에선 타이머가 정직하지만, 현상 구역에선 "남은 시간"을 신뢰할 수 없다 → 추출 텐션 증폭.
> - **시계의 이점**: 손목시계가 비선형 시간에 동조하므로, **진짜 남은 시간/왜곡 정도를 읽어주는 다이제틱 지표** 역할(측정기 본래 용도를 게임플레이로 선체험). [→ navigation.md, anomaly.md]
> - 빈도·왜곡 폭·깊이 가중치 = `GameTuning`. 상세 구현/연출 = [anomaly.md](anomaly.md).

## 6. 낮 / 밤 출전 시스템

### 6.1 기본 구조

지역에 출전하기 전 플레이어는 낮 또는 밤을 선택한다.

```text
지역 선택
↓
낮 / 밤 선택
↓
장비 세팅
↓
출전
```

같은 지역이라도 낮과 밤은 목적, 적, 보상, 이벤트가 다르다.

> **여기서 '낮/밤'은 시간이 아니라 그 지역의 짙은 현상 침식 정도를 뜻한다.** '낮' = 침식이 옅어 폐허로만 보이는 상태 / '밤' = 침식이 짙어져 어두워지고 루디·이상현상이 나타나는 상태. (→ §5)

---

### 6.2 낮 출전

낮은 정보 수집과 준비 중심이다.

| 요소 | 내용 |
|---|---|
| 위험도 | 낮음 |
| 적 | 적거나 약함 |
| NPC | 등장 가능 |
| 쪽지/기록 | 자주 발견 |
| 루디 | 거의 없음 |
| 고급 보상 | 적음 |
| 탈출 | 비교적 쉬움 |
| 목적 | 밤 공략 준비 |

낮에 할 수 있는 일:

- NPC 만나기
- 쪽지 읽기
- 밤에 열리는 장소 정보 획득
- 안전한 탈출구 위치 확인
- 밴딧 위치 파악
- 잠긴 문 열쇠 찾기
- 밤 이상현상 힌트 획득
- 기본 재료 파밍

---

### 6.3 밤 출전

밤은 루디 회수와 고위험 파밍 중심이다.

| 요소 | 내용 |
|---|---|
| 위험도 | 높음 |
| 적 | 밴딧, 몬스터 등장 |
| NPC | 거의 없음. 특수 NPC만 가능 |
| 루디 | 주요 획득 가능 |
| 고급 보상 | 많음 |
| 이상현상 | 본격 발생 |
| 탈출 | 일부 제한 또는 조건 필요 |
| 목적 | 위험을 감수한 고가치 파밍 |

밤에 할 수 있는 일:

- 루디 회수
- 고급 장비 파밍
- 밴딧 캠프 습격 또는 회피
- 몬스터 조우
- 이상현상 해결
- 낮에 얻은 정보 활용
- 특수 구역 진입
- 동생/기억 관련 단서 발견

---

### 6.4 낮 정보가 밤에 주는 영향

낮과 밤은 분리되어 있지만, 낮에서 얻은 정보가 밤에 실제로 반영되어야 한다.

| 낮에서 한 일 | 밤에 생기는 변화 |
|---|---|
| 쪽지 발견 | 숨겨진 탈출구 표시 |
| NPC 구조 | 밤에 도움 NPC 또는 보급품 등장 |
| 열쇠 획득 | 밤 특수 구역 진입 가능 |
| 괴현상 흔적 조사 | 밤 이상현상 패턴 예고 |
| 밴딧 위치 파악 | 밤 밴딧 캠프 위치 표시 |
| 발전기 수리 | 밤 특정 건물 조명 활성화 |
| 지도 조각 획득 | 루디 위치 후보 표시 |
| 시계 단서 발견 | 멈춘 시계 이상현상 대응 가능 |

---

## 7. 15분 지역 제한

### 7.1 기본 규칙

한 번의 지역 출전은 기본적으로 **15분 제한**을 가진다.

목적은 플레이어에게 계속 탈출 판단을 강제하는 것이다.

```text
좋은 아이템을 얻었으니 지금 나갈까?
루디를 하나 더 찾고 나갈까?
부상 상태인데 더 깊이 들어갈까?
탈출구까지 갈 시간을 남겨야 하지 않을까?
```

---

### 7.2 시간 흐름

| 시간 | 상태 |
|---|---|
| 0~3분 | 진입, 주변 파밍, 루트 확인 |
| 3~7분 | 중간 구역 진입, 첫 전투/이벤트 |
| 7~11분 | 고가치 파밍, 루디 후보 발견 |
| 11~13분 | 탈출 판단, 가방 정리 |
| 13~15분 | 탈출 시도, 추격 위험 |
| 15분 이후 | 위험도 폭증 |

15분이 지나도 즉시 사망시키지는 않는다.  
대신 다음 변화가 발생한다.

- 적 밀도 증가
- 이상현상 강화
- 일부 탈출구 폐쇄
- 강한 추적자 등장
- 시야 감소
- 루디 반응 폭주

---

## 8. 근접 전투 시스템

### 8.1 전투 방향

초기 버전에서는 총기를 제외한다.  
전투의 목표는 근접 무기만으로 재미를 만드는 것이다.

전투 감각은 다음을 지향한다.

> **약공격 / 강공격 / 구르기 / 스태미너 / 그로기 / 적 공격 캔슬이 있는 소울라이크식 근접 전투**

---

### 8.2 기본 조작

| 조작 | 기능 |
|---|---|
| 이동 | 캐릭터 이동 |
| 조준/방향 | 마우스 또는 이동 방향 기준으로 공격 방향 지정 |
| 약공격 | 빠르고 안정적인 기본 공격 |
| 강공격 | 느리지만 큰 피해와 높은 그로기 수치 |
| 구르기 | 회피, 위치 이동, 포위 탈출 |
| 가드 | 선택 기능. 데모에서는 보류 가능 |
| 락온 | 적 하나를 중심으로 방향 유지 |
| 상호작용 | 파밍, 문 열기, 쪽지 읽기, NPC 대화 |
| 인벤토리 | 아이템 확인, 정리, 버리기 |

---

### 8.3 약공격

약공격은 빠르고 안정적인 기본 공격이다.

역할:

- 스태미너 소모가 적다.
- 후딜이 짧다.
- 연속 공격이 가능하다.
- 그로기 수치는 낮다.
- 잡몹 처리와 안전한 견제에 사용한다.

예시 수치:

```text
약공격 1타: 피해 8 / 스태미너 6 / 그로기 5
약공격 2타: 피해 9 / 스태미너 6 / 그로기 6
약공격 3타: 피해 12 / 스태미너 8 / 그로기 8
```

---

### 8.4 강공격

강공격은 이 게임 근접 전투의 핵심이다.

역할:

- 느리다.
- 스태미너 소모가 크다.
- 피해량이 높다.
- 그로기 수치가 높다.
- 적의 공격을 끊을 수 있다.

예시 수치:

```text
강공격: 피해 20 / 스태미너 22 / 그로기 25
차지 강공격: 피해 32 / 스태미너 35 / 그로기 45
```

강공격은 단순한 큰 피해 기술이 아니라, **적의 공격 타이밍을 끊는 리스크 보상 기술**이어야 한다.

---

### 8.5 스태미너

스태미너는 전투 판단의 핵심 자원이다.

| 행동 | 스태미너 소모 |
|---|---:|
| 약공격 | 낮음 |
| 강공격 | 높음 |
| 차지 강공격 | 매우 높음 |
| 구르기 | 중간 |
| 달리기 | 지속 소모 |
| 가드 | 피격 시 소모 |

스태미너가 0이 되면:

- 공격 불가
- 구르기 불가
- 가드 불가
- 짧은 탈진 상태 발생

데모에서는 너무 가혹하게 만들지 않고, 0.5~1초 정도 위험해지는 수준으로 조정한다.

---

### 8.6 그로기와 공격 캔슬

적에게는 숨겨진 그로기 게이지가 있다.

공격이 적중하면 그로기 수치가 쌓인다.

| 행동 | 그로기 증가 |
|---|---:|
| 약공격 | 낮음 |
| 강공격 | 높음 |
| 차지 강공격 | 매우 높음 |
| 뒤에서 공격 | 추가 |
| 패링 성공 | 대량 증가. 추후 기능 |

적이 그로기에 걸리면:

```text
적 공격 취소
↓
짧은 무방비 상태
↓
추가타 또는 처형 가능
```

적의 공격 단계:

```text
대기
↓
예비 동작
↓
공격 판정
↓
후딜레이
```

플레이어의 강공격이 적의 예비 동작 중 적중하고, 그로기 수치가 충분하면 공격이 캔슬된다.

---

### 8.7 구르기

구르기는 위험한 공격을 피하거나 포위 상태를 벗어나는 용도다.

| 요소 | 방향 |
|---|---|
| 무적 시간 | 짧게 있음 |
| 이동 거리 | 짧음~중간 |
| 스태미너 소모 | 중간 |
| 후딜레이 | 약간 있음 |
| 연속 사용 | 가능하지만 스태미너 압박 |

구르기가 너무 강하면 전투가 단조로워지므로, 후딜레이와 스태미너 소모가 필요하다.

---

### 8.8 전투 타격감 체크리스트

| 요소 | 설명 |
|---|---|
| 타격 정지 | 맞는 순간 아주 짧게 멈춤 |
| 피격 반응 | 적이 맞았을 때 흔들리거나 밀림 |
| 강공 히트감 | 강공은 더 큰 정지와 무거운 사운드 필요 |
| 그로기 연출 | 적이 확실히 무너지는 느낌 |
| 사운드 | 타격음, 숨소리, 스태미너 부족음 |
| 카메라 흔들림 | 강공/그로기/처형 때만 제한적으로 사용 |
| 공격 예고 | 적의 공격이 불합리하지 않게 보이기 |

#### 밴딧

사람형 적이다.

특징:

- 근접 무기 사용
- 가드 또는 회피 가능
- 파밍 장소 점거
- 귀중품 보유

- 플레이어와 비슷한 전투 규칙을 가짐

짙은 현상과 연결된 적이다.

특징:

- 특정 조건에서 강해짐

## 11. 이상현상 시스템

이상현상은 밤 지역을 특별하게 만드는 시스템이다.

역할:

- 지역 변칙성 제공
- 낮/밤 차별화
- 공포와 긴장감 제공
- 미션 목표로 사용
- 탈출 조건과 연결
- 동생/기억 스토리 단서 제공

### 11.1 이상현상 예시

| 이상현상 | 효과 | 낮 정보 활용 |
|---|---|---|
| 반복되는 골목 | 특정 길로 가면 같은 장소로 돌아옴 | 쪽지의 표식 순서를 보고 탈출 |
| 멈춘 시계 | 일부 타이머와 적 움직임이 비정상 작동 | 주인공 시계 단서로 패턴 파악 |
| 문 두드리는 소리 | 문을 열면 보상 또는 매복 | 낮에 위험 문 표시 발견 |
| 검은 행렬 | 강한 무리가 특정 길을 지나감 | NPC가 행렬 시간대 제공 |
| 가짜 탈출구 | 탈출구처럼 보이지만 함정 | 낮 단서로 진짜/가짜 구분 |

```text
가방: 5 x 4

장비 슬롯: 무기 / 방어구 / 장신구
빠른 사용 슬롯: 4칸
```

아이템은 크기를 가진다.

| 아이템 | 크기 |
|---|---|

| 약초 | 1x1 |

| 물병 | 1x2 |
| 나이프 | 2x1 |
| 도끼 | 3x2 |
| 망치 | 2x2 |
| 부품 상자 | 2x2 |
| 루디 조각 | 1x1 |
| 큰 루디 결정 | 2x2 |

핵심 재미:

> 좋은 아이템을 발견했지만 가방이 부족해서 무엇을 버릴지 고민하는 것.

## 13. 탈출 시스템

지역마다 여러 개의 탈출구가 존재한다.

| 탈출구 유형 | 설명 |
|---|---|
| 기본 탈출구 | 항상 사용 가능 |
| 조건 탈출구 | 열쇠, 도구, 정보 필요 |
| 시간 탈출구 | 특정 시간 이후 활성화 |
| 낮 정보 탈출구 | 낮에 정보를 얻어야 표시 |
| 위험 탈출구 | 일정 시간 버티면 탈출 |
| 이상현상 탈출구 | 괴현상 해결 후 사용 가능 |

탈출은 즉시 완료되지 않고, 짧은 대기 시간이 필요하다.

```text
탈출 지점 도착
↓
8초간 상호작용 또는 대기
↓
적 접근 가능
↓
버티면 탈출 성공
```

## 14. 사망 / 손실 규칙

사망 또는 탈출 실패 시 손실이 있어야 긴장감이 생긴다.

| 항목 | 사망/실패 시 |
|---|---|
| 파밍 아이템 | 전부 손실 |
| 착용 장비 | 내구도 크게 감소 또는 일부 손실 |
| 중요 스토리 아이템 | 손실되지 않음 또는 안전가옥으로 회수 |
| 캐릭터 | 사망하지 않고 중상 복귀 |
| 안전가옥 | 유지 |
| 부상 | 출혈, 골절, 감염 등 발생 가능 |

초기 버전에서는 캐릭터 영구 사망은 제외한다.
