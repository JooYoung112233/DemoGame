## 21. 1차 데모 범위

### 21.1 데모 목표

> **근접 전투가 재미있는지, 15분 루팅 탈출이 성립하는지, 낮 정보가 밤 플레이에 영향을 주는지 검증한다.**

---

### 21.2 데모 지역: 폐상가

폐상가가 1차 데모에 적합한 이유:

- 파밍 오브젝트를 만들기 쉽다.
- 실내/실외를 섞기 좋다.
- 낮에는 NPC/쪽지를 배치하기 좋다.
- 밤에는 밴딧 점거와 몬스터 출현이 자연스럽다.
- 탈출구를 여러 개 만들기 좋다.

---

### 21.3 데모 구성

| 요소 | 권장 수 |
|---|---:|
| 지역 | 1개. 폐상가 |
| 낮/밤 모드 | 둘 다 구현 |
| 제한 시간 | 15분 |
| 적 | 밴딧 2종, 몬스터 1종, 낮 약한 적 1종 |
| 무기 | 4종 |
| 파밍 오브젝트 | 10종 |
| 아이템 | 30~40종 |
| NPC | 낮에 1~2명 |
| 쪽지 | 5개 |
| 이상현상 | 2개 |
| 탈출구 | 3개 |
| 안전가옥 시설 | 4개 |
| 미션 | 메인 2개, 서브 3개 |

---

### 21.4 데모 낮 플레이 예시

```text
1. 안전가옥에서 파이프, 붕대, 작은 가방 장착
2. 폐상가 낮 출전
3. 편의점에서 음식과 부품 파밍
4. NPC 발견
5. NPC가 “밤에 지하창고 문이 열린다”는 힌트 제공
6. 쪽지에서 후문 탈출구 위치 확인
7. 잠긴 창고 열쇠 획득
8. 기본 탈출구로 복귀
9. 안전가옥에서 작업대 강화
```

---

### 21.5 데모 밤 플레이 예시

```text
1. 낮에 얻은 열쇠와 정보로 폐상가 밤 출전
2. 밴딧 2명이 입구 근처 순찰
3. 전투 회피 후 지하창고 진입
4. 고급 부품과 루디 조각 발견
5. 몬스터 출현
6. 강공격으로 그로기 유도
7. 가방이 꽉 차서 일부 아이템 포기
8. 12분 시점에 탈출 결정
9. 후문 탈출구에서 8초 버티기
10. 전리품 들고 안전가옥 복귀
```

## 23. 보류 요소

초기 버전에서는 아래 요소를 보류한다.

| 요소 | 보류 이유 |
|---|---|
| 총기 | 근접 전투 맛을 먼저 검증해야 함 |
| 복잡한 동료 시스템 | 개발 범위 증가 |
| 완전 오픈월드 | 2인 개발에 부담 큼 |

| 대규모 스토리 컷신 | 제작 비용 큼 |
| 복잡한 은신 AI | 초기 데모 이후 확장 |
| 영구 사망 | 진입 장벽이 커질 수 있음 |

## 24. 핵심 설계 원칙

### 24.1 전투

> 약공격은 안정적이고, 강공격은 위험하지만 성공하면 적의 공격을 끊을 수 있어야 한다.

### 24.2 파밍

> 좋은 아이템을 얻었을 때, 플레이어가 “지금 나가야 하나?”를 고민해야 한다.

### 24.3 낮/밤

> 낮은 정보를 얻는 시간, 밤은 그 정보를 써서 위험을 감수하는 시간이어야 한다.

### 24.4 루디

> 루디는 단순 돈이 아니라, 밤 지역에 들어가야 하는 이유이자 안전가옥 성장의 핵심 자원이어야 한다.

### 24.5 스토리

> 플레이어는 처음부터 세계를 구하려는 것이 아니라, 살아남기 위해 루디를 모으다가 자신의 과거와 동생의 진실에 다가가야 한다.

## 25. 현재 결정된 것 / 더 다듬을 것

### 결정된 것

- 슬롯/카드/턴제 제외
- 총기는 초기 제외
- 근접 전투 중심
- 낮/밤 출전 분리
- 15분 제한 지역 루팅
- 루디 회수와 안전가옥 성장
- 전당포 주인으로 튜토리얼/거래/스토리 진입
- 컨테이너 안전가옥
- NPC 호의도와 상점 확장
- 동생 미스터리와 엔딩 분기

### 다음에 다듬을 것

1. 근접 전투 수치와 조작감
2. 폐상가 1차 데모 맵 구성
3. 낮/밤 폐상가 이벤트 테이블
4. 루디와 짙은 현상의 정확한 규칙
5. 전당포 주인과 주요 NPC 5명 설정
6. 안전가옥 시설 강화 비용표
7. 엔딩 분기 조건

## 26. 최종 요약

현재 게임의 최종 방향은 다음과 같다.

```text
기억을 잃은 주인공
↓
손목시계를 맡기려 전당포 방문
↓
전당포 주인이 주인공을 알아봄
↓
정보를 대가로 루디 회수 의뢰
↓
컨테이너 안전가옥 획득
↓
낮에는 NPC/쪽지/정보 수집
↓
밤에는 밴딧/몬스터/이상현상 속에서 루디 파밍
↓
15분 안에 탈출
↓
안전가옥 강화와 NPC 호의도 상승
↓
동생과 짙은 현상의 진실 추적
↓
엔딩 분기
```

이 기획의 핵심 재미는 다음 문장으로 압축된다.

> **낮에 단서를 모으고, 밤에 위험을 감수해 루디를 가져오며, 살아남기 위해 안전가옥을 키우고, 잃어버린 동생의 진실을 찾아가는 게임.**
