# 레이드 시스템

## 현재 상태

### 레이드 타이머
- 제한시간: **20분** (1200초)
- HUD: 화면 상단 중앙 `MM:SS` 표시
  - 2분 이하: 주황색 경고
  - 30초 이하: 빨간색 깜빡임
- 시간초과: 아이템 50% 랜덤 손실 후 안전가옥 강제 귀환

### 탈출
- ExitPoint 타입 InteractableObject 사용
- `exitWaitTime > 0` 설정 시 카운트다운 대기 (거리 이탈 시 취소)
- 탈출 성공 시 RaidManager에 기록 → Safehouse 복귀 → RaidResultUI 표시

### 루팅
- LootContainer에 `initialLoot` 배열로 초기 아이템 설정 (Inspector)
  - itemId, count, chance(스폰확률) per entry
- 상자 열면(E키) 내부 아이템 전부 자동으로 PlayerInventory로 이동
- 공간 부족 시 남은 아이템은 상자에 유지
- 모든 아이템 획득 시 IsLooted = true (재상호작용 시 "비어있음" 표시)
- 획득한 아이템은 RaidManager에 추적 기록

### 광원 운용 — 빛의 역설 〔확정 방향 · 수치 TBD〕

> 세계관 = [gdd-core §5.2/§5.3](gdd-core.md). 레이드 중 광원 선택이 위험·보상에 직결.

- **탐지등(루디 광원) = 기본·안전**(빛의 역설 예외). 레이드 중 **약하게 방전** → 여분 루디로 교체하며 운용(가혹하지 않은 광원 관리 긴장). 방전 속도·여분 용량 = `GameTuning`.
- **비루디 광원**(플레어·횃불·발견 전등·화염 무기)은 즉효(넓은 시야·온기·화염 전투)지만 그 자리에 **침식 게이지**를 쌓는 양날 — 불 계열 가중치 최대. "지금 밝힐까 vs 아껴둘까". → [navigation.md §4](navigation.md)(랜턴 점멸 예고), [anomaly.md](anomaly.md)
- **루디 회수 + 충전 재진입 동기**: 루디는 현상에서만 회수되고 마모로 소진되므로, 레이드는 「회수」뿐 아니라 「현상 노드에서 충전」(빠름·위험)이라는 재진입 이유도 가진다. [→ gdd-core §5.3](gdd-core.md), [anomaly.md](anomaly.md)

### 귀환 정산 (RaidResultUI)
- Safehouse 씬 로드 시 자동 표시
- 실제 데이터 표시:
  - 생존 시간
  - 획득 아이템 목록 (희귀도 색상 포함)
  - 아이템 총 개수/무게
  - 아이템 총 가치 (sellPrice 합산)
- Enter/클릭으로 닫기

### 약탈자 회수 (사망 루프) — ✅ 2026-07-11 구현 (⑧ 「시간 잔상」 폐기·대체)

> 2026-07-11: 「시간 잔상」(사망 지점 정적 컨테이너)안을 **폐기**하고, 사용자 결정으로 **약탈자 회수**로 대체 — 정적 회수 지점 대신 **살아있는 적을 사냥해 되찾는** 능동 루프.

- **사망 시 소지품(보안 컨테이너 제외)이 「회수 대기열」에 담긴다** (기존 "가방 전부 소멸"(2026-06-02) 대체 — 삭제가 아니라 캡처). 가방 아이템 자체는 소실(내용물만 회수 대상).
- **다음 레이드**에 스폰된 적 중 몇 마리가 **약탈자**로 지정돼 그 물품을 나눠 지닌다(`GameTuning.scavengerCount` 기본 3, 라운드로빈 분배). 잡아서 **시체를 뒤지면 회수**.
- **한 번의 기회** — 분배 시점에 대기열을 비운다. 그 레이드에서 못 잡거나 못 챙기고 벗어나면 **영구 소실**. (다시 죽으면 그때 잃은 물품으로 새 대기열.)
- **식별**: HUD 표식 없음. 약탈자는 **몸이 보랏빛**(일반 적=붉은빛)으로 틴트 — 관찰로 구분. 시체 라벨도 "약탈자 …".
- **세계관 정합**: §5.0 비공식 공급망 = 회수꾼이 시체를 턴다. 시계가 몸은 역행시켜도 소지품은 회수꾼 손에.
- **구현**: `Combat/ScavengerLoot.cs`(정적 대기열·분배) · `RaidManager.OnPlayerDeath`가 손실을 `Capture` · `EnemySpawner`가 스폰 직후 `Distribute` · `EnemyController.MakeScavenger`(틴트 + 시체 루팅 주입, ② LootContainer 재사용). **세션 런타임**(세이브 미포함 — 크로스세션 영속은 후속). F1 씬 탭 "잃은 물건 시뮬". 구현 순서 = A+B 통합 10종 중 **8번째**(⑧ 슬롯 재정의).

## 기획 결정 로그

### 2026-06-06 — '밤' → '짙은 현상' 재정의 + 시간 수치
- **질문**: 레이드 위협을 '밤'으로 볼지, '짙은 현상'이라는 존재로 볼지?
  - **결정**: **'밤'은 통칭일 뿐, 실제 위협 = 짙은 현상.** 회수꾼 브리핑(S-013)도 "밤 출격"이 아니라 "현상을 조심하라"로 변경. 현상은 한낮에도 번질 수 있고, 닿으면 사람이 안 돌아온다. 정체는 후반 다른 개념으로 공개 — 지금은 모호하게.
  - **수치**: 레이드 제한 **20분**, 짙은 현상 1회 지속 **≈10분**(루디 출현·최대 위험 창).
  - ~~**현상 계측기**~~ → **2026-06-08 폐기.** 예고 = **랜턴 점멸**. 상세 → [navigation.md](navigation.md) §4.

### 2026-06-08 — 계측기 → 랜턴 점멸
- **결정**: 현상 근접 예고를 별도 아이템 대신 **착용 랜턴 불빛 깜빡임**으로. MQ-002(랜턴 의뢰)와 통합.

### 2026-07-10 — 시체 회수(사망 루프) 「시간 잔상」
- **질문**: 사망 시 소지품 처리와 회수 루프를 어떻게 만들까?
  - **결정**: 사망 시 소지품(**세큐어 컨테이너 제외**)이 사망 지점에 **「시간 잔상」 컨테이너**로 남음. 세계관 정합 — 시계가 시간을 회수해 몸은 거점으로 역행하지만 소지품은 역행에서 제외돼 그 자리에 응고([gdd-core §5](gdd-core.md) 사망=시간역행 룰과 연결). **잔상은 최신 1개만** — 다시 죽으면 이전 잔상은 현상에 삼켜져 소멸. 유지 기한 없음(다음 사망까지). 회수 = 잔상 열어 꺼내기. 구현 접점: SaveManager 영속(병렬 핫파일 — 구현 시점 조율 필요 명시).
  - **근거**: 죽음이 "한 번 더 들어갈 이유"가 되는 장치 — 타르코프/낙원 공통 핵심.

### 2026-07-10 — 지도 + 시계 나침반
- **질문**: 길찾기/지도 시스템을 어떻게?
  - **결정**: ① **상시 미니맵 없음**(긴장 유지). ② **M키 전체화면 지도** — `map_fragment` 획득한 구역만 열림(미획득=안개), 현위치+발견 랜드마크 표시(map_fragment 실사용처 확보). ③ **시계 나침반** — HUD 시계 토글 키로 활성 탈출구 방향을 바늘이 가리킴(스토리 S-014 나침반 떡밥 회수, [story-script.md](story-script.md) 정합). 2차 = 시간 잔상(내 시체) 방향도 가리킴.
  - **근거**: 처음 간 지역에서 탈출구 방향을 알 수단이 없었음.
