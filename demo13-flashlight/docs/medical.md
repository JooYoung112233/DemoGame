# 의료/치료 시스템

## 현 상태 = 진실

### 부위 (5부위)
| 부위 | 영향 | 비고 |
|---|---|---|
| 머리 (Head) | 시야 흐림, 판정 디버프 | 치명 부위 |
| 몸통 (Torso) | HP 최대치 감소, 스태미너 회복 저하 | 핵심 부위 |
| 양팔 (Arms) | 공격 속도 저하, 차징 시간 증가 | 좌우 통합 |
| 왼다리 (Left Leg) | 이동속도 감소 | 이동 패널티 |
| 오른다리 (Right Leg) | 이동속도 감소 | 이동 패널티 |

- 다리 양쪽 부상 시 이동속도 대폭 감소 (중첩)
- 각 부위마다 독립적인 HP 또는 상태 트래킹

### 부상 종류 (핵심 3종)
| 부상 | 효과 | 미치료 시 | 발생 조건 |
|---|---|---|---|
| 출혈 (Bleeding) | 시간당 HP 감소 (DoT) | HP 0까지 지속 | 근접 피격, 총상 |
| 골절 (Fracture) | 해당 부위 기능 대폭 저하 | 자연치유 없음 | 강공격 피격, 높은 데미지, 낙하 |
| 통증 (Pain) | 스태미너 회복 저하, 행동 약간 느려짐 | 시간 경과로 서서히 감소 | 모든 피격 누적 |

### 치료 아이템 (키트 + 전용 혼합)
| 아이템 | 대상 부상 | 속도 | 비고 |
|---|---|---|---|
| 구급상자 (First Aid Kit) | 출혈/통증 | 느림 (5초) | 범용, 골절 불가 |
| 붕대 (Bandage) | 출혈 | 빠름 (2초) | 전용, 가벼움 |
| 부목 (Splint) | 골절 | 보통 (3초) | 전용, 무거움 |
| 진통제 (Painkiller) | 통증 | 즉시 | 전용, 일시적 효과 (지속시간 있음) |

### 치료 메커니즘
- 인벤토리에서 치료 아이템 선택 → 부위 선택 → 치료 시간 경과 → 부상 제거/감소
- 치료 중 이동 불가 (캔슬 가능)
- 안전가옥 침대: 모든 부상 완치 (휴식)

### UI 계획
- 캐릭터 실루엣 + 부위별 상태 색상 표시 (초록/노랑/빨강)
- Tab키 등으로 의료 패널 열기
- 부상 아이콘 + 잔여 효과 시간
