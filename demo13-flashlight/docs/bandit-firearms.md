# 밴딧 총기 시안

## 2026-09-11 사용자 요청·결정

- 질문/요청: 총을 사용하는 밴딧을 권총·돌격소총 두 종류로 먼저 만들고 확인하고 싶다. 미착용 상태에서 적을 만나면 총을 꺼내 조준·사격하고, 총을 든 채 걷기도 가능하게 한다. 비전투 수납 위치는 권총은 다리, 돌격소총은 등 뒤가 어떨까?
- 사용자 방향: 권총은 한 손 사격, 돌격소총은 양손 사격. 비전투에는 권총을 허벅지 홀스터에, 돌격소총을 등 뒤에 수납하는 컨펌용 시안 제작.
- 구현 범위: 기존 방망이 밴딧을 유지하고 별도 총기형 프리팹·확인용 씬/미리보기를 만든다. 수납→꺼내기→조준→총 든 걷기→사격/반동→수납을 확인한다. 정식 적 배치와 전투 밸런스 확정은 사용자 컨펌 후 진행.
- 제작 메모: 손목을 억지로 꺾지 않도록 무기 그립과 양팔 연결을 함께 검사한다. 권총 홀스터는 오른쪽 허벅지 바깥쪽, 소총은 등 뒤 대각선 배치로 시작한다.
- 후속 사용자 지시: “총 애니 있으니 확인하고 무료 에셋 받아둔거에”. 보관된 Kevin Iglesias Human Soldier Animations FREE의 권총 Aim01/Aim02 및 Shoot01, AssaultRifle Aim01/Shoot01를 우선 확인·재사용한다. 해당 무료 묶음에서 전용 꺼내기/수납 클립은 검색되지 않아 수납 전환은 별도 보완한다.

## 상태

- 2026-09-11 / 질문·확인: “플레이어 무기는 인벤토리에서 착용하는 개념이니까 확인해둬”. / 사용자 결정: 인벤토리의 무기 장착 슬롯을 시각 표시의 기준으로 삼는다. 단순 소지는 표시하지 않으며, 달릴 때 수납해도 장착 슬롯·아이템·탄약 상태는 유지한다. 장착 해제·교체 시 손/몸의 기존 무기 표시도 함께 제거·교체한다.

- 2026-09-11 플레이어 규칙 변경: “플레이어 총이나 무기 수납은 달릴때만 넣도록 하자”. 플레이어는 정지·일반 걷기 때 장착 무기를 든다. 달리기(스프린트) 때만 총/근접무기를 수납하고 달리기를 멈추면 다시 든다. 앞서 적은 플레이어의 조준 입력 종료 후 자동 수납 방침을 이 결정으로 대체한다. 밴딧의 비전투 수납 규칙은 유지한다.
- 구현 메모: 플레이어 권총은 오른쪽 다리, 소총·검·방망이는 등 뒤에 수납한다. 회피 동작을 달리기 수납으로 취급하지 않는다. 조준·재장전 중에는 스프린트를 멈추며, 사격은 즉시 무기를 손으로 복귀시키고 마지막 발사 후 0.2초까지 스프린트를 중단한다. 장착 슬롯은 건드리지 않는다.

- 2026-09-11 사용자 컨펌: 오른쪽 어깨 견착 수정에 “좋다”. 후속 요청: “모션 우리 플레이어도 넣어줄래?” 승인된 권총·소총 모션을 플레이어의 총기 장착·조준·사격·이동과 연결한다. 플레이어의 전투 상태 판단은 기존 입력/총기 로직을 기준으로 적용한다.

- 2026-09-11 컨펌 피드백: “양손이 총이 너무 중앙같은데”. 소총을 몸 중앙에서 오른쪽 어깨 쪽으로 옮겨 개머리판을 견착하는 자세로 조정하고 왼손 그립을 재검증한다. 권총 자세는 유지한다.

### 플레이어 연결 (2026-09-11)

- `CharacterPanelUI`의 장착 처리 → `PlayerEquipment.EquipWeapon`/`SetSlotInstance` → `TopDownPlayer` 표시 경로를 사용한다. 인벤토리에 가지고만 있는 무기는 표시하지 않는다.
- 기존 `Pistol9` 장착 시 한손 권총 모델·조준/걷기/반동을 표시한다. `WeaponData.firearmStance=AssaultRifle`은 양손 소총 자세를 선택한다. 소총 모션은 연결했지만 신규 소총 아이템·스탯·구경은 추가하지 않았다.
- 총기 상체만 기존 이동 애니메이션에 덮어쓰고 하체·루트·바라보는 방향은 보존한다. 정지·걷기는 손에 유지, 실제 스프린트에서만 수납한다. 무기 장착 해제/교체 시 손·수납 모델도 정리한다.
- 실제 `PlayerGun.TryFire`가 손의 총구 위치에서 기존 `Projectile`을 발사한다. 탄창·잔탄·피해량·발사 주기는 기존 시스템을 사용한다.
- 검·방망이는 스프린트 때 등에 표시하며 상체 잡기 레이어를 해제한다. 나머지 임시 근접무기도 등 수납 위치로 이동한다. 수납은 장착 슬롯·무기 인스턴스·잔탄을 변경하지 않는다.
- `tools/verify_player_firearms.cs`: 실제 장착 API, 단순 소지 시 숨김, 걷기↔스프린트, 정지 유지, 회피 모션 구분, 수납 도중 복귀, 총 교체·해제, 실제 총구 발사/잔탄 1발 소모, 검·방망이 수납 검사. Editor 격리 검증이며 키보드/인벤토리 UI의 Play 수동 조작 검증은 별도다.
- `tools/verify_player_bat.cs`: 기존 방망이 공격·그립·무기 교체 회귀 검사 통과. `ArtWork/PlayerFirearms/{Walk,SprintFront,SprintBack}.png`는 실제 플레이어 모델 렌더다. 화면 왼쪽부터 검·방망이·소총·권총.
