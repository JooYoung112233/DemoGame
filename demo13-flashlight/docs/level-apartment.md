# 레벨 디자인 — 폐아파트 단지 (Apartment) — STEP 3 그레이박스 설계

> 1지역 **랜드마크#2** (중심 (650,300), 위험 ★★, [`world-map.md`](world-map.md) §7-5 J②). 수직 탐색 + 열쇠 체인 1단계.
> **다층 처리(층 시스템 전 그레이박스 기법)**: 층 레이아웃을 **한 씬에 나란히(side-by-side)** 깔고 **계단(`gb_door`)으로 인접 층 전환**. 층 전환 시스템이 생기면 side-by-side → 실제 stacked 레이어로 재배치.
> 현 상태 = 진실. 결정 바뀌면 덮어쓰고 하단 변경 로그에.

## 1. 컨셉
- 한 줄: 고층 아파트 **1동**을 **1층 로비 → 2~3층 세대 → 펜트하우스**로 수직 탐색. 위로 갈수록 보상↑·위험↑·탈출 멀어짐.
- 핵심 게이트: **`key_apt_admin`(1층 경비실)** → **펜트하우스 잠금 해제** → 귀중품 + **`key_tower_card`**(다음 랜드마크 유리타워 R&D 열쇠).
- 위험 ★★. 평상시 인간 적(밴딧/약탈자), **현상 활성 시 강화/오염 변종 + 이상체**(§world-map L).

## 2. 진입 / 연결
| | 방향 | 비고 |
|---|---|---|
| 진입 | **A1 남부대로(서)** — 상가골목/약국 조각에서 | + S2(남동 스폰) 인접 |
| 막힌 길 | **B5** 단지 내부 간선 붕괴 | 단지 가로지르기 불가 → 외곽 우회(시간↑) |
| 온워드 | **A2 동부종단(북) → 유리타워** | `key_tower_card`로 다음 랜드마크 연결 |

## 3. 층 구성 (side-by-side 레이아웃, 계단 `gb_door`로 연결)
| 층 | 레이아웃 | 적(평상시) | 루트 | 열쇠·문 |
|---|---|---|---|---|
| **1층 로비** | 정문 진입 + 로비 + **경비실** + 우편실. 계단실↑ | 밴딧 1~2 | ★ 잡화 | **`key_apt_admin`**(경비실 책상) |
| **2층 세대** | 복도 + 호실 3~4(`gb_door`로 진입, 컨테이너 다수) + 계단↑↓ | 밴딧 2 | ★★ 생활물자 | — |
| **3층 세대** | 복도 + 호실 3~4 + 계단↑↓ | 약탈자 2~3 | ★★ 생활물자 | — |
| **펜트하우스** | 넓은 단일 세대. 입구 **`key_apt_admin` 잠금** | 강화 밴딧 1 | ★★★ 귀중품 | 잠금 해제 → **`key_tower_card`** + 귀중품 |

- **계단 = `gb_door`** "Stair_1to2" / "Stair_2to3" / "Stair_3toPent" — 인접 층 레이아웃을 잇는다(side-by-side에선 옆 칸으로 이동 = 층 이동 표현).
- **호실 = `gb_door`로 들어가는 폐쇄 방**(튜토 건물 기법). 안에 `gb_crate`/`gb_shelf` 컨테이너.

## 4. 적 · 현상 (§world-map L)
- **평상시(현상 없음)**: 인간 적 — 층 올라갈수록 ↑(1층 1~2 → 펜트 강화 1). `gb_enemy` 사전 배치.
- **현상 활성(랜덤)**: 강화/오염 변종 + 현상 전용 이상체 스폰. **`gb_anomaly`(AnomalySpawnPoint) 층별 1~2**(로비·세대 복도·펜트). 현상 시 Anomaly 티어 루트(루디·희귀).

## 5. 루트
- ★★: 1층 잡화 / 2~3층 생활물자(컨테이너 다수) / 펜트 귀중품. 현상 시 루디·희귀(Anomaly 티어).
- `key_apt_admin` → 펜트(귀중품 + `key_tower_card`) = 구역 간 왕래 동기(world-map C 열쇠 체인).

## 6. 그레이박스 조각 (지금 빌드 가능 — 층 시스템 불필요)
- **한 씬에 4개 층 레이아웃 가로 배치**(1층 | 2층 | 3층 | 펜트), 계단 `gb_door`로 인접 칸 연결.
- 1층 정문 = A1/약국 조각에서 진입(연결 마커 `gb_spawn` From_Street).
- 펜트 입구 = **`key_apt_admin` 잠금 문**(Key 게이트 체험), 안에 `key_tower_card`.
- `gb_anomaly` 층별 배치(현상 스폰).
- 빌더: **`Zone1GreyboxLayout.BuildApartmentLandmark`로 착수**(2026-06-06, 성장형). **진입 = 튜토 차고(2번째 블럭) 동측 통로 → 동측 길**(서측 갭 y46~54, 월드 x[114,196] y[20,160]). 현재 = 지상층 착수(서측 광장 + 아파트 동 1채 서문 + `key_apt_admin` + 적 + 라벨 + 탈출 `Exit_Apt`). **수직 다층(side-by-side/계단)·세대 다수는 층 시스템 후** 또는 다음 디테일 패스. **현상(gb_anomaly) 제거.** (이 문서 = 폐아파트 디테일 설계 참조.)
- **층 시스템 생기면**: side-by-side → 실제 stacked 레이어(계단=수직 전환)로 재배치.
