## 1. 상가 골목 (낮) — 데모 구역 v1 (확정 — 구조 골격)

> 구역·동선·리스크리워드·적·퀘스트앵커 골격은 확정. 정확한 건물/벽 형태는 Prop2D 배치 시 확정.

### 1.1 컨셉
- **한 줄**: 좁은 폐(廢)상가 골목. 남쪽은 안전(스폰·탈출), 북쪽으로 갈수록 루트·위험·탈출거리 동반 상승.
- **핵심 감정**: "편의점만 털고 안전하게 나갈까, 뒷골목 고보상까지 욕심낼까?"
- **시간 목표**: 안전 루프 ~4분 / 욕심 루프 ~7~9분 (15분 레이드 안에서 1~2바퀴).

### 1.2 규모
- **데모 구역 크기**: 약 **84 × 64m** (전체 800×700의 상가골목 footprint을 데모용으로 압축).
- 타일 1m. 좌표: 남(Y작음)=입구, 북(Y큼)=깊은 곳.

### 1.5 동선 / 도로
- **메인 골목(Z1)**: 남(스폰)→북 관통하는 세로 척추.
- **동서 연결로 A**(Y~24): 편의점 ↔ 셔터상가 연결.
- **동서 연결로 B**(Y~48): 잔해건물 ↔ 뒷골목 연결.
- **막다른 길**: Z4(잔해)·Z5(뒷골목)는 한쪽을 **철거 가능한 바리케이드/잔해로 막아** 들어가면 되돌아 나와야 함 → 위험 노출 시간 ↑. (통합 시 이 막힘을 치우면 인접 랜드마크 연결로가 됨 — §2.3)

### 1.6 리스크-리워드 곡선
```
보상·위험·탈출거리
   ↑                          ● Z5 뒷골목(고보상/협상꾼)
   │                  ● Z4 잔해(생존자)
   │          ● Z2 편의점
   │   ● Z1 노점
   ●Z0 ───────────────────────────→ 깊이(북쪽)
```
- **안전 루프**: 스폰 → 편의점(Z2) → E0. 짧고 안전, 보상 평이.
- **욕심 루프**: 스폰 → 골목 → 뒷골목(Z5, 협상꾼 돌파/우회) → 고보상 → D탈출(북동) 또는 E0 복귀. 길고 위험, 탈출 결정 압박.

## 2. 전체 지역1 통합 관계 (필수 — 나중에 합쳐짐)

> 이 데모 구역은 **독립 씬이 아니라, 전체 폐상가(800×700) 랜드마크#1 "상가 골목"의 핵심부**다.
> 통합 시 충돌을 막기 위해 **처음부터 통합을 전제로 제작**한다.

### 2.1 데모 구역 ↔ 전체맵 대응
- 전체맵 상가골목 랜드마크#1: footprint **X 110~290 (폭180) × Y 80~230 (폭150)**, 중심 (200,155), 위험 ★ ([`world-map.md`](world-map.md) §7-5).
- 데모 구역(84×64m)은 이 footprint의 **핵심부**. 통합 시 주변(북·동)으로 확장되며 다른 랜드마크로 이어진다.
- **제작 좌표 규칙**: 데모는 **로컬 원점(0,0)~ (84,64)** 기준으로 제작 → 통합 시 **월드 오프셋을 더해** 그 위치에 배치(`world = local + offset`). 데모 맵을 맵툴 "맵 저장"으로 **프리팹화**해 두면 전체 InGameScene의 상가골목 위치에 그대로 인스턴스 가능.
- **잠정 오프셋(통합 시 확정)**: 데모 S1 local(42,6) → 전체 S1 world(150,60)에 맞추면 offset ≈ **(108, 54)**. (정밀값은 통합 시점에 footprint 보고 확정)

### 2.2 데모 전용 → 전체 통합 시 전환
| 데모(지금) | 전체 통합 시 |
|---|---|
| 단일 스폰 S1(남중앙) | 전체 6스폰 중 상가골목 인접분(S1). 나머지 스폰은 타 랜드마크 쪽 |
| 안전 탈출 E0(데모 남서) | 전체 고정 E0 world(200,25)로 통합/대체 |
| 동적 탈출 D(북동) | 전체 D1~D4 체계의 일부 또는 타 랜드마크 길목으로 재배치 |
| **막다른 Z4(북서)·Z5(북동)** | **연결로로 개방** — 북쪽이 폐아파트(★★)·유리타워(★★★★) 방향 도로로 뚫림 |

### 2.3 ⚠️ 레벨 디자인 제약 (지금 반영해야 함)
- **막다른 경계는 "치울 수 있는 잔해/바리케이드"로 막을 것.** Z4·Z5의 북쪽 막힘을 영구 벽이 아니라 **철거 가능한 잔해·셔터·바리케이드**로 두면, 통합 시 치우는 것만으로 인접 랜드마크 연결로가 된다. (영구 벽으로 막으면 통합 때 재작업)
- **출구 방향 일관성**: Z5(북동)→유리타워, Z4(북서)→폐아파트 방향을 미리 의식하고 그쪽으로 길을 열어둘 여지를 남긴다.
- **루트 밀도 스케일**: 데모 단독 밀도는 "한 구역 완결"용. 전체 통합 시엔 랜드마크 5개 합산이라 **구역당 밀도를 전체 기준으로 재조정** 필요(데모 값은 통합 시 낮춰질 수 있음).

### 2.4 변하지 않는 것 (통합 무관)
- 낮/밤은 **같은 지오메트리 + phase 이벤트**(조명·NPC·루트·적 교체). 통합과 별개.
- 구역 위험 위계(Z0<Z1<Z2≈Z3<Z4<Z5)와 리스크-리워드 곡선은 전체에서도 유지.

## 배치 명세 (그레이박스 v1)

> 위 §1 레벨 디자인을 **그레이박스 프리팹(gb_\*)으로 실제 좌표 배치**한 사양. 에디터 스크립트가 이 표대로 씬을 생성한다.
> 좌표계: XY 평면, Z=0, 1 unit = 1m. 맵 **84(W) × 64(H)**. 남(Y=0)=입구, 북(Y=64)=깊은 곳.

- **생성 씬**: `Assets/Scenes/ScrapMarket_GB.unity` — 맵 콘텐츠 전용(카메라/조명/매니저/플레이어 없음 → Systems 부트 씬이 additive로 공급). 모든 그레이박스는 단일 `Map` 루트 하위.
- **빌더**: `Assets/Editor/ScrapMarketGreyboxLayout.cs` — 메뉴 `Tools ▸ TopDown ▸ Map ▸ Build ScrapMarket Greybox Layout` (배치모드 진입점 `ScrapMarketGreyboxLayout.Build`). 멱등(같은 경로로 덮어씀).
- **벽 = 막대(bar)**: `gb_wall` 인스턴스의 `transform.localScale = (lengthX, thicknessY, 1)`, 위치는 막대의 **중심**. 두께 1. BoxCollider2D가 스케일을 따라가 충돌이 비주얼과 일치한다.
- **바닥**: `gb_floor` 1개를 84×64 전체로 스케일(중심 (42,32), scale (84,64,1)). 정렬은 프리팹값(Ground/-10)이라 항상 최하단.
- **바리케이드 = 통합 연결점 표시**: `gb_barricade`(주황) 막대는 **철거 가능 막힘**(§2.3). 치우면 인접 랜드마크 연결로가 된다 — Z4 입구↔폐아파트, Z5 동쪽끝↔유리타워.
