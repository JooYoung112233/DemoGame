### 2026-06-05 — 플레이어/맵 스케일 정합
- **질문**: 플레이어 점유 크기 2×2(2m) vs 1×1(1m)? (그레이박스/타일은 1m 단위)
- **결정**: **1×1(1m).** 그레이박스 1m 타일과 정합 → 문·통로 1m도 그대로 통과(2m 확대 불필요). 좀보이드 표준(캐릭터=1타일).

- **밀도 메모(좀보이드式)**: 플레이어 1m 기준 복도 4m=4칸은 다소 넓음 → 추후 3m로 좁히고 방도 약간 축소해 밀도↑ 검토(전투 공간과 트레이드오프, 실제 배치 보고 결정).

## 1. 폐상가 (낮) — 데모 구역 v3 (확정 — 스토리 MQ-001 첫 출격 동선)

> 데모 구역 = **스토리 그대로의 일방통행(LINEAR) 선형 동선**. 분기 없는 단일 복도가 구역을 스토리 순서대로 관통.
> v3는 [story-script.md](story-script.md) **S-004~S-006(첫 낮 레이드)** 동선을 1:1로 realize한다:
> **철문 진입 → 폐상점(첫 파밍) → 버려진 도로 → 밴딧 코너(첫 전투) → 창고(민이·노크규칙·쪽지) → 맨홀 탈출.**
> v2(추상 구역명 편의점/셔터상가/잔해/뒷골목 + 북단탈출)는 폐기 → v3로 개정. 상세는 하단 변경 로그.

### 1.1 컨셉
- **한 줄**: 빽빽한 폐(廢)상가 사이 **좁은 골목 하나**를 따라 남→북으로 관통하는 첫 레이드 동선. **창고**가 목표, **창고 앞 맨홀**로 탈출.
- **핵심 감정**: "코너를 돌 때마다 뭐가 있을까?" — 길은 외길이라 안 헷갈리되, 지그재그 코너가 시야를 끊어 긴장(밴딧 = 코너 조우).
- **학습 목표(스토리 순)**: 이동/시야 → 루팅(폐상점) → 길가 파밍(버려진 도로) → 전투(밴딧 코너) → 문 통과(창고 셔터) → 단서/민이(창고) → 탈출(맨홀).
- **시간 목표**: 1회 관통 ~3~5분. 스토리상 "작은 건물 2~3채 + 버려진 도로, **좁고 단순한 첫 지역**"(S-005).
- **스토리 핵심**: 창고에 **민이의 흔적**(셔터 아래 마른 손자국 + 안에서 긁은 자국) + 벽의 **노크 규칙**("세 번 두드리면 대답해…") + **쪽지/단서**. 민이 = **동생 복선**(S-031 꿈의 어린아이 목소리 / SQ-001 갇힌 생존자 라인과 연결).

### 1.2 규모
- **데모 구역 크기**: **44 × 56m** (스토리 "좁고 단순한 첫 지역" — v2 48×58에서 더 압축).
- 타일 1m. 좌표: 남(Y=0)=**철문 진입**(전당포/안전가옥에서 도착), 북(Y=56)=심부(약국 방향, 바리케이드로 봉쇄).
- **탈출 = 창고 앞 맨홀**(북단이 아님). 동선은 남→북으로 깊어지다 **창고(북서) 앞에서 맨홀로 추출**.
- **골목/복도 폭 = 4m** 일정. 방은 작고 조밀. 복도/방 외 공간은 전부 **건물블록(filled gb_wall)**.

## 2. 전체 지역1 통합 관계 (필수 — 나중에 합쳐짐)

> 이 데모 구역은 **독립 씬이 아니라, 전체 폐상가(800×700) 랜드마크#1 "상가 골목"의 핵심부**다.
> 통합 시 충돌을 막기 위해 **처음부터 통합을 전제로 제작**한다.

### 2.1 데모 구역 ↔ 전체맵 대응
- 전체맵 상가골목 랜드마크#1: footprint **X 110~290 (폭180) × Y 80~230 (폭150)**, 중심 (200,155), 위험 ★ ([`world-map.md`](world-map.md) §7-5).
- 데모 구역(v3 44×56m)은 이 footprint의 **핵심부**. 통합 시 주변(북·동)으로 확장되며 다른 랜드마크로 이어진다.
- **제작 좌표 규칙**: 데모는 **로컬 원점(0,0)~ (44,56)** 기준으로 제작 → 통합 시 **월드 오프셋을 더해** 그 위치에 배치(`world = local + offset`). 데모 맵을 맵툴 "맵 저장"으로 **프리팹화**해 두면 전체 InGameScene의 상가골목 위치에 그대로 인스턴스 가능.
- **잠정 오프셋(통합 시 확정)**: 데모 S1 local(6,3) → 전체 S1 world(150,60)에 맞추면 offset ≈ **(144, 57)**. (정밀값은 통합 시점에 footprint 보고 확정)

### 2.2 데모 전용 → 전체 통합 시 전환
| 데모(지금, v3) | 전체 통합 시 |

### 2.3 ⚠️ 레벨 디자인 제약 (지금 반영해야 함)
- **막다른/경계는 "치울 수 있는 잔해/바리케이드"로 막을 것.** v3의 통합 연결점 바리케이드 2곳을 영구 벽이 아니라 **철거 가능한 gb_barricade**로 두어, 치우는 것만으로 인접 랜드마크 연결로/밤 입구가 된다.
  - **Pharmacy_Barricade_N** — 창고 **북단 통로**(13, 54) size 10×1 → 치우면 **북쪽 약국**(SQ-002 "폐상가 북쪽 무너진 약국") + 심부 폐상가 방향 개방. (북벽 X8~18 갭이 그 뒤에 열려 있음.)
  - **Basement_Block** — 창고 **동측 안쪽**(20, 50) size 1×4 → 밤 phase에 치우면 **지하창고(루디) 입구** 개방(S-022, 낮엔 봉쇄). 밤 전용 컨텐츠 훅.
- **남쪽 = 안전가옥(전당포) 진입**: 남단 철문 스폰은 **바리케이드 없이 열린 게이트**(전당포에서 도착하는 입구). 통합 시에도 남쪽은 안전가옥 방면 진입로로 유지.
- **출구 방향 일관성**: 북→약국/심부, 창고 동측→밤 지하, 남→안전가옥 방향을 미리 의식하고 바리케이드/게이트를 그쪽 벽에 배치(개방 여지 확보).
- **루트 밀도 스케일**: 데모 단독 밀도는 "첫 레이드 한 줄 관통"용. 전체 통합 시엔 랜드마크 5개 합산이라 **구역당 밀도를 전체 기준으로 재조정** 필요(데모 값은 통합 시 낮춰질 수 있음).

### 2.4 변하지 않는 것 (통합 무관)
- 낮/밤은 **같은 지오메트리 + phase 이벤트**(조명·NPC·루트·적 교체). 통합과 별개. (밤엔 `Basement_Block`이 지하창고 입구로 열림 = 같은 맵의 phase 변화.)
- 구역 위험 위계(철문<폐상점≈도로<밴딧 코너<창고)와 리스크-리워드 곡선은 전체에서도 유지.
