# 내비게이션 — 시계 나침반 + 미니맵/맵 시스템

> 레이드 내 길찾기 보조 2종을 다룬다: **시계 나침반**(방향)과 **미니맵/맵**(공간).
> 시계는 스토리 핵심 장치(현상 측정기·동생 나침반·영야 키)를 **게임플레이로 앞당겨 체험**시키는 디제틱 도구다.
> 사망=시간역행 암시의 **서사 결정**은 [`story.md`](story.md) 2026-06-05 항목에 기록. 이 문서는 **게임플레이·UX·시스템 기반**.
>
> **상태: 설계 확정 + 기반 코드 구현** (2026-06-05). 코드: `Assets/Scripts/Navigation/` (구현 메모 §3.6). 세이브 영속·아트는 후속.

## 0. 설계 원칙

- **시계 = 방향만** (어디로). 항상 사용 가능, 디제틱(손목시계를 본다).
- **맵 = 공간 레이아웃** (벽·구역·탈출구·탐색 정도). **지식으로 게이트** — 처음엔 없음.
- **둘은 보완 관계**: 맵이 없어도 시계가 헤딩을 주고, 맵을 얻으면 경로를 짤 수 있다.
- **HUD가 곧 떡밥**: 시계의 기능적 등장이 후반 서사(나침반·시간현상)를 자연스럽게 미리 심는다. 평범한 "길잡이"로 등장 → 점진적으로 "측정기/시간장치"로 정체 공개.
- 시계의 스토리 캐논과 **모순 없이 확장**한다 — 기존: "동생 위치를 가리키듯 진동", "가까울수록 초침이 거세게 반응", "멈춘 시계 이상현상"([story.md](story.md), [gdd-core.md](gdd-core.md)).

## 1. 시계의 3가지 역할 (단일 계기로 통합)

시계 = 하나의 디제틱 계기. **초침(needle)** 이 핵심 표현 수단.

### 1.1 나침반 모드 — 방향 지시 (튜토리얼 + 퀘스트 마커)

초침이 현재 **관심 지점(POI)** 방향을 가리킨다. 떠 있는 3D 화살표가 아니라 **시계를 보는** 연출이라 "시계가 길을 안내한다"는 테마를 1일차부터 각인.

- **타겟 우선순위** (위에서부터):
  1. **튜토리얼 단계 목표** — 오프닝(S-000~S-006)에서 전당포·첫 탈출구·첫 파밍 등으로 유도. → "튜토리얼 방향" 요구 충족.
  2. **활성 퀘스트 목표** — `QuestManager`의 현재 추적 퀘스트 목표 좌표. → "퀘스트 마커 방향" 요구 충족.
  3. **(후반) 동생 단서 / 영야** — 캐논의 "동생 위치를 가리킴". 같은 초침, 더 높은 무게.
- **거리 피드백**: 가까울수록 초침 떨림/틱 빨라짐 or 발광 강화 → 캐논 "가까울수록 거세게 반응" 일치. **거리값 숫자는 비공개**(방향만, 레이아웃은 맵의 몫).
- **기존 `QuestHUD`(텍스트 추적기)와 역할 분담**: QuestHUD=목표 텍스트/진행도, 시계=공간 방향. 중복 아님, 보완.

### 1.2 공명 모드 — 이상현상 경고 (앰비언트)

이상현상 근처에서 초침이 불규칙하게 튀거나 멈춘다. **S-015(첫 짙은 현상)**: 현상 구간 안에서 멈춘 초침이 **탈출 방향**으로 살짝 기울어짐(1회, `watch_compass_hint_seen`) — 고장난 줄 알았던 시계가 길을 가리키는 첫 떡밥. **S-015_WATCH**(루디 접촉): "시계가 멈췄다 / 주변이 멈춘 건가?" 큰 이상. 후반엔 은밀한 위험·비밀 근접 단서로도 재사용.

### 1.3 시간 회수 — 사망 연출 (메타)

**핵심 개념**: 죽으면 시계가 **흘러간 시간을 회수**한다. (되돌림·리와인드가 아님 — **회수**가 플레이어가 배우는 말.)

**일반 사망**([raid.md]): 초침 역회전 + 회수 연출(화면·틱) → 가방 손실 → 안전가옥 풀회복 부활. 시계가 사망→부활의 **시각 앵커**.

**S-015 첫 짙은 현상 — `S-015_RECOVER` (1회 튜토리얼)**:
- 현상 구간 안 **스크립트 킬** 1회. 안전가옥 귀환 **없음** — **레이드 안**에서 부활.
- 시계가 **현상 구간 진입 이후 흐른 레이드 시간**을 타이머에서 **회수**. 가방 손실 **없음**.
- 플래그: `watch_time_recovery_tutorial_done`. **이후 모든 사망**도 같은 '시간 회수' 연출로 개념 각인.

- **데모에선 설명 없는 암시만.** "왜 죽어도 돌아오는가?" / "시간이 왜 회수되는가?" — 형이상학은 잠금 보류.
- 후반 "짙은 현상은 기억과 시간에 영향을 줌"(Act 3, [gdd-progression.md](gdd-progression.md)) 복선.
- ⚠️ **실시간 시간 조작 플레이 메커닉 아님.** S-015는 개념 1회 체험 + 일반 사망은 *연출* + 떡밥. `watch_time_recovery_tutorial_done` 이후 타르코프식 가방 손실 긴장 유지.

## 2. 시계 UI

### 2.1 형태 — ✅ 결정: B3 하이브리드 (하단 중앙 상시 + 들어올려 검사)

- **상시 (B1)**: **방향 지시**(나침반 헤딩)를 화면 **하단 중앙에 작게** 상시 표시. 작은 시계 다이얼/컴퍼스 스트립 — 초침이 현재 타겟 방향을 가리킴. 마찰 0, 전투 중에도 길 안내.
- **검사 (B2)**: 키 홀드(**M키** — Tab은 인벤토리(UIManager)가 선점)로 **시계를 들어올려** 큰 면 + 맵 상세를 봄. 월드 살짝 디밍. 깊은 정보(맵·통로 주석)는 여기서.
- 시간역행 사망 연출·공명 떨림은 두 표현 모두에서 재생(상시 위젯 떨림 → 들어올리면 더 크게).

> 배치 주의: 하단 중앙은 **빠른 사용 슬롯 4칸**([gdd-core.md](gdd-core.md) §12.2)과 인접 → 슬롯 바로 위 얇은 스트립으로 두거나 좌우로 분리. 위치는 레이아웃 시 조정.

## 3. 맵 / 미니맵 — 기반(foundation) 설계

> 사용자 요청: **"기반만"** — 아키텍처·데이터 모델·해금 훅까지. 아트·연출·폴리시는 후순위.

### 3.1 데이터 모델

- **`RaidMap`** (레이드/지역별 1개): 레벨 레이아웃을 **구역 그래프** 또는 **거친 그리드**로 보유.
  - `fog[]` — 셀/구역별 탐색 상태(미발견/발견)
  - `markers[]` — 탈출구(E0·D탈출 등, [level-scrapmarket.md](level-scrapmarket.md)), 파밍 POI, 퀘스트 목표, 플레이어 위치
  - `passages[]` — 문/통로 상태(정상·잠김·막힘·일방통행). **사일런트 힐식 자동 주석** 대상 (§3.4)
- **`MinimapController`** (HUD): 알려진 부분만 렌더. 미발견은 fog로 가림. 초기엔 추상 도형(예쁜 아트 X).
- **`MapRevealSource`** (인터페이스): 맵을 밝히는 출처를 추상화 →
  1. **탐색** — 플레이어 인접 셀 자동 공개(fog of war 베이스)
  2. **지도 아이템 획득** — 구역/전체 공개 (§3.2)
  3. **정보 거래** — 전당포에서 낮 정보 구매 → 밤 활용("낮 단서로 밤 활용" 코어 기둥)

### 3.2 해금 모델 (열린 질문 — 사용자 고민중)

| 안 | 방식 | 평가 |
|---|---|---|
| **C1 (추천)** | **구역 지도 조각** — 레이드에서 "지도 조각" 파밍 → 해당 **구역**을 미니맵에 영구 공개(+컨테이너/탈출구 마커). 조각 누적 → 전체 지역 맵 | 파밍 동기·정보경제·진행감 최상. 기존 정보 아이템(쪽지·**지도 조각**) 카테고리와 정합([gdd-core.md](gdd-core.md) §12.3) |
| C2 | **전체 지도 1개** — 맵 아이템 1개로 이번 레이드 전체 공개 | 단순·소비적, 진행감 약함 |
| C3 | **순수 fog of war** — 아이템 없이 걸으면 자동 채워짐 | 가장 단순, 단 "맵 아이템" 아이디어 폐기 / 보상 결 약함 |

→ **권장: C3(fog) 베이스 위에 C1(조각) 얹는 하이브리드.** 즉 ① 내가 직접 밟은 즉시 주변은 항상 자동 공개(절대 길 잃지 않음) + ② **가보지 않은 구역·컨테이너/탈출구 마커는 지도 조각/정보 구매로 해금**. 결과: 기본 길찾기 쾌적 + 의미 있는 맵-루팅 + 정보경제 훅.

### 3.3 영속성 — ✅ 결정: 안전가옥 지도판 누적

발견한 구역 지식·통로 주석이 [safehouse.md](safehouse.md) 지도판에 **영구 기록** → 메타 진행. "낮에 알아낸 구조를 밤에 활용" 기둥과 직결, 정보경제 강화. (레이드마다 리셋하는 안은 폐기 — 2026-06-05 결정.) 단, **고정 요소만 영속**(레이아웃·잠긴 문·컨테이너·탈출구). 확률로 막힌 문(§3.4)은 매 레이드 랜덤이라 **이번 판 한정 표기** — 영구 저장하지 않음.

### 3.4 통로 상태 표기 (사일런트 힐식) — ✅ 채택

문/통로를 **자동 주석**한다. 잠긴 문에 두 번 헛걸음하지 않게 + 다음 출격 계획을 세우게. 디제틱 — 시계와 같은 결로, 종이 지도에 손으로 끄적인 표기 느낌.

| 상태 | 표기 | 의미 / 동선 |
|---|---|---|
| 정상 | 선 없음 | 통과 가능 |
| **잠김** | 빨간 자물쇠/✕ + "열쇠?" | 특정 열쇠·자물쇠따기 필요 → **되돌아와 해금** (열쇠 경제·영속성과 직결) |
| **막힘** | 빗금/잔해 | 잔해로 막힘. [destructible.md](destructible.md) 파괴 가능 오브젝트면 도구·무기로 뚫기, 아니면 영구 차단 |
| **일방통행** | 화살표 | 반대편에서만 열림(잠긴 반대편). 막다른 길 회피 단서 |

**배치 모델 (잠김 vs 막힘):**
- **잠긴(열쇠) 문 = 수동 배치(고정).** 특정 열쇠·잠금과 연결해 레벨 디자인이 의도적으로 게이팅. 매 레이드 동일 위치 → 영속 주석이 의미 있음(열쇠 경제).
- **막힌 문 = 확률 배치(절차적).** 매 레이드 일부 통로가 **랜덤으로 막힘** → 동선이 유니크하게 변주(반복성, [replayability.md](replayability.md) "밤마다 구조 변화"와 정합). 파괴 가능 잔해면 뚫고 갈 여지.

- **주석 시점**: 플레이어가 그 문에 **닿거나 시도**하면 해당 통로만 즉시 표기 — 구역 맵 전체 해금(§3.2)과 **독립**. 가본 적 없어도 "그 문은 잠김"은 한 번 부딪히면 기억됨.
- **영속(고정만)**: 잠긴 문·컨테이너·탈출구 등 **고정 요소** 주석만 §3.3대로 지도판에 누적("저 문은 창고 열쇠 필요"가 다음 레이드에 그대로). **확률로 막힌 문은 매 레이드 재생성 → 이번 판만 표기**(영구 저장 X — 안 그러면 거짓 정보).
- 잠긴 **컨테이너**(잠긴 상자·금고, [gdd-core.md](gdd-core.md) §12.1)도 같은 방식으로 위치 마킹 가능 — "열쇠 구하면 여기 다시" 루프.
- (선택 플레이버) 사일런트 힐처럼 **어두우면 지도를 못 읽음** → 손전등/시야([rendering.md](rendering.md)) 켜야 판독. 분위기↑지만 마찰 주의 — **후순위**.

### 3.5 기반 구현 범위 (첫 삽)

1. ✅ `RaidMap` 데이터(구역 + fog + 마커/통로) → `RaidMapTypes.cs` + `RaidMapManager.cs`
2. ✅ 미니맵 HUD 스텁(탐색 구역 + 플레이어 점 + 탈출구/통로, 추상 도형) → `NavigationHUD.cs`
3. ✅ 맵 해금 훅 + 지도 아이템 reveal → `MapFragmentReveal.cs`
4. ✅ 시계 나침반 타겟 배선(튜토리얼→퀘스트→스토리→탈출구 폴백) → `CompassTarget.cs` + `NavigationHUD.cs`
5. ⬜ (후순위) 아트·`멈춘 시계` 시 맵/초침 교란 연출 + 세이브 영속

- `RaidMapManager`(데이터 매니저): `SystemsSceneBuilder` **매니저 목록** + `GameBootstrap` 폴백.
- `NavigationHUD`(UI): **UIManager UI 패널**로 편입(GameHUD·QuestHUD와 동일) — UIManager `navigationHUD` 필드 + `EnsureChildren` 폴백 + `SystemsSceneBuilder.UiPanels` 등록. 별도 자동스폰/DDOL 없음(UIManager가 생성·영속 담당).

에디터 반영은 **Tools ▸ TopDown ▸ Build ▸ Systems Scene** 재실행. Systems 미빌드 시 `GameBootstrap`(매니저)·`UIManager`(패널) 폴백이 자동 생성. `NavigationHUD`는 GameHUD처럼 항상 존재하되 **레이드 중에만 표시**.

**배선(레벨 제작 시):**
- 나침반은 **즉시 작동** — 타겟 없으면 가장 가까운 탈출구를 가리킴. 퀘스트/튜토리얼 유도는 목표 지점에 `CompassTarget`(우선순위 지정) 부착.
- 미니맵 구역: **맵 빌더(`GameSceneBuilder` → InGame)가 기본 구역 1개 자동 배치**(`MapZone_All`, 상가골목, 28×24). 디자이너가 `MapZoneVolume`을 구역별로 더 쪼개면 fog/해금이 세분화됨.
- 잠긴 문: 기존 `DoorController`(Key/Quest)에 `PassageMarker` 추가 → 자동 "잠김" 주석(+`passageId`로 영속).
- 막힌 문: `PassageMarker`의 `randomBlock` 체크 + `blockChance`(기본 0.18) → 매 레이드 확률 막힘.
- 지도 아이템: 줍기 `InteractableObject`에 `MapFragmentReveal` 추가(`revealZoneIds` 또는 전체).

**스텁/후속:** ~~세이브 영속 미연동~~ **✅ 2026-07-11 해소**(`RaidMapManager.GetSaveData/LoadSaveData` + `GameSaveData.raidMap` + 새게임 리셋 — 지역별 발견 존·통로가 실제로 누적 저장) · 아트 없음(PlaceholderSprite 도형) · 멈춘 시계 교란 연출 후순위 · 입력키 **M**(Tab 선점, 인스펙터 변경 가능).

## 4. 밸런스 / 리스크 메모

- **"시계가 항상 방향을 주면 탐험·긴장이 줄지 않나?"** → 시계는 **방향만**, 레이아웃·거리·위협은 비공개. 이상현상 중엔 초침 교란(§1.2)으로 신뢰도 흔듦. 맵의 공간 정보는 별도로 벌어야 함.
