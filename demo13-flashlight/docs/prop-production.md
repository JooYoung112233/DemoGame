# 프랍 생성 진행 추적 (씬 추출 방식)

> **제작 방식 = 통일(2026-06-10): 맥락 씬 1장 생성 → 개별 프랍 슬라이스.** 낱개 그리드 시트 방식 폐기.
> 한 이미지 안에서 각도·화풍·조명·팔레트가 자동 통일됨(드리프트 해결). 같은 씬으로 방 배경 + 프랍 동시 확보.
> 표준 = [`topdown-art-spec.md`](topdown-art-spec.md) ✅프랍 생성 표준 (70° 윗면1/3·정면마주보기·LOW 디테일·짙은톤).

## 씬 제작 2대 규칙 (필수)
1. **평면 균일 조명 (flat lighting)** — 베이크된 방향 그림자·어두운 구석 금지. 잘라낸 프랍을 엔진 2D 라이트가 비추므로. (씬이 분위기로 어두우면 슬라이스가 못 씀)
2. **프랍 간격 띄우기** — 서로 겹치지 않게 배치(슬라이스 쉽게). 바닥은 단순/중립 톤.
- 레퍼: 매 씬에 **하이드아웃·전당포·거리 통과 시트** 첨부(화풍 고정).
- 차량은 방향(가로/세로) 포함, 벽장식·천장·외벽·간판·바닥·데칼은 **평면 플랫 시트**(씬 아님).

## 방향 변형 (orientation)
- 대칭 프랍 = 1장. 방향성 프랍(소파·침대·책상·사물함 등) = 앞 + 가로(플립으로 4방향).
- 씬에서 슬라이스한 건 보통 앞 1방향 → 방향성 프랍은 **가로(측면) 패스 별도**(앞 슬라이스 첨부 "rotated 90°").
