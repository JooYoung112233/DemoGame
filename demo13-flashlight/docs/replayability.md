# 반복성 · 엔드게임 Progression (검토 중)

> PvE 루팅 게임의 구조적 약점("파밍/돈벌이가 물린다")을 해결하기 위한 시스템 방향.
> **상태: 검토 중 (확정 아님)** — 2인 개발 제약 하에서 우선순위 논의 단계.

---

## 문제 정의 (2026-05-29)

**PvE 루팅의 구조적 천장:**
- PvE는 "정답"이 있음 → 적 패턴/루트/동선이 외워지면 긴장이 사라지고 작업(作業)이 됨
- 돈벌이가 안정적으로 예측되는 순간 "설렘"이 "계산"으로 바뀜
- 타르코프가 안 질리는 진짜 이유는 PvP(무한 변수 생성기)인데, PvE는 그 변수를 직접 다 만들어야 해서 비쌈

**핵심 원칙:**
> 돈은 절대 메인 목표가 되면 안 된다. 돈은 윤활유, 진짜 엔진은 "해금/성장/서사적 호기심".

---

## 검토 중인 시스템 (우선순위순)

### 🥇 1. 장비 부품 모딩 (수리 X → 개조 O)
- **상태:** 강력 추천, 1순위 후보
- 단순 수리가 아니라 **부품을 달아서 장비를 강화**
- 네트코드/AI 불필요 → **데이터 + UI 시스템**이라 2인 개발에 적합
- 효과: **부품 자체가 파밍 목표**가 됨 (돈이 아니라 부품이 당근)
- 같은 무기여도 빌드에 따라 플레이가 갈림 → 싸게 만드는 깊이
- **미해결 질문:** 장비 강화의 "끝"이 있나, 무한인가? (엔드게임 설계 vs 밸런스 인플레 관리)

### 🥈 2. 레이드 지역 격상 (위험 다이얼)
- **상태:** 강력 추천, 1순위 후보 (모딩과 묶음)
- "맵 변경"의 똑똑한 우회로 — 지형을 안 바꾸고 맵을 *변수*로 만듦
- 플레이어가 일부러 구역을 격상 → 적 강해짐/많아짐 → 비싼 아이템 풀림
- = 플레이어가 스스로 긴장도를 조절하는 risk/reward 노브
- 구현은 사실상 **파라미터 곱셈** (스폰 수×, 적 티어×, 루트 테이블 격상) → 콘텐츠 제작이 아니라 수치 시스템이라 저비용

**1+2 시너지 (자가발전 루프):**
```
지역 격상 → 위험↑ → 고급 부품 드롭 → 장비 강화 →
더 높은 격상 감당 → 더 비싼 보상 → …
```
→ 돈을 메인에서 빼고 "부품으로 장비를 키우는 것"을 progression 축으로.

### 🥉 3. 밴딧 생태계
- **상태:** 검토 중, 스코프 축소 전제
- 풀버전(세력 전쟁, 영역 다툼)은 AI 작업 지옥 → 2인엔 무리
- 축소 버전 가능: 밴딧 캠프 + 가끔 순찰/추격 + 서로 싸우는 연출
- "예측 불가능"을 일부 흉내냄. 위 두 개보다 비쌈

### ⚠️ 4. Co-op 멀티플레이 (좀보이드식)
- **상태:** 장기 목표, 당장은 보류
- 변수 생성기로는 최강(사람 = 무한 변주)
- 단, 실시간 루팅 서바이벌 동기화(적 AI/루트 상태/낮밤/전투)는 2인 개발에 시간 블랙홀
- Co-op은 PvP보다 쉬움(안티치트/래그보정 불필요)
- **권고:** 싱글로 재미 검증 먼저 → 코드를 멀티 가능하게 설계만 해두기. 멀티는 "재미가 증명된 게임"에만 거는 베팅
