## 2. ⚠️ 적용 상태 — "생성됨 ≠ 게임 적용됨"

- **아이템 아이콘**: 시트 34장 생성됨 but **게임 SO 할당 0/204**(items.md §분량). → **슬라이스 + ItemData.icon 연결**이 남은 핵심 작업.
- **NPC/프랍/전당포 등**: 생성됨, 씬·프리팹 적용은 부분적(그레이박스 단계). → 정식 스프라이트 연결 필요.
- 즉 **"만든 것"의 다수가 아직 인게임에 안 붙음** — 생성보다 **통합(슬라이스·연결·임포트 셋업)**이 병목.
