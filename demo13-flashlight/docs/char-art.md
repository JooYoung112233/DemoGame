# 캐릭터 · 적 아트/애니메이션 리스트

> **목적**: 플레이어·적·NPC의 애니메이션(모션) 제작 단위를 전부 펼친 리스트.
> **작업 체크리스트: [`char-anim-list.csv`](char-anim-list.csv)** (46행) — 대상/캐릭터/분류/상태/그립·변형/프레임/우선순위.
> 작성: 2026-06-10. 상위 개요 [`art-needs.md`](art-needs.md) §1, 전투 수치 [`combat.md`](combat.md), 스타일 [`topdown-art-spec.md`](topdown-art-spec.md), 적 로스터 [`gdd-core.md`](gdd-core.md) §10.

## 1. 핵심 원칙 — "리그는 공유, 스킨만 교체"

적 대부분이 **인간형(밴딧·약탈꾼·배회자…)** 이다. 같은 Spine 스켈레톤 1개를 만들고
**텍스처(스킨)만 교체**하면 모션을 전부 재사용할 수 있다. → 모션은 한 번, 외형만 타입별로.

| 항목 | 처리 | 제작 단위 |
|---|---|---|
| **인간형 적 모션** | 공용 리그 1개 (Idle/Chase/공격/피격/그로기/사망 등) | **10 클립 1회** |
| **인간형 적 외형** | 타입별 스킨/텍스처 교체 | **타입당 1 스킨** (8종) |
| **무기 클래스 추가 모션** | 원거리(조준/발사)·탱크(방패자세)만 추가 | +3 클립 |
| **이상체(비인간형)** | 외형이 달라 전용 리그 필요 | 별도 6 클립 + 변종 스킨 |
| **방향** | 측면(동/서) 1방향 제작 → **좌우 플립** | 상/하/대각은 2차 |
| **손상/오염** | 캐릭터는 셰이더 `_FlashAmount`(피격 플래시)만, 손그림 X | 코드 |

## 3. 플레이어 (P1 최우선)

**스펙**: 3등신 SD, 곱슬 흑발·마른 체형·올리브 셔츠·카고팬츠·갈색 부츠. 128×128, 80° 베이크, 플랫 셰이딩.
**무기는 손 본(hand bone) 어태치** → 그립별 자세만 다르고 무기 스프라이트는 갈아끼움.

| 분류 | 모션 | 변형 | 프레임 |
|---|---|---|---|
| 이동 | Idle · Walk | 그립 4종(맨손/한손/양손/총) | Idle ~4 / Walk ~8 |
| 이동 | Run | 공용 | ~8 |
| 행동 | 약공 콤보 | Light1(6)·Light2(6)·Light3(8) | 판정 프레임 정의 필요 |
| 행동 | 강공 | Heavy(7)·HeavyFull(9)·차징루프 | 히트스탑 0.05~0.06 |
| 행동 | 구르기·피격·사망 | Dodge(~5)·Hit(~3)·Dead(~6) | 구르기 0.2초 무적 |

> **첫 산출물 = 플레이어 측면 1세트.** 이게 전체 캐릭터의 화풍 마스터 레퍼가 된다(적·NPC가 여기에 맞춤).

## 4. 적 로스터 (gdd-core §10 기준)

### 4-1. 낮 적 (적고 약함 — 학습용)
| 적 | 키(가안) | 타입 | 우선 |
|---|---|---|---|
| 배회자 | `wanderer` | 인간형 스킨 | P2 |
| 약탈꾼 잔당 | `scavenger` | 인간형 스킨 | **P1**(폐상가) |
| 잠복자 | `lurker` | 인간형 스킨 | P2 |

### 4-2. 밤 적 — 밴딧 (인간형, 플레이어와 비슷한 전투 규칙)
> gdd는 "밴딧"을 단일군으로 정의. 아래 세부 타입은 코드(`bandit_melee`)·NPC 문서 기반 **변형 제안**.

| 적 | 키(가안) | 추가 모션 | 우선 |
|---|---|---|---|
| 밴딧 근접 | `bandit_melee` | (공용) | **P1** |
| 밴딧 원거리 | `bandit_ranged` | 조준·발사/투척 | P2 |
| 밴딧 탱크 | `bandit_tank` | 방패자세·대형 scale | P2 |
| 밴딧 협상꾼 | `bandit_negotiator` | (공용+대화) | P2 |

### 4-3. 밤 적 — 몬스터 (이상현상 연결)
| 적 | 키(가안) | 타입 | 우선 |
|---|---|---|---|
| 이상체 | `anomaly_creature` | **전용 리그** | P3 |
| 오염 변종 | `corrupted_bandit` | 밴딧 리컬러+이펙트 | P2 |

### 4-4. AI 상태 → 모션 매핑 (EnemyController)
```
Patrol(Idle/배회) → Chase(Walk) → AttackWindup(예비 0.8초·빨강깜빡)
   → Attack(공격) → Hit(피격) → 복귀
   → 그로기 가득 → Stunned(무방비 2초) → Dead(쓰러짐)
```
인간형은 이 7개를 **공용 리그에서 1회 제작**, 원거리/탱크만 +조준·발사·방패 추가.

## 5. NPC (상세는 art-needs §1)

- 대부분 **고정 상주** → 전신 Idle(고개 끄덕임) 정도. 이동 애니 불필요.
- **대화 포트레이트 표정 6종**(중립/호의/분노/슬픔/놀람/의심)이 핵심 — DialogueUI용.
- 8종: 전당포 주인(강무진·마스터레퍼)·회수꾼·구역 관리인·떠돌이상인·밴딧 협상꾼·생존자·노점상·의사.
- **앵커 트릭**: 신규 캐릭터 생성 시 합격본(플레이어 또는 전당포 주인)을 같은 시트에 앵커로 넣어 화풍 드리프트 방지 → 앵커는 버리고 새 것만 추출.

## 6. 기술 메모

- **현재 구현**: Spine 런타임 설치(`Assets/Spine`). 플레이어 공격은 프레임 기반 런타임 정의(`TopDownPlayer.EnsureDefaultAttacks`)만 있고 **실제 스프라이트/애니 미제작**(비주얼 대기).
- **적 기존 자산**: 구버전 `enemy_1~4.png`(텍스처화 안 됨) — 신규 스타일로 교체 대상.
- **피격 연출**: 적 = 셰이더 흰 플래시(엔티티) / 플레이어 = 화면 연출(비네트·색수차) — 분리 ([`combat.md`](combat.md)).

---

## 7. 제작 순서

1. **플레이어 측면 1세트(18클립)** — 화풍 마스터 확정
2. **인간형 공용 리그 + 모션(10클립)** + **P1 스킨**(약탈꾼 잔당·밴딧 근접)
3. 나머지 인간형 스킨(배회자·잠복자·원거리·탱크·협상꾼·오염변종) + 무기 추가 모션
4. **이상체 전용 리그**(밤/현상 단계)
5. NPC 포트레이트 표정 시트 → 전신 Idle
