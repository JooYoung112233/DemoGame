# 온보딩 — 「소식지」 전면 UI (신문 컨셉)

> 현 상태 = 진실. 결정이 바뀌면 덮어쓰고 변경 로그에 추가.
> 관련: [story-script.md](story-script.md)(프롤로그=코어 루프 온보딩), [quests-region1.md](quests-region1.md)(메타 시스템 해금), [safehouse-intel.md](safehouse-intel.md)(라디오 소식).

## 1. 문제 — 프롤로그만으론 부족

- **프롤로그(S-000~S-018)** = 코어 루프 온보딩으로 충분(인벤·전당포·게시판·레이드·거처·수면·탐지등·루디·납품). ✅
- 그러나 **메타 시스템**(평판·BD 일일·NQ·하이드아웃 모듈·파견·라디오·물물교환·보관함·지하철)은 **전부 prologue_complete 이후 해금** → 프롤로그 밖.
- 프롤로그 직후 한꺼번에 열리면 **압도**(시스템 13+). → **계단식 해금 + 한 번에 하나씩 가르치기** 필요.

## 2. 해법 — 소식지(신문) 전면 UI

> **시스템이 처음 해금되는 순간, 신문 한 면이 전면에 뜬다.** 그 시스템이 "뭐고 어떻게 쓰나"를 기사 한 면으로 크게.

- **세계관 정합**: 전기 끊긴 봉쇄 도시 = 종이 정보가 귀함. 거점에 도는 **수기/등사 소식지**(거점 소식판) 또는 옛 신문 클리핑. **라디오(음성 상시 소식)와 짝** — 신문=해금 안내(1회), 라디오=상시 소식·리드.
- **형식**: 전면 1면 = **제호(masthead) + 굵은 헤드라인 + 짧은 본문(설명 3~5줄) + 컷(일러스트/아이콘 1)**. 탈색·그리미 인쇄 톤.
- **1회성**: 해금 시 1번. 닫으면 끝. **거점 소식판/아카이브에서 재열람**(놓쳐도 다시 봄).
- **저비용**: **신문 템플릿 1종**(레이아웃·프레임 고정) + **텍스트·컷만 교체**. 아트 부담 최소.
- **부가 가치**: 각 호에 **세계관 한 조각**(도시 소식·소문)을 곁들여 worldbuilding 채널로도 사용. 2지역 떡밥도 후반 호에 실을 수 있음.

## 3. 발행 목록 (해금 트리거 → 소식지)

> "한 번에 하나, 풀리는 순간에, 첫 사용을 손 잡고." 해금을 일부러 **수 시간에 걸쳐 계단식**으로 늦춰 학습 곡선 분산.

| # | 해금 트리거 | 헤드라인(예) | 가르치는 것 |
|:-:|------------|-------------|------------|
| 1 | `prologue_complete` | **"게시판에 일감이 붙다"** | 게시판 BD 일일 + 평판 등급 |
| 2 | 거처 획득(S-010) | **"내 집, 그 다음은"** | 하이드아웃 창고·침실 |
| 3 | NQ-M02 제작 도면 | **"수리공의 손길"** | 작업대·의료대(제작) |
| 4 | SQ-001 생존자 구출 | **"구인 — 회수 인력 모집"** | 파견(인력·인텔) |
| 5 | 발전기→라디오 가동 | **"다시 들리는 목소리"** | 라디오 소식·리드 |
| 6 | 떠돌이 재방문 | **"장터, 물물교환 개시"** | 물물교환(barter) |
| 7 | 첫 보관함 입수 | **"정리정돈 특집"** | 보관함 카테고리·내부 격자 |
| 8 | 평판 B+ | **"멈춘 지하철"** | SQ-003 캡스톤 → 2지역 훅 |

- 트리거는 quests-region1의 해금 게이트(평판·NQ-M·SQ)와 1:1. 새 플래그 최소.
- 코어 루프(인벤·전투·탐지등 등)는 **프롤로그가 담당** → 소식지는 **메타 전용**.

## 4. 소식지 본문 골격 (예시 1·4)

```
[1면] ───────────────────────────────
  폐상가 소식판                    제N호
  ═══════════════════════════════════
  ▌ 게시판에 일감이 붙다
  이름값을 쌓은 회수꾼에게 게시판이
  매일 일감 두 장을 내건다. 수령은
  게시판, 보고는 의뢰인. 평판이 오르면
  더 굵직한 의뢰가 붙는다.
  [컷: 못질된 게시판]
─────────────────────────────────────

[4면] ───────────────────────────────
  폐상가 소식판                    제N호
  ═══════════════════════════════════
  ▌ 구인 — 회수 인력 모집
  거처에 사람을 들이면, 가본 곳으로
  내보내 정보를 가져오게 할 수 있다.
  자원이 아니라 "어디에 뭐가 있다"를.
  장비를 들려 보낼수록 성공률이 오른다.
  [컷: 배낭 멘 실루엣]
─────────────────────────────────────
```

## 5. 구현 메모

- **`NewspaperUI`**(전면, Systems 씬 상주) — 헤드라인/본문/컷을 데이터로 받아 템플릿에 렌더. uGUI, 1920×1080.
- **`NewspaperData`**(SO): issueId, 트리거 플래그, 헤드라인, 본문, 컷 스프라이트, worldbuilding 줄(선택).
- **트리거**: `StoryTriggerManager`/해금 이벤트 → 첫 1회 `NewspaperUI.Show(issue)` + one-shot 기록(`TutorialPrompt` 패턴 재활용).
- **아카이브**: 거점 소식판 오브젝트 → 발행분 재열람(놓침 방지).
- 한글 = 동적 폰트(Malgun Gothic, NoteUI 패턴).
