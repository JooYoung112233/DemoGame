# 안전가옥 시스템

## 현재 상태: 방향 확정

## 확정된 방향

**덕코프식 물리 공간 + 오브젝트 배치 성장**

- 컨테이너 1개를 탑다운 물리 공간으로 구현
- 플레이어가 직접 걸어다니며 시설과 상호작용
- 업그레이드 = 같은 컨테이너에 시설 오브젝트가 추가/개선되는 방식
- 방 자체를 바꾸지 않음 (낙원식 등급별 방 변경 X)
- 복잡한 정보(제작 레시피, 업그레이드 트리 등)는 메뉴 UI로 처리
- 기존 탑다운 이동/상호작용/조명 시스템 재활용

### 레퍼런스

| 게임 | 참고 요소 |
|---|---|
| 덕코프 (Escape from Duckov) | 쿼터뷰 물리 은신처, PvE 익스트랙션 루프 |
| 타르코프 | 시설 업그레이드 트리 구조 참고 |
| 낙원 (LAST PARADISE) | 시각적 성장 느낌 참고 (방 버전 교체는 제외) |

### 결정 사항

1. 안전가옥은 물리 공간으로 걸어다닌다 ✅
2. 시설 상호작용은 직접 접근 후 상호작용 ✅
3. 습격 방어 이벤트 — 추후 결정 (초기 데모에서 보류)
