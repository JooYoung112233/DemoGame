# 안전가옥 시스템

## 현재 상태: 방향 확정 + 확장 기획 확정

## 확정된 방향

**덕코프식 물리 공간 + 오브젝트 배치 성장**

- 컨테이너 1개를 탑다운 물리 공간으로 구현
- 플레이어가 직접 걸어다니며 시설과 상호작용
- 업그레이드 = 같은 컨테이너에 시설 오브젝트가 추가/개선되는 방식
- 방 자체를 바꾸지 않음 (낙원식 등급별 방 변경 X)
- 복잡한 정보(제작 레시피, 업그레이드 트리 등)는 메뉴 UI로 처리
- 기존 탑다운 이동/상호작용/조명 시스템 재활용

### 레퍼런스

| 게임 | 참고 요소 |
|---|---|
| 덕코프 (Escape from Duckov) | 쿼터뷰 물리 은신처, PvE 익스트랙션 루프 |
| 타르코프 | 시설 업그레이드 트리 구조 참고 |
| 낙원 (LAST PARADISE) | 시각적 성장 느낌 참고 (방 버전 교체는 제외), 가구 구매 시스템 참고 |

### 결정 사항

1. 안전가옥은 물리 공간으로 걸어다닌다 ✅
2. 시설 상호작용은 직접 접근 후 상호작용 ✅
3. 습격 방어 이벤트 — 추후 결정 (초기 데모에서 보류)

## 맵 레이아웃: 뒷골목 (Back Alley)

### 컨셉

안전가옥 = **철조망으로 둘러싼 넓은 공터 (달동네/판자촌)**. 건물 없이 천막/컨테이너/노점 같은 임시 구조물만 배치.
철조망 너머로 폐도시가 보여서 "안전한 안쪽 vs 위험한 바깥"의 시각적 긴장감 상시 유지.
오브젝트는 **슬롯 방식** — 초기에는 전당포 + 컨테이너만 있고, 진행에 따라 빈 슬롯에 새 시설이 해금.

### 쿼터뷰 맵 구조 (위에서 본 그리드, ~16x12)

```
  ═══════ 철조망 펜스 (바깥: 폐도시 스카이라인) ═══════
  ║                                                    ║
  ║  [A1: 전당포]                      [B1: 빈 슬롯]    ║
  ║   천막+카운터+NPC                   → 수리점         ║
  ║                                                    ║
  ║  [A2: 컨테이너 창고]               [B2: 빈 슬롯]    ║
  ║   📦📦📦 L자 배치                  → 가구점         ║
  ║                                                    ║
  ║          ╔═══ 넓은 공터 ═══╗                       ║
  ║          ║  🔥 드럼통불    ║                        ║
  ║          ║  💡 가로등     ║                        ║
  ║          ║  🧍 플레이어   ║                        ║
  ║          ╚════════════════╝                        ║
  ║                                                    ║
  ║  [A3: 빈 슬롯]                    [B3: 빈 슬롯]    ║
  ║   → 블랙마켓                       → 의료소         ║
  ║                                                    ║
  ║        [게시판]    ═══ [철창문/게이트] ═══           ║
  ═══════════════════════════ → 폐도시 (레이드) ════════
```

### 시설 슬롯 시스템

| 슬롯 | 위치 | 초기 상태 | 해금 후 |
|------|------|----------|--------|
| A1 | 좌상단 | **전당포** (천막 노점, NPC 매매+퀘스트) | - |
| A2 | 좌중단 | **컨테이너 창고** (컨테이너 2~3개) | - |
| A3 | 좌하단 | 빈 공터 (드럼통+타프) | 블랙마켓 (정보 거래) |
| B1 | 우상단 | 빈 공터 (잡동사니 더미) | 수리점 (작업대+도구벽) |
| B2 | 우중단 | 빈 공터 (팔레트+빈 상자) | 가구점 (천막 딜러) |
| B3 | 우하단 | 빈 공터 (접이식 테이블) | 의료소 (천막 클리닉) |

### 빈 슬롯 비주얼

- 초기: 빈 땅 + 최소 잡동사니 (드럼통, 팔레트, 빈 상자 등)
- 해금 시: 천막/타프 설치 + NPC 등장 + 시설 오브젝트 배치
- **건물 없음** — 모든 시설은 천막/노점/임시 구조물

### 외벽: 철조망 펜스

- 녹슨 철조망 메쉬 + 금속 기둥
- 상단 가시철사 코일
- 일부 구간 합판/물결 철판/타프로 보강 (패치워크)
- 펜스 너머로 폐도시가 보임 → 안/밖 대비

### 공터 오브젝트 (분위기)

- 불 피운 드럼통, 가로등(작동 1개), 발전기(꺼짐)
- 플라스틱 의자, 케이블 릴 테이블, 우유 상자 좌석
- 빨래줄, 잡초, 물웅덩이, 산탄 타이어
- 바닥: 갈라진 아스팔트 + 흙, 바래진 주차선

### 게시판 + 철창문 구역

- 게시판: 철창문 옆, 존 선택 (InteractType.MapBoard)
- 철창문: 넓은 더블도어 게이트 (차량 통과 가능 폭), 체인+자물쇠
- 게이트 너머: 폐도시로 이어지는 도로

### 맵 규모 (타일 기준)

- **총 맵: ~16x12 타일** (넓은 공터)
- **중앙 빈 공간: 최소 6x6 타일** (넓은 보행 공간)
- 캐릭터가 맵 안에서 작게 보일 정도의 스케일

### 카메라

- 쿼터뷰 고정 카메라 (기존 InGameScene과 동일 각도)
- 전체 맵이 한 화면에 거의 보이는 줌 레벨
- 플레이어 이동에 따라 부드럽게 팔로우 (CameraFollow 재활용)

## 재화 시스템

| 재화 | 용도 | 획득 |
|---|---|---|
| **루디 (Rudy)** | 기본 재화. 시설 구매/업그레이드, NPC 거래 | 레이드 파밍, 아이템 판매 |
| (추가 재화) | 추후 확장 가능 (프리미엄, 특수 등) | 미정 |
| **특수 재료** | 시설 업그레이드 부자재 (고철, 나사, 천 등) | 레이드 파밍 |

- 기존 `sellPrice`/`buyPrice`의 단위를 "스크랩 코인" → "루디"로 변경
- 시설 구매/업그레이드 비용 = 루디 + 특수 재료 아이템

## 창고 시스템 (가구 기반)

### 핵심 개념

창고 = **카테고리별 전용 가구**. 낙원처럼 NPC에게 가구를 구매하여 안전가옥에 배치.

### 가구 종류

**SO 경로**: `Assets/Resources/Data/Furniture/` — `Tools > Night City > Generate Default Furniture` 로 재생성 가능.

**Interactable Creator 프리셋** (창고 + `SafehouseStorage` + FurnitureData 자동 연결):

| 프리셋 | 오브젝트 이름 | FurnitureData | 프롬프트 |
|--------|---------------|---------------|----------|
| 냉장고 | `Fridge` | `fridge.asset` | 냉장고 열기 |
| 서랍장 | `Drawer` | `drawer.asset` | 서랍 열기 |
| 무기거치대 | `WeaponRack` | `weapon_rack.asset` | 무기 꺼내기 |
| 책장 | `Bookshelf` | `bookshelf.asset` | 책장 열기 |
| 재료함 | `MaterialBin` | `material_bin.asset` | 재료함 열기 |
| 금고 | `Safe` | `safe.asset` | 금고 열기 |

| 가구 | 허용 카테고리 | 기본 격자 | 비고 |
|---|---|---|---|
| **일반 상자** (`box_basic`) | 전체 (제한 없음) | 4x4 | 범용 창고, 프리셋 「창고 (범용)」 |
| **냉장고** | Consumable (음식/음료) | 3x5 | 음식물 전용 |
| **서랍** | Medical, Consumable, Misc | 5x3 | 소형 잡화 |
| **무기 거치대** | Weapon | 6x2 | 무기 전용, 가로형 |
| **책꽂이** | Key, Misc (문서류) | 3x4 | 열쇠/쪽지/문서 |
| **재료함** | Material | 4x5 | 제작 재료 전용 |
| **금고** | Valuable | 3x3 | 귀중품 전용, 비쌈 |

### 규칙

- **카테고리 제한**: 전용 가구에 안 맞는 카테고리 아이템은 **배치 불가**
- **범용 상자**: 카테고리 제한 없음 (아무거나 보관 가능)
- **복수 보유**: 같은 가구를 여러 개 구매 가능 (냉장고 2대, 상자 3개 등)
- **NPC 구매**: 안전가옥 NPC에게 루디 + 재료로 구매
- **물리 배치**: 구매한 가구는 안전가옥 공간에 오브젝트로 배치됨

### 데이터 구조 (설계안)

```
FurnitureData (ScriptableObject)
├── furnitureId     : string ("box_basic", "fridge", "weapon_rack" 등)
├── displayName     : string ("일반 상자", "냉장고")
├── gridWidth       : int (격자 가로)
├── gridHeight      : int (격자 세로)
├── allowedCategories : ItemCategory[] (허용 카테고리, 빈 배열=전체 허용)
├── buyPriceRudy    : int (루디 가격)
├── buyMaterials    : MaterialCost[] (필요 재료)
├── sprite          : Sprite (가구 스프라이트)
└── description     : string
```

```
SafehouseStorage (리팩터링 필요)
├── ownedFurniture  : List<FurnitureInstance> (보유 가구 목록)
│   ├── data        : FurnitureData
│   ├── grid        : InventoryGrid (각 가구별 독립 격자)
│   └── position    : Vector3 (안전가옥 내 배치 위치)
```

### 구매 흐름

1. 안전가옥 NPC에게 말을 건다
2. 가구 상점 UI → 구매할 가구 선택
3. 루디 + 재료 확인 → 구매
4. 안전가옥에 가구 오브젝트 자동 배치 (또는 플레이어가 위치 선택)
5. 이후 해당 가구에 다가가서 상호작용 → 전용 격자 열림

## 제작 시스템

**레시피 SO · 에디터 절차**: [`crafting.md`](crafting.md) — `Assets/Resources/Data/Recipes/` → Create → Night City → Recipe Data.

**제작 UI (구현됨)**: `MedicalBench` / `CookingBench` / `Workbench` 타입 `InteractableObject`에 **E** → `CraftingUI`. 씬·Creator로 직접 배치.

### 의료대 — 일회용 치료템 전용

- **제작 가능**: 일회용(스택) 치료템만 (붕대, 부목, 거즈, 진통 패치 등)
- **제작 불가 / NPC 구매**: 고급 치료템 (구급상자, 봉합 키트, 수술 키트, 모르핀 등)
- 레이드에서 파밍한 재료(`cloth_rag`, `chemical_flask` 등)로 제작
- 의료대 레벨업 → 제작 가능 종류 확장

### 조리대 — 음식 재료 → 버프 음식

- 레이드에서 **음식 재료** (식재료 아이템)를 가져와 조리
- 조리 결과물은 **이로운 버프** 부여:
  - 피로도 회복량 증가
  - 수분 회복량 증가
  - 일정 시간 체력 재생
  - 스태미나 회복 속도 증가 등
- **레시피**: 맵에서 레시피 아이템을 루팅하여 해금 (새 아이템 카테고리 추가)
- 조리대 레벨업 → 고급 레시피 해금, 버프 효과 강화
- 낙원 참고: 기본 음식 대비 조리 음식이 확실히 나은 보상

### 작업대 — 레시피 해금 + 수리

**레벨 없음, 레시피 해금 방식** (조리대와 동일 패턴)
- 작업대 자체에 레벨 개념 없음
- 맵에서 **무기/도구 제작 레시피**를 루팅하거나 NPC에게 구매하여 해금
- 해금된 레시피 + 재료 → 제작
- 작업대 업그레이드(설치 개선)가 필요한 경우: **루디 + 재료** (타르코프식 비용)

**수리 시스템**
- **재료 소모형**: 수리할 때마다 재료(고철, 천 등) 소비
- 내구도 완전 회복이 아닌 **일부 회복** (예: 1회 수리 = +30%)
- 수리 재료는 무기 종류에 따라 다름 (금속 무기 → 고철, 가죽/천 계열 → 천 조각 등)

**내구도 0 처리: 사용 불가 (파괴 아님)**
- 내구도 0 → 장착/공격 불가, 인벤에 남아있음
- 작업대에서 수리하면 부활
- 좋은 무기를 잃는 억울함 방지, 수리 동기 유지
