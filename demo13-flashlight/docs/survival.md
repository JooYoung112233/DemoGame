# 생존 스탯 (Survival)

## 개요
플레이어는 **4개 생존 스탯**으로 관리된다. 전투 자원(체력·기력)에 더해 **허기·수분**을 도입(2026-06-05)하여, "자고 → 배고프고 목말라 → 보급하러 나가는" 생존 루프를 만든다.

> 체력·기력은 기존 시스템(→ [medical.md](medical.md), [combat.md](combat.md) §8.5). 허기·수분이 신규 축.

---

## 1. 4대 스탯

| 스탯 | 범위 | 감소 요인 | 회복 요인 | 고갈(0) 시 |
|------|------|----------|----------|-----------|
| 체력 (HP) | 0~100 | 피격·환경·아사/탈수 | 수면, 의료(붕대 등) | 사망 |
| 기력 (Stamina) | 0~100 | 달리기·공격·구르기, 허기/수분 부족 | 자연 회복(평소), 수면(즉시 풀), 커피·에너지바 | 탈진(행동 불가·그로기 취약) |
| 허기 (Hunger) | 0~100 | 시간 경과·활동(레이드)·수면 | 음식(통조림·에너지바 등) | 체력 서서히 감소(아사) |
| 수분 (Thirst) | 0~100 | 시간·활동·수면 (허기보다 빠름) | 물(물병 등) | 기력 회복·최대 저하 → 지속 시 체력 감소 |

- 시작값: 전부 100 (첫 거처 진입 S-011 기준).

---

## 2. 구간 & 페널티

| 구간 | 수치 | 상태 | 효과 |
|------|------|------|------|
| 정상 | 70~100 | — | 페널티 없음 |
| 주의 | 31~69 | HUD 아이콘 점멸 | 경고만 |
| 위험 | 1~30 | 비네트 경고 | 기력 최대치·회복률 ↓ (이동·전투 불리) |
| 고갈 | 0 | 적색 비네트 | 허기 0 = 체력 지속 감소 / 수분 0 = 기력 급감 + 체력 감소 |

- 허기·수분 둘 다 위험 이하면 페널티 가중.
- 수치/감소율은 밸런싱 **가안** — 조정 가능.

---

## 3. 감소율 (가안)

| 행동 | 허기 | 수분 |
|------|------|------|
| 레이드 1회(낮 한 바퀴) | -15 | -20 |
| 수면 1회 | -25 | -25 |
| 안전가옥 상주(시간 경과) | 완만(분당 미세) | 완만 |

> 수분이 허기보다 빨리 닳아 "물 먼저" 압박을 준다.

---

## 4. 회복 아이템 (→ [items.md](items.md))

| 아이템 | 효과 | useEffect |
|--------|------|-----------|
| 통조림 (canned_food) | 허기 +40 | Eat |
| 물병 (water_bottle) | 수분 +45 | Drink |
| 에너지바 (energy_bar) | 허기 +15 + 기력 회복 | Eat + RestoreStamina |
| 커피 (coffee) | 기력 회복↑ (수면욕 디버프 완화) | RestoreStamina |

- useEffect 매핑: `Eat`(허기) / `Drink`(수분) / `RestoreStamina`(기력). `effectValue` = 회복량.
- 기존 `Food` useEffect는 `Eat`/`Drink`로 세분(구현 시 enum 확장).

---

## 5. 수면 (거처 — 박스 침상)

거처(컨테이너)의 **박스 침상**에 E → "잘까?" → 수면.

- **회복**: 체력 100%, 기력 100%.
- **소모**: 허기 -25, 수분 -25.
- **시간 경과**: 낮↔밤 전환 트리거(레이드 타이밍 제어).
- **게임 저장**: 수면 = 세이브 포인트(SaveManager).

**트레이드오프**: 자면 전투력은 회복되지만 배고픔·갈증이 누적 → 보급 동기.

**핵심 루프**:
```
수면(체력·기력 회복 / 허기·수분 ↓)
  → 허기·수분 경고
  → 떠돌이 상인 보급(스크랩으로 물·통조림)
  → 스크랩 부족 시 잡템 판매·민간 의뢰로 충당
  → 레이드(루디 회수 + 생필품 소모)
  → 귀환·수면 …
```

## 6. 음식 신선도 / 부패 (추후 구현)

- 음식 아이템에 **신선도(0~100%)** 또는 유통기한 부여.
- 시간 경과로 부패 진행 → 부패 시 허기 회복량 ↓ + 식중독 디버프(개그성 페널티).
- **보존식**(통조림·건조식)은 부패 매우 느림/없음 / **신선식**(빵·고기 등)은 빠름.
- 아이스박스 보관 시 부패 속도 ↓ (§7).

## 7. 온도 / 냉장 — 아이스박스 (추후 구현)

- **아이스박스 = 창고물품(컨테이너형 아이템)** — 창고(stash) 안에 놓는 케이스. 물리 가구 아님. [→ inventory.md]
- **음식 보관**: 부패 주기 지연(냉장).
- **음료 보관**: '시원함' 상태 부여 → 마실 때 **수분 회복량 +보너스**(시원한 물이 갈증을 더 해소).
  - 시원함은 시간이 지나면 미지근해짐(상온화) → 보너스 소멸.
- 전기 끊긴 세계 설정상 전력 불요(얼음·단열식) 가정 — 상세 추후.

## 기획 결정 로그

### 2026-06-05 — 생존 스탯(허기·수분) + 수면 루프 도입
- **질문**: 거처 수면 시 회복/소모 규칙은? 생존 루프를 어떻게 거는가?
  - **결정**: 4대 스탯(체력·기력·허기·수분). **수면 = 체력·기력 100% 회복 + 허기/수분 각 -25.** 허기/수분 위험 시 기력 페널티, 0 시 체력 감소. 보급(음식·물) 필요 → 떠돌이 상인 구매 동기로 연결. (수치 가안.)
  - **근거**: "자고 일어나면 배고프다"는 트레이드오프로 상점·레이드 루프를 강제. items.md의 '포만감/갈증(추후)' 미정의분을 실제 수치(통조림 허기+40 / 물병 수분+45)로 확정.
  - **연동**: [story-script.md](story-script.md) S-011(수면·정리·저장)·S-012(보급), [economy.md](economy.md) 스크랩 화폐, [safehouse.md](safehouse.md) 박스 침상.

### 2026-06-05 — 음식 부패 + 아이스박스(창고물품)
- **질문**: 냉장/음식 보존을 어떻게 다루나?
  - **결정**: 음식 **신선도/부패** 도입(보존식 느림/신선식 빠름, 부패 시 회복↓ + 디버프). **아이스박스 = 창고물품(컨테이너 아이템)**으로 구현 — 음식 부패 지연 + 음료 '시원함' → 수분 회복 보너스(시간 지나면 상온화). 모두 **추후 구현**, 지금은 시스템·떡밥만. [→ inventory.md 창고물품, items.md]
  - **근거**: '가구 = 창고물품' 방향 전환(inventory.md, safehouse.md)에 맞춰 냉장고를 stash 컨테이너 아이템으로. 생존 루프(허기·수분)에 보존·온도 변수 추가.
