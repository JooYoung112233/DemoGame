# 생존 스탯 (Survival)

## 개요
플레이어는 **4개 생존 스탯**으로 관리된다. 전투 자원(체력·기력)에 더해 **허기·수분**을 도입(2026-06-05)하여, "자고 → 배고프고 목말라 → 보급하러 나가는" 생존 루프를 만든다.

> 체력·기력은 기존 시스템(→ [medical.md](medical.md), [combat.md](combat.md) §8.5). 허기·수분이 신규 축.

---

## 1. 4대 스탯

| 스탯 | 범위 | 감소 요인 | 회복 요인 | 고갈(0) 시 |
|------|------|----------|----------|-----------|
| 체력 (HP) | 0~100 | 피격·환경·아사/탈수 | 수면, 의료(붕대 등) | 사망 |
| 기력 (Stamina) | 0~100 | 달리기·공격·구르기, 허기/수분 부족 | 자연 회복(평소), 수면(즉시 풀), 커피·에너지바 | 탈진(행동 불가·그로기 취약) |
| 허기 (Hunger) | 0~100 | 시간 경과·활동(레이드)·수면 | 음식(통조림·에너지바 등) | 체력 서서히 감소(아사) |
| 수분 (Thirst) | 0~100 | 시간·활동·수면 (허기보다 빠름) | 물(물병 등) | 기력 회복·최대 저하 → 지속 시 체력 감소 |

- 시작값: 전부 100 (첫 거처 진입 S-011 기준).

## 2. 구간 & 페널티

| 구간 | 수치 | 상태 | 효과 |
|------|------|------|------|
| 정상 | 70~100 | — | 페널티 없음 |
| 주의 | 31~69 | HUD 아이콘 점멸 | 경고만 |
| 위험 | 1~30 | 비네트 경고 | 기력 최대치·회복률 ↓ (이동·전투 불리) |
| 고갈 | 0 | 적색 비네트 | 허기 0 = 체력 지속 감소 / 수분 0 = 기력 급감 + 체력 감소 |

- 허기·수분 둘 다 위험 이하면 페널티 가중.
- 수치/감소율은 밸런싱 **가안** — 조정 가능.

## 3. 감소율

> ⚠️ 아래 표는 초기 가안. **실제 구현은 §3.5(시간 기반 차감)로 정착**됐다(2026-06-18). 구 가안은 참고용으로만 남긴다.

| 행동 | 허기 | 수분 |
|------|------|------|
| 레이드 1회(낮 한 바퀴) | -15 | -20 |
| 수면 1회 | -25 | -25 |
| 안전가옥 상주(시간 경과) | 완만(분당 미세) | 완만 |

> 수분이 허기보다 빨리 닳아 "물 먼저" 압박을 준다.

## 3.5. 차감 속도 — 현 구현 (진실, 2026-06-18)

실제 구현은 **레이드 중 시간 기반 연속 차감**(안전구역=정지)으로 정착. 스탯은 **수분(Water) / 포만감(Satiety)** 2축, 각 0~100. 코드: `Assets/Scripts/Player/SurvivalStats.cs`.

| 파라미터 | 값 | 의미 |
|----------|-----|------|
| `waterDrainPerSec` | `100f / (18f * 60f)` ≈ 0.0926/s | 수분 100→0 ≈ **18분** (레이드 실시간) |
| `satietyDrainPerSec` | `100f / (36f * 60f)` ≈ 0.0463/s | 포만감 100→0 ≈ **36분** (레이드 실시간) |
| `starveHpPerSec` | 0.6/s | 빈 스탯(0) 1개당 초당 HP 감소(silent DoT). 둘 다 0이면 2배. |

- 차감은 **레이드(`RegionTimeManager.ActiveRegionId` 존재) 중에만**, 안전가옥에서는 정지.
- 기획 의도 "수분 6h / 포만감 12h(게임시간)"의 그레이박스 실시간 매핑. 추후 GameTuning 외부화 예정.

### 6분 레이드 반복 환산 (검증 필요 — 산술 가정)

풀스탯(100)에서 회복 없이 레이드(1회 ≈ 6분)를 누적할 때:

| 누적 레이드 | 경과(분) | 수분 (분당 ≈5.56) | 포만감 (분당 ≈2.78) |
|:---:|:---:|---|---|
| 1회 | 6 | ≈ 67 | ≈ 83 |
| 2회 | 12 | ≈ 33 | ≈ 67 |
| 3회 | 18 | ≈ **0 (위험)** | ≈ 50 |
| 4회 | 24 | **0 (DoT)** | ≈ 33 |
| 5회 | 30 | 0 | ≈ 17 |
| 6회 | 36 | 0 | ≈ **0** |

- **수분**: 3회째 레이드 끝(18분)에 0 → 위험권. 4회째엔 완전 고갈 DoT.
- **포만감**: 6회째 레이드 끝(36분)까지 버팀 → 음료보다 압박이 절반.
- 의도: 수분이 더 빨리 압박 = 잦은 물 보급 동기. 포만감은 장기 운영 자원.
- ⚠️ "안전구역 회복 0, 풀스탯 시작" 가정의 산술 환산. 실측 TTK·실사용은 별도 검증 필요.

## 5. 수면 (거처 — 박스 침상)

거처(컨테이너)의 **박스 침상**에 E → "잘까?" → 수면.

- **회복**: 체력(4h 40% / 8h 100%), 스태미너 풀.
- **소모(현 구현, 2026-06-18)** — `Assets/Scripts/UI/SleepUI.cs`:

  | 옵션 | hpPct | 수분 차감 | 포만감 차감 |
  |------|-------|-----------|-------------|
  | 4시간 수면 | 0.40 | **18** | **18** |
  | 8시간 수면 | 1.00 | **38** | **38** |

  (구 가안 "각 -25"에서 차감 3배 가속에 맞춰 상향. hpPct/hours는 유지.)
- **시간 경과**: 모든 지역 시계를 수면 시간만큼 진행(낮↔밤 전환).
- **게임 저장**: 수면 = 세이브 포인트(SaveManager / SaveCheckpoints).

**트레이드오프**: 자면 전투력은 회복되지만 배고픔·갈증이 누적 → 보급 동기.

**핵심 루프**:
```
수면(체력·기력 회복 / 허기·수분 ↓)
  → 허기·수분 경고
  → 떠돌이 상인 보급(스크랩으로 물·통조림)
  → 스크랩 부족 시 잡템 판매·민간 의뢰로 충당
  → 레이드(루디 회수 + 생필품 소모)
  → 귀환·수면 …
```

## 6. 음식 신선도 / 부패 (추후 구현)

- 음식 아이템에 **신선도(0~100%)** 또는 유통기한 부여.
- 시간 경과로 부패 진행 → 부패 시 허기 회복량 ↓ + 식중독 디버프(개그성 페널티).
- **보존식**(통조림·건조식)은 부패 매우 느림/없음 / **신선식**(빵·고기 등)은 빠름.
- 아이스박스 보관 시 부패 속도 ↓ (§7).

## 7. 온도 / 냉장 — 아이스박스 (추후 구현)

- **아이스박스 = 창고물품(컨테이너형 아이템)** — 창고(stash) 안에 놓는 케이스. 물리 가구 아님. [→ inventory.md]
- **음식 보관**: 부패 주기 지연(냉장).
- **음료 보관**: '시원함' 상태 부여 → 마실 때 **수분 회복량 +보너스**(시원한 물이 갈증을 더 해소).
  - 시원함은 시간이 지나면 미지근해짐(상온화) → 보너스 소멸.
- 전기 끊긴 세계 설정상 전력 불요(얼음·단열식) 가정 — 상세 추후.
