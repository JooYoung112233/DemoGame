## 1. 컨셉
- 한 줄: 유리 오피스 타워 — **저층 로비 → 상층 R&D**(카드키 게이트, 고급 부품·루디·전자). **`key_tower_card`(폐아파트 펜트)로 상층 개방 → `key_dome_code`(식물원 돔 열쇠)** 획득.
- 위험 ★★★★. 평상시 강화 밴딧. **현상 빈발·강함**(이상체 다수 + 변종, §world-map L) — 1지역 고위험 핵심.
- "후반 진입": 열쇠 체인상 폐아파트를 거쳐야 상층이 열림 → 자연스러운 후반.

## 3. 층 구성 (side-by-side + 계단 `gb_door`)
| 층 | 레이아웃 | 적(평상시) | 루트 | 열쇠·문 |
|---|---|---|---|---|
| **저층 로비(1~2)** | 로비 + 안내데스크 + 사무실 2~3. 엘리베이터 정지, 계단실↑ | 강화 밴딧 2~3 | ★★ 잡화·전자 | — |
| **상층 R&D(3~5)** | **카드키 게이트 입구** + 실험실/서버실(고급). 좁은 복도 | 강화 밴딧 + 변종 2~3 | ★★★★ 부품·루디 | 입구 **`key_tower_card` 잠금**, 안에 **`key_dome_code`** |

- 계단 = `gb_door` "Stair_LtoUp" 등(엘리베이터 정지 연출). 실험실/사무실 = `gb_door`로 들어가는 폐쇄 방.
- 상층 입구 카드키 게이트 = **`key_tower_card` 잠금 `gb_door`**(없으면 못 들어감) → 고급 루트 보호.

## 4. 적 · 현상 (§world-map L)
- **평상시**: 강화 밴딧(고위험), 상층일수록 ↑.
- **현상 활성(빈발·강함)**: 이상체 **다수** + 강화/오염 변종. **`gb_anomaly` 다수**(로비·R&D 복도·옥상, 안개 가장자리). 현상 시 Anomaly 티어 **최상급 루트**(루디·희귀↑).

## 5. 루트
- ★★★★: 저층 잡화·전자 / 상층 R&D 고급 부품·루디(카드키 뒤). 현상 시 최상급. → 1지역 최고급 일반 루트(식물원 금고 다음).

## 6. 그레이박스 조각 (지금 빌드 가능)
- 저층 로비 + 상층 R&D **side-by-side**, 계단 `gb_door`. **동측 진입**(B6 정면 차단 표현 = 정면 `gb_barricade`).
- 상층 입구 = **`key_tower_card` 잠금 게이트**, R&D 안에 **`key_dome_code`** + 고급 컨테이너.
- `gb_anomaly` 다수(고위험 현상 구역).
- 빌더: **별도 TowerGreyboxLayout 폐기 → `Zone1GreyboxLayout`로 통합**(통짜 연속 맵 전환, 2026-06-06). 현재 Zone1 coarse 골격에 **L3 링**으로. 저층/상층 R&D 디테일은 **층 시스템** 또는 L3 구역 디테일 시. **현상 제거.** (이 문서 = Zone1 L3 구역 디테일 참조용 유지.)
- 층 시스템 생기면 side-by-side → stacked.
