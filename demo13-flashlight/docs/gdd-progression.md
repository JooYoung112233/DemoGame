## 15. 안전가옥 시스템

### 15.1 기본 개념

안전가옥은 전당포 주인이 소개해준 작은 컨테이너에서 시작한다.

초기 상태:

- 낡은 침대
- 작은 보관함
- 고장난 작업대
- 불안정한 조명
- 빈 벽면의 지도판

플레이어는 루디와 재료를 모아 안전가옥을 확장한다.

---

### 15.2 안전가옥 시설

| 시설 | 기능 |
|---|---|
| 침대 | 부상/피로 회복 |
| 창고 | 아이템 보관 |
| 작업대 | 무기 수리/제작 |
| 의료대 | 치료템 제작/부상 치료 |
| 조리대 | 음식 제작 |
| 발전기 | 조명과 시설 가동 |
| 지도판 | 지역 정보/낮밤 정보 확인 |
| 게시판 | NPC 의뢰 확인 |
| 방어시설 | 습격 이벤트 피해 감소 |
| 라디오 | 특수 이벤트/구조 요청 수신 |

---

### 15.3 안전가옥 강화

| 강화 | 효과 |
|---|---|
| 창고 확장 | 보관 칸 증가 |
| 발전기 수리 | 전력 시설 사용 가능 |
| 작업대 강화 | 고급 제작 해금 |
| 의료대 강화 | 부상 치료 비용 감소 |
| 지도판 강화 | 탈출구/위험도 정보 표시 |
| 침대 강화 | 출격 후 피로 회복 증가 |
| 방어벽 설치 | 습격 피해 감소 |
| 라디오 안테나 | 특수 미션 수신 |
| 루디 조명 | 밤 출전 정보 일부 표시 |

## 16. NPC / 호의도 시스템

NPC는 단순 상인이 아니라 미션, 정보, 상점 확장, 엔딩 조건과 연결된다.

### 16.1 호의도 상승 방법

- 미션 완료
- 필요한 아이템 전달
- 낮 지역에서 구조
- 밤 지역에서 단서 회수
- 특정 선택지 선택

### 16.2 호의도 보상

| 호의도 보상 | 설명 |
|---|---|
| 판매 품목 증가 | 더 좋은 장비/재료 판매 |
| 미션 추가 | 개인 퀘스트 개방 |
| 정보 제공 | 밤 지역 힌트 제공 |
| 제작 레시피 | 특수 장비 제작 가능 |
| 안전가옥 기능 | 시설 효율 증가 |
| 엔딩 단서 | 동생/짙은 현상 관련 정보 제공 |

### 16.3 주요 NPC 후보

| NPC | 역할 | 호의도 보상 |
|---|---|---|
| 전당포 주인 | 메인 의뢰, 루디 거래, 감정 | 고급 거래, 주인공 과거 단서 |
| 의사 | 치료, 부상 관리 | 희귀 치료제, 감염 치료 |
| 수리공 | 장비 수리, 안전가옥 강화 | 제작 레시피, 시설 강화 할인 |
| 떠돌이 상인 | 랜덤 아이템 판매 | 밤 전용 장비 판매 |
| 전직 공무원 | 세계관 정보 | 도시 봉쇄·은폐 기록, 금지 구역 정보 |
| 수상한 아이 | 동생 단서 | 이상현상 힌트, 숨겨진 길 정보 |

## 17. 미션 시스템

미션은 낮/밤 출전과 안전가옥 성장을 연결하는 역할을 한다.

| 미션 | 내용 |
|---|---|
| 회수 | 특정 아이템 가져오기 |
| 조사 | 특정 장소 방문 후 정보 획득 |
| 구조 | NPC 또는 생존자 데리고 탈출 |
| 처치 | 특정 밴딧/몬스터 제거 |
| 설치 | 특정 장소에 장치 설치 |
| 수리 | 발전기, 문, 탈출구 복구 |
| 거래 | 루디 또는 귀중품 전달 |
| 추적 | 동생/과거 관련 단서 찾기 |

### 17.1 첫 메인 미션

목표:

> 밤 지역에서 루디 조각 1개를 회수해 전당포 주인에게 가져가기.

보상:

- 컨테이너 사용 허가
- 기본 거래 해금
- 플레이어 이름에 대한 단서 1개
- 다음 지역 정보 해금

## 18. 메인 스토리 진행

> ⚠️ **§18~19는 초기 GDD 판본 — 현 스토리 캐논과 어긋남. 진실 = [story.md](story.md)(§2 기원·§4 지역·§5 엔딩).**
> 주요 변경: ① 현상 기원 = **운석 소녀 알파 + 강무진의 비인도 실험 + 새벽의 죽음/시간역행 부활**(story.md §2.0) — 아래 "Act 3 짙은 현상의 중심"의 막연한 서술 대체. ② **동생 노을 = 실존 X(알파가 심은 가짜 기억)** — §19의 "동생 스토리"는 표층일 뿐. ③ **엔딩 3종(입양/사망/구출) → 2종**(① 진엔딩 진실 / ② 굿엔딩 거짓 동생, 둘 다 배드 아님). 아래 A/B/C는 **폐기.** ④ 낮/밤 → 안전/짙은현상. 본 절은 역사 참고용으로만 둔다.

### Act 1. 살아남기

목표:

- 전당포 주인을 통해 루디 의뢰 수락
- 첫 루디 회수
- 컨테이너 안전가옥 정비
- 낮/밤 출전 시스템 학습
- 타운 NPC 소개

주요 단서:

- 시계가 평범한 물건이 아님
- 전당포 주인이 주인공을 알고 있음
- 루디와 짙은 현상이 연결됨

---

### Act 2. 기억의 조각

목표:

- 주인공의 과거 추적
- 동생 존재 확인
- 전당포 주인이 숨기는 정보 발견
- 낮 NPC와 쪽지를 통해 기억 단서 수집

주요 단서:

- 오래된 사진
- 동생 이름
- 입양 기록
- 도시 봉쇄 전 자료
- 손목시계와 멈춘 시계 이상현상 연결

---

### Act 3. 짙은 현상의 중심

목표:

- 루디의 정체 확인
- 동생의 최종 행방 확인
- 전당포 주인의 진짜 목적 확인
- 엔딩 분기 진입

주요 단서:

- 루디는 단순 에너지원이 아님
- 짙은 현상은 기억과 시간에 영향을 줌
- 주인공이 기억을 잃은 이유가 드러남
- 동생의 운명이 플레이어 선택에 따라 달라짐

## 19. 동생 스토리 / 엔딩 분기

주인공은 기억을 잃기 전 동생을 잃어버렸거나, 잃어버렸다고 믿고 있다.

### 엔딩 A. 입양 / 생존 엔딩

진실:

> 주인공은 동생을 버린 것이 아니라, 살리기 위해 누군가에게 맡겼다.

결말:

- 동생은 살아 있음
- 하지만 주인공을 기억하지 못하거나 원망함
- 세계는 여전히 불안정함
- 씁쓸하지만 생존한 결말

조건 예시:

- 기본 메인 미션 완료
- 일부 단서 수집
- 특정 NPC 호의도 중간 이상

---

### 엔딩 B. 사망 / 진실 엔딩

진실:

> 동생은 짙은 현상 초기에 사망했고, 주인공은 죄책감 때문에 기억을 잃었다.

결말:

- 동생은 구하지 못함
- 주인공은 기억을 되찾음
- 짙은 현상의 진실 일부를 세상에 밝힘
- 비극적 결말

조건 예시:

- 핵심 단서 부족
- 특정 NPC 미션 실패
- 짙은 현상 관련 선택지 실패

---

### 엔딩 C. 구출 / 희망 엔딩

진실:

> 동생은 죽지 않았고, 짙은 현상 안에서 시간과 기억이 비틀린 채 살아 있었다.

결말:

- 동생 구출 성공
- 하지만 큰 대가가 있음
- 루디 공급망 또는 안전가옥 일부를 포기해야 할 수 있음
- 주인공은 기억 일부를 다시 잃을 수 있음

조건 예시:

- 주요 NPC 호의도 높음
- 낮/밤 단서 대부분 수집
- 특수 이상현상 해결
- 최종 지역에서 특정 선택 성공

## 20. 전체맵 / 지역 후보

| 지역 | 낮 특징 | 밤 특징 |
|---|---|---|
| 주택가 | NPC/쪽지 많음 | 밴딧 약탈 |
| 폐상가 | 기본 파밍 좋음 | 밴딧/몬스터 혼합 |
| 병원 | 치료템/NPC | 감염 몬스터 |
| 지하철역 | 정보/탈출 힌트 | 이상현상 강함 |
| 경찰서 | 낮에는 잠김/조사 | 고급 장비/밴딧 |
| 공장지대 | 부품/재료 | 강한 밴딧과 기계 이상현상 |
| 극장가 | 스토리/쪽지 | 보스/괴현상 |
| 중앙광장 | 도시 봉쇄 흔적 | 후반 고위험 지역 |
