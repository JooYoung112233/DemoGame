## 1. ⚠️ 최우선 확인 — 기존 시안 스프라이트는 해상도가 부족하다

`Assets/Resources/UI/Image/`의 13장은 **시안 목업(`시안.png`, 1366×791)에서 1:1로 잘라낸 것**이다.
(검증: 목업 내 STORAGE 패널 영역 ≈520×730 ↔ `storage.png` 516×730 — 일치)

그런데 게임 UI 기준 해상도는 **1920×1080**(CanvasScaler, `ui-prefab-plan.md` 기준)이다.
→ **모든 기존 스프라이트가 1.41배 업스케일되어 렌더된다.** 종이 질감·찢긴 가장자리가 가장 먼저 뭉개지는 배율이다.

**결론: 기존 13장도 재납품 대상.** 아래 환산표 기준으로 다시 그린다(또는 원본 고해상도 파일이 있으면 재출력).

| `box.png` | 76×76 | 107×107 | **214×214** |
| `btn.png` | 232×50 | 326×70 | **652×140** |

### 배율 규칙 (전 신규 에셋 공통)
- **2× 납품이 기본.** 1440p·4K 디스플레이에서 UI 캔버스가 확대돼도 버티는 표준 헤지. Unity에서 Pixels Per Unit로 흡수한다.
- 비용을 줄여야 하면 **1×(1920 기준)이 바닥선**. 지금의 1366 기준 치수 아래로는 절대 내려가지 않는다.
- 예외: 아이콘 시트는 §5 그리드 규칙을 따른다(이미 2× 반영된 수치).

## 2. 스타일 기준선

> **룩의 결정권은 [`ui-reference.md`](ui-reference.md)에 있다.** 캐논 = **이중 언어**(종이=문서형 / 프레임=기능형).
> 이 절은 그 캐논을 그리기 위한 재질·색 기준만 다룬다. 어느 패널이 어느 언어인지는 `ui-reference.md` §5 배분표를 본다.

| 항목 | 기준 |
|---|---|
| 컨셉 | **낡은 종이·판지 + 어두운 금속 프레임.** 폐허에서 주워 쓰는 기록물 느낌 |
| 종이(문서형) | 섬유결·얼룩·접힌 자국·찢긴 가장자리. **밝다** |
| 프레임(기능형) | 무광 금속·녹·긁힘. 질감 최소·균일. **어둡다** |
| 라이팅 | 플랫. 드롭섀도·베벨·글로우 금지 (엔진 Light2D와 별개 레이어라 어색해짐) |
| 원근 | 정면 평면. UI는 인게임 탑다운 시점각(80°/70°/60°) 적용 대상이 **아님** |
| 아이콘 | 굵은 실루엣 우선. 얇은 선 금지(1920에서 1px 되면 사라짐) |

### 색 팔레트 (시안에서 추출한 근사치 — 아트가 원본 기준으로 확정)
| 역할 | 근사 hex |
|---|---|
| 종이(밝음) | `#C9BCA5` |
| 종이 그늘 | `#A2947C` |
| 프레임(어두움) | `#2A2724` |
| 배경(가장 어두움) | `#14110F` |
| 텍스트 on 종이 | `#2B2620` |
| 텍스트 on 어두움 | `#D8CCB6` |
| 금속 액센트 | `#8A7B5E` |

> **밝기 대비가 캐논의 핵심이다** — 화면에서 밝은 영역 = 읽을 것, 어두운 영역 = 조작할 것. 이 대비를 무너뜨리는 색 조정은 하지 않는다.

> ⚠️ **시맨틱 색은 그리지 말 것** — 희귀도 5색(회/초/파/보/금)·부상 색·게이지 채움 색·경고색은 **엔진(`UITheme`)이 코드로 입힌다.** 해당 파츠는 **흰색/회색조**로 납품하면 런타임에 틴트된다.

## 3. 9-slice 규약

UI 프레임 대부분은 9-slice로 늘어난다. **보더 안쪽(늘어나는 영역)에 특징적인 무늬가 있으면 안 된다.**

| 유형 | 보더 규칙 |
|---|---|
| 대형 종이 패널 (`item`, `storage`) | **넉넉히 ≈90px(1× 기준) / 180px(2×)** — 찢긴 모서리를 보더 안에 통째로 넣어야 늘어나도 안 망가짐 |
| 소형 프레임 (`box`, `itembox`, `storage_box`) | 12~20px(1×) — 테두리 두께만 |
| 가로 버튼 (`btn`, `btnb`) | 좌우 24px / 상하 0 (세로는 안 늘림) |
| 탭 (`storage_btn_*`) | 좌우 12px / 상하 0 |
| 게이지 (`bar_*`) | 좌우 6px / 상하 0 |

### ⚠️ 9-slice가 안 되는 것
`name.png` / `name_icon.png`(찢긴 종이 태그)는 **비대칭이라 9-slice 시 찢김이 좌우로 늘어져 깨진다.**
→ **폭 변형(짧음/중간/긺) 3종을 각각 고정 크기로 납품**하거나, 좌·중·우 3-slice로 분리해 납품한다. CSV에 3종으로 잡아뒀다.

## 4. 상태 변형 (시안에 없는 부분 — 신규 작업)

시안은 **normal 상태만** 있다. 인터랙션에 필요한 나머지를 그려야 한다.

| 요소 | 필요 상태 |
|---|---|
| 버튼(Primary/Secondary) | normal · **hover** · **pressed** · **disabled** (각 4) |
| 탭 | on · off(둘 다 있음) · **hover**(신규) |
| 슬롯 셀 | normal · **드래그오버 유효**(초록 틴트용 흰 프레임) · **드래그오버 무효**(빨강 틴트용) |
| 체크박스/토글 | on · off |

> hover/pressed/disabled를 **별도 스프라이트로 그리지 않고** 엔진 틴트(밝기 ±)로 처리하는 선택지도 있다.
> **결정 필요** — 아트 비용 vs 질감 유지. 종이 질감은 단순 틴트로도 꽤 버티는 편이라, 최소 **pressed만 별도 스프라이트 + hover/disabled는 틴트**를 권한다.

## 5. 아이콘 규격

| 항목 | 기준 |
|---|---|
| 그리드 | **64×64 px** 셀 (2× 납품 기준. 1920 화면에서 32px로 표시) |
| 대형 아이콘 | 128×128 (장비 슬롯·시설 아이콘) |
| 형식 | **시트 1장 + 셀 그리드 정렬** (개별 파일 아님). 슬라이스는 엔진에서 |
| 색 | 단색 실루엣 + 1톤 음영. 배경 투명 |
| 여백 | 셀 안쪽 4px 여백 확보(잘림 방지) |
| 선 굵기 | 최소 4px(2× 기준). 얇은 선 금지 |

> **아이템 아이콘 204종은 이 문서 범위가 아니다** — 별도 트랙([`item-icon-checklist.csv`](item-icon-checklist.csv), 3/4 시점 타르코프식). 여기 아이콘은 **UI 안에서 기호로 쓰이는 정면 평면 픽토그램**이다. 두 스타일을 섞지 말 것.

## 6. 네이밍 · 납품 · 임포트

### 파일명 (소문자 스네이크, 접두사 필수)
| 접두사 | 대상 | 예 |
|---|---|---|
| `panel_` | 패널/팝업 배경 | `panel_storage.png` |
| `frame_` | 소형 프레임/박스 | `frame_itembox.png` |
| `btn_` | 버튼 | `btn_primary_pressed.png` |
| `tab_` | 탭 | `tab_on.png` |
| `slot_` | 격자 셀·슬롯 | `slot_grid.png` |
| `bar_` | 게이지 | `bar_fill.png` |
| `tag_` | 종이 태그/배너 | `tag_title_m.png` |
| `ico_` | 아이콘 시트 | `ico_equip_slots.png` |

### 납품
- **PNG-32 (알파 포함), 무손실.** 배경 투명 — 마젠타 키잉은 인게임 스프라이트용 규칙이고 **UI에는 적용하지 않는다**
- 레이어 원본(PSD/Clip)도 함께 — 상태 변형·색 조정 재작업용
- 9-slice 보더 값을 **파일별로 표기해서 전달**(CSV `9slice_LRTB` 열에 기입)

### Unity 임포트 설정 (엔진 담당, 아트 참고용)
```
Texture Type      : Sprite (2D and UI)
Sprite Mode       : Single (아이콘 시트만 Multiple)
Pixels Per Unit   : 100
Mesh Type         : Full Rect          ← 9-slice 필수
Filter Mode       : Bilinear
Compression       : None (UI는 무압축)
Generate Mip Maps : Off
Border            : 파일별 지정값
```

## 12. 미결 — 아트와 합의 필요

1. **hover/pressed/disabled를 스프라이트로 그릴지, 엔진 틴트로 갈지** (§4). 권장 = pressed만 스프라이트.
2. **2× 납품 확정 여부** (§1). 비용 이슈면 1×(1920)가 바닥선.
3. **한글 폰트** — 시안 라벨이 전부 대문자 영문(`ITEM NAME`, `TAKE ALL`)인데 실게임은 한국어다. 찢긴 종이 태그에 한글을 얹으면 시안의 콘덴스드 리듬이 안 나온다.
   - 캐논 확정으로 **리스크가 종이 9패널로 좁혀졌다**(`ui-reference.md` §7) → **종이용 1종 + 프레임용 1종 2폰트 체제**를 권장.
   - 선결: `ui-prefab-plan.md` §6대로 TMP Essential Resources 미임포트 상태 → TMP 전환 자체가 블록돼 있음.
4. **`name.png` 태그 처리** — 폭 3종 고정 vs 3-slice (§3). 폰트 결정 후 판단.
