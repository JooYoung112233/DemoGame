## 1. 핵심 원칙: 자원 생산 ❌ / 탐사 확장 ⭕

### 문제 인식 (2026-06-10)

안전가옥에서 지속적으로 자원을 생산하게 만들면(농사, 자동 채집, 자동 생산 시설 등)
**"밖에 나갈 필요가 없음"** 으로 귀결된다. BRB의 핵심은 레이드(탐사)이므로
안전가옥이 탐사를 **대체**하면 안 된다.

### 결정

안전가옥은 **자원을 생산하는 장소가 아니라 탐사를 확장하는 장소**다.

| 역할 | 채택 |
|---|:---:|
| 자원 생산 (농사/자동채집/자동생산) | ❌ 금지 |
| 탐사 확장 (새 목표 생성) | ⭕ |
| 랜드마크 정보 수집 | ⭕ |
| 라디오 수신 (세계관/이벤트) | ⭕ |
| 숨겨진 장소 발견 | ⭕ |
| 세계관 전달 | ⭕ |

### 확장 후 게임 루프

```
레이드(탐사)
  ↓
안전가옥 복귀
  ↓
라디오 수신 / NPC 파견 결과 확인
  ↓
새 랜드마크·상호작용 지점 발견 (= 인텔 획득)
  ↓
새 목표 생성
  ↓
다시 레이드
```

플레이어는 **밖에서 자원을, 안전가옥에서 정보를** 얻고, 그 정보로 다시 밖으로 나간다.

## 2. 시스템 ① — NPC 랜드마크 파견 (정보 수집)

NPC를 특정 랜드마크로 보내 **자원이 아닌 "정보"** 를 가져오게 한다.

- 파견 대상 랜드마크 예: 약국, 경찰서, 학교, 병원, 지하철역, 아파트 단지
- 파견 결과 = 인텔(정보) 예:
  - "약국 뒤편에 잠긴 금고 발견"
  - "창고에 잠긴 문 발견"
  - "지하 창고 입구 발견"
- 인텔 획득 순간 **플레이어 월드(레이드 맵)에 새 상호작용 지점이 생성**된다
- 플레이어가 직접 방문해서 금고 개방 / 잠긴 문 해제 / 숨겨진 공간 진입을 수행

**핵심 장점**: NPC 탐사가 플레이어 탐사를 대체하지 않고, 오히려 **새로운 탐사 목표를 만들어낸다.**

### 2-A. 파견 메커닉 상세 (2026-06-10 확정 — 미결정 항목 해소)

> 전체 표(인력 스탯·성공률 공식·장비·유형·파견지)는 [`quests-region1.md`](quests-region1.md) §9.7 ③ "파견 시스템 상세 A~G". 여기는 원칙·요지.

- **보상 = 하이브리드(정보 위주 + 소량 보급)**: 주 보상 = **인텔(새 상호작용 지점 월드 생성 / 파견지·POI 해금 / 새 인력)**, 보조 = **소량 소모품 1~2**. **루디·핵심 재료 idle 수익 없음**(원칙 §1 유지). 현상 정찰도 **루디 위치 인텔만** 줌(따는 건 플레이어 직접).
- **파견 인력** = 구출·합류 NPC(**SQ-001 갇힌 생존자가 첫 인력**, 구조 파견으로 추가 영입). 등급(견습/숙련/베테랑)·특기(운반/정찰/채집/구조)·상태(정상/부상/피로). 성공 누적 승급.
- **팀 = 한 파견에 최대 2인**: 합산 기여 + 시너지(같은 특기 효율 / 보완 특기 성공·부가 인텔). 단독은 페널티.
- **장비 지급(팀 3슬롯)**: 무기(성공↑·손실↓)·방어구(손실 경감)·의료(자동 치료)·식량물(장시간)·지도(성공↑) → 인벤 자원으로 성공률·안전을 삼.
- **성공률** = 미션 base + 인력 + 팀 + 장비 + 파견Lv + 평판. 결과 = 실패/성공/대성공(인텔 등급↑).
- **시간 단위 = 실시간(오프라인 진행)** 기본(데모 짧게). *대안: 레이드 N회 — 튜닝 가능.*
- **리스크**: 실패 시 빈손/피로/부상, 고위험(현상·구조)은 **인력 손실** 위험.
- **파견지 = 탐험으로 해금**: 플레이어가 그 구역에 직접 도달하거나 지도·인텔을 획득해야 파견 가능(가본 곳에만). 레이드↔파견 선순환.
- **해금 게이트**: 관리인 하이드아웃 파견 보드 Lv(신뢰60→75→90 + 평판). [→ quests-region1 §9.7 ③]

## 3. 시스템 ② — 라디오

안전가옥(은신처) 전용 콘텐츠. **라디오 자체가 보상을 주는 것이 아니라 탐사 동기를 제공한다.**

- 은신처 내부에 설치 (관리인 하이드아웃 모듈 — [`safehouse.md`](safehouse.md) 시설 목록 / [`quests-region1.md`](quests-region1.md) §9.7 ③)
- **발전기 전력으로 가동**(연료 = `fuel_can`, 루디=전력체도 가능 — 루디는 충전·방전 활성 자원이라 가동 시 방전 소비 [→ gdd-core §5.3](gdd-core.md)). 발전기 전제 — 연료 끊기면 off
- 주파수(채널)를 맞춰 정보를 수신 — 정보·리드 중심(괴신호/스토리 해독 채널 제외, 2026-06-10)

### 수신 가능한 정보 4종

| 분류 | 예시 |
|---|---|
| **랜드마크 정보** | "구 시청 인근에서 신호 감지" / "지하철 역사 내부에서 구조 요청" / "병원 옥상에 조명 확인" |
| **생존자 방송** | "누군가 아직 살아있다" / 도움 요청 / 물자 교환 제안 방송 |
| **세계관 조각** | 사건 발생 직전 방송, 군 통신, 실험 기록, 개인 일기, 구조 요청 |
| **특수 이벤트** | 희귀 랜드마크 해금, 숨겨진 지역 발견, 특수 NPC 등장, 의뢰 생성 |

## 4. 시스템 ③ — 랜드마크 확장 (재방문)

플레이어가 **이미 방문한 장소도 NPC 파견 대상**이 될 수 있다.

```
플레이어가 약국 방문 (클리어)
  → NPC 파견
  → "새로운 지하 공간 발견" 인텔
  → 약국 재방문
  → 새 콘텐츠 해금
```

**장점**: 맵 제작 비용 절감 + 콘텐츠 수명 증가 (기존 레벨 재활용).

## 6. 작업 계획 (구현 단계)

> 로드맵 위치: Stage 9(안전가옥 강화) 이후 권장 — 게시판 의뢰·은신처 시설 해금이 선행되어야 함. [`dev-roadmap.md`](dev-roadmap.md)

### Phase A — 인텔 데이터 골격
- `LandmarkIntelData` (ScriptableObject): intelId, 대상 지역/랜드마크, 해금 지점 ID, 출처(라디오/파견/블랙마켓), 전달 텍스트
- `IntelManager` (싱글톤, DontDestroyOnLoad): 획득/소비 인텔 추적, SaveManager 영속화
- 인텔 획득 토스트/로그 UI (ToastManager 재활용)

### Phase B — 라디오 (은신처 클릭 시설)
- `Hideout.unity` 클릭 시설에 라디오 추가 (`HideoutController` 클릭 → 라디오 UI — 기존 침대/작업대 패턴)
- 라디오 UI: 주파수 다이얼 연출 + 루디 소모 → 정보 풀에서 가중 추첨
- 수신 풀 4종(랜드마크/생존자/세계관/특수) 데이터 테이블
- 세계관 조각은 수집형 기록(아카이브)으로 저장 — `story.md` 단서 시스템과 연계 검토

### Phase C — NPC 파견
- 파견 UI: 랜드마크 선택 → 비용 지불 → 대기 → 결과(인텔) 수령
- 파견 가능 NPC·시간 단위는 미정 (아래 미결정 항목)
- 파견 결과 = `LandmarkIntelData` 지급 (Phase A 재사용)

### Phase D — 월드 반영 (인텔 → 레이드 맵)
- 레이드 맵에 **인텔 게이트 오브젝트** 사전 배치 (잠긴 금고/문/숨은 입구 — `InteractableObject` 확장, 인텔 미보유 시 비활성/잠김 표시)
- `RaidMapManager` 주석 + `CompassTarget` 으로 인텔 지점 안내
- 보상 테이블: 인텔 게이트 전용 루트 ([`region-loot.md`](region-loot.md) 연계)

### Phase E — 재방문 확장
- 클리어한 레벨에 추가 인텔 게이트 공간(지하/옥상 등) 배치
- 라디오 특수 이벤트 → 의뢰 생성(QuestManager) / 특수 NPC 스폰 연결

## 7. UI 방향 (참조 이미지) — 2026-06-17

> 그레이박스 이후 본 UI 룩의 방향. 레이아웃 구조만 확정, 아트는 추후.

### 7-A. 라디오 UI (레트로 무전 콘솔)

참조 = 스팀펑크/레트로 무전기 패널(다이얼·게이지·노브 둘러싼 콘솔, 중앙 = 분위기 배경).

- **상단**: **주파수(채널) 맞추기** — 다이얼/슬라이더로 주파수 튜닝, 채널 잠금/노이즈 연출.
  - **주파수 다이얼 동조 방식(2026-06-18 구현):** 88.0~108.0MHz 밴드를 슬라이더 손잡이로 끌어 연속 조절, 채널은 밴드 위 틱 마커(89.1/94.5/100.3/106.7)로 배치 → 현재 주파수가 채널 ±0.5 안이면 그 채널에 동조(lock)·수신 활성, 범위 밖이면 "치지직" 노이즈·수신 비활성, 레벨 미달 채널은 동조해도 "[잠김 Lv N]". 소리는 TODO.
- **우측**: 맞춘 채널의 **대사/정보 출력** — 수신 메시지(랜드마크/생존자/세계관/특수) 텍스트가 흘러나옴.
- **좌측**: **도움 문서·힌트** — 수신 해독에 참고할 자료/단서/아카이브(세계관 조각 수집본 연계 §Phase B).
- 중앙 = 무전 분위기(배경/연출). → Phase B "주파수 다이얼 연출" 구체화.

### 7-B. NPC 지역 파견(출전) UI (위성맵 + 좌측 정보 패널)

참조 = 타르코프식 위성 지도 + 좌측 파란 정보 패널(거점/임무 정보 오버레이).

- **배경**: 위성/탑다운 **지역 맵** — 파견 가능 랜드마크·거점이 마커로 표시(탐험으로 해금된 곳만 §2-A).
- **좌측 정보 패널**: 파견 구성을 출력 — **누굴 보내는가**(인력 선택·등급·특기·상태), **무엇이 나오는가**(예상 인텔/보상·성공률), 거점 정보(이미지+설명).
- 마커 선택 → 좌측에 그 거점 상세 + 인력/장비 배정 → 파견 실행.
- 현재 그레이박스 `DispatchUI`(슬롯·목적지·타이머)의 정식 UI 목표 형태.
