# 월드맵 — Be Right Back (BRB)

> **현 상태 = 진실.** 컨셉 아트 기준 월드 구조. 플레이 가능 맵·씬과 1:1 대응은 아직 없음.

## 문서 목적

BRB 세계의 **거시 월드맵 컨셉 아트**를 기록한다.  
중앙 「영야」 코어 + 6개 외곽 지구 + 헥사 고속환형·지하철·탈출·위험 구역 범례를 개발·기획 참고용으로 고정한다.

**소스**: 컨셉 아트 (2026-05-25)  
**관련**: `gdd-progression.md` §20 전체맵 후보, `dev-roadmap.md` 4단계 폐상가

## 7-5. 1지역 배경 레퍼런스: 서울 마곡지구 (강서구)

**적용 범위**: **1지역(데모 플레이 지역, scrap_market)에 한정.** 마곡은 다른 6지구와 무관 — 나머지 지구는 기존 컨셉 유지. 1지역 한 맵 안의 **서브존·동선·랜드마크 설계 레퍼런스로만** 사용. 게임 속 지명은 허구 유지(실명·상표 미사용, 아트가이드 "NO Korean text" 준수).

### 왜 마곡인가 (1지역 한정)
- **습지 매립 신도시** — 원래 한강변 농지·습지였다가 2010년대 개발. "밤에 도시가 자연으로 되돌아간다 = 짙은 현상"과 정합. 매립지가 밤마다 침수·구조변화하는 근거.
- **한 지역 안에 다양성** — 상권·아파트·식물원·유리타워가 좁은 범위(~3.5km²)에 밀집 → **단일 지역 맵 안에서 서브존 다변화**가 자연스러움.
- **신선한 폐허 톤** — "새것인데 버려진 유리빌딩 신도시". 흔한 낡은 폐건물과 차별화.

### 1지역 내부 서브존 ↔ 마곡 실장소 매핑

| 1지역 서브존 (맵 구획) | 마곡 실제 장소 (레퍼) | 차용 랜드마크 | 게임 역할 |
|------------------------|----------------------|---------------|-----------|
| 상가 골목 (진입부) | 마곡나루·발산역 상권 | 역세권 상가, 먹자골목 | 시작 파밍, 좁은 골목 전투 |
| 대단지 폐아파트 | 마곡엠밸리 아파트 | 고층 아파트 동 | 수직 탐색, 다수 컨테이너 |
| 유리 R&D 블록 | LG사이언스파크 | 유리 오피스 타워군 | 고급 루트, 후반 진입 구역 |
| 유리온실 / 습지 | 서울식물원 | **거대 유리온실 돔 + 호수습지** | 시그니처 랜드마크, 현상 침수 구역 |
| 강변 도로 (경계) | 한강 마곡철교변 | 강변 부두·고가 | 맵 경계, 탈출구 후보 |

※ 게임 내 표기는 허구 지명만 사용. 표는 **블록 배치·동선·랜드마크 발상용**.

### 1지역 맵 동선 힌트
- **한강이 북쪽 경계** → 맵 상단을 강변/탈출구로
- **상권(진입)→아파트→유리타워→식물원** 순으로 위험도·보상 상승 동선
- **서울식물원 유리온실 돔** = 1지역의 랜드마크 + "짙은 현상"이 가장 강한(빈발) 침수 구역으로

### 1지역 맵 스케일 & 레이드 파라미터 (확정)

**스케일 기준 (코드 검증)**: `tileSize = 1f` → **1타일 = 1m**. 플레이어 `moveSpeed = 5`(걷기 5m/s), 질주 ×1.6(8m/s), 앉기 ×0.5(2.5m/s). 질주는 스태미나 제약(소모 12/s, 풀스태 ≈8.3초)으로 장거리 실효 ≈6m/s.

**설계 의도**: 고정 맵 / 스폰 다수 / **고정 탈출구 1 + 유동 탈출구 4** / **레이드 15분** / 한 판에 **랜드마크 5개 중 1~2개만 도달** + 퀘스트 1개 완수 가능.

**15분 레이드 시간 예산 (역산 근거)**:

| 활동 | 비중 | 시간 |
|------|------|------|
| 이동 | 50% | 450초 |
| 루팅(정지) | 30% | 270초 |
| 전투·경계 | 20% | 180초 |

- 이동 450초 × 실효 5m/s = 경로 2,250m, 굴곡 ×1.7 → 순수 직선 이동량 ≈1,320m(왕복 포함) → **편도 최대 침투 ~600~700m**
- 랜드마크 간격 **~290~490m**(1000×900) → 한 판 1개 확실 + 2번째는 가까운 쌍·스폰일 때만 → 나머지는 반복 레이드로 커버 ✅

**확정 맵 크기: 1000 × 900 타일 (1000m × 900m, ≈0.9km², 실제 마곡 약 1/4 압축)** — *멀티레이드 전제로 2026-06-06 확대(구 800×700 ×1.25).*
- 짧은변 직선걷기 ~3.0분 / 긴변 ~3.3분 / 대각선 ~4.5분
- 막는 건 맵이 아니라 **시간·욕심** — 직선질주하면 다 보이지만 빈손 탈출. 루팅하면 1~2개. → "한 집만 더?" 긴장. 맵이 커 한 판 도달 랜드마크↓ = **반복 레이드 동기↑**(§STEP 2 I).

**구조 배치**:
- **스폰 다수**: 가장자리·코너 분산 → 판마다 가까운 랜드마크 달라짐(스폰=콘텐츠 로테이션)
- **고정 탈출구 ×1**: 저위험 상가골목 쪽, 항상 안전 회수 보장
- **유동 탈출구 ×3(랜덤/판)**: 풀에서 3개 활성, 스폰서 먼 쪽 우선 → 안 가던 구역 유인(커버리지 분산)
- **퀘스트**: 목표를 랜드마크 1~2개 반경에 배치 → 집중 15분+ 런으로 완수, 매판 다른 랜드마크로 로테이션

**크기 변천**: 500×450(2~3개, 빡빡) / 800×700(1~2개) / **1000×900(1~2개·딥런 시 1개, 멀티레이드용 채택)** — 멀티레이드라 "과대"가 오히려 반복 동기로 작동.

### 1지역 블록 레이아웃 (좌표 확정)

**좌표계**: X 0~1000(서→동), Y 0~900(남→북). 북쪽(Y↑)=한강 경계. 1타일=1m. (1000×900, 2026-06-06 확대)

**서브존 5 (랜드마크)**:

| 존 | 중심(X,Y) | 점유범위(X × Y) | 위험 | 역할 |

| 폐아파트 단지 | (650,300) | 550–750 × 200–400 | ★★☆☆☆ | 수직탐색, 컨테이너 다수 |

#### H. 크기·밀도·시간 튜닝 (한 판 = 1~2 랜드마크 '깊게' → 15분+)
- **맵 크기 = 1000×900 확정**(2026-06-06 ×1.25 확대, 멀티레이드 §I). 한 판 15분+는 footprint가 아니라 **밀도 + 수직 깊이**로 채운다("막는 건 맵이 아니라 시간·욕심"). 맵이 커진 만큼 한 판 도달 랜드마크는 1~2개(딥런 1개) → 반복 레이드. 어느 칸이든 한 판은 **1~2 랜드마크를 깊게**.
- **갱신 시간 모델 — 깊은 1~2 랜드마크 런(넓은 대로 반영)**:

  | 활동 | 비중 | 시간 | 비고 |
  |------|------|------|------|
  | 이동(대로 빠름 + 골목 느림) | 35% | ~315s | 진입·랜드마크 간·탈출 |
  | 내부 파밍(다층 + 소형 건물) | 40% | ~360s | 랜드마크 층별 + F 소형 진입 |
  | 전투·경계 | 25% | ~225s | 랜드마크/골목 적 조우 |

  → 합 ~900s ≈ **15분**, 펜트하우스/상층까지 **깊게 털면 16~20분**(욕심 = 시간 초과 위험).
- **밀도 타깃**:
  - 랜드마크 내부 = **층당 루트 컨테이너 6~10 + 적 1~3기**. 1개 랜드마크 깊이 파밍 ≈ **5~7분**.
  - 간선 변 **소형 건물 = 동선 30~50m마다 1채**(F). 골목엔 막다른 점포 다수.
  - **전투 = 한 판 3~6회 조우**(랜드마크 내부 + 골목 코너). 대로는 원거리 조우, 골목은 근접.
- **샘플 런(≈16분)**: 진입(대로) 2분 → 폐아파트 1~3층+펜트하우스 깊이 파밍·전투 6분 → 골목 이동(B 우회) 2.5분 → 유리타워 저층+상층 R&D 4분 → 소형 2채 1.5분 → 탈출 2분 = **18분** → 욕심 줄이면 14~15분. "딱 1~2개, 더 욕심내면 시간 초과."

#### I. 리플레이성 (여러 번 레이드 전제 — 매판 다른 경험)
1지역은 **반복 공략**이 목적(5랜드마크 = 한 판 1~2개 → 전부 보려면 3~5판). 그래서 랜드마크를 5개로 둔다. 매판 다른 경험을 **4축**으로:
1. **스폰 로테이션(5)** — 시작 위치마다 가까운 랜드마크가 달라 진입 동선·우선순위 변동(§블록 레이아웃 스폰5, 각 랜드마크 1:1).
2. **랜덤 탈출(3/판, 스폰과 멀리)** — 추출 지점이 매판 달라 귀환 루트·딥런 가능 구역 변동(유동탈출=콘텐츠 게이트). 스폰↔활성탈출 항상 멀어 맵 횡단 강제.
3. **퀘스트 로테이션** — 출전 시 퀘스트 발급, 매판 목표를 다른 랜드마크 반경에 배치 → 안 가던 구역 유인. MQ(메인)+SQ(서브)+DQ(반복) 풀 섞기([quest.md](quest.md)/[quests-region1.md](quests-region1.md)).
4. **랜덤 짙은현상**(§L) — 매판 다른 구간·시점에 현상 발생 → 그 판 한정 루디·희귀 + 현상 몬스터, 미회수 시 증발([anomaly.md](anomaly.md)). 적·루트가 판마다 달라짐.
→ **맵 커도 무방**(멀티레이드라 빈 이동도 '다음 판 콘텐츠'). **맵 1000×900 확정**(§H).

#### L. 적·스폰 = 짙은현상 기반 (낮/밤 무관)
적 종류·스폰은 낮/밤이 아니라 **현상 유무**로 갈린다([anomaly.md](anomaly.md) — 현상 = 랜덤 위험/보상 타임어택).
- **현상 없음(평상시)**: **인간 적**(탐색꾼·밴딧·약탈자) — 랜드마크에 **맵툴 사전 배치**(`gb_enemy`/EnemyController). 위험 위계(§J)대로 분포, 항상 존재.
- **현상 활성(랜덤)**: 그 구간에 **현상 몬스터 + Anomaly 티어 루트(루디·희귀)** 동시 스폰 → **사라지기 전 회수**, 종료 시 미회수 루트·몬스터 **증발**. 몬스터 = **현상 전용 이상체 + 기존 강화/오염 변종**(둘 다).
- **스폰 방식("스폰 방향")**: 맵툴 **`AnomalySpawnPoint`**(타입=몬스터/루트/오브젝트, 구역 자동연결) **배치 우선** → 현상 활성 시 **최소거리 밖·안개 가장자리**에서 등장(옆에서 즉시 X). 없으면 `AnomalyZone.RandomPoint` 폴백. (anomaly.md Phase 2)
- **랜드마크별 현상 빈도/강도 차등**: **식물원(시그니처)·유리타워 = 현상 빈발·강함**(이상체 최다, Anomaly 루트 최고) / 상가·강변 = 드묾·약함. → 평상시 인간 적의 위험 위계(§J) + 현상 강도 = **이중 난이도 축**.
- **리플레이성**: 현상은 매 판 다른 구간·시점에 랜덤 발생(§I) → "이번 판 어디에 떴나"가 콘텐츠.
