# 월드맵 — Be Right Back (BRB)

> **현 상태 = 진실.** 컨셉 아트 기준 월드 구조. 플레이 가능 맵·씬과 1:1 대응은 아직 없음.

BRB 세계의 **거시 월드맵 컨셉 아트**를 기록한다.  
중앙 「영야」 코어 + 6개 외곽 지구 + 헥사 고속환형·지하철·탈출·위험 구역 범례를 개발·기획 참고용으로 고정한다.

## 7-5. 1지역 배경 레퍼런스: 서울 마곡지구 (강서구)

**적용 범위**: **1지역(데모 플레이 지역, scrap_market)에 한정.** 마곡은 다른 6지구와 무관 — 나머지 지구는 기존 컨셉 유지. 1지역 한 맵 안의 **서브존·동선·랜드마크 설계 레퍼런스로만** 사용. 게임 속 지명은 허구 유지(실명·상표 미사용, 아트가이드 "NO Korean text" 준수).

### 왜 마곡인가 (1지역 한정)
- **습지 매립 신도시** — 원래 한강변 농지·습지였다가 2010년대 개발. "밤에 도시가 자연으로 되돌아간다 = 짙은 현상"과 정합. 매립지가 밤마다 침수·구조변화하는 근거.
- **한 지역 안에 다양성** — 상권·아파트·식물원·유리타워가 좁은 범위(~3.5km²)에 밀집 → **단일 지역 맵 안에서 서브존 다변화**가 자연스러움.
- **신선한 폐허 톤** — "새것인데 버려진 유리빌딩 신도시". 흔한 낡은 폐건물과 차별화.

### 1지역 내부 서브존 ↔ 마곡 실장소 매핑

| 1지역 서브존 (맵 구획) | 마곡 실제 장소 (레퍼) | 차용 랜드마크 | 게임 역할 |
|------------------------|----------------------|---------------|-----------|
| 상가 골목 (진입부) | 마곡나루·발산역 상권 | 역세권 상가, 먹자골목 | 시작 파밍, 좁은 골목 전투 |
| 대단지 폐아파트 | 마곡엠밸리 아파트 | 고층 아파트 동 | 수직 탐색, 다수 컨테이너 |
| 유리 R&D 블록 | LG사이언스파크 | 유리 오피스 타워군 | 고급 루트, 후반 진입 구역 |
| 유리온실 / 습지 | 서울식물원 | **거대 유리온실 돔 + 호수습지** | 시그니처 랜드마크, 밤 침수 구역 |
| 강변 도로 (경계) | 한강 마곡철교변 | 강변 부두·고가 | 맵 경계, 탈출구 후보 |

※ 게임 내 표기는 허구 지명만 사용. 표는 **블록 배치·동선·랜드마크 발상용**.

### 1지역 맵 동선 힌트
- **한강이 북쪽 경계** → 맵 상단을 강변/탈출구로
- **상권(진입)→아파트→유리타워→식물원** 순으로 위험도·보상 상승 동선
- **서울식물원 유리온실 돔** = 1지역의 랜드마크 + 밤 "짙은 현상"이 가장 강한 침수 구역으로

### 1지역 맵 스케일 & 레이드 파라미터 (확정)

**스케일 기준 (코드 검증)**: `tileSize = 1f` → **1타일 = 1m**. 플레이어 `moveSpeed = 5`(걷기 5m/s), 질주 ×1.6(8m/s), 앉기 ×0.5(2.5m/s). 질주는 스태미나 제약(소모 12/s, 풀스태 ≈8.3초)으로 장거리 실효 ≈6m/s.

**설계 의도**: 고정 맵 / 스폰 다수 / **고정 탈출구 1 + 유동 탈출구 4** / **레이드 15분** / 한 판에 **랜드마크 5개 중 1~2개만 도달** + 퀘스트 1개 완수 가능.

**15분 레이드 시간 예산 (역산 근거)**:

| 활동 | 비중 | 시간 |
|------|------|------|
| 이동 | 50% | 450초 |
| 루팅(정지) | 30% | 270초 |
| 전투·경계 | 20% | 180초 |

- 이동 450초 × 실효 5m/s = 경로 2,250m, 굴곡 ×1.7 → 순수 직선 이동량 ≈1,320m(왕복 포함) → **편도 최대 침투 ~600~700m**
- 랜드마크 간격 **~300m** → 한 판 1개 확실 + 2번째 걸칠까말까 ✅

**확정 맵 크기: 800 × 700 타일 (800m × 700m, ≈0.56km², 실제 마곡 약 1/6 압축)**
- 짧은변 직선걷기 2.3분 / 긴변 2.7분 / 대각선 3.5분
- 막는 건 맵이 아니라 **시간·욕심** — 직선질주하면 다 보이지만 빈손 탈출. 루팅하면 1~2개. → "한 집만 더?" 긴장 성립.

**구조 배치**:
- **스폰 다수**: 가장자리·코너 분산 → 판마다 가까운 랜드마크 달라짐(스폰=콘텐츠 로테이션)
- **고정 탈출구 ×1**: 저위험 상가골목 쪽, 항상 안전 회수 보장
- **유동 탈출구 ×4**: 코너·오지, 해당 판에만 활성 → 안 가던 구역 유인(커버리지 분산)
- **퀘스트**: 목표를 랜드마크 1~2개 반경에 배치 → 집중 15분 런으로 완수 가능

**크기 대안**: 500×450(2~3개 도달, 빡빡) / **800×700(1~2개, 권장)** / 1000×900(0~1개, 과대)

### 1지역 밀도 설계 (낙원식) — 진행중 🚧

**목표**: 막힌 길 / 숨겨진 방 / 잠긴 방 등으로 공간을 빽빽하게. 낙원(LAST PARADISE) 레퍼런스 — 밀집 인테리어 + 열쇠 게이트 + 숨겨진 캐시.

**코드 기반 (이미 구현되어 있음 — 신규 시스템 불필요)**:
- `InteractableObject.InteractType.Door` 타입 존재
- `DoorController.cs` 완비 — 잠금 해제 4종:
  - `LockType.None` (바로 열림), `Key` (열쇠 아이템 `requiredKeyId` 필요, `consumeKey` 옵션), `Quest` (퀘스트 완료), `Switch` (레버/스위치)
  - `activateOnOpen[]` / `deactivateOnOpen[]` → **문 열면 방 내부·숨겨진 통로 활성화** (숨겨진 방 구현에 그대로 사용)
  - 물리 차단: `doorCollider` 통과 방지, 열리면 비활성
- 열쇠 = `ItemData` Key 카테고리 (이미 존재) + `ItemDatabase.Get(keyId)`

**적용 방향 (다음 작업 시 설계할 것)**:
- **막힌 길**: 무너진 잔해·바리케이드로 간선도로 차단 → 굴곡 ×1.7 유도, 우회 강제
- **잠긴 방** (`LockType.Key`): 고급 루트를 열쇠 뒤에 배치. 열쇠는 다른 구역서 파밍 → 구역 간 왕래 동기
- **숨겨진 방** (`Switch` + `activateOnOpen`): 레버·균열벽으로 비밀 캐시 개방
- **퀘스트 문** (`LockType.Quest`): 스토리·퀘스트 게이트
