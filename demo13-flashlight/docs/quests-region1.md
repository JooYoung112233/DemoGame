# 퀘스트 & 미션 — 1지역 (폐상가 교역 지구)

> 현 상태 = 진실. 결정이 바뀌면 이전 내용을 덮어쓰고, 변경 로그에 추가.

---

## 1. 퀘스트 구조 개요

```
[메인 MQ / 사이드 SQ] ──→ 스토리·해금 (일회성)
     │
     ▼ prologue_complete
[게시판 BQ] ──→ 평판·스크랩 메인 루프 (수령=보드 / 보고=의뢰인)
     │              ╲
     │               [NPC 개인 NQ] ──→ 신뢰·호감 마일스톤 (일회·반복 혼합)
     ▼
[전당포 DQ] ──→ 일일 1회 (루디·수집, 별도 슬롯)
     │
     ▼
[실적 AM] ──→ 누적 달성 (백그라운드)
```

> **동시 진행**: **계약 슬롯 1개**(BQ 또는 NQ) + **DQ 슬롯 1개**(전당포, MQ-002 후). AM은 제한 없음.

| 항목 | 내용 |
|------|------|
| 수주 | S-004 (게시판에서 "민이를 찾아 주세요" 의뢰서 수령, 의뢰자 = 수아) |
| 목표 | 폐상가 **안전 구간**에서 '민이' 흔적 (창고 손자국·노크 규칙) |
| 완료 조건 | 창고 흔적 발견 → 귀환 → **회수꾼에게 보고** |
| 보상 | 스크랩 x10 (수아 보수) + **평판 +10** + SQ-002 해금 |
| 의뢰인 | **베테랑 회수꾼** (게시판 수령 / 보고는 회수꾼) |

**진행 중 자동 트리거 (씬 ID):**
- 진입 → S-005 (수색 튜토리얼)

- 적대 탐색꾼 조우 → S-005_COMBAT (전투 튜토리얼)

- 맨홀 탈출 → S-006

> MQ-001 완료 후 회수꾼이 개인 의뢰 **SQ-002(회수꾼의 상자)**를 제안 → 완료 시 거처(컨테이너) 알선.

> **BQ/NQ와 별도 슬롯** — 계약 1개 + DQ 1개 동시 가능.

### 의뢰 대사 (공통)

```
수주 시:
  전당포 주인: "하나 부탁할 게 있어."
  (의뢰 내용 UI 표시)

완료 시:
  전당포 주인: "잘했어. 여기."
  (보상 지급 UI)

포기 시:
  전당포 주인: "알겠어. 다음에 다시 와."
```

### 의뢰 갱신 규칙

- 매일 자정 (게임 내 시간 or 실시간) 새 의뢰로 교체
- 진행 중인 의뢰가 있으면 갱신되지 않음
- 같은 의뢰가 연속 출현하지 않음 (최소 1일 간격)
- DQ-006, DQ-007 (루디 납품)은 가중치 낮음 (10%)

### 6-1. 신규 NPC 상세

**고정 노점상 (`vendor`)**
- 폐상가 한 점포에 눌러앉은 정착 상인. **상시 같은 자리**, 안전 구간 레이드에서 영업.
- 떠돌이 상인과 차별: 떠돌이=랜덤·고가·희귀, 노점상=고정·안정·소모품 위주.
- 판매: 붕대·배터리·통조림·수리키트·(탄약). 누적 거래 시 소폭 할인(거래 실적 AM-041 연동).
- 폐상가 토박이 → 지역 소문·파밍 포인트 잡담 제공(세계관 전달).

**밴딧 협상꾼 (`bandit_negotiator`)**
- 폐상가 밴딧 무리의 협상 담당. 전투 일변도가 아닌 **선택지** 제공:
  - 통행료(화폐/아이템) 지불 → 해당 구역 안전 통과
  - 거래(장물 매입/매도)
  - 적대 → 전투 (주변 밴딧 합세)
- **두려움 시스템 연동**: 위협/제압 시 두려움↑ → 통행료 면제·순종. 회유(거래)는 중립 유지.
- 떡밥: 밴딧 무리 배후 암시(후속 지역 연결).

**갇힌 생존자 (`trapped_survivor`)**
- 무너진 상점 내부 특정 지점에 갇힌 민간인. 낮 레이드에서 발견.
- **1회성 구출 미션(SQ-001)**: 잔해 제거(도구/조건) → 구출.
- 구출 보상: 화폐 + 아이템 + **2지역 떡밥**("침묵 생활 지구에 사람이 모여 산다더라").
- 구출 후 안전가옥 합류 X (떠나거나 노점상 근처 정착해 짧은 후속 잡담).

```
6. 레이드 — 목표 달성 · 파밍 · 루디

8. 전당포 — 루디 매입 / DQ 완료 / 잡템 판매
9. 수면 — 생존 스탯 · DQ/BQ 보드 갱신
```
