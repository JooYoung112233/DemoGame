> 현 상태 = 진실. 결정이 바뀌면 이전 내용을 덮어쓰고, 변경 로그에 추가.

## 1. 퀘스트 구조 개요

```
[메인 퀘스트] ──→ 스토리 진행 (일회성)
     │
     ▼
[반복 의뢰]  ──→ 일일 루프 (MQ-002 완료 후 해금)
     │
     ▼
[실적 미션]  ──→ 누적 달성 보상 (항상 추적)
```

## 2. 메인 퀘스트 (일회성)

### MQ-001: 첫 탐색

| 항목 | 내용 |
|------|------|
| 수주 | S-003 (전당포 제안 수락 시 자동) |
| 목표 | 폐상가 교역 지구 (낮)에 진입하여 탈출구로 귀환 |
| 완료 조건 | 폐상가 낮 레이드 1회 완료 (탈출 성공) |
| 보상 | 밤 레이드 해금 |
| 의뢰인 | 전당포 주인 |

**진행 중 자동 트리거:**
- 첫 파밍 시 → 내레이션 (S-011)
- 떠돌이 상인 구역 진입 시 → 상인 대화 (S-012)
- 밴딧 접근 시 → 전투 (S-013)
- 쪽지 파밍 시 → 단서 획득 (S-014)

---

### MQ-002: 첫 루디 회수

| 항목 | 내용 |
|------|------|
| 수주 | S-015 귀환 시 자동 |
| 목표 | 폐상가 교역 지구 (밤)에서 루디 조각을 회수하여 전당포 주인에게 전달 |
| 완료 조건 | 루디 조각 1개 납품 |
| 보상 | 전당포 정식 거래 해금, 반복 의뢰 해금, 화폐 보상 |
| 의뢰인 | 전당포 주인 |

**진행 중 자동 트리거:**
- 지하창고 루디 획득 시 → 시계 이상현상 (S-023, 첫 1회만)

## 3. 반복 의뢰 — 전당포 일일 의뢰

> MQ-002 완료 후 해금. 1일 1회 갱신. 전당포 주인에게 말 걸어서 수주.
> 동시에 1개만 진행 가능.

### 의뢰 풀 (랜덤 선택)

| ID | 이름 | 유형 | 목표 | 보상 |
|----|------|------|------|------|
| DQ-001 | 물자 수집 | 수집 | 통조림 3개 납품 | 화폐 (소) |
| DQ-002 | 소모품 확보 | 수집 | 붕대 2개 + 배터리 1개 납품 | 화폐 (소) |
| DQ-003 | 고철 수거 | 수집 | 고철 5개 납품 | 화폐 (중) |
| DQ-004 | 위협 제거 | 처치 | 밴딧 3명 처치 (낮 or 밤) | 화폐 (중) |
| DQ-005 | 야간 순찰 | 처치 | 밤 레이드에서 밴딧 2명 처치 | 화폐 (중) + 붕대 x1 |
| DQ-006 | 루디 납품 | 납품 | 루디 조각 1개 납품 | 화폐 (대) |
| DQ-007 | 루디 다량 납품 | 납품 | 루디 조각 3개 납품 | 화폐 (특대) |
| DQ-008 | 폐상가 정밀 수색 | 탐색 | 특정 파밍 포인트 3곳 수색 완료 | 화폐 (소) + 랜덤 아이템 |

### 의뢰 대사 (공통)

```
수주 시:
  전당포 주인: "하나 부탁할 게 있어."
  (의뢰 내용 UI 표시)

완료 시:
  전당포 주인: "잘했어. 여기."
  (보상 지급 UI)

포기 시:
  전당포 주인: "알겠어. 다음에 다시 와."
```

### 의뢰 갱신 규칙

- 매일 자정 (게임 내 시간 or 실시간) 새 의뢰로 교체
- 진행 중인 의뢰가 있으면 갱신되지 않음
- 같은 의뢰가 연속 출현하지 않음 (최소 1일 간격)
- DQ-006, DQ-007 (루디 납품)은 가중치 낮음 (10%)

## 5. 해금 테이블

```
[게임 시작]
  │
  ├→ 안전가옥: 침대, 보관함 ─── S-004에서 해금
  ├→ 장비: 녹슨 파이프, 붕대 x2 ─── S-004에서 획득
  │
  ▼
[MQ-001 수주] ─── S-003
  │
  ├→ 지도판 사용 가능 ─── S-005 (첫 휴식 후)
  ├→ 폐상가 (낮) 출격 가능
  │
  ▼
[MQ-001 진행 중 — 폐상가 낮 레이드]
  │
  ├→ 떠돌이 상인 첫 조우 ─── S-012 (거래 가능)
  ├→ 전투 튜토리얼 ─── S-013
  ├→ 쪽지 단서 획득 ─── S-014 (밤 지하창고 힌트)
  │
  ▼
[MQ-001 완료] ─── S-015 (귀환)
  │
  ├→ 폐상가 (밤) 해금
  ├→ MQ-002 자동 수주
  │
  ▼
[MQ-002 진행 중 — 폐상가 밤 레이드]
  │
  ├→ 지하창고 접근 가능 (쪽지 힌트 있을 시 마커 표시)
  ├→ 루디 파밍 가능
  ├→ 시계 이상현상 체험 ─── S-023 (첫 1회)
  │
  ▼
[MQ-002 완료] ─── S-030 (루디 납품)
  │
  ├→ 전당포 정식 거래 해금 (풀 상점)
  ├→ 반복 의뢰 (DQ) 해금
  ├→ 실적 미션 (AM) 추적 시작
  ├→ 자유 반복 레이드 루프 진입
  │
  ▼
[반복 루프 — 1지역 엔드 콘텐츠]
  │
  ├→ 낮/밤 자유 선택 레이드
  ├→ 전당포 일일 의뢰 (1일 1개)
  ├→ 떠돌이 상인 랜덤 조우 (낮 30%)
  ├→ 장비/아이템 축적
  ├→ 실적 미션 달성
  │
  ▼
[2지역 업데이트 시 — 여기서 이어짐]
  │
  ├→ 지도판에 "침묵 생활 지구" 해금
  ├→ 전당포 주인 새 대화 추가
  ├→ MQ-003 수주
  └→ ...
```

## 7. 1지역 밸런스 가이드라인

> 수치는 초안. 플레이테스트 후 조정.

### 레이드 1회 예상 수익

| 구분 | 예상 시간 | 예상 화폐 | 예상 아이템 |
|------|----------|----------|------------|
| 낮 (안전) | 5~10분 | 50~100 | 잡템 3~5개 |
| 밤 (위험) | 10~15분 | 100~200 | 잡템 2~4개 + 루디 0~2개 |

### 상점 가격 (기준점)

| 아이템 | 구매가 | 판매가 |
|--------|--------|--------|
| 붕대 | 30 | 10 |
| 배터리 | 50 | 15 |
| 저급 나이프 | 150 | 50 |
| 통조림 | 20 | 8 |

### 의뢰 보상 (기준점)

| 등급 | 화폐 |
|------|------|
| 소 | 50~80 |
| 중 | 100~150 |
| 대 | 200~300 |
| 특대 | 400~500 |

### 진행 페이스 목표

- **1세션 (30분)**: MQ-001 + MQ-002 완료 → 루프 진입
- **1주일 (매일 30분)**: 장비 중급 도달, 실적 미션 중반
- **2~3주**: 실적 미션 대부분 달성, 상인 호감도 축적
- **이후**: 2지역 업데이트 대기 (축적된 자원/호감도가 2지역에서 이점)
