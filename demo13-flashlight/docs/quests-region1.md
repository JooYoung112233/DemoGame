# 퀘스트 & 미션 — 1지역 (폐상가 교역 지구)

> 현 상태 = 진실. 결정이 바뀌면 이전 내용을 덮어쓰고, 변경 로그에 추가.

---

## 1. 퀘스트 구조 개요

```
[메인 MQ / 사이드 SQ] ──→ 스토리·해금 (일회성)
     │
     ▼ prologue_complete
[게시판 BQ] ──→ 평판·스크랩 메인 루프 (수령=보드 / 보고=의뢰인)
     │              ╲
     │               [NPC 개인 NQ] ──→ 신뢰도 마일스톤 (일회·반복 혼합)
     ▼
[전당포 DQ] ──→ 일일 1회 (루디·수집, 별도 슬롯)
     │
     ▼
[실적 AM] ──→ 누적 달성 (백그라운드)
```

> **동시 진행**: **계약 슬롯 1개**(BQ 또는 NQ) + **게시판 일일 슬롯**(BD 최대 2, §9.3) + **DQ 슬롯 1개**(전당포, MQ-002 후). AM은 제한 없음.

### MQ-001: 민이를 찾아 주세요

| 항목 | 내용 |
|------|------|
| 수주 | S-004 (게시판에서 "민이를 찾아 주세요" 의뢰서 수령, 의뢰자 = 수아) |
| 목표 | 폐상가 **안전 구간**에서 '민이' 흔적 (창고 손자국·노크 규칙) |
| 완료 조건 | 창고 흔적 발견 → 귀환 → **회수꾼에게 보고** |
| 보상 | 스크랩 x10 (수아 보수) + **평판 +10** + SQ-002 해금 |
| 의뢰인 | **베테랑 회수꾼** (게시판 수령 / 보고는 회수꾼) |

**진행 중 자동 트리거 (씬 ID):**
- 진입 → S-005 (수색 튜토리얼)
- 첫 파밍 → S-005_LOOT (무게/골라담기 튜토리얼)
- 적대 탐색꾼 조우 → S-005_COMBAT (전투 튜토리얼)
- 창고 흔적(노크 규칙) 발견 → S-005_WAREHOUSE (`mq001_trace_found`)
- 맨홀 탈출 → S-006

> MQ-001 완료 후 회수꾼이 개인 의뢰 **SQ-002(회수꾼의 상자)**를 제안 → 완료 시 거처(컨테이너) 알선.

## 3. 전당포 일일 의뢰 (DQ)

> MQ-002 완료 후 해금. 1일 1회 갱신. 전당포 주인에게 말 걸어 **수주**.
> **BQ/NQ·게시판 BD와 별도 슬롯** — 계약 1개 + DQ 1개 + BD 2개 동시 가능.
> **역할 분리(2026-06-09)**: DQ = **전당포 주인(강무진)이 직접 사들이는 거래 의뢰** — 매입·감정·루디·희귀·재고 전문. 일반 생존품 수집·전투·정찰 잡무는 **게시판 BD(§9.3)** 담당. 둘은 색이 겹치지 않음.

### 의뢰 갱신 규칙

- 매일 자정 (게임 내 시간 or 실시간) 새 의뢰로 교체
- 진행 중인 의뢰가 있으면 갱신되지 않음
- 같은 의뢰가 연속 출현하지 않음 (최소 1일 간격)
- DQ-006, DQ-007 (루디 납품)은 가중치 낮음 (10%)

### 6-1. 신규 NPC 상세

**고정 노점상 (`vendor`)**
- 폐상가 한 점포에 눌러앉은 정착 상인. **상시 같은 자리**, 안전 구간 레이드에서 영업.
- 떠돌이 상인과 차별: 떠돌이=랜덤·고가·희귀, 노점상=고정·안정·소모품 위주.
- 판매: 붕대·배터리·통조림·수리키트·(탄약). 누적 거래 시 소폭 할인(거래 실적 AM-041 연동).
- 폐상가 토박이 → 지역 소문·파밍 포인트 잡담 제공(세계관 전달).

**밴딧 협상꾼 (`bandit_negotiator`)**
- 폐상가 밴딧 무리의 협상 담당. 전투 일변도가 아닌 **선택지** 제공:
  - 통행료(화폐/아이템) 지불 → 해당 구역 안전 통과
  - 거래(장물 매입/매도)
  - 적대 → 전투 (주변 밴딧 합세)
- **두려움 시스템 연동**: 위협/제압 시 두려움↑ → 통행료 면제·순종. 회유(거래)는 중립 유지.
- 떡밥: 밴딧 무리 배후 암시(후속 지역 연결).

**갇힌 생존자 (`trapped_survivor`)**
- 무너진 상점 내부 특정 지점에 갇힌 민간인. 낮 레이드에서 발견.
- **1회성 구출 미션(SQ-001)**: 잔해 제거(도구/조건) → 구출.
- 구출 보상: 화폐 + 아이템 + **2지역 떡밥**("침묵 생활 지구에 사람이 모여 산다더라").

## 9. 지속 플레이 퀘스트 라인 — 의뢰서 × NPC 관계

> `prologue_complete` 이후 **2지역 전** 메인 동기. 플레이어가 매일 할 일 = **평판 올리기** + **NPC 신뢰 쌓기** + **스크랩·루디 축적**.

### 9.1 두 축 — 평판 vs 신뢰도

> **시스템 단순화(2026-06-09)**: 관계 3축(호감/신뢰/두려움) → **신뢰도 단일**로 통합. **호감은 신뢰도로 합침**. **두려움**은 위협 루트 전용으로만 별도 존치(story.md §10 강무진 희생). 즉 플레이어가 보는 미터기 = **① 평판(전역) + ② NPC 신뢰도**(+ 숨은 두려움).

| 축 | 의미 | 오르는 방법 | 플레이어 보상 |
|----|------|------------|--------------|
| **평판** (이름값) | 폐상가 **사회 신용** | BQ·MQ·SQ·루디 납품 | 게시판 **의뢰 등급** 해금 · 지역 상점(정가) |
| **신뢰도** (NPC별) | **개인 NPC**와의 관계 | NQ·대화 선택 · 약속 이행 | 개인 의뢰·할인·정보·스토리 단계 |

> 평판 ≠ 신뢰도. 회수꾼 신뢰도 80이어도 평판 낮으면 고급 BQ 잠김.

**신뢰도 적립 규칙 (2026-06-09 — 하드 조정)**

> 관계도 너무 빨리 차지 않게: 마일스톤만 크게, 반복은 찔끔, 하루 상한.

- **마일스톤(서사 NQ, 일회성)** = 표기값(보통 +5~8) — 관계의 큰 점프는 여기서만.
- **반복 의뢰(지역·신뢰)** = **반복 +1 / 일회 +2** 고정.
- **BD/BQ 관계 뿌리기** = 원칙 제거, **flavor용 특정 1~2개만 +1**.
- **일일 상한: NPC당 +3/일** — 한 NPC에게 의뢰를 몰아줘도 하루 +3까지만 누적(초과분 무효).
- **신뢰도 게이트 사다리**: 마일스톤 해금 임계 = **신뢰도 50 · 70 · 90**(기존 40/60 → 상향).

## 9.7 상점·하이드아웃 (평판 × 신뢰도 해금)

> 4 허브 NPC는 각자 **테마 역할**을 가진다 — **전당포·회수꾼·떠돌이 = 상점**(테마 카탈로그), **관리인 = 하이드아웃 관리**(모듈·라디오·파견). 관계가 깊어질수록 **더 다양해지고 싸지고, 거점이 커진다** — 신뢰도 쌓기의 직접 보상.
> ⚠️ 가격·품목은 **placeholder**(아이템 판매가 확정 후 조정). 레이드 현지의 **고정 노점상(`vendor`, §6-3)**은 별개(낮 영업·간단 소모품) — 아래는 **안전가옥 허브**.

### 해금 3층 (수치 + 서사)

| 층 | 무엇을 여나 | 효과 |
|----|------------|------|
| **신뢰도** (NPC별) | **카테고리 폭 + 할인 + 희귀 회전** | T0(기본) → T1(신뢰30) → T2(신뢰60) → T3(신뢰90) |
| **평판** (전역) | **재고 "품질·정가"** | D+ 중급 입고·정가 / C+ 고급 입고 / B+ 희귀 입고율↑ / A+ 특수 1종 |

**파견(Dispatch) 모듈** — 정보·탐사 확장 루프 (idle 정찰)

> ⚠️ **원칙 정합(`safehouse-intel.md`)**: 안전가옥은 **자원 생산 ❌ / 탐사 확장 ⭕**. 파견은 **자원 faucet이 아니라 인텔(새 탐사 목표) 생성기.** 보상 = **하이브리드(정보 위주 + 소량 보급)** — 루디·핵심 재료 idle 수익 없음. 상세 시스템 = `safehouse-intel.md` Phase C와 합본.

- **파견 인력** = 구출·합류 NPC. **SQ-001 갇힌 생존자** 구출 시 첫 파견 인력 합류(침실 수용 인원 한도).
- **파견 보내기** → **레이드 단위/실시간 타이머** 후 결과 회수(접속 안 해도 거점이 **새 탐사 목표를 찾아온다** → "한 집 더" 외 동기).
- **결과 = 인텔 위주**: 새 상호작용 지점(잠긴 금고/문/지하 입구) 월드 생성 · 파견지/POI 해금 · 새 인력. **보조 = 소량 보급(소모품 1~2)**.
- **성공률** = 인력 숙련 + 파견 Lv + 평판 + 장비 지급. **실패 시** 빈손/부상/최악엔 인력 손실 위험(고위험 파견).
- 신뢰도/평판↑ → 파견 슬롯·성공률·고급(고위험) 파견 해금.

#### 파견(Dispatch) 시스템 상세 (수치 전부 placeholder)

> **타이머 = 실시간(오프라인 진행)**. 접속 안 해도 벽시계 기준 경과 → 복귀 시 결과 수령(로컬 타임스탬프 diff). 데모는 시간 짧게.

| 스탯 | 값 | 영향 |
|------|------|------|

| **특기** | 운반(자원·교역) / 정찰(정보) / 채집(루디) / 구조 | 일치 파견 시 +10, 보상량↑ |

| **2인(팀)** | 두 인력 기여 **합산**, 기회비용 ↑(둘 묶임) |
| 2인 · **같은 특기** | 보상량 **+25%** (효율 특화) |
| 2인 · **보완 특기** | 성공률 **+8**, **부가 전리품(2차 롤)** 확률 + |

> 침실 수용 인원 = 보유 인력 수, 파견 보드 슬롯 = **동시 파견 미션 수**. 2인 파견은 인력 2명을 한 슬롯에 묶음.

**C. 성공률 공식**

```
성공률 = 미션 base + Σ(인력 기여) + 팀 보정 + 장비 보너스 + 파견Lv + 평판
         (상한 95 / 하한 5)
```

| 요소 | 보정 |
|------|------|
| 미션 base | 교역 85 / 자원 70 / 정보 55 / 루디 35 / 구조 30 |
| 인력 기여(명당) | 견습 +5 · 숙련 +12 · 베테랑 +20 · 특기 일치 +10 |
| 팀 보정 | 단독 −15 / 보완 2인 +8 |
| 파견 보드 Lv | +0 / +5 / +10 |
| 평판 | D +0 / C +5 / B +10 |
| 장비 지급 | 아래 D |

**결과 등급**: 실패 / 성공 / **대성공(크리)**. 크리 확률 = (성공률 95 초과분 + 베테랑·시너지 보너스) → 보상 **1.5~2배 + 희귀 롤**.

**D. 장비 지급 — 성공률·안전을 산다 (팀당 3슬롯)**

| 지급 | 효과 | 소모 |
|------|------|------|
| **무기**(`pipe`/`knife`/`axe`) | 교전 대비 → 성공 **+3/+6/+10**(저/중/고), 인력 손실 위험↓ | 회수(파손 10~20%) |
| **방어구**(`coat_light`/`vest_scrap`/`armor_night`) | **실패 시 부상·손실 경감**(손실 5%→1%) | 회수 |
| **의료**(`bandage`/`hemostatic_powder`/`first_aid_kit`) | 부상 시 **자동 치료 → 인력 손실 방지** | 실패 시 소모 |
| **식량·물**(`canned_food`/`water_bottle`) | 장시간(루디·구조) 가능, 피로 제거 | 소모 |
| **탐지등 연료**(`ruby_shard`/`battery_aa`) | 야간(정보·루디) 성공 **+** | 소모 |
| **지도**(`map_fragment`) | 길 안다 → 정보·루디 성공 **+8** | 소모 |

> 장비 투자 = 인벤 자원의 또 다른 출구("좋은 장비 들려보내 루디 파견 성공률을 산다"). 무지원 파견은 base만.

**E. 파견 유형 & 보상 (5종)**

> **하이브리드 보상**: 주 보상 = **인텔(새 탐사 목표)**, 보조 = **소량 보급(소모품 1~2)**. 루디·핵심 재료 idle 수익 없음(레이드에서만). 대성공 = 인텔 등급↑ + 보급량↑.

| 유형 | 소요 | base | 주 보상 (인텔·탐사) | 보조(소량 보급) | 실패 시 |
|------|:---:|:---:|------|------|------|
| **보급 심부름**(교역) | 20분 | 85 | 상인 신뢰도+1 · 다음 방문/시세 정보 | 소모품 1~2(`bandage`/`battery_aa`/`canned_food`) | 빈손 |
| **랜드마크 조사**(중) | 30분 | 70 | **새 파견지 해금 단서** · 지도 확장(`map_fragment`) | 소모품 1 | 빈손 |
| **인텔 정찰**(중) | 1h | 55 | **새 상호작용 지점 생성**(잠긴 금고·문·지하 입구 → 레이드 맵) · POI / **2지역 단서** | 소모품 1 | 빈손 + 피로 |
| **현상 정찰**(고위험) | 2h | 35 | **루디 위치·현상 심부 인텔**(→ 플레이어가 직접 가서 채집) · `anomaly_residue` 위치 | 소모품 1 | 부상 · **인력 손실 위험** |
| **구조 신호**(고위험) | 3h | 30 | **새 인력 영입**(탐사 확장) | — | 못 구함 + 파견대 부상 |

> 핵심: 파견은 **"어디에 뭐가 있다"를 알아 오고, 따는 건 플레이어가 직접.** 현상 정찰도 루디를 **idle로 안 줌** — 위치 인텔만(레이드 동기 보존).

**F. 보드/침실 Lv (관리인 업그레이드)**

| 단계 | 해금 | 효과 |
|------|------|------|
| 파견 Lv1 | 신뢰60 | 슬롯 1 · 교역·자원·정보 파견 |
| 파견 Lv2 | 신뢰75 + 평판 C | 슬롯 2 · **현상 정찰·구조 파견 해금** |
| 파견 Lv3 | 신뢰90 + 평판 B | 슬롯 3 · 장거리 고보상 · 크리율 + |
| 침실 Lv1/2/3 | 신뢰30~ | 인력 수용 2/4/6명 |

- **파견 비용**: 보낼 때 보급(식량/물 1개 or 스크랩 소) — 무한 스팸 방지.
- **라디오 연동**: Lv↑면 파견 결과 **원격 알림** + 장거리(고보상) 파견 해금.

**G. 파견 지역 (Dispatch Locations) — 탐험으로 해금**

> 핵심: **파견은 "내가 가본 곳"에만 보낼 수 있다.** 플레이어가 레이드에서 그 구역에 **직접 도달**하거나 그 구역의 **지도·정보(`map_fragment`/POI 인텔)를 획득**해야 파견지가 열린다.
> **레이드 탐험 → 파견지 해금 → 인력이 그곳을 자동 farming → 더 깊이 탐험**. 직접 플레이(레이드)와 idle(파견)이 맞물리는 고리. `map_fragment`·POI 인텔에 **실사용처**가 생김.

| 파견지 | 구역 | 해금 조건(플레이어 직접) | 제공 유형 | 보상 색 | 난이도 |
|--------|------|------|------|------|:---:|
| 상가골목 점포 | 안전 초입 | 튜토리얼 후 기본 개방 | 교역·자원 | 스크랩·재료 | 안전 |
| 북쪽 약국 | 북쪽 심부 | 약국 도달 + `map_fragment`(북쪽) [BD-13/SQ-002] | 자원·정보 | 의료·정보 | 중 |
| 무너진 상가 | 붕괴 구역 | 붕괴 상점 조사 [BD-14/SQ-001] | 구조·자원 | 인력·잡템 | 중 |
| 현상 경계 | 현상 외곽 | 경계 정찰 `map_fragment` [BD-15] | 정보·루디 | 인텔·루디 | 위험 |
| 짙은 현상 지하창고 | 현상 심부 | 현상 레이드 생환 + 지하 지도 [MQ-002] | 루디 채집 | 루디·잔해 | 고위험 |
| 배수로·맨홀 너머 | 탈출로 | 맨홀 탈출 경험 [S-006] | 정보·교역 | 지도·열쇠 | 중 |

- **해금 = 탐사 타일 도달(자동)** 또는 **지도·인텔 아이템 획득**. 깊은 곳(현상 심부)은 **도달 + 지도 둘 다** 필요.
- 파견지마다 **제공 유형·보상 색·base 난이도**가 다름 → 같은 "루디 채집"도 어느 파견지냐에 따라 수익·위험 차이.
- 파견지 해금은 **영구**. 더 깊은 파견지 = 더 큰 보상·위험.
- 2지역+ 오픈 시 **새 파견지 자동 추가** → 파견 시스템도 함께 확장(지역 진행과 동반 성장).
