# 밤의 도시 시스템 기획서 v2

## 게임 제목

**다녀올게 (Be Right Back)**

- 확정일: 2026-05-28
- 영문 제목: Be Right Back
- 선정 근거: 매 레이드 출격 시 안전가옥을 떠나며 하는 말이자, 세 가지 엔딩(입양/생존, 사망/진실, 구출/희망) 모두에서 전혀 다른 무게로 돌아오는 단어. 플레이어가 수십 시간 무심하게 반복한 단어가 엔딩에서 결정적 의미를 갖는 구조.
- 복수 엔딩 연결: 동생이 마지막으로 남긴 말 / 주인공이 되찾은 기억 속 약속 / 다시 떠나야 하는 선택 — 세 결말 어디에서든 성립
- 영문 선정 근거: 가볍고 일상적인 톤("금방 올게")이 못 돌아올 수도 있는 레이드 맥락에서 잔인하게 작동하며, 엔딩에서 의미가 뒤집힘

---

## 0. 문서 목적

이 문서는 현재까지 확정된 **다녀올게** 게임의 스토리, 전투, 루팅, 낮/밤 출전, 안전가옥, NPC 호의도 구조를 하나의 시스템 문서로 정리한 2차 초안이다.

기존에 검토했던 슬롯/카드/턴제 구조는 제외한다.  
총기는 초기 버전에서 제외하고, 추후 확장 요소로 보류한다.

현재 게임의 중심은 다음과 같다.

> **기억을 잃은 주인공이 낮에는 정보를 모으고, 밤에는 짙은 현상 지역에 들어가 루디를 회수하며, 근접 전투와 루팅/탈출을 통해 안전가옥을 성장시키고 잃어버린 동생의 진실을 추적하는 생존 루팅 액션 게임.**

---

## 1. 게임 한 줄 정의

> **낮과 밤이 나뉜 도시에서, 15분 안에 파밍하고 살아서 탈출하는 근접 생존 루팅 액션 게임.**

플레이어는 안전가옥에서 출격을 준비하고, 전체맵에서 지역을 선택한다.  
같은 지역이라도 낮과 밤의 목적이 다르다.

- 낮: 정보 수집, NPC, 쪽지, 준비
- 밤: 루디 회수, 밴딧/몬스터 전투, 이상현상, 고위험 파밍

---

## 2. 핵심 기둥

| 핵심 | 설명 |
|---|---|
| 근접 전투 | 약공격, 강공격, 구르기, 스태미너, 그로기 중심 |
| 루팅/탈출 | 15분 제한 안에 파밍하고 탈출해야 함 |
| 낮/밤 분리 | 낮 정보가 밤 공략에 영향을 줌 |
| 짙은 현상 | 밤 지역을 위험하고 비정상적으로 만드는 핵심 장치 |
| 루디 | 전기가 사라진 세계에서 가장 중요한 자원 |
| 안전가옥 | 컨테이너 거점. 루디와 재료로 성장 |
| NPC 호의도 | 미션, 상점 확장, 정보, 엔딩 단서와 연결 |
| 기억/동생 미스터리 | 플레이어가 장기적으로 추적하는 메인 스토리 |

## 3. 기본 플레이 루프

```text
안전가옥 컨테이너
↓
전체맵에서 지역 선택
↓
낮 / 밤 출전 선택
↓
장비와 가방 세팅
↓
지역 진입
↓
15분 동안 탐색 / 전투 / 파밍 / 미션 수행
↓
탈출구 확보 또는 탈출 지점 이동
↓
탈출 성공
↓
전리품 정산
↓
전당포 거래 / NPC 보고 / 안전가옥 강화
↓
새로운 정보 또는 다음 지역 해금
```

플레이어가 반복해서 고민해야 하는 질문은 다음과 같다.

```text
조금 더 파밍할까?
지금 탈출할까?
저 적을 잡을까, 피할까?
강공으로 끊을까, 구르기로 피할까?
낮에 더 조사할까, 바로 밤에 들어갈까?
루디를 팔까, 안전가옥 강화에 쓸까?
좋은 아이템을 챙기기 위해 무엇을 버릴까?
```

## 4. 스토리 도입

### 4.1 시작 상황

플레이어는 낯선 타운에서 깨어난다.

- 기억 없음
- 이름도 확실하지 않음
- 몸에는 상처가 있음
- 가진 것은 낡은 옷, 작은 가방, 손목에 찬 오래된 시계뿐

당장 먹고 잘 방법이 없기 때문에, 플레이어는 손목시계를 전당포에 맡기려 한다.

---

### 4.2 전당포 첫 만남

전당포 주인은 시계를 보자마자 플레이어를 알아본다.

```text
전당포 주인:
“시계라… 요즘 이런 걸 맡기러 오는 사람은 드문데.”

그는 시계를 받아 들고 뒷면을 확인한다.
순간, 그의 손이 멈춘다.

전당포 주인:
“…너, 살아 있었냐?”

플레이어:
“날 압니까?”

전당포 주인:
“아는 정도가 아니지. 그런데 정보는 공짜가 아니야.”
```

전당포 주인은 플레이어에게 말한다.

- 정부는 붕괴 직전이다.
- 전기는 거의 끊겼다.
- 밤이 되면 일부 지역이 **짙은 현상**에 잠긴다.
- 짙은 현상 지역에는 괴물, 밴딧, 이상한 물건이 나타난다.
- 그곳에서만 얻을 수 있는 **루디**가 현재 가장 중요한 자원이다.
- 루디를 가져오면 플레이어의 이름과 과거에 대한 정보를 조금씩 알려주겠다고 한다.

---

### 4.3 컨테이너 안전가옥

전당포 주인은 플레이어에게 작은 컨테이너 하나를 소개한다.

표면상 이유:

> “당장 잘 곳도 없을 테니 여기서 지내라.”

실제 이유:

> 플레이어를 루디 회수꾼으로 쓰기 위함.

이 컨테이너가 게임의 기본 안전가옥이다.

---

## 5. 세계관 핵심

### 5.1 밤

이 세계의 밤은 단순한 시간 변화가 아니다.  
밤이 깊어지면 특정 지역이 현실과 어긋난 상태가 된다.

사람들은 이를 **짙은 현상**이라고 부른다.

---

### 5.2 짙은 현상

짙은 현상은 밤 지역에 발생하는 비정상 현상이다.

특징:

- 길 구조가 달라진다.
- 없던 문과 골목이 생긴다.
- 같은 장소가 반복된다.
- 원래 없던 귀중품이 발견된다.
- 밴딧과 몬스터가 더 활발히 움직인다.
- 루디가 생성된다.
- 탈출구가 바뀌거나 가짜 탈출구가 생긴다.
- 주인공의 기억, 시계, 동생 단서와 연결된다.

게임적으로는 밤 지역의 위험도, 보상, 특수 이벤트를 만드는 핵심 시스템이다.

---

### 5.3 루디

루디는 짙은 현상 지역에서만 발견되는 특수 자원이다.

전기가 사라진 세계에서 장치와 조명을 움직일 수 있게 해주는 공급 재료이며, 모든 세력이 루디를 원한다.

| 사용처 | 설명 |
|---|---|
| 전력 공급 | 안전가옥 발전기, 조명, 시설 가동 |
| 거래 | 전당포와 NPC의 핵심 거래 자원 |
| 안전가옥 강화 | 작업대, 지도판, 의료대 등 강화 |
| 미션 | NPC가 요구하는 주요 회수품 |
| 스토리 | 짙은 현상과 기억 상실의 진실에 연결 |

루디는 단순 화폐가 아니라, 플레이어가 밤 지역에 들어가야 하는 이유다.

---

## 6. 낮 / 밤 출전 시스템

### 6.1 기본 구조

지역에 출전하기 전 플레이어는 낮 또는 밤을 선택한다.

```text
지역 선택
↓
낮 / 밤 선택
↓
장비 세팅
↓
출전
```

같은 지역이라도 낮과 밤은 목적, 적, 보상, 이벤트가 다르다.

---

### 6.2 낮 출전

낮은 정보 수집과 준비 중심이다.

| 요소 | 내용 |
|---|---|
| 위험도 | 낮음 |
| 적 | 적거나 약함 |
| NPC | 등장 가능 |
| 쪽지/기록 | 자주 발견 |
| 루디 | 거의 없음 |
| 고급 보상 | 적음 |
| 탈출 | 비교적 쉬움 |
| 목적 | 밤 공략 준비 |

낮에 할 수 있는 일:

- NPC 만나기
- 쪽지 읽기
- 밤에 열리는 장소 정보 획득
- 안전한 탈출구 위치 확인
- 밴딧 위치 파악
- 잠긴 문 열쇠 찾기
- 밤 이상현상 힌트 획득
- 기본 재료 파밍

---

### 6.3 밤 출전

밤은 루디 회수와 고위험 파밍 중심이다.

| 요소 | 내용 |
|---|---|
| 위험도 | 높음 |
| 적 | 밴딧, 몬스터 등장 |
| NPC | 거의 없음. 특수 NPC만 가능 |
| 루디 | 주요 획득 가능 |
| 고급 보상 | 많음 |
| 이상현상 | 본격 발생 |
| 탈출 | 일부 제한 또는 조건 필요 |
| 목적 | 위험을 감수한 고가치 파밍 |

밤에 할 수 있는 일:

- 루디 회수
- 고급 장비 파밍
- 밴딧 캠프 습격 또는 회피
- 몬스터 조우
- 이상현상 해결
- 낮에 얻은 정보 활용
- 특수 구역 진입
- 동생/기억 관련 단서 발견

---

### 6.4 낮 정보가 밤에 주는 영향

낮과 밤은 분리되어 있지만, 낮에서 얻은 정보가 밤에 실제로 반영되어야 한다.

| 낮에서 한 일 | 밤에 생기는 변화 |
|---|---|
| 쪽지 발견 | 숨겨진 탈출구 표시 |
| NPC 구조 | 밤에 도움 NPC 또는 보급품 등장 |
| 열쇠 획득 | 밤 특수 구역 진입 가능 |
| 괴현상 흔적 조사 | 밤 이상현상 패턴 예고 |
| 밴딧 위치 파악 | 밤 밴딧 캠프 위치 표시 |
| 발전기 수리 | 밤 특정 건물 조명 활성화 |
| 지도 조각 획득 | 루디 위치 후보 표시 |
| 시계 단서 발견 | 멈춘 시계 이상현상 대응 가능 |

## 7. 15분 지역 제한

### 7.1 기본 규칙

한 번의 지역 출전은 기본적으로 **15분 제한**을 가진다.

목적은 플레이어에게 계속 탈출 판단을 강제하는 것이다.

```text
좋은 아이템을 얻었으니 지금 나갈까?
루디를 하나 더 찾고 나갈까?
부상 상태인데 더 깊이 들어갈까?
탈출구까지 갈 시간을 남겨야 하지 않을까?
```

---

### 7.2 시간 흐름

| 시간 | 상태 |
|---|---|
| 0~3분 | 진입, 주변 파밍, 루트 확인 |
| 3~7분 | 중간 구역 진입, 첫 전투/이벤트 |
| 7~11분 | 고가치 파밍, 루디 후보 발견 |
| 11~13분 | 탈출 판단, 가방 정리 |
| 13~15분 | 탈출 시도, 추격 위험 |
| 15분 이후 | 위험도 폭증 |

15분이 지나도 즉시 사망시키지는 않는다.  
대신 다음 변화가 발생한다.

- 적 밀도 증가
- 이상현상 강화
- 일부 탈출구 폐쇄
- 강한 추적자 등장
- 시야 감소
- 루디 반응 폭주

## 8. 근접 전투 시스템

### 8.1 전투 방향

초기 버전에서는 총기를 제외한다.  
전투의 목표는 근접 무기만으로 재미를 만드는 것이다.

전투 감각은 다음을 지향한다.

> **약공격 / 강공격 / 구르기 / 스태미너 / 그로기 / 적 공격 캔슬이 있는 소울라이크식 근접 전투**

---

### 8.2 기본 조작

| 조작 | 기능 |
|---|---|
| 이동 | 캐릭터 이동 |
| 조준/방향 | 마우스 또는 이동 방향 기준으로 공격 방향 지정 |
| 약공격 | 빠르고 안정적인 기본 공격 |
| 강공격 | 느리지만 큰 피해와 높은 그로기 수치 |
| 구르기 | 회피, 위치 이동, 포위 탈출 |
| 가드 | 선택 기능. 데모에서는 보류 가능 |
| 락온 | 적 하나를 중심으로 방향 유지 |
| 상호작용 | 파밍, 문 열기, 쪽지 읽기, NPC 대화 |
| 인벤토리 | 아이템 확인, 정리, 버리기 |

---

### 8.3 약공격

약공격은 빠르고 안정적인 기본 공격이다.

역할:

- 스태미너 소모가 적다.
- 후딜이 짧다.
- 연속 공격이 가능하다.
- 그로기 수치는 낮다.
- 잡몹 처리와 안전한 견제에 사용한다.

예시 수치:

```text
약공격 1타: 피해 8 / 스태미너 6 / 그로기 5
약공격 2타: 피해 9 / 스태미너 6 / 그로기 6
약공격 3타: 피해 12 / 스태미너 8 / 그로기 8
```

---

### 8.4 강공격

강공격은 이 게임 근접 전투의 핵심이다.

역할:

- 느리다.
- 스태미너 소모가 크다.
- 피해량이 높다.
- 그로기 수치가 높다.
- 적의 공격을 끊을 수 있다.

예시 수치:

```text
강공격: 피해 20 / 스태미너 22 / 그로기 25
차지 강공격: 피해 32 / 스태미너 35 / 그로기 45
```

강공격은 단순한 큰 피해 기술이 아니라, **적의 공격 타이밍을 끊는 리스크 보상 기술**이어야 한다.

---

### 8.5 스태미너

스태미너는 전투 판단의 핵심 자원이다.

| 행동 | 스태미너 소모 |
|---|---:|
| 약공격 | 낮음 |
| 강공격 | 높음 |
| 차지 강공격 | 매우 높음 |
| 구르기 | 중간 |
| 달리기 | 지속 소모 |
| 가드 | 피격 시 소모 |

스태미너가 0이 되면:

- 공격 불가
- 구르기 불가
- 가드 불가
- 짧은 탈진 상태 발생

데모에서는 너무 가혹하게 만들지 않고, 0.5~1초 정도 위험해지는 수준으로 조정한다.

---

### 8.6 그로기와 공격 캔슬

적에게는 숨겨진 그로기 게이지가 있다.

공격이 적중하면 그로기 수치가 쌓인다.

| 행동 | 그로기 증가 |
|---|---:|
| 약공격 | 낮음 |
| 강공격 | 높음 |
| 차지 강공격 | 매우 높음 |
| 뒤에서 공격 | 추가 |
| 패링 성공 | 대량 증가. 추후 기능 |

적이 그로기에 걸리면:

```text
적 공격 취소
↓
짧은 무방비 상태
↓
추가타 또는 처형 가능
```

적의 공격 단계:

```text
대기
↓
예비 동작
↓
공격 판정
↓
후딜레이
```

플레이어의 강공격이 적의 예비 동작 중 적중하고, 그로기 수치가 충분하면 공격이 캔슬된다.

---

### 8.7 구르기

구르기는 위험한 공격을 피하거나 포위 상태를 벗어나는 용도다.

| 요소 | 방향 |
|---|---|
| 무적 시간 | 짧게 있음 |
| 이동 거리 | 짧음~중간 |
| 스태미너 소모 | 중간 |
| 후딜레이 | 약간 있음 |
| 연속 사용 | 가능하지만 스태미너 압박 |

구르기가 너무 강하면 전투가 단조로워지므로, 후딜레이와 스태미너 소모가 필요하다.

---

### 8.8 전투 타격감 체크리스트

| 요소 | 설명 |
|---|---|
| 타격 정지 | 맞는 순간 아주 짧게 멈춤 |
| 피격 반응 | 적이 맞았을 때 흔들리거나 밀림 |
| 강공 히트감 | 강공은 더 큰 정지와 무거운 사운드 필요 |
| 그로기 연출 | 적이 확실히 무너지는 느낌 |
| 사운드 | 타격음, 숨소리, 스태미너 부족음 |
| 카메라 흔들림 | 강공/그로기/처형 때만 제한적으로 사용 |
| 공격 예고 | 적의 공격이 불합리하지 않게 보이기 |

## 13. 탈출 시스템

지역마다 여러 개의 탈출구가 존재한다.

| 탈출구 유형 | 설명 |
|---|---|
| 기본 탈출구 | 항상 사용 가능 |
| 조건 탈출구 | 열쇠, 도구, 정보 필요 |
| 시간 탈출구 | 특정 시간 이후 활성화 |
| 낮 정보 탈출구 | 낮에 정보를 얻어야 표시 |
| 위험 탈출구 | 일정 시간 버티면 탈출 |
| 이상현상 탈출구 | 괴현상 해결 후 사용 가능 |

탈출은 즉시 완료되지 않고, 짧은 대기 시간이 필요하다.

```text
탈출 지점 도착
↓
8초간 상호작용 또는 대기
↓
적 접근 가능
↓
버티면 탈출 성공
```

사망 또는 탈출 실패 시 손실이 있어야 긴장감이 생긴다.

| 항목 | 사망/실패 시 |

| 중요 스토리 아이템 | 손실되지 않음 또는 안전가옥으로 회수 |
| 캐릭터 | 사망하지 않고 중상 복귀 |
| 안전가옥 | 유지 |
| 부상 | 출혈, 골절, 감염 등 발생 가능 |

초기 버전에서는 캐릭터 영구 사망은 제외한다.

## 15. 안전가옥 시스템

### 15.1 기본 개념

안전가옥은 전당포 주인이 소개해준 작은 컨테이너에서 시작한다.

초기 상태:

- 낡은 침대
- 작은 보관함
- 고장난 작업대
- 불안정한 조명
- 빈 벽면의 지도판

플레이어는 루디와 재료를 모아 안전가옥을 확장한다.

---

### 15.2 안전가옥 시설

|---|---|
| 침대 | 부상/피로 회복 |
| 창고 | 아이템 보관 |
| 작업대 | 무기 수리/제작 |
| 의료대 | 치료템 제작/부상 치료 |
| 조리대 | 음식 제작 |
| 발전기 | 조명과 시설 가동 |
| 지도판 | 지역 정보/낮밤 정보 확인 |
| 게시판 | NPC 의뢰 확인 |
| 방어시설 | 습격 이벤트 피해 감소 |
| 라디오 | 특수 이벤트/구조 요청 수신 |

---

### 15.3 안전가옥 강화

| 강화 | 효과 |
|---|---|

| 침대 강화 | 출격 후 피로 회복 증가 |
| 방어벽 설치 | 습격 피해 감소 |
| 라디오 안테나 | 특수 미션 수신 |
| 루디 조명 | 밤 출전 정보 일부 표시 |

## 16. NPC / 호의도 시스템

### 16.1 호의도 상승 방법

- 미션 완료
- 필요한 아이템 전달
- 낮 지역에서 구조
- 밤 지역에서 단서 회수
- 특정 선택지 선택

### 16.2 호의도 보상

| 호의도 보상 | 설명 |
|---|---|
| 판매 품목 증가 | 더 좋은 장비/재료 판매 |
| 미션 추가 | 개인 퀘스트 개방 |
| 정보 제공 | 밤 지역 힌트 제공 |
| 제작 레시피 | 특수 장비 제작 가능 |
| 안전가옥 기능 | 시설 효율 증가 |
| 엔딩 단서 | 동생/짙은 현상 관련 정보 제공 |

### 16.3 주요 NPC 후보

| NPC | 역할 | 호의도 보상 |
|---|---|---|
| 전당포 주인 | 메인 의뢰, 루디 거래, 감정 | 고급 거래, 주인공 과거 단서 |

| 수리공 | 장비 수리, 안전가옥 강화 | 제작 레시피, 시설 강화 할인 |
| 떠돌이 상인 | 랜덤 아이템 판매 | 밤 전용 장비 판매 |
| 전직 공무원 | 세계관 정보 | 정부 붕괴 기록, 금지 구역 정보 |
| 수상한 아이 | 동생 단서 | 이상현상 힌트, 숨겨진 길 정보 |

## 17. 미션 시스템

미션은 낮/밤 출전과 안전가옥 성장을 연결하는 역할을 한다.

| 미션 | 내용 |
|---|---|
| 회수 | 특정 아이템 가져오기 |
| 조사 | 특정 장소 방문 후 정보 획득 |
| 구조 | NPC 또는 생존자 데리고 탈출 |
| 처치 | 특정 밴딧/몬스터 제거 |
| 설치 | 특정 장소에 장치 설치 |
| 수리 | 발전기, 문, 탈출구 복구 |
| 거래 | 루디 또는 귀중품 전달 |

### 17.1 첫 메인 미션

목표:

- 기본 거래 해금

## 18. 메인 스토리 진행

### Act 1. 살아남기

목표:

- 전당포 주인을 통해 루디 의뢰 수락
- 첫 루디 회수
- 컨테이너 안전가옥 정비
- 낮/밤 출전 시스템 학습
- 타운 NPC 소개

주요 단서:

- 시계가 평범한 물건이 아님
- 전당포 주인이 주인공을 알고 있음
- 루디와 짙은 현상이 연결됨

---

### Act 2. 기억의 조각

목표:

- 주인공의 과거 추적
- 동생 존재 확인
- 전당포 주인이 숨기는 정보 발견
- 낮 NPC와 쪽지를 통해 기억 단서 수집

주요 단서:

- 오래된 사진
- 동생 이름
- 입양 기록
- 정부 붕괴 전 자료
- 손목시계와 멈춘 시계 이상현상 연결

---

### Act 3. 짙은 현상의 중심

목표:

- 루디의 정체 확인
- 동생의 최종 행방 확인
- 전당포 주인의 진짜 목적 확인
- 엔딩 분기 진입

주요 단서:

- 루디는 단순 에너지원이 아님
- 짙은 현상은 기억과 시간에 영향을 줌
- 주인공이 기억을 잃은 이유가 드러남
- 동생의 운명이 플레이어 선택에 따라 달라짐

## 19. 동생 스토리 / 엔딩 분기

주인공은 기억을 잃기 전 동생을 잃어버렸거나, 잃어버렸다고 믿고 있다.

### 엔딩 A. 입양 / 생존 엔딩

진실:

> 주인공은 동생을 버린 것이 아니라, 살리기 위해 누군가에게 맡겼다.

결말:

- 동생은 살아 있음
- 하지만 주인공을 기억하지 못하거나 원망함
- 세계는 여전히 불안정함
- 씁쓸하지만 생존한 결말

조건 예시:

- 기본 메인 미션 완료
- 일부 단서 수집
- 특정 NPC 호의도 중간 이상

---

### 엔딩 B. 사망 / 진실 엔딩

진실:

> 동생은 짙은 현상 초기에 사망했고, 주인공은 죄책감 때문에 기억을 잃었다.

결말:

- 동생은 구하지 못함
- 주인공은 기억을 되찾음
- 짙은 현상의 진실 일부를 세상에 밝힘
- 비극적 결말

조건 예시:

- 핵심 단서 부족
- 특정 NPC 미션 실패
- 짙은 현상 관련 선택지 실패

---

### 엔딩 C. 구출 / 희망 엔딩

진실:

> 동생은 죽지 않았고, 짙은 현상 안에서 시간과 기억이 비틀린 채 살아 있었다.

결말:

- 동생 구출 성공
- 하지만 큰 대가가 있음
- 루디 공급망 또는 안전가옥 일부를 포기해야 할 수 있음
- 주인공은 기억 일부를 다시 잃을 수 있음

조건 예시:

- 주요 NPC 호의도 높음
- 낮/밤 단서 대부분 수집
- 특수 이상현상 해결
- 최종 지역에서 특정 선택 성공

## 20. 전체맵 / 지역 후보

| 지역 | 낮 특징 | 밤 특징 |
|---|---|---|
| 주택가 | NPC/쪽지 많음 | 밴딧 약탈 |
| 폐상가 | 기본 파밍 좋음 | 밴딧/몬스터 혼합 |
| 병원 | 치료템/NPC | 감염 몬스터 |
| 지하철역 | 정보/탈출 힌트 | 이상현상 강함 |
| 경찰서 | 낮에는 잠김/조사 | 고급 장비/밴딧 |
| 공장지대 | 부품/재료 | 강한 밴딧과 기계 이상현상 |
| 극장가 | 스토리/쪽지 | 보스/괴현상 |
| 중앙광장 | 정부 붕괴 흔적 | 후반 고위험 지역 |

## 21. 1차 데모 범위

### 21.1 데모 목표

> **근접 전투가 재미있는지, 15분 루팅 탈출이 성립하는지, 낮 정보가 밤 플레이에 영향을 주는지 검증한다.**

---

### 21.2 데모 지역: 폐상가

폐상가가 1차 데모에 적합한 이유:

- 파밍 오브젝트를 만들기 쉽다.
- 실내/실외를 섞기 좋다.
- 낮에는 NPC/쪽지를 배치하기 좋다.
- 밤에는 밴딧 점거와 몬스터 출현이 자연스럽다.
- 탈출구를 여러 개 만들기 좋다.

---

### 21.3 데모 구성

| 요소 | 권장 수 |
|---|---:|
| 지역 | 1개. 폐상가 |
| 낮/밤 모드 | 둘 다 구현 |
| 제한 시간 | 15분 |
| 적 | 밴딧 2종, 몬스터 1종, 낮 약한 적 1종 |
| 무기 | 4종 |
| 파밍 오브젝트 | 10종 |
| 아이템 | 30~40종 |
| NPC | 낮에 1~2명 |
| 쪽지 | 5개 |
| 이상현상 | 2개 |
| 탈출구 | 3개 |
| 안전가옥 시설 | 4개 |
| 미션 | 메인 2개, 서브 3개 |

---

### 21.4 데모 낮 플레이 예시

```text
1. 안전가옥에서 파이프, 붕대, 작은 가방 장착
2. 폐상가 낮 출전
3. 편의점에서 음식과 부품 파밍
4. NPC 발견
5. NPC가 “밤에 지하창고 문이 열린다”는 힌트 제공
6. 쪽지에서 후문 탈출구 위치 확인
7. 잠긴 창고 열쇠 획득
8. 기본 탈출구로 복귀
9. 안전가옥에서 작업대 강화
```

---

### 21.5 데모 밤 플레이 예시

```text
1. 낮에 얻은 열쇠와 정보로 폐상가 밤 출전
2. 밴딧 2명이 입구 근처 순찰
3. 전투 회피 후 지하창고 진입
4. 고급 부품과 루디 조각 발견
5. 몬스터 출현
6. 강공격으로 그로기 유도
7. 가방이 꽉 차서 일부 아이템 포기
8. 12분 시점에 탈출 결정
9. 후문 탈출구에서 8초 버티기
10. 전리품 들고 안전가옥 복귀
```

## 24. 핵심 설계 원칙

### 24.1 전투

> 약공격은 안정적이고, 강공격은 위험하지만 성공하면 적의 공격을 끊을 수 있어야 한다.

### 24.2 파밍

> 좋은 아이템을 얻었을 때, 플레이어가 “지금 나가야 하나?”를 고민해야 한다.

### 24.3 낮/밤

> 낮은 정보를 얻는 시간, 밤은 그 정보를 써서 위험을 감수하는 시간이어야 한다.

### 24.4 루디

> 루디는 단순 돈이 아니라, 밤 지역에 들어가야 하는 이유이자 안전가옥 성장의 핵심 자원이어야 한다.

### 24.5 스토리

> 플레이어는 처음부터 세계를 구하려는 것이 아니라, 살아남기 위해 루디를 모으다가 자신의 과거와 동생의 진실에 다가가야 한다.

- 근접 전투 중심
- 낮/밤 출전 분리
- 15분 제한 지역 루팅
- 루디 회수와 안전가옥 성장
- 전당포 주인으로 튜토리얼/거래/스토리 진입
- 컨테이너 안전가옥
- NPC 호의도와 상점 확장
- 동생 미스터리와 엔딩 분기

### 다음에 다듬을 것

1. 근접 전투 수치와 조작감

3. 낮/밤 폐상가 이벤트 테이블
4. 루디와 짙은 현상의 정확한 규칙
5. 전당포 주인과 주요 NPC 5명 설정
6. 안전가옥 시설 강화 비용표

## 26. 최종 요약

현재 게임의 최종 방향은 다음과 같다.

```text
기억을 잃은 주인공
↓
손목시계를 맡기려 전당포 방문
↓
전당포 주인이 주인공을 알아봄
↓
정보를 대가로 루디 회수 의뢰
↓
컨테이너 안전가옥 획득
↓
낮에는 NPC/쪽지/정보 수집
↓
밤에는 밴딧/몬스터/이상현상 속에서 루디 파밍
↓
15분 안에 탈출
↓
안전가옥 강화와 NPC 호의도 상승
↓
동생과 짙은 현상의 진실 추적
↓
엔딩 분기
```

이 기획의 핵심 재미는 다음 문장으로 압축된다.

> **낮에 단서를 모으고, 밤에 위험을 감수해 루디를 가져오며, 살아남기 위해 안전가옥을 키우고, 잃어버린 동생의 진실을 찾아가는 게임.**
