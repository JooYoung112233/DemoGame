## 1. 캐논 = 이중 언어

`시안.png`는 이미 **한 화면 안에서 두 언어를 쓰고 있다.** 우연이 아니라 이게 캐논이다.

| | **종이 (문서형)** | **프레임 (기능형)** |
|---|---|---|
| 시안 사례 | ITEM NAME 패널 | STORAGE 패널 |
| 재질 | 크림색 종이·판지. 섬유결·얼룩·접힌 자국·찢긴 가장자리 | 어두운 무광 금속. 균일·플랫·질감 최소 |
| 밝기 | **밝다** `#C9BCA5` | **어둡다** `#2A2724` |
| 의미 | "세계 안에 실재하는, 주워서 읽는 물건" | "플레이어가 조작하는 도구" |
| 정보 | 읽는다 (정지) | 만진다 (반복) |

**화면 규칙: 밝은 영역 = 읽을 것 / 어두운 영역 = 조작할 것.**
이게 판독성의 근거다. 종이 질감을 격자에 깔면 아이콘이 배경과 싸워서 루팅 속도가 죽는다.

## 2. 판정 기준 3개 (새 패널은 여기서 자동 분류)

느낌으로 정하지 않기 위한 테스트. **순서대로 적용하고, 하나라도 걸리면 프레임이다.**

### ① 손에 드는가
> 주인공이 그 물건을 실제로 **집어들 수 있나?**
> - 든다 — 쪽지·지도·의뢰서·정산 명세·신문·파견 보드 → **종이**
> - 못 든다 — 가방 격자·설정 메뉴·특성 트리·HUD → **프레임**

### ② 얼마나 자주 만지는가
> **한 레이드에 10번 이상 보거나 조작하면 무조건 프레임.**
> 질감은 반복 노출에서 피로를 만든다. 빈도가 재질을 이긴다.

### ③ 스크롤·격자·드래그가 있는가
> **종이에는 스크롤·격자·드래그앤드롭을 넣지 않는다.**
> 종이는 정지된 한 장이다. 그런 조작이 필요하면 그건 이미 프레임이다.

> 세 기준이 충돌하면 **②가 이긴다.** 판독성이 정체성보다 우선한다.

---

## 3. 겹칠 때 규칙

시안이 이미 답을 그려놨다 — ITEM NAME(종이)이 STORAGE(프레임) **위에 떠 있다.**

- **종이는 항상 프레임 위 레이어.** 반대는 없다
- **종이를 프레임 안에 중첩하지 않는다.** 액자 속 액자가 되어 깊이가 무너짐
- 한 화면에 종이는 **최대 1장**. 두 장이 필요하면 설계가 틀린 것
- 프레임은 여러 개 병렬 가능 (인벤 + 창고 + 장비창)

## 4. 예외 2종 (캐논 밖, 범위를 못 넘게 못 박음)

이중 언어로 안 덮이는 게 **딱 두 종류** 있다. 늘리지 않는다.

| 예외 | 정의 | 해당 | 근거 |
|---|---|---|---|
| **기물 (디제틱 오브젝트)** | 실물 기계를 통째로 그림. 종이도 프레임도 아님 | `RadioUI` | 주파수 다이얼을 돌리는 행위 자체가 연출 — 프레임으로 하면 그냥 슬라이더가 됨 |
| **무프레임 (텍스트 온리)** | 배경 스프라이트 없음. 텍스트 + 단색 α만 | `NarrationUI` · `ToastManager` · `TutorialPrompt` | 게임플레이 위에 얹히는 것 — 어떤 프레임을 씌워도 시야를 가림 |

> ⚠️ **새 패널을 예외로 빼려면 이 표에 근거를 적고 추가해야 한다.** 근거 없이 늘어나면 캐논이 무너진다.

## 6. TitleScreen 단독 규정

타이틀은 어느 언어도 아니다. **일러스트 1장(손목시계 클로즈업 + 빗방울)이 화면을 지배하고, 그 위에 종이 배너로 표제**를 얹는다. 메뉴 버튼은 종이 버튼(`btn_primary`) 재사용.

근거: 타이틀은 게임 안이 아니라 게임 밖이라 디제틱 규칙이 적용되지 않음.

## 7. 이 캐논이 강제하는 것 (제작 영향)

| 항목 | 결과 |
|---|---|
| **종이 아트 물량** | 28패널 중 9개만 — 단일 언어 대비 대폭 절감. 대형 종이 배경은 `panel_item` 계열 재사용 + 크기 변형 |
| **프레임 아트 물량** | 15개지만 **9-slice 프레임 소수로 전부 커버 가능** — 새로 그릴 게 적음 |
| **한글 폰트 리스크** | **종이 태그 9개 패널에만 국한.** 프레임 쪽은 일반 산세리프로 안전하게 갈 수 있음 |
| **HUD 판독성** | GameHUD·QuestHUD·QuickSlotBar·NavigationHUD 전부 프레임 → 레이드 중 질감 노이즈 없음 |
| **`ui-asset-list.csv` 정합** | 기존 발주 목록과 충돌 없음 — `panel_item`(종이)·`panel_storage`(프레임) 이미 분리돼 있음 |
