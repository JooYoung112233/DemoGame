# 짙은현상 — 구간 메커닉 (루트/몬스터 생명주기)

> 세계관 = [`gdd-core.md §5.1`](gdd-core.md) · 시각(풀스크린 fog) = [`rendering.md` 짙은현상](rendering.md)의 `DenseAnomalyController`.
> 이 문서 = **게임플레이**: 현상이 구간/지역에 나타났다 사라지는 동안의 **추가 루트·몬스터 스폰/증발**.

## 한 줄
짙은현상 = **위험/보상 타임어택**. 구간에 나타남 → 그 안에 추가 루트(루디·희귀) + 몬스터 생김 → **사라지기 전에 회수** → 현상이 걷히면 미회수 루트·몬스터가 **같이 증발**. "욕심 vs 생존".

## 생명주기 (구간 단위)
```
잠복 → 징조(안개 모임·예고 마커) → 활성(루트 시간차 스폰 + 몬스터 + 짙은 안개)
     → 쇠퇴(종료 경고·마지막 회수 기회) → 붕괴(미회수 루트+몬스터 디졸브, 안개 후퇴) → 쿨다운
```
- **지속 N분**(GameTuning로 조절 예정). 활성 구간은 `MapZoneVolume`(내비)로 정의, 시각은 `DenseAnomalyController`를 **구간 범위**로 확장.
- **루트 = `RegionLootCatalog`의 "Anomaly" 티어**(루디·희귀 가중치↑). 스폰 위치 = 구간 내 분산.

## 자연스러운 "등장" (뿅 금지) — 핵심
현상이 **물질을 응결/드러내는 것처럼**. 후보:
1. **안개 걷힘 reveal** — 아이템이 원래 거기 있던 듯, 그 지점 안개가 국소적으로 옅어지며 alpha 페이드인. 현상 움직임이 스폰을 가림.
2. **응결/결정화 condense** — 루디·이상물건이 현상에서 "맺힘": scale 0→1 + 글로우 + 작은 빛 수렴. 현상이 물질을 토함.
3. **wisp 낙하** — 안개 입자 하나가 바닥으로 흘러내려 흩어지며 그 자리에 아이템(이펙트가 스폰 마스킹).
4. **시간차 점진** — t=0에 다 안 깔고 활성 동안 30초~1분 걸쳐 띄엄띄엄(시공간 분산) → 구간이 "익어감" + 오래 머물수록 보상↑/위험↑.
5. **기존 오브젝트 변질** — 새 아이템이 아니라 구간 내 기존 상자/프롭이 오염돼 루트화(글로우 오버레이 → 루팅 가능). "뿅" 자체가 없음.

> **추천 조합 = ①reveal + ④시간차 + (희귀/루디만)②응결.** 잡템은 안개 걷힘으로 슬쩍, 루디·희귀는 응결로 눈에 띄게. (구현은 WorldItem 스폰 시 alpha/scale 트윈 + 안개 국소 약화)

## 자연스러운 "소멸" (사라질 때도 뿅 금지)
- **등장의 역재생**: 안개가 그 지점을 다시 삼키며 페이드아웃 / 아이템이 wisp로 풀어져 현상 중심으로 빨려 올라감 / 디졸브.
- **마지막 경고(텐션 훅)**: 종료 ~30초 전부터 아이템 깜빡임·불안정 + 현상 색/맥동 변화 + 내비 HUD 구간 마커 점멸 → "빨리 챙겨!".

## 몬스터 소멸
- 삭제가 아니라 **"현상으로 돌아감"**: 안개로 녹아들거나 바닥으로 가라앉음. 종료 임박 시 더 공격적(막판) 후 흩어짐 — 온 곳(어둠)으로 회귀하는 연출.

## 기존 시스템 연동
| 요소 | 재사용 |
|---|---|
| 시각(fog) | `DenseAnomalyController` — 지역/화면 → **구간 범위**로 확장 |
| 구간 정의 | `MapZoneVolume` / `RaidMapManager`(내비) |
| 예고/마커 | `NavigationHUD`(미니맵) — 현상 구간 표시/점멸 |
| 루트 | `RegionLootCatalog` "Anomaly" 티어 + `WorldItem.Drop`(스폰 트윈 추가) |
| 몬스터 | `EnemyController` — 현상 스폰 풀 + despawn 연출 |
| 타이밍 | `GameTuning`(지속 N분·스폰 간격·경고 시간) |

## 위험/보상 메모
- 체류시간/깊이 ↑ → 루디·희귀 ↑ but 몬스터·회수 데드라인. 클래식 추출 텐션.
- 루디는 현상에서만(§5.3) → 들어갈 이유. 회수 실패 = 증발 = 욕심의 대가.

## 미정 / 다음 결정
- 등장 연출 조합 확정(위 추천 vs 다른 조합).
- 현상 발생 = 랜덤 시점/위치 vs 스크립트(레이드 중 1~2회). 빈도·동시 개수.
- 몬스터: 현상 전용 종 vs 기존 종 강화. 들어가야만 스폰 vs 멀리서도.
- 회수한 루디/루트는 현상 밖으로 나가면 안전(확정?) — 가방에 들어오면 영구.
