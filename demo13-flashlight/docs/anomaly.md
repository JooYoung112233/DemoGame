# 짙은현상 — 구간 메커닉 (루트/몬스터 생명주기)

> 세계관 = [`gdd-core.md §5.1`](gdd-core.md) · 시각(풀스크린 fog) = [`rendering.md` 짙은현상](rendering.md)의 `DenseAnomalyController`.
> 이 문서 = **게임플레이**: 현상이 구간/지역에 나타났다 사라지는 동안의 **추가 루트·몬스터 스폰/증발**.

## 한 줄
짙은현상 = **위험/보상 타임어택**. 구간에 나타남 → 그 안에 추가 루트(루디·희귀) + 몬스터 생김 → **사라지기 전에 회수** → 현상이 걷히면 미회수 루트·몬스터가 **같이 증발**. "욕심 vs 생존".

## 생명주기 (구간 단위)
```
잠복 → 징조(안개 모임·예고 마커) → 활성(루트 시간차 스폰 + 몬스터 + 짙은 안개)
     → 쇠퇴(종료 경고·마지막 회수 기회) → 붕괴(미회수 루트+몬스터 디졸브, 안개 후퇴) → 쿨다운
```
- **지속 N분**(GameTuning로 조절 예정). 활성 구간은 `MapZoneVolume`(내비)로 정의, 시각은 `DenseAnomalyController`를 **구간 범위**로 확장.
- **루트 = `RegionLootCatalog`의 "Anomaly" 티어**(루디·희귀 가중치↑). 스폰 위치 = 구간 내 분산.

## 발생 / 예측 (랜덤 + 읽을 수 있게)
- **발생 = 랜덤**(레이드 중 시점·위치 무작위). 빈도·동시 개수·지속 N분 = `GameTuning`.
- **예측 수단**(랜덤이지만 대비 가능하게):
  - **랜턴 점멸(현재)**: 짙은 현상 **근접** 시 착용 랜턴 불빛 깜빡임(가까울수록 빠름). ~~`phenom_meter`~~ 폐기(2026-06-08). [→ rendering.md, navigation.md]
  - **미니맵 예고(보조)**: `NavigationHUD` 구간 마커·점멸.
  - **시계(나중)**: 멈춘 시계 이상현상 — 임박 시 이상 작동(다이제틱 예고). gdd 멈춘시계 단서와 연결.
  - **징조**: 안개 모임·색 변화로 눈치채기.

## 스폰 규칙 (연출 시작 시 한꺼번에, 자연스럽게)
- **스폰 위치 = 맵툴로 배치한 스폰 포인트 우선** — 디자이너가 몬스터/루트/오브젝트 지점을 직접 지정(맵툴 Prop2D/SpawnPoint 배치 모델). 마커(`AnomalySpawnPoint`)는 **타입(몬스터/루트/오브젝트)** + **소속 구역**(내부/최근접 자동, 또는 zoneId) 보유. 배치된 게 없으면 `AnomalyZone.RandomPoint`(반경 내 랜덤, 가장자리 바이어스)로 **폴백**.
- 현상 **연출이 시작되는 순간** 몬스터 + 오브젝트 + 파밍 루트가 **함께** 스폰. "뿅"은 위 등장 연출(안개 걷힘/응결/시간차)로 마스킹.
- **몬스터 최소 거리**: 플레이어 바로 옆 즉시 스폰 **금지** — `minSpawnDist`(예 6~8m) 밖에서만. 권장: **현상 구간 가장자리/안개 속(시야 밖)에서 등장 → 안으로 걸어 들어옴**(거리 자연 확보 + "현상에서 나온다" 테마). 근처여도 즉시 공격 X — 안개에서 페이드인 후 행동.
- 루트/오브젝트는 거리 제한 없이 구간 전체에 **시간차 점진** 분산.

## 자연스러운 "등장" (뿅 금지) — 핵심
현상이 **물질을 응결/드러내는 것처럼**. 후보:
1. **안개 걷힘 reveal** — 아이템이 원래 거기 있던 듯, 그 지점 안개가 국소적으로 옅어지며 alpha 페이드인. 현상 움직임이 스폰을 가림.
2. **응결/결정화 condense** — 루디·이상물건이 현상에서 "맺힘": scale 0→1 + 글로우 + 작은 빛 수렴. 현상이 물질을 토함.
3. **wisp 낙하** — 안개 입자 하나가 바닥으로 흘러내려 흩어지며 그 자리에 아이템(이펙트가 스폰 마스킹).
4. **시간차 점진** — t=0에 다 안 깔고 활성 동안 30초~1분 걸쳐 띄엄띄엄(시공간 분산) → 구간이 "익어감" + 오래 머물수록 보상↑/위험↑.
5. **기존 오브젝트 변질** — 새 아이템이 아니라 구간 내 기존 상자/프롭이 오염돼 루트화(글로우 오버레이 → 루팅 가능). "뿅" 자체가 없음.

> **추천 조합 = ①reveal + ④시간차 + (희귀/루디만)②응결.** 잡템은 안개 걷힘으로 슬쩍, 루디·희귀는 응결로 눈에 띄게. (구현은 WorldItem 스폰 시 alpha/scale 트윈 + 안개 국소 약화)

## 자연스러운 "소멸" (사라질 때도 뿅 금지)
- **등장의 역재생**: 안개가 그 지점을 다시 삼키며 페이드아웃 / 아이템이 wisp로 풀어져 현상 중심으로 빨려 올라감 / 디졸브.
- **마지막 경고(텐션 훅)**: 종료 ~30초 전부터 아이템 깜빡임·불안정 + 현상 색/맥동 변화 + 내비 HUD 구간 마커 점멸 → "빨리 챙겨!".

## 몬스터 (둘 다: 전용 + 강화)
- **종류 = 둘 다**: ①현상 **전용 종**(이상체/괴물, 안개에서만 존재·회귀) + ②기존 종(밴딧 등)의 **현상 강화/오염 변종**.
- **스폰**: 위 '스폰 규칙'(연출 시작 시, 최소 거리, 가장자리/안개에서 등장).
- **소멸**: 삭제 X → **"현상으로 돌아감"** — 안개로 녹거나 바닥으로 가라앉음. 종료 임박엔 더 공격적(막판) 후 흩어짐(온 곳=어둠으로 회귀).

## 기존 시스템 연동
| 요소 | 재사용 |
|---|---|
| 시각(fog) | `DenseAnomalyController` — 지역/화면 → **구간 범위**로 확장 |
| 구간 정의 | `MapZoneVolume` / `RaidMapManager`(내비) |
| 예고/마커 | `NavigationHUD`(미니맵) — 현상 구간 표시/점멸 |
| 루트 | `RegionLootCatalog` "Anomaly" 티어 + `WorldItem.Drop`(스폰 트윈 추가) |
| 몬스터 | `EnemyController` — 현상 스폰 풀 + despawn 연출 |
| 타이밍 | `GameTuning`(지속 N분·스폰 간격·경고 시간) |

## 위험/보상 메모
- 체류시간/깊이 ↑ → 루디·희귀 ↑ but 몬스터·회수 데드라인. 클래식 추출 텐션.
- 루디는 현상에서만(§5.3) → 들어갈 이유. 회수 실패 = 증발 = 욕심의 대가.

## 확정 (2026-06-05)
- **등장 연출** = 추천 조합(안개 걷힘 reveal + 시간차 점진 + 희귀/루디는 응결). 소멸 = 역재생 + 종료 ~30초 전 경고.
- **발생** = 랜덤 + 예측 아이템(현재)/시계(나중).
- **몬스터** = 전용 종 + 기존 강화종 **둘 다**. 연출 시작 시 스폰, **최소 거리** 밖/안개 가장자리에서 등장.

## 미정 / 다음 결정
- 빈도·동시 현상 개수·지속 N분 기본값(GameTuning 노출).
- 회수한 루트는 현상 밖으로 나가면 영구 안전(가방에 들어오면 확정?) — 가안 yes, 확인 필요.
- 예측 아이템 구체(가이거식 비프 / 방향 화살표 / 남은시간 표시 중).
- "구간 들어가야 스폰" vs "멀리서도 보임" — 가안: 구간 진입/근접 시 활성.

## 구현 상태 (Phase)
- **Phase 1 (기반) ✅ 2026-06-05**: 생명주기 상태머신 + 발생 오케스트레이션 + 타이밍.
  - `Scripts/Anomaly/AnomalyZone.cs` — 구역(위치+반경) + 상태머신(잠복→징조→활성→쇠퇴→붕괴→쿨다운) + 이벤트(OnTelegraph/OnActivate/OnWaning/OnCollapse/OnDormant) + 스폰배치 쿼리(Contains/RandomPoint, edgeBias).
  - `Scripts/Anomaly/AnomalyManager.cs` — 레이드 중 랜덤 발생 + 동시개수 제한 + 디버그 HUD/K키.
  - `Editor/AnomalyTools.cs` — `Tools▸TopDown▸Build▸Anomaly Zone`로 구역 배치.
  - `GameTuning` 짙은현상 타이밍(활성/징조/경고/붕괴/간격/동시수/몬스터최소거리) → Control Panel에서 조절.
  - **테스트**: 씬에 Anomaly Zone 배치 → Play → **K키**로 즉시 발생, 좌상단 HUD로 단계/남은시간, Gizmo 색도 단계별.
- **Phase 2 (스폰)** ← 다음: **맵툴 배치 스폰 포인트(`AnomalySpawnPoint`, 타입별) 우선** + `RandomPoint` 폴백. 활성 시 루트(시간차+트윈)·몬스터(최소거리/가장자리) 스폰, 붕괴 시 미회수/몬스터 증발. 이벤트 훅(OnActivate/OnCollapse)에 구독.
- **Phase 3 (연출)**: DenseAnomalyController 구간 범위 + 안개 걷힘/응결 트윈 + 경고 점멸.
- **Phase 4 (예측)**: 예측 아이템 + 내비 미니맵 예고 마커.
