## 2. 세계관 배경 (사건 순서)

> **시대 = 아포칼립스 아님.** 세계·정부·사회는 정상 작동. 무너진 건 **이 도시 하나**. 정부가 짙은 현상 도시를 **봉쇄+은폐**, 봉쇄선 밖은 **무법지대**. 무대 구조 = [gdd-core.md §5.0](gdd-core.md). 아래 "붕괴"는 **세계 붕괴가 아니라 이 도시의 붕괴·봉쇄**를 뜻한다.

### 도시 붕괴 이전

- 정부 산하 **특수 현상 연구소**에서 짙은 현상의 원인을 연구
- **전당포 주인**(본명 강무진, 통칭 '강 박사') = 연구 책임자
- **주인공**(본명 새벽) = 그의 연구 조수
- 연구 과정에서 현상이 기억과 시간을 비트는 힘이라는 것을 발견
- 주인공에게 어린 동생(노을)이 있었고, 전당포 주인도 그 사실을 알고 있었음

### 정부 은폐 작전

- 현상의 위험성이 정치적 문제로 번짐 → 정부가 존재 자체를 은폐 결정
- **연구원 제거 작전** 실행 — 시설 폐쇄, 기록 말소, 연구원 실종 처리
- 전당포 주인은 혼란 속에서 **주인공을 두고 도망**
- 주인공은 작전 와중에 짙은 현상에 직접 노출 → **기억 상실**
- 동생(노을)은 혼자 남음. 강무진은 키울 형편이 없어 **보호 기관에 입양을 알아봄**(뒷돈 포함) — 이후 행방은 플레이어·강무진 모두 **미상** (S-018 회상으로 잔상만 노출)

### 봉쇄 이후 (게임 시작 시점)

- 정부가 도시를 **봉쇄·은폐**하고 철수 → 봉쇄선 안은 전기 끊김, 밖은 **무법지대**로 방치. (정부 기능 마비가 아니라 **이 도시에서 정부가 빠진 것**)
- 단, 봉쇄는 **자원작전**이기도 하다 — 정부는 현상을 이용해 **미래 자원 루디를 독점 채굴** 중. 은폐는 그 채굴을 가리는 명분. 다만 불의 역설로 **불빛을 못 써** 어둠 속 저광량 채굴만 가능 → 비효율 → 어둠을 누비는 **회수꾼(비공식 공급망/암시장)**이 가치를 가짐. 정부는 무대엔 흔적만(채굴 장비 잔해 등), 접점은 **블랙마켓 내부자**(§7). [→ gdd-core.md §5.0]
- 짙은 현상이 봉쇄구역 전역으로 확산 — **공간 침식**(시간대·낮밤과 무관). 레이드 위협도 **「밤」이 아니라 짙은 현상 구역** [→ raid.md]
- 플레이어 거점(타운·전당포·컨테이너)은 **봉쇄선 밖 무법지대**, 레이드는 **봉쇄선 안 봉쇄구역**으로 침투 [→ gdd-core.md §5.0]
- **루디**(`ruby_shard`) = 현상 부산물·전력체. 봉쇄구역 안에서만 발견. 탐지등 연료·전당포 납품 대상
- **스크랩** = 일상 화폐 (잡템 판매·상점·퀘스트 보상). [→ economy.md]
- 전당포 주인은 신분 감추고 무법지대에서 전당포 운영, 루디·귀중품 매입
- 주인공은 기억 없이 무법지대 타운에서 깨어남

### 지역2 — 침묵 생활 지구 · "사람들"

> 통합: 기존 ②. 테마: 첫 NPC 합류, 동생 첫 단서, 거점에 처음 '사람'이 생긴다.
> **무대**: 봉쇄 직후 주민들이 미처 빠져나가지 못한 밀집 폐아파트 단지. 빨래·식탁·장난감 — 멈춘 일상이 그대로 남아 있다. "사람이 살던 곳"의 질감 = 지역1(상업/교역)과의 대비.

**랜드마크 (3) — 각 랜드마크가 수직/하강 구조로 깊이를 가진다.** "넓게 흩뿌린 방"이 아니라 **올라가고 내려가는 세 개의 장소**.

#### ① 메아리 주민동 — *올라갈수록 사적이고 위험한 수직 미로*
- 1층 상가 아케이드(진입·상대적 안전, 고정 노점상·소문) → 거주 세대 미로(잠긴 문·생활/의료 루트) → 옥상(조망·노출 위험).
- **깊이**: 층을 오를수록 사적인 공간. 세대마다 멈춘 일상이 다른 이야기를 한다 — 식탁에 차려진 밥, 벽의 가족사진, 약통이 쏟아진 욕실. 한 세대는 "봉쇄 그날"의 정황이 환경으로만 읽힌다(짐 싸다 만 캐리어·끊긴 라디오).
- **사람**: 옥상 꼭대기에 **전직 공무원**이 은둔. 극도로 경계 → 신뢰물(정부 ID 등)+호감으로만 개방. (**추적** 선택, 아래)
- **위협**: 거주동 복도를 도는 약탈 갱단 순찰.

#### ② 침묵의 지하 — *내려갈수록 빛과 시간이 죽는 하강*
- 주차장 → 보일러실. 단지의 **짙은 현상 시드**. 내려갈수록 빛이 꺼지고 시간 왜곡이 시작된다.
- **깊이**: 하강 = 어둠·현상 학습. 복도 끝에 사람 잔상이 스쳐 가고, 같은 세대 문이 한 번 반복된다(약하게). 첫 **현상 전용종**(약)이 안개에서 걸어 나온다.
- **단서**: 가장 깊은 보일러실에 **오래된 사진**(어린아이 둘, 뒷면 "…을") → **동생 단서 #1**: "이 아이가… 나인가?"

#### ③ 안뜰 밴딧 캠프 — *의사를 가둔 작은 잠입 레벨*
- 단지 중정을 점거한 약탈 갱단. 빼앗은 의약품·의사 장비를 쌓아두고, **의사를 인질**로 붙들고 있다.
- **깊이**: 보초 동선·조명·인질 위치가 정면/잠입을 가르는 미니 레벨. 시끄럽게 풀면 증원, 조용히 풀면 의사가 먼저 마음을 연다.
- **선택(유대)**: 의사 구출 — *전멸·위협*(빠름, **두려움↑**, 합류해도 신뢰는 거래 수준) vs *잠입·협상*(어렵지만 **유대↑** → 후반 의사 호감 라인·치료 보너스).

**파밍 테마**: 생활·의료품↑(붕대·진통제·통조림·물·천) + 주민 유품(`val_`). "사람이 살던 곳"의 물건.

**핵심 선택 — 엔딩 기여 (§5.0 2축)**
- **전직 공무원 정보**(주민동 옥상): 개방 시 정부 봉쇄·은폐·**채굴 정보** → **추적↑**(후반 연구소·블랙마켓 단서 가속) / 방치 시 추적 더뎌짐.
- **의사 구출 방식**(안뜰 캠프): 잠입·협상 → **유대↑** / 전멸 → 두려움↑·유대 영향 적음.

**귀환 후**
- 의사 진찰: "이 흉터… 보통 부상이 아니야. **현상에 노출된 흔적**이야." → 단서(#2): 주인공=현상 노출자.
- 강무진에게 사진 → 잠깐 침묵 후: "…기억나는 게 있냐?" (강무진 단계 0→1 떡밥)

**사이드**: 숨은 생존자 구출(지역1 SX 연장) — **유대↑**, 소문/지역3 떡밥.

**해금**: 의료소(B3)/의사 · 지역3 · NPC 의사(거점)·전직 공무원(현지)
**스토리 수확**: 동생 존재 첫 인지 · 주인공=현상 노출자 · 거점에 첫 사람 · (선택)정부 채굴 정보
**엔딩 기여 요약**: 의사 협상=**유대** · 공무원 정보=**추적** · 사진·흉터=**동생 단서 #1·#2**

### 지역3 — 「묻힌 정비창」 · "기록과 흔적"

> 통합: 기존 ③ 공업설비 + ④ 철도. 테마: 수리공·상인 합류, 정부 채굴·연구소 증거, 동생 추적, 시계의 정체.
> **무대 구조 = 외부 없음. 단일 내부 복합체, 아래로만 내려가는 3층 수직 던전.** 봉쇄 직전 정부가 루디를 캐고 마지막 열차를 띄운 **묻힌 산업·화물 복합체**. 위는 멀쩡한 공장, **내려갈수록 정부의 비밀과 짙은 현상이 짙어진다** — 하강 자체가 "추적" 테마. 지역2의 분산형(올라가는 단지)과 정반대, **닫힌 지하 1개소 집중형.**

**랜드마크 (단일) — 지하 산업 복합체, 3층 하강**

#### 1층 — 정비 작업장 *(지상 바로 아래, 천창 빛, 상대적 안전)*
- 폐공장 라인·컨베이어·공구. 빛이 드는 입구층.
- **수리공** — 밴딧이 여기서 부품을 뜯게 강제 노동시킨다. 구출 → **수리점(B1) 해금**. (**유대 선택**: 정면 진압 vs **라인 정전시켜 몰래 빼냄**)
- **떠돌이 상인** — 작업장 한쪽 사무실에 바리케이드 치고 은신(외부 출몰 대신 **내부 정착형**). 거래·호감 40+ → **가구점(B2) 해금**.
- 루트: 부품·고철·공구.

#### 지하 1층 — 발전·기록실 *(비상등만, 어두워짐)*
- 발전·정제 설비 + 사무·문서고.
- **정부 채굴 흔적** — 정부 마크 채굴 장비 잔해·비워진 루디 케이지 = 봉쇄=자원작전 **첫 물증**.
- 파쇄 문서·연구원 명단(일부 잘림) "특수 현상 연구소".
- **봉인된 정부 구역**(정부 마크 철문) — 현상 침식 시에만 열린다. **추적 선택의 입구**.
- 시간 왜곡 시작 — 비상등 깜빡임·복도 한 번 반복(약).

#### 지하 심부 — 화물 터널 *(현상 짙음, 핵심층)*
- 묻힌 화물 철도 터널. **봉쇄 직전 마지막 열차가 여기서 떠났다.**
- 승강장 역무 부스 **탑승 기록부** → 동생(노을) 이름, 목적지 **성역 방면** (동생 단서 #3).
- 봉인 구역 내부 연구 일지: *"시계형 측정기가 현상 파동에 동조함을 확인. 조수 ████에게 장기 착용 지시."* → **시계 = 연구 장비** 확인.
- 시간 왜곡 최고조(지역3 기준) — **없는 열차 소리·플랫폼 과거 잔상·반복 복도**, 현상 전용종 강화.

**핵심 선택 — 엔딩 기여 (§5.0 2축)**
- **수리공 구출 방식**(1층): 몰래 빼냄 → **유대↑** / 정면·강압 → 두려움↑. + 상인 정착도 유대.
- **봉인 구역 심부 진입**(지하 심부): 고위험을 무릅쓰고 끝까지 → 시계 정체·정부 채굴 진실 풀셋 → **추적↑** / 입구만 보고 회수 → 부분.

**파밍 테마**: 부품·고철·공구·전기 재료, 연구·정부 문서 조각. "기계와 기록"의 질감.

**귀환 후**
- 수리공: "그 공장, 예전엔 정부가 썼어. 뭔가 실험했다더라."
- 강무진에게 시계 얘기 → 눈을 피함: "…그건, 내가 준 거야." (호감 60+: "측정용이라고만 말했지.")
- 전직 공무원(호감↑): "특수 현상 연구소… 본부는 극장 지하였어."

**해금**: 수리점(B1)/수리공 · 가구점(B2)/상인(호감 조건) · 지역4 · 정보(연구소 본부=극장 지하, 정부 채굴)
**스토리 수확**: 동생 이동 경로(성역 방면, 단서 #3) · 시계 정체(측정기, 강무진이 줌) · **정부 자원작전 물증** · 시간 왜곡 심화
**엔딩 기여 요약**: 수리공 몰래 구출·상인 정착=**유대** · 봉인 구역 심부=**추적** · 탑승 기록부=**동생 단서 #3**

### 지역4 — 기억의 극장 지구 · "재생되는 진실"

> 통합: 기존 ⑤ 공연오락 + ⑥ 성역추모. 테마: 연구소 본부, 기억 재현, 전당포 정체 확정, 동생 생존 반전, 블랙마켓.

**안전 구간**
- 폐극장·네온거리와 대성당·추모공원이 잇닿은 구역(과거의 화려함 ↔ 추모).
- 극장 관리 기록: "지하 시설 정부 임대, 출입 통제" → 연구소 **본부** 위치 확정(현상 침식 시 입구 노출).
- 추모벽에서 **동생(노을) 이름 — 사망 기록** → 주인공 무너짐.
- 대성당 **보호시설 기록** — 동생이 대피 명단에. 목적지 "긴급 보호소 — 중앙 방면". 추모벽 사망 기록은 **오류/은폐** → **생존 반전**.
- **블랙마켓 해금** — 연구소 본부 발견 후 **정보 브로커**(전직 공무원의 옛 동료, 정부 내부자) 접근 → 블랙마켓(A3). 정부 채굴·은폐 내부 정보·단서 판매.

**짙은 현상 구간**
- **연구소 본부**(극장 지하, 최대 시설) — **기억 재현**: 주인공이 조수로 일하던 장면, 젊은 강무진이 시계를 건네는 장면, 군 진입·강무진이 **뒷문으로 혼자 빠져나가는 장면**("기다려요!" → 문이 닫힘).
- 책임자 사무실: **연구원 명단 전체 + 주인공 인사기록**(본명 **새벽**, 직급 조수, 비상연락처 = **노을**).
- 대성당 지하가 현상으로 확장 — **기도하는 그림자들**, 깊은 곳에 **동생 메모**("오빠가 '다녀올게' 했어. 아직 안 왔어") + 중앙 방면 이동 흔적.
- **시계의 강한 공명** — 동생 흔적에 가까울수록 초침이 거세게 반응(위치=중앙). 비선형 시간 최고조.

**귀환 후**
- 강무진 대면(증거 제시): 호감 60+ → 무너지듯 고백("나였어. 너를 두고 도망쳤어…"), 본명·전모 공개. 호감/두려움 루트별 분기(§10).
- "동생이 중앙으로 갔다고? 영야 핵심에? …거기 들어간 사람은 안 돌아와. 하지만 네 시계가 있으면 들어갈 순 있어." → **동행 자청**("나도 가겠다. 빚이 있으니까.").

**해금**: 블랙마켓(A3)/정보 브로커 · 지역5(시계+강무진 동행+단서) · 정보(전당포=강무진 확정, 주인공 본명, 동생 생존·중앙행)
**스토리 수확**: 전당포 정체 완전 공개 · 주인공 과거 확정 · **동생 생존 반전**·최종 행방(중앙) · 시계=영야 진입키/나침반 · 강무진 속죄 동행 결심

### 지역5 — 중앙 영야 심장 · "다녀올게"

> 통합: 기존 ⑦. 테마: 최종 진입, 진실, 강무진 희생, 엔딩 분기.

**진입 조건**: 시계 보유 + 강무진 동행(호감 40+ or 스토리 강제) + 지역4 메인 완료 + (선택) 단서 수집률 → 엔딩 분기.

**진입 / 내부**
- 도시 **짙은 현상 심층** — 침식 극심, 시계 공명 시에만 길이 열림. 강무진 동행("이번엔 끝까지 같이 가마.").
- 현상의 중심 — 시간·공간 뒤섞임 최고조. 과거 장면들(연구소·아파트·열차역·대성당)이 겹쳐 출현.
- **루디 정체 공개**: 현상이 기억과 시간을 갈아낸 부산물 — 사람들의 기억이 물질화된 것. **정부 자원작전의 끝**: 정부조차 불빛을 못 써 이 중심엔 닿지 못했다 = 미답 영역.
- 중심에 **흑월 첨탑** — 모든 것의 시작점.

**강무진의 희생**
- 첨탑 진입 중 현상 폭주·통로 붕괴 → 과거와 동일한 **"한 사람만 빠져나가는 문"** 재현. 이번엔 강무진이 주인공을 동생 방향으로 밀어넣고 남는다("이번엔 안 도망쳐." / "다녀올게, 라고는 안 할게."). 호감/두려움 루트별 무게 차이.

**동생과의 대면 → 엔딩 분기**
- 첨탑 중심에서 동생의 존재를 확인 — 여기서 엔딩이 갈림(§5).


## 5. 엔딩 분기

### 5.0 엔딩 구동 — 단서 + 2축(유대·추적) + 시계 공명

> 현행 판정축(동생 단서 수집률 · NPC 호감도 · 시계 공명)을 유지하되, **각 지역의 핵심 선택**을 두 누적 지표로 모은다. 지역별 선택은 §4 각 지역 "엔딩 기여" 항목에 명시.

| 축 | 의미 | 쌓는 선택(예) | 영향 |
|---|---|---|---|
| **유대 (Bond)** | 사람을 구하고 신뢰를 쌓음 | NPC 구출·합류, 위협 대신 협상, 곁의 사람 우선 | 호감도 60+ 인원 ↑ → **C(구출)** 기여 |
| **추적 (Pursuit)** | 정부 은폐·연구소·동생 진실을 끝까지 팜 | 위험한 단서 회수, 봉인구역 진입, 내부자 거래, 폭로 의지 | 핵심 단서 확보 ↑ → **B(진실)/C** 조건 |

**2축 → 3엔딩 매핑** (단서 수집률이 1차 게이트, 2축이 성격 결정)

| 엔딩 | 유대 | 추적 | 한 줄 |
|---|:---:|:---:|---|
| **A 생존** | 중/하 | 중/하 | 적당히 챙기고 빠짐 — 진실도 사람도 끝까지 가지 않음 |
| **B 진실** | 하 | **상** | 진실은 끝까지 팠으나 곁의 사람은 못 지킴 → 폭로行 |
| **C 구출** ★ | **상** | **상** | 사람도 진실도 모두 끝까지 — 동생을 꺼냄 |

> 두 축은 **별도 수치라기보다 선택의 누적 경향**(플래그 합)으로 구현. 세부 임계는 플레이테스트로 조정.

---

### 엔딩 A: 생존 — "다녀올게"의 일상

> 동생은 현상 직전에 누군가에게 맡겨졌고, 이 안에 있는 것은 기억의 잔상.

- 동생은 살아 있지만 다른 곳에 있음. 여기서 찾은 것은 과거의 흔적
- 주인공은 기억을 되찾고, 동생을 찾아 떠날 결심
- "다녀올게" = 동생에게 다시 다가가겠다는 약속

**조건:**
- 동생 단서 50~79% 수집
- **유대·추적 둘 다 중/하** (어느 쪽도 끝까지 가지 않음)
- 메인 퀘스트 기본 완료

### 엔딩 B: 진실 — "다녀올게"가 지켜지지 못한 약속

> 동생은 현상 초기에 사망. 주인공은 죄책감에 기억을 잃었다.

- 첨탑 중심에서 동생의 마지막 순간을 "재현"으로 목격
- 동생이 "다녀올게"라는 약속을 믿고 기다리다 현상에 삼켜짐
- 주인공은 진실을 받아들이고, 현상을 세상에 알리기로 결심

**조건:**
- **추적 상 + 유대 하** (진실은 팠으나 사람은 못 지킴)
- 지역4(기억의 극장) 핵심 단서는 일부 확보했으나 동생 생존 증거(보호시설 기록+메모) 불완전 → 생사 반전 미성립
- 또는 동생 단서 50% 미만 + 유대 낮음

### 엔딩 C: 구출 — "다녀올게"가 지켜진 약속  ★ 진엔딩(트루 엔딩)

> 동생은 현상 안에서 시간이 비틀린 채 살아 있었다.

- 충분한 단서 + **시계의 공명**으로 현상 속에서 동생을 꺼냄 (시계가 동생 위치를 가리키는 나침반 역할)
- 대가: 루디 공급이 끊김 (현상 핵심을 건드렸으므로) 또는 주인공 기억 일부 재상실
- "다녀올게" = 마침내 이행된 약속. 돌아온 것.
- **본 작품의 정사(캐논) 엔딩.** A·B는 조건 미달 시 분기.

**조건:**
- 동생 단서 80% 이상 (**추적 상**)

## 10. 강무진 — 서사 관계 단계

> npc-dialogue.md §1-5 "서사 관계 단계"의 강무진 적용. 3축(호감/신뢰/두려움)은 거래·일반 대화용, 아래 단계는 과거·죄책감의 서사 진행. **진행 = 신뢰도 임계 + 진실 단서 둘 다 충족** (수치만으론 안 열림).

| 단계 | 이름 | 해금 조건 | 공개 내용 / 강무진의 변화 |
|:---:|------|----------|------------------------|
| **0** | 낯선 거래상 | 시작 (호감 15) | 면식 숨김. "정보는 공짜가 아니야." 거래만 |
| **1** | 면식 인정 | 신뢰 40 + `시계 이상 목격`(S-015_WATCH) + S-017 시계 보고 | 1지역: "시계가 반응했다고?"·"잘 간직해"만. 본명·과거 면식 인정은 지역4 이후 |
| **2** | 죄책 고백 | 신뢰 60 + `연구소·도망 진실`(지역3 시계 정체 / 지역4 본부) + 두려움 < 31 | 연구 시절, 주인공이 조수였음. "너를 두고 도망쳤어." — 무너짐 |
| **3** | 속죄 동행 | 신뢰 80 + `연구소 본부 진실`(지역4) + 두려움 < 31 | 은폐 작전 전모, 본명(강무진) 공개, 기억상실 원인, 진심 어린 사과. "같이 가겠다." |

> 짙은 현상 기본 정보·지역 위험도 등 일반 대사는 3축 호감도 구간(npc-dialogue.md §6)으로 처리 — 단계와 별개로 중립부터 열림.

### 두려움 루트

| 두려움 구간 | 반응 |
|------------|------|
| 경계 (31~60) | 할인, 순종. 과거 이야기는 회피. **관계 단계 1까지만** |
| 복종 (61~100) | 즉각 정보 제공, 큰 할인. **단계 2~3(죄책 고백·속죄) 영구 차단** |

> 두려움 루트에서도 스토리 진행은 가능하지만, 전당포 주인의 희생 장면에서 감정적 무게가 크게 줄어듦. "왜 이 사람이 나를 위해 죽지?"라는 의문만 남는 구조.

  - **결정**: **아포칼립스 폐기.** 세계·정부·사회는 정상 작동. 무너진 건 **이 도시 하나**. 정부가 짙은 현상 발생 도시를 **봉쇄+은폐**하고 철수.
- **질문**: 플레이어 거점과 레이드 무대의 위치?
  - **결정**: 거점(타운·전당포·컨테이너 안전가옥) = **봉쇄선 밖 무법지대(완충지대)**. 레이드 = **봉쇄선 안 봉쇄구역(짙은 현상)**으로 침투. 회수 후 무법지대로 귀환.
- **질문**: 정부는 현재 무대에 어떻게 존재?
  - **결정**: **무대에 직접 없음.** 멀리서 봉쇄선 유지 + 현상 은폐만. 과거 은폐 작전(연구소 제거·기록 말소)의 주체로서 스토리·블랙마켓 내부자 서사에만 연결.
  - **근거**: ① 기존 정부 은폐 스토리(연구소·기록 말소·블랙마켓 정부 내부자)는 **기능하는 정부**를 전제하므로 봉쇄+은폐 프레임이 오히려 정합적. ② 안전가옥 허브 + 봉쇄구역 레이드라는 추출 게임 구조와 "바깥 거점 → 안으로 침투"가 자연스럽게 맞물림. ③ "정부 붕괴"는 은폐 주체가 사라져 서사 모순 → 폐기.
  - **반영**: [gdd-core.md §5.0](gdd-core.md)(신설 — 시대·무대·봉쇄선 다이어그램), gdd-core §4.2 전당포 설명, 본 문서 §2 "봉쇄 이후". 「전기 거의 끊김」은 **봉쇄선 안**에 한정(바깥 무법지대는 열악하나 단전 아님).

- **질문**: 짙은 현상 안에서 시간이 다르게 흐르도록 세계관 추가? 성격과 게임 적용 범위?
  - **결정**: **비선형·뒤섞임으로 확정** — 현상 안에선 시간이 선형이 아니라 순서가 무너지고 **과거·현재가 겹친다**(잔상 재생·반복 복도·비틀린 생존). **게임 적용 = 타이머에도 작용(메커닉화)**: 현상 구역 체류 시 레이드 15분 타이머가 불안정해지고, 손목시계가 진짜 남은 시간을 읽는 다이제틱 지표가 됨.
  - **근거**: 기존 떡밥(엔딩 C "동생이 시간이 비틀린 채 생존", ⑤ 기억 재현, ③ 반복 복도, 시계=현상 측정기·동조)이 **이미 비선형 시간을 전제**하고 있었음 → 흩어진 떡밥을 하나의 세계관 기둥으로 승격. 타이머 작용으로 추출 텐션 강화 + 시계 본래 용도를 레이드에서 선체험.
  - **반영**: [gdd-core.md §5.4](gdd-core.md)(신설 — 시간 왜곡 + "믿을 수 없는 시계" 메커닉), [anomaly.md](anomaly.md)(타이머 메커닉·Phase 5·변경 로그). 엔딩 C·단서 서사는 기존 그대로(이 결정이 근거를 명문화).

- **질문**: 지역을 총 5개로 잡는다. 기존 7지역 아크(①~⑦)를 어떻게 정리?
  - **결정**: **7지역 → 5지역 압축(병합).** 지역1(데모 폐상가) 유지. 후반 6개를 병합: **지역2=②**(사람들), **지역3=③+④**(기록과 흔적: 공업+철도), **지역4=⑤+⑥**(재생되는 진실: 공연오락+성역), **지역5=⑦**(중앙 영야). 기존 스토리 기둥(의사·수리공·상인·정보브로커, 연구소·시계 정체·동생 단서·전당포 정체·생존 반전·희생)은 모두 보존하며 위치만 재배치.
  - **근거**: 본선 길이를 5지역으로 줄이되 서사 손실 0. 인접 테마끼리 병합(공업+철도=산업/기록, 공연+성역=극장가/추모) → 지역 정체성 더 또렷. 새 세계관 훅(정부 채굴 물증=지역3, 비선형 시간 심화=지역3→4→5 점증)을 자연스럽게 끼움.
  - **반영**: §4 전면 재작성(지역2~5 + 7→5 매핑표), §7 해금표·§8 NPC 첫등장·§10 강무진 단계 조건·§11 단서 위치·§12 흐름도 모두 5지역 라벨로 갱신. **미반영(코드)**: `WorldRegionCatalog`("7 districts")·`RegionLootCatalog` 등 데이터는 추후 5지역으로 정리 필요(별도 작업).

- **질문**: 엔딩 분기 구동축과 지역별 선택 연동?
  - **결정**: **현행 3변수(단서 수집률·호감도·시계 공명) 유지 + 지역별 선택을 2축(유대·추적)으로 누적.** 유대=사람 구함/신뢰, 추적=정부 은폐·진실 파기. 2축→3엔딩: A(둘 다 중하)·B(추적 상·유대 하, 폭로)·C(둘 다 상+단서 full+시계공명, 진엔딩). §5.0 신설.
  - **근거**: 기존 신호(호감도≈유대, 단서≈추적)를 두 우산으로 묶어 기존 A/B/C와 충돌 없이 지역별 선택을 연결. "사람 vs 진실"이라는 추출 게임 테마와 정합.
- **질문**: 지역2 내용 심화?
  - **결정**: 폐아파트 단지(멈춘 일상) 무대 + 생활·의료 파밍 테마 + **핵심 선택 2개**(의사 구출 방식=유대 / 전직 공무원 정보=추적) + 동생 단서 #1(사진)·#2(흉터 소견). §4 지역2 확장.
- **질문**: 맵 구성을 어떻게? (서브구역 다수 vs 소수 랜드마크)
  - **결정**: **랜드마크를 2~3개로 줄이고 각각에 수직/하강 구조로 깊이를 준다.** 지역2 = ①메아리 주민동(올라가는 수직 미로·공무원·환경 스토리) / ②침묵의 지하(내려가는 현상 하강·동생 사진·전용종) / ③안뜰 밴딧 캠프(의사 구출 잠입 미니레벨). 적·루트·선택·단서를 랜드마크 안에 녹임.
  - **근거**: 넓게 흩뿌린 방 목록보다 "올라가고 내려가는 소수의 장소"가 공간 기억·긴장·환경 스토리텔링에 유리. **이 패턴(지역당 랜드마크 2~3, 수직/하강 깊이)을 지역4~5 공통 설계 원칙으로 적용**(단, 지역3은 단일 내부 예외 — 아래).

- **질문**: 지역3 구성?
  - **결정**: **외부 없음 — 단일 내부 복합체 「묻힌 정비창」, 아래로만 내려가는 3층 수직 던전.** 1층 정비 작업장(빛·수리공·상인 내부 정착) → 지하1 발전·기록실(정부 채굴 물증·봉인 정부 구역=추적 입구) → 지하 심부 화물 터널(탑승 기록부=동생 #3·시계 정체·시간 왜곡 최고조). 핵심 선택: 수리공 몰래 구출=유대 / 봉인 구역 심부 진입=추적.
  - **근거**: "내려갈수록 정부의 비밀·짙은 현상이 짙어진다"는 하강 구조 자체가 추적 테마와 직결. 지역2(분산·올라가는 단지)와 정반대의 **닫힌 지하 1개소 집중형**으로 지역 간 공간 대비. 외부 컷 → 제작 범위도 한 복합체로 집중.
  - **다음**: 지역4(기억의 극장) — 사용자 확인 후 진행.

- **질문**: 정부의 동기를 봉쇄+은폐에서 확장 — 정부도 현상을 이용해 루디를 채굴? 무대 노출과 플레이어와의 관계는?
  - **결정**: **정부의 진짜 동기 = 은폐 + 미래 자원 루디 독점 채굴(자원작전).** 단 §5.2 불의 역설로 **불빛을 함부로 못 써** 어둠 속 저광량 채굴만 가능 → 비효율. 그래서 어둠을 누비는 **인간 회수꾼이 비공식 공급망(암시장)**으로 가치를 가지고, 정부 독점과 경쟁 구도. **무대 노출 = 오프스테이지 + 흔적만**(정부 마크 채굴 장비 잔해 등, 직접 등장 X) → 앞선 "정부 무대엔 거의 없음" 결정과 양립.
  - **근거**: 봉쇄에 "자원 독점"이라는 실리 동기를 부여해 은폐가 더 설득력 있어짐. 불의 역설이 "왜 정부가 직접 다 못 캐고 회수꾼이 필요한가"를 자연스럽게 설명 → 플레이어의 회수꾼 직업과 암시장 경제·블랙마켓 내부자(§7) 서사가 하나로 묶임.
  - **반영**: [gdd-core.md §5.0](gdd-core.md)(정부 항목 확장), §5.3(루디 = 미래 자원·독점 vs 암시장), 본 문서 §2.
