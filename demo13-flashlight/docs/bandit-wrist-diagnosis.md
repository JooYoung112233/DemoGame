# 밴딧 방망이 손목 진단 — 2026-09-11

사용자 요청: 마지막으로 만든 밴딧의 방망이 자세에서 손이 이상한 현상을 확인.

## 확인 결과

- 최신 `ArtWork/SimpleBandit/PatrolCarry/ReviewFrame_1.png`에서 한 손 휴대 자세의 손목과 둥근 손 실루엣이 어색하다.
- Unity 프리뷰 씬에서 CarryIdle/Walk/Run을 각각 4개 시점으로 샘플링했다. 오른손 로컬 회전은 프리팹 초기 자세 대비 약 143~157도이고, 팔꿈치→손목과 손목→손 소켓 방향 사이 각도는 약 99~126도이다. 이 수치는 리그 기하 측정값이며 해부학적 관절각과 동일하지 않다.
- 원인: `tools/setup_bandit_patrol_carry.cs`가 방망이를 아래/뒤로 향하게 만드는 월드 회전을 `hand.rotation`에 직접 대입한다. 상완과 전완은 기존 보행 자세에 가깝게 유지되어 필요한 회전이 손목에 집중된다.
- 비교용 양손 BatIdle/BatWalk의 오른손 회전 차이는 약 53도, 팔→손 소켓 방향 각도는 약 45도이다.
- 기존 `verify_bandit_patrol_carry.cs`의 11개 검증은 재실행 시 통과. 손잡이 중심 정렬·지면 여유·상태 전환만 검증하므로 손목 꺾임을 검출하지 않는다.

## 후속 수정 방향 (미적용)

손목을 자연스러운 로컬 자세로 유지하면서 상완·전완과 함께 방망이 방향을 풀어야 한다. 한 손 휴대→양손 준비→공격 전환도 재확인해야 한다. 손 모델의 쥔 형태 개선은 회전 수정 후 별도로 판단한다.

진단 스크립트: `tools/inspect_bandit_wrist_pose.cs`.
수치 결과: `../../ArtWork/SimpleBandit/WristDiagnosis/Checks.json`.
