# 아트(VIEW) 필요 목록 — 시스템별 정리

> **목적**: 기획이 정의한 각 시스템이 화면에 보이려면 어떤 아트 에셋이 필요한지 한눈에 정리한 인덱스.
> 상세 스펙(시점/해상도/프롬프트)은 각 전용 문서로 연결. 이 문서는 "무엇이, 얼마나, 지금 어디까지" 를 본다.
> 작성: 2026-06-10. 상태 표기: ✅완료 · 🔄진행 · ⬜필요 · ◽선택(없어도 됨)

## 0. 아트 스타일 기준선 (전 에셋 공통, 확정)

상세: [`topdown-art-spec.md`](topdown-art-spec.md), [`rendering.md`](rendering.md)

| 항목 | 기준 |
|---|---|
| **카메라** | 2D Orthographic 정탑다운 (틸트는 아트에 베이크, 오브젝트 회전 0) |
| **시점각** | 바닥·벽 = **80°** / 가구·오브젝트(프랍) = **70°**(2026-06-10, 60→70 상향 — 바닥과 위화감↓) / 캐릭터·NPC = **60°**(가독성) |
| **라이팅** | 플랫·균일, 방향 그림자 없음 (런타임 Light2D가 조명) |
| **색감** | Desaturated(탈채도) 폐허 톤, 플랫 셰이딩(베이스 1색 + 그림자 1톤) |
| **배경** | 마젠타 #FF00FF (Color→Alpha 제거) |
| **해상도** | 바닥 256², 벽 256×192, 캐릭터 128², NPC 포트레이트 512², 아이템 아이콘 시트 |
| **피벗** | 바닥=중심 / 벽·프랍·캐릭터=하단중심 |
| **픽셀 도트** | 셰이더 후처리 (원본은 플랫 유지) |

**파이프라인**: Tilemap(바닥/벽) + **Prop2D 카탈로그**(프랍/오브젝트) → 맵툴 씬뷰 배치 → `Assets/Maps/` 프리팹. 상세 [`map-tool.md`](map-tool.md) / [`map-tool-guide.md`](map-tool-guide.md).

**진행 중 작업물**: `Assets/GPT/` 에 GPT 생성 이미지 축적 중 (NPC 20 · 건물 60 · 안전구역 20 · 전당포예제 7 · 데칼 4 · 주인공집 1 · 레퍼 7). 아직 스프라이트 슬라이스/카탈로그 등록 전인 원본 다수.
