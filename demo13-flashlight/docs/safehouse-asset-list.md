## 구현 우선순위

### Phase 1 — 걸어다닐 수 있는 맵
1. 바닥 타일 (F-01~F-05) 깔기
2. 펜스 외곽 (W-01, W-02, W-07) 배치
3. 메인 게이트 (W-06)
4. 전봇대 (P-02) + 드럼통 불 (P-01) — 조명

### Phase 2 — 핵심 시설
5. 컨테이너 (S-04, S-05)
6. 전당포 (S-01~S-03, P-06)
7. 게시판 + 지도판 (P-03, P-04)

### Phase 3 — 생활감
8. 의자, 테이블, 상자류 (D-01~D-15)
9. 빨랫줄 (P-05)
10. 텐트류 (S-06, S-07)

### Phase 4 — 분위기
11. 펜스 바깥 배경 (BG-01~BG-06)
12. 펜스 패치 변형 (W-03~W-05)
