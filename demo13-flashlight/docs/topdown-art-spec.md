# 탑다운 아트 스펙 (AI 이미지 생성용)

> 레퍼런스 스타일: 탑다운 ~80° 실내 서바이벌 호러 (레퍼: Darkwood)
> 어둑한 무드 + **시야 콘(FOV)** 기반 가시성(손전등 폐기, 하이브리드). Desaturated.
> **카메라 = 2D Orthographic. 원근(80° 틸트)은 카메라가 아니라 아트 자체에 베이크.**

---

## 0. 시점 규격 (확정 2026-06-02)

- **카메라**: 2D Orthographic 정면 뷰 (카메라는 기울이지 않음)
- **아트 각도 = ~80° 틸트를 이미지에 미리 그려넣음** — 거의 위에서 보되 살짝 눕혀, **정면/측면이 조금 보임**(완전 직하 90° 아님)
- **모든 타일·오브젝트는 Unity에서 회전 (0,0,0)으로 배치** — 순수 2D, 스프라이트가 카메라 정면을 향함. (회전·빌보드·눕힘 없음)
- 벽 = 윗면 + **앞면이 살짝 보이는** 낮은 두께 (80° 틸트라 정면이 약간 노출)
- 바닥 = 평평한 텍스처 (80° 틸트 그림자/원근 살짝)
- 오브젝트(책/천/상자) = 위에서 살짝 눕혀 본 모습 (약간의 높이감)
- ⚠️ **바닥/벽은 80° 시점** 기준
- **가구·오브젝트(프랍) = high 3/4 약 70°** (2026-06-10 정정: 60°→70°)
  - 진짜 80°로 그리면 가구가 윗면만 보여 안 읽힘(책장/금고/진열장) → 정면을 조금 보이게
  - **단 60°는 너무 정면이라 80° 바닥과 20° 차 = 사물이 뒤로 누워 떠 보임** → **70°로 세워 바닥(80°)에 근접**(차 10°). 윗면 지배 + 정면은 살짝만(약 1/4 이하)
  - 가구끼리 각도 통일이 핵심 (제각각 금지). 정면 입면도(낮은 각도)로 튀는 것 금지
  - 접지 그림자 + 좌상단 광원으로 바닥과의 위화감 최소화
- **캐릭터·NPC = high 3/4 약 60°** (가독성·얼굴/개성 — 프랍보다 살짝 정면 유지)

## 1. 공통 규칙

| 항목 | 값 |
|---|---|
| **배경** | 마젠타(#FF00FF) — Color to Alpha로 제거 |
| **라이팅** | **플랫/균일** — 방향 그림자 없음. 런타임 2D Light가 조명 |
| **색감** | **Desaturated(탈채도)** 기본. 시야 콘 안에서 살짝 밝게 |
| **PPU** | 전 에셋 통일 (예: 64~128 PPU) |
| **표면 질감** | **노이즈/그레인/점박이(stipple) 텍스처 금지 — 필수.** 바닥/벽/지붕/건물 표면은 매끈한 면 + 큰 단위 얼룩·균열만. 자갈/돌블록/큐브 패턴도 금지. (모든 건물·구조물 프롬프트에 항상 `NO noise/grain/stipple, NO cobblestone/cube texture, smooth surfaces` 포함) |

## 1-1. 실내/건물 모듈 구조 (맵툴 배치, 확정 2026-06-05)

실내·건물은 **통짜 한 장이 아니라 레이어 분리**로 제작 → 맵툴에서 조립/배치:

| 레이어 | 내용 | 비고 |
|---|---|---|
| **바닥 타일** | 바닥(마루/타일/콘크리트) | 셀 단위 깔기 |
| **벽** | 사방 벽 (직선/코너/T/세로) | 하이브리드: 남향 정면 띠 + 나머지 윗면. [`safehouse-tile-prompt.md`] |
| **천장** | 지붕/천장 레이어 | 외부=지붕 보임, 내부 진입 시 숨김/투명 토글 |
| **그외 프랍** | 가구·시설·오브젝트·데칼 | 낱장 스프라이트, Y정렬 배치 (해금 시설도 여기) |

- **컨셉용 통짜 1장**(풀버전)은 비전 확정·추출 소스로만. 실제 구현은 **레이어 분리 후 맵툴 배치**.
- AI로 풀버전 + 빈버전 뽑아 **차이=프랍** 추출 → 빈 베이스(바닥+벽) 위에 프랍/시설 얹음.

## 2. 에셋별 스펙

### 바닥 타일 (Floor)
```
Top-down floor tile seen from a steep ~80° angle (almost overhead, slight tilt).
Square tile (NOT isometric diamond), worn [wood planks / concrete / dirt].
Seamless edges so tiles repeat without visible seams.
Flat even lighting, desaturated muted tones.
Transparent or magenta (#FF00FF) background.
Canvas: 256×256 (square).
Pivot: Center.
```

### 벽 (Wall)
```
Wall segment seen from a steep ~80° top-down angle — top surface plus a SHORT sliver
of the front face visible (slight height), NOT a full elevation view.
Cracked plaster, brick edge. One segment = one tile width. Tileable left-right.
Canvas: 256×192 (a bit of vertical room for the front-face sliver).
Pivot: bottom-center (so the base sits on the tile).
```

### 오브젝트/프랍 (Props)
```
[book / cloth / crate / rug / trash] seen from a high 3/4 ~70° top-down angle (steep,
close to the 80° floor). TOP face DOMINANT + only a SHORT front sliver (≤1/4 height).
Face-on (camera tilted straight down), NOT isometric, NOT a corner/45° cube, NOT a low
front elevation. Single object, dark grey (#3C3C3C) solid background, no shadow.
Pivot: bottom-center for standing objects, center for flat objects (rug/trash).
```
> **각도 (2026-06-10 정정: 60→70°)**: 프랍 = **윗면 지배 + 정면 살짝(≤1/4)**, 정면 마주보기. 70°로 세워 80° 바닥에 근접(차 10°). ❌아이소(코너·45°) ❌정면 입면도(60°보다 낮음) ❌완전 정면.
> **배경 (2026-06-10 변경)**: 프랍·캐릭터·NPC = **짙은 회색(#3C3C3C) 단색**(마젠타 폐기). 키잉/임포트 시 알파 컷아웃.
>
> ### ✅ 프랍 생성 표준 (2026-06-10 확정 — 모든 배치 필수)
> 레퍼: **하이드아웃 실내 프랍 시트(각도 마스터) + 전당포 시트 + 거리 시트**(항상 첨부). **각도 정답 = 하이드아웃 시트**(침대·작업대·선반·사물함 윗면이 시원하게 보이는 ~70°). 키 큰 물건(사물함/서랍장/선반)은 하이드아웃 시트의 동일 물건과 직접 비교해 맞출 것 — 그보다 정면이면(60°) 리테이크.
> 1. **각도** = ~70° high 3/4. **윗면이 위쪽 1/3 정도 보임** + 정면 마주보기. ❌옆면(아이소 코너) ❌정면 입면도(윗면 얇음·60°).
> 2. **디테일 = LOW + 플랫 셀셰이딩. 절대 올리지 말 것.** 매끈한 단색 면 + 1~2 셰이드톤 + 큰 얼룩 몇 개(작은 점 아님). **점박이(stipple)·그레인·noise·디더링·모래알 표면·3D 렌더 룩·잔 스펙클·과한 스크래치·금속 그라데 전면 금지.** = 손으로 그린 2D 게임아트/셀셰이드 컨셉아트 느낌. (전당포 레퍼의 깔끔한 플랫 면이 기준)
>    - ⚠️ AI가 미세 그레인을 자꾸 얹음 → 프롬프트에 강하게 명시 + **판단은 실제 게임 크기(축소)로**(100% 확대 시 보이는 미세 노이즈는 인게임에선 거의 안 보임). 남으면 슬라이스 후 posterize+약블러로 정리.
>    - **표면 디테일 구분(2026-06-10)**: **프랍 = 완전 플랫**(민짜 면). **바닥·벽 같은 큰 면 = 넓은 풍화 얼룩·균열 약간 허용**(완전 민짜는 가짜처럼 보임). 단 **잔 스펙클(fine speckle)·점박이는 둘 다 금지**. 확대샷 말고 게임 크기로 판단.
> 3. 짙은 회색 배경 + 약간의 색·재질 변화(회색 단조 금지).
>    - **유리(진열장·냉장고문·자판기·유리칸막이·창문)**: 너무 플랫하면 유리로 안 읽힘 → **셀식 유리** = 반투명 틴트(안 물건 살짝 비침) + 대각선 하이라이트 줄 1~2개(플랫 흰 띠). 그레인/그라데 없이.
> 4. 한 시트 6종, 2×3 격자, 간격 띄워 슬라이스 쉽게.

### 캐릭터
```
Character seen from a steep ~80° top-down angle.
Head/shoulders prominent, slight body length visible (not a pure overhead disc).
Can be abstract (a rounded body with a flashlight cone indicator).
Canvas: 128×128. Pivot: bottom-center.
```

#### 확정 주인공 디자인 (2026-06-02)
- 곱슬 흑발, 마른 체형, **긴팔 셔츠**(올리브/카키), 카고팬츠+벨트, 갈색 부츠
- 3등신 SD 비율
- **플랫 셰이딩**: 재질당 베이스 1색 + 그림자 1톤. 그라데이션/디더링/픽셀노이즈 금지
  - 도트 질감·라이팅은 **셰이더로 후처리** → 원본은 단순 플랫하게 유지(방향 추가·장비 교체 유연)

#### 방향 제작 순서
1. **1차**: 횡방향 — 동(오른쪽 보기) / 서(왼쪽 보기, 좌우 플립). 80° 틸트에서 동/서 = 거의 측면 실루엣
2. **2차 (나중)**: 상/하 또는 대각 방향 추가
- 좌우 플립으로 동/서를 한 세트로 커버 → 검증·제작 비용 최소

#### 측면 캐릭터 공통 규칙 (2026-06-02)
- **양팔/양손이 항상 보이게** (왠만하면). 순수 정측면이면 먼 팔이 가려지므로, 먼 쪽 팔을 살짝 앞/밖으로 빼서 양손 다 읽히게
- 팔다리가 몸통·소지품(방패/무기)에 가려 사라지지 않게 — 전신 완전체로
- 측면이되 살짝 틀어 양손 노출 OK (완전 정측면 고집 X)

#### NPC 캐릭터 (2026-06-05)
- **기준 = 정면(front-facing) 3등신 치비.** 특이 연출 없으면 NPC는 전부 정면(플레이어를 향함)
- **NPC 마스터 레퍼 = 전당포 주인 스프라이트** (3등신 치비, 정면, 플랫+2~3톤 형태감, 1024² 캔버스 중앙). 신규 NPC 생성 시 이 이미지를 첨부해 비율·화풍·각도·디테일레벨·캔버스·위치를 락
  - 디테일 레벨 = "플랫하지만 2~3 셰이드로 형태감 있는" 중간 (너무 플랫=단색 카툰 / 너무 디테일=페인터리 둘 다 금지)
  - GPT가 성인=리얼 비율로 자동 이탈하므로, "3등신 치비/큰 머리/리얼 금지"를 강하게 명시 + 레퍼 첨부 필수
  - 체형·복장·소품으로 NPC 구분 (디테일 높이지 말고 실루엣·색으로 성격 표현)
- 플레이어(측면)와 방향이 달라도 OK — 탑다운에서 NPC 정면은 자연스러움
- 배경: 진한 회색 단색(키잉용) 또는 투명
- **"머리/스케일 = 통일, 몸 = 체형별 차별" 패턴**: 모든 NPC가 같은 치비 머리 크기·같은 스프라이트 스케일을 공유하되, **체형(실루엣)은 캐릭터마다 다르게** → 화풍 통일 + 개성 확보
  - 예: 전당포 주인 = 둥글/풍채, 베테랑 회수꾼 = 마른/길쭉, 관리인 = 보통 등
  - 머리 크기·디테일 레벨·화풍은 절대 건드리지 않음. 차별화는 몸 실루엣·복장·소품·얼굴 인상으로만
- **고정 캔버스 (전 NPC 공통)**: 1024×1024 정사각, 인물 중앙 정렬, 발 하단·머리 상단, **세로 약 80% 차지**, 마스터 레퍼와 동일 스케일 → 임포트 시 모든 NPC가 같은 크기로 정렬
- **앵커 트릭 (NPC 일관성 표준, 확정 2026-06-05)**: GPT는 cross-generation(따로 뽑은 캐릭터끼리)은 화풍이 드리프트하지만, **한 이미지 안에서는 일관**됨. 따라서 신규 NPC를 뽑을 때 **이미 합격한 캐릭터(전당포 주인 + 관리인 등 1~2명)를 같은 줄 앵커로 포함**해서 한 번에 생성 → 새 NPC가 앵커에 맞춰짐. 생성 후 **앵커는 버리고 새 NPC만 잘라서** 사용.
  - 앵커는 항상 같은 합격본으로 고정. 한 번에 새 NPC는 3~4명까지. 앵커 2명이 1명보다 안정적.

#### NPC 포트레이트 (대화 UI용, 2026-06-05)
- **용도**: DialogueUI 대화창 초상화 (흉상)
- **규격**: **반측면(3/4 뷰) 흉상**(머리 + 어깨/상체 일부). 정면 정측면 아님 — 몸·얼굴을 살짝 틀어 대화 텍스트 쪽을 바라보는 각도. 정사각 캔버스(예: 512×512), 인물 중앙, 진한 회색 단색 배경
  - 방향: 한쪽(예: 우측 보기) 기준 제작 → 대화창 반대편 배치 시 좌우 플립
  - 3/4라 표정·시선 전달이 좋고 어깨 라인으로 입체감
- **화풍**: 전신 스프라이트와 **동일 픽셀 화풍·팔레트·디테일레벨**. 각 NPC의 전신 스프라이트를 레퍼로 첨부해 얼굴·복장·인상 일치
- **표정**: 캐릭터당 **표정 시트**로 제작 — 같은 흉상·같은 머리 위치·같은 프레이밍에서 표정만 바꿔 한 시트에 그림. 대화창에서 **감정 태그별 흉상 통째로 스왑**(얼굴만 잘라 끼우지 않음 — 정렬 안정).
  - 기본 표정 6종: 중립 / 미소·호의 / 분노 / 슬픔·근심 / 놀람 / 의심·능글
  - 한 시트에 같이 생성 → 머리 위치 일치 → 슬라이스해 표정별 포트레이트 스프라이트로 저장
- **일관성**: 전신 세트와 동일하게 **앵커 트릭** 적용 — 합격한 포트레이트 1~2개를 앵커로 끼워 나머지 생성
- 1지역 7 NPC(전당포/회수꾼/관리인/상인/노점상/밴딧/생존자) + 젊은 남녀부터 제작

#### 적/밴딧 캐릭터 (2026-06-02)
- **화풍·디테일·비율을 플레이어와 100% 통일** (같은 아티스트가 그린 느낌). 플레이어보다 디테일 높이지 않음
- **측면(동/서) 우선 + 좌우 플립** — 플레이어와 동일한 방향 제작 방식
- 플랫 셰이딩 동일 (베이스 1색 + 그림자 1톤)
- 밴딧 종류: 방패 경비병(SEC), 후드 칼잡이, 넝마 환자형, 후드 스캐빈저 등 — 디자인은 유지하되 화풍만 통일

## 2-0. 레이드 건물 진입 = 지붕 알파 페이드 + 통일 각도 (2026-06-10 확정)

- **진입 방식 = 지붕(천장) 알파 페이드 walk-in**(연속 맵, 좀보이드식). 문/건물 안으로 들어가면 **지붕이 투명**해지며 밑의 실내가 드러남(별도 씬 전환 아님).
- **각도 통일**: 실내(전당포·하이드아웃)는 **이미 직하 방 박스(~80–85°)로 제작 완료** → **실외(지역)를 거기에 맞춤.**
  - 실외 = **~80° 직하**, 건물 = **지붕**(윗면, +남쪽 정면 짧은 띠 정도). 진입 시 지붕 페이드 → **밑의 직하 실내 노출**.
  - 실외 지붕·실내 방 둘 다 직하 = **한 각도** → 페이드 전환 자연스러움. **실내 재제작 안 함**(기존 방 박스 사용).
  - 너무 누운(75°↓) 정면 facade는 앞벽이 실내를 가려 페이드와 충돌 → **지붕 위주 직하로**.
- 프롭은 ~70–75° 유지(가독성), 바닥·건물지붕·실내는 ~80°.

> **안전구역 건물 진입 = 씬 전환(2026-06-10 확정, roof-fade 아님).** 거점(전당포·하이드아웃)은 차분한 허브라 **문→별도 실내 화면 전환**(하이드아웃 Hideout.unity 방식). 실내·외부가 다른 화면이라 **각도 불일치 무관** → 기존 실내(누운 ~70°) 그대로 사용. roof-fade는 **레이드 건물 전용**(아래 §2-0, 그쪽 실내는 처음부터 ~80° 평면으로 신규 제작 — 기존 거점 실내 재작업 X).
> **씬 전환 실내 = 컷어웨이(2026-06-10).** 고정 카메라 별도 화면이라 4면 벽 불필요 → **윗벽(back)+짧은 옆벽만, 아래(front) 개방**(문/문턱만). "방 들여다보기"로 읽힘. 고정 화면이라 **슬라이스 없이 이미지 통째를 배경+클릭 핫스팟**으로 써도 됨.
> **안전구역 건물 = 개성 부여(2026-06-10).** 잠금상점이라도 "다 같은 셔터" 금지 → 건물마다 재질·실루엣·지붕 디테일·간판 모양 다르게(한눈에 구분). 전당포=벽돌 차양 / 수리점=공업 정비소(롤셔터·유증기·지붕 배관/물탱크) / 의료소=흰 클리닉(십자 심볼) / 가구점=목재 전시창 / 블랙마켓=수상한 요새화(낙서·보강문·안테나) / 컨테이너집=초록 골판. 전부 빈 간판(글자 X), 납작 탑다운(지붕 3/4 + 정면 띠 1/4).

### 건물 에셋 구조 = 2겹 (2026-06-10)
진입형 건물 = **①실내(바닥+벽+프랍, 들어가면 보임) + ②지붕/천장(밖에선 덮음, 진입 시 알파 페이드로 사라짐)** 2장. 지붕 footprint = 실내와 동일(겹쳐 페이드).
- 외관·실내 **재질 일치**(예: 벽돌 외관 ↔ 벽돌 실내). 전당포 = 벽돌로 통일(기존 실내 벽돌로 재생성).
- **실내 보유 = 전당포·하이드아웃 둘뿐**(나머지 잠금상점은 2지역 해금) → 천장+실내 쌍은 이 둘만. **잠금상점 4채 = 지붕(닫힌 건물)만**.
- 지붕 추출 = 옥상만(균열·실외기·파라펫), 정면/문/창 제외.

## 2-1. 지역 무드 — 봉쇄구역(현상) 야외 (2026-06-10)

레이드 폐허·현상 지역 외부 에셋(바닥·외벽·건물·랜드마크) 전용 분위기. **안전구역(전당포·하이드아웃)엔 적용 X** — 거긴 멀쩡한 거점.

> 로어: 현상으로 **시간이 다르게 흐르는 봉쇄구역** → 과잉 부패·잠식·정적.

프롬프트에 붙일 무드 문단:
```
ATMOSPHERE (sealed anomaly zone where time flows differently): heavy decay — cracked
concrete, crumbling brick, shattered empty windows, thick climbing vines and overgrowth
creeping over surfaces, weeds breaking through the floor, scattered rubble and fallen
debris, rust streaks, an eerie "frozen in time" stillness. Cold desaturated palette with
muted green overgrowth.
BUT keep the established TOP-DOWN ~70–80° baked perspective + flat cel-shaded painterly
style. NOT isometric, NOT pixel art.
```
- ⚠️ 무드 레퍼(아이소·픽셀 폐허 이미지)는 **분위기 어휘만** 차용 — 각도/렌더 앵커로 첨부 금지(아이소·픽셀로 끌려감).
