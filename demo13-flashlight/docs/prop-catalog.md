## 1. 변형 축 — "뭘 손으로 그리고, 뭘 셰이더로 때우나"

의자 하나도 `나무/철제/플라스틱 × 멀쩡/금간/부서짐`으로 다 그리면 수백 장이 된다.
이 프로젝트는 **이미 가진 시스템으로 상당수를 자동 처리**하므로, 손으로 그릴 양을 다음처럼 줄인다.

| 변형 축 | 처리 방법 | 손그림 필요? |
|---|---|---|
| **재질** (나무/철제/플라스틱/패브릭/가죽/유리…) | 실루엣·색이 달라짐 → **재질별로 그린다** | ✅ 그림 |
| **금간 / 그을음 / 물때 / 이끼 / 표면 오염·부패** | **BRB/DamageOverlay 셰이더**가 절차적으로 균열+그라임 오버레이 ([`destructible.md`](destructible.md)) | ❌ 셰이더 |
| **썩어서 구멍·찢어짐 등 실루엣이 바뀌는 파손** | 외곽선이 달라져 오버레이로 불가 → **변형 스프라이트로 그림** (예: 썩은 판자바닥, 찢어진 매트리스) | ✅ 그림 |
| **단계적 손상 (1→2→3)** | `Breakable` 컴포넌트 + 오버레이 강도 | ❌ 코드/셰이더 |
| **완전 부서진 최종형** (산산조각/붕괴) | 오버레이로 표현 한계 → **별도 스프라이트 1장**(파괴최종형 Y인 프랍만) | △ 일부만 그림 |
| **상태 토글 (켜짐/꺼짐, 닫힘/열림, 깨진창/판자창)** | 의미가 다른 별개 비주얼 → **변형으로 그린다** | ✅ 그림 |

**결론**: 손으로 그릴 것 = **재질 변형(멀쩡 상태) + 의미 있는 토글 변형 + 일부 파괴최종형**.
"금간 의자/그을린 책상" 같은 오염·손상 베리에이션은 **그리지 않고 셰이더로** 입힌다.

## 4. 제작 워크플로

1. **재질 변형(멀쩡)만 그린다** — CSV의 `재질/변형` 열 한 행 = 스프라이트 1장
2. 같은 시점(**70°** high 3/4, 2026-06-10 상향)·탈채도·플랫 셰이딩으로 통일 ([`topdown-art-spec.md`](topdown-art-spec.md))
3. Unity에서 Prop2D 카탈로그 등록 (탭: 프랍/오브젝트/데칼/천장) → 콜라이더·그림자·기능 부여 ([`map-tool.md`](map-tool.md))
4. **금간/오염은 안 그림** — 배치 후 `Breakable`+`DamageOverlay`로 단계 손상 자동
5. **파괴최종형 Y** 프랍(20종)만 부서진 최종 스프라이트 1장 추가 → Breakable 마지막 단계
6. **데칼 9시트**는 바닥/벽 위에 흩뿌려 반복감 제거 (Decal Scatter Brush)

> 제작 순서 권장: **P1 먼저**(폐상가·안전가옥 채움) → 루팅 기능 있는 수납/박스류 우선 → P2(확장 레벨) → P3(디테일).
