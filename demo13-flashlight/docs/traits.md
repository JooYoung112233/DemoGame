# 캐릭터 특성(퍽) 시스템

> **현 상태 = 진실.** 진행형 퍽 트리 — 회수꾼이 살아남고 깊이 들어갈수록 특성을 "찍는다". 낙원(Last Paradise)·좀보이드식 빌드 다양화를, **이 게임의 세계관(현상·빛의역설·루디·시계)**에 맞춰 설계.
>
> 연동: 스탯 = [`StatDB`/PlayerStatData](inventory.md) · 평판/경제 = [economy.md](economy.md) · 의료 = [medical.md](medical.md) · 현상·루디·시계 = [gdd-core.md §5](gdd-core.md)·[anomaly.md](anomaly.md). **수치는 전부 `GameTuning` TBD.**

---

## 1. 모델 (확정 2026-06-17)

- **진행형 퍽 트리**: 캐릭터 생성 시 몰아주지 않는다. **레이드·평판으로 퍽 포인트(PP)를 벌어** 점차 해금.
- **긍정 퍽 + 부정 특성(낙인) 둘 다**:
  - **긍정 퍽** = PP 소모로 해금(카테고리 트리, 티어 선행조건).
  - **부정 특성(낙인)** = 영구 약점을 **자청**하면 **PP 환급** → 더 강한 빌드. (좀보이드 트레이드오프를 진행형에 이식)
  - 일부 퍽은 **트레이드오프 내장**(강한 효과 + 작은 대가) — 선택의 무게.
- **리스펙**: 기본 불가(영구 빌드). 거점 고급 시설(또는 희귀 아이템)로 **제한적 1회성 초기화**만 — 추후.

## 2. 포인트(PP) 경제 〔수치 TBD〕
- **획득**: 회수꾼 **평판 레벨업**마다 +1 (주 공급) · 특정 **마일스톤**(첫 짙은 현상 생환, 지역 첫 입성, 핵심 단서 등) 일시 보너스.
- **부정 특성 환급**: 선택 즉시 +N PP (강도별 1~3). 보유 가능 부정 특성 수 상한(예: 3) = `GameTuning`.
- **티어 게이트**: 트리 상위 퍽은 하위 퍽 또는 평판 레벨 선행. "찍는 맛" + 빌드 정체성.

### 3.6 ★ 현상 (Anomaly) — 세계관 고유 트리 [→ gdd-core.md §5, anomaly.md]
> 이 게임만의 정체성. 짙은 현상·빛의 역설·루디·시계와 직접 묶인다. 깊이 들어가는 자의 트리.

| 퍽 | 효과 | 티어 |
|---|---|---|
| 어둠 적응 | 짙은 현상 시야 페널티↓ — 콘 밖 형체를 더 멀리 인식 | 1 |
| **빛 절제** | 비루디 광원의 **침식 게이지 누적↓**(빛의 역설 완화) → 더 깊이·오래 버팀 | 2 |
| 루디 감각 | 주변 **루디·현상 노드 위치 감지**(핑) + 순도 직감 | 2 |
| 시계 동조 | "믿을 수 없는 시계"의 왜곡을 더 정확히 읽음 — **진짜 남은 시간 표시 정밀↑** | 2 |
| 현상 친화 ※트레이드오프 | 현상권 루디·희귀 보상↑ **BUT** 침식·몬스터 어그로도↑ | 3 |
| **되감기 친화** ※트레이드오프 | 죽음→시계 시간 회수 시 손실(가방·시간)↓ **BUT 기억이 더 흐려진다** (서사: 새벽의 기원과 공명, §2.4) | 3 |
| **(부정) 현상 과민** | 현상권에서 스태미너·시야 페널티↑, PP 환급 | — |
| **(부정) 빛 의존** | 탐지등 꺼지면(방전) 공황 — 정확도·이동↓, PP 환급 | — |

> 현상 트리는 **서사와 직결**: '되감기 친화'·'빛 의존' 같은 특성이 주인공의 기원(죽음→부활, 빛의 역설)을 *플레이로* 만지게 한다. 깊게 파는 빌드일수록 진실에 가까워지는 결.

## 4. 구현 메모 〔구현 전〕
- 데이터: `TraitData`(ScriptableObject) — id·이름·설명·카테고리·티어·선행조건·PP비용(또는 환급)·효과(스탯 수정/플래그). `StatDB`/PlayerStatData에 모디파이어로 적용.
- UI: 캐릭터 패널("01 캐릭터 상태", [→ inventory.md])에 **특성 탭**(트리 뷰 + PP 잔량). 양피지 6패널 톤과 통일.
- 효과 적용 = 기존 스탯/시스템 훅 재사용(전투·의료·인벤·현상·시계). **새 수치는 밸런싱 단계([balance-tuner])에서.**
- **미정(TBD)**: PP 곡선·각 퍽 수치·부정 특성 환급량/상한·리스펙 방식·트리 시각.
