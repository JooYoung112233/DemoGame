# 스토리 스크립트 — 1지역 빌드 (구현)

> 게임 내 대사·연출·분기를 구현 수준으로 기술한 마스터 스크립트.
> **1지역(폐상가 교역 지구)까지만 포함.** 2지역 이후는 별도 문서로 확장.
>
> **이 문서 = "어떻게"(대사·씬·연출).** 스토리 구조·세계관·엔딩 설계는 → [story.md](story.md).

---

## 구현 제약


| 항목    | 제약                                                                           |
| ----- | ---------------------------------------------------------------------------- |
| 카메라   | 고정 탑다운 2D(Orthographic). 줌/패닝/앵글 변경 없음                                       |
| 캐릭터   | 탑다운 2D 스프라이트. 물건 주고받기 등 세밀 연기 불가                                             |
| NPC   | 고정 위치. 에스코트/이동 없음                                                            |
| 연출    | 화면 단위 이펙트만 (페이드, 플래시, 쉐이크, 색수차)                                              |
| 대화    | DialogueUI 사용. 전용 UI(시계 팝업 등) 만들지 않음                                         |
| 사운드   | `[BGM]`/`[앰비언트]`/`[SE]` 3분류로 각 씬 명시. 도입부는 BGM 최소(적막) + 환경음 위주                |
| 톤     | 검은 현상으로 붕괴한 세계. NPC는 기본 삭막·경계. 친절·호의는 관계(단계/호감도)를 쌓은 뒤에만. 첫 대면은 차갑게          |
| 대사 분량 | **전문(풀 스크립트).** 대화가 주고받으며 자연스럽게 흐르게 작성. 스토리 대화는 압축 금지 (반복 일일의뢰 등 기능성 대사만 짧게) |
| 선택지   | 기본 2개. 핵심 분기만 3개                                                             |


## 표기 규칙

- `[화면]` — 화면 이펙트 (페이드, 플래시 등)
- `[UI]` — HUD, 팝업, 튜토리얼
- `[게임]` — 조작 가능 구간, 전투, 파밍
- `[조건]` — 분기 조건
- `[선택지]` — DialogueUI 선택지
- `[BGM]` — 배경 음악 (없으면 "없음" 명시)
- `[앰비언트]` — 환경음 루프 (빗소리, 바람, 라디오 잡음 등)
- `[SE]` — 효과음 단발 (발소리, 타격, 문, 시계 틱 등)
- `[기술]` — 구현 방식 메모 (씬, 셰이더 등)
- `→` — 시스템 호출 (퀘스트, 아이템, 플래그)

**화자 표기**: 이름 미공개 NPC는 `???`로 표기 (예: 전당포 주인 = 본명 강무진, 서사 단계 3 공개 전까지 `???`). 설계 문서(story.md)는 본명 사용 가능, 게임 대사(이 문서)는 `???`.

## T-000. 타이틀 화면

```
[화면] 검은 화면 2초. 빗소리 서서히 페이드 인 + 은은한 BGM 루프 시작.
[화면] 중앙에 멈춘 손목시계 클로즈업 (타이틀 전용 아트). 유리 위로 빗방울이 흐른다.
[화면] 초침은 정지. BGM이 1사이클 돌 때쯤 딱 한 번 "틱" 하고 미세하게 떨린다 — 시간 현상 복선.
[화면] 시계 뒷면에 각인이 있으나 김이 서려 읽히지 않는다 (→ S-000으로 이어지는 떡밥).
[화면] 로고 페이드 인: "다녀올게" (손글씨체) / "Be Right Back" (작은 영문 서브).

[UI] 메뉴: 새로 시작 / 이어하기 (세이브 없으면 비활성) / 설정 / 종료

[사운드] 빗소리 앰비언트 루프 + 은은한 BGM 루프. 초침 "틱" SFX는 떨림 순간에만.
[기술] 별도 TitleScene. 실시간 2D (시계 스프라이트 + 빗 파티클 + 유리 김서림 셰이더). 영상 클립 미사용.

→ "새로 시작" → S-000 (프롤로그 — 별도 오프닝 없이 바로 깨어남, 빗소리 끊김 없이 연결)
→ "이어하기" → 세이브 로드 → 안전가옥 or 마지막 지점
```

> 디자인 의도: 첫 화면부터 "멈춘 시간"과 "시계"를 각인. 무엇을 봤는지 모른 채 분위기만 남기고, S-000에서 그 시계를 손목에서 다시 발견하며 연결.

## 반복 레이드

- 폐상가 낮/밤 자유 선택 출격

- 루디: 밤 레이드에서만 획득 가능

## 전당포 일일 의뢰

전당포 주인에게 말을 걸면 의뢰 1개를 받을 수 있음 (1일 1회 갱신).

전당포 주인: (의뢰 수락 시)
  "하나 부탁할 게 있어."

전당포 주인: (의뢰 완료 시)
  "잘했어. 여기."

> 구체적인 의뢰 목록은 quests-region1.md 참조.

## 떠돌이 상인 재등장

- 낮 레이드 시 **30% 확률**로 폐상가 내 랜덤 위치에 등장
- 거래만 가능 (대화 이벤트는 첫 조우에서 끝남)
- 거래 횟수가 호감도에 누적됨 (2지역 이후 정착 조건 대비)

### 2026-05-28

- **질문**: 스크립트 형식?
  - **결정**: 플롯 아웃라인 형태. 씬 단위 구조.
- **질문**: 도입부 범위?
  - **결정**: 첫 귀환까지 (깨어남 → 전당포 → 첫 낮/밤 레이드 → 루디 납품).
- **질문**: 1지역 빌드 범위?
  - **결정**: CH0 (깨어남) + CH1 (폐상가 교역 지구)만 포함. 2지역 이후는 별도 문서.
- **질문**: 연출 수준?
  - **결정**: 2인 개발 + 쿼터뷰 2.5D 제약 반영. 카메라 워크 없음, NPC 에스코트 없음, DialogueUI 재활용, 화면 이펙트만.
- **질문**: 장르 방향?
  - **결정**: 루트 슈터. 스토리는 루프를 방해하지 않는 수준. 대사 압축, 루프 진입 5분 이내. 반복 플레이로 천천히 풀어가는 구조.
- **질문**: 1지역 컷오프 포인트?
  - **결정**: MQ-002 (첫 루디 회수) 완료 후 반복 루프 진입. 지도판에 나머지 6지역 잠금 표시. 전당포 일일 의뢰 + 반복 레이드가 엔드 콘텐츠.
- **질문**: 루디 납품 후 바로 끝나면 아쉽다?
  - **결정**: S-031 여운 씬 추가. 첫 휴식 시 꿈(어린아이 목소리) + 전당포 주인 혼잣말("살아 있으려나") 목격. 동생 복선 + "루디 더 가져오면 알려줄게" 동기 부여. 이후 반복 루프 자연 진입.
- **질문**: 1지역에 등장하는 NPC?
  - **결정**: 전당포 주인 + 떠돌이 상인만. 의사/수리공/공무원/아이는 2지역 이후.
- **질문**: 스토리 시스템 구현 구조?
  - **결정**: StoryPlayer(씬 재생) + StoryLocale(다국어) + StoryTriggerManager(이벤트→플래그→자동트리거 연결) 3단 구조. 게임 이벤트(씬 전환, NPC 대화, 침대 휴식, 파밍, 탈출)가 플래그를 설정하면 StoryPlayer.CheckAutoTriggers()가 해당 씬 자동 재생.
- **질문**: 스토리 스크립트 외부화 방식?
  - **결정**: JSON 2층 분리. Scripts/*.json (씬 흐름, 언어 무관) + Locale/*.json (텍스트, 언어별). 번역 시 Locale만 추가.

### 2026-06-04

- **질문**: 타이틀 화면 비주얼 / 사운드?
  - **결정**: 비주얼 = **멈춘 손목시계 클로즈업** (타이틀 전용 아트, 초침 정지 + 가끔 1틱 떨림 = 시간현상 복선). 사운드 = **빗소리 앰비언트 + 은은한 BGM 루프**, 초침 SFX는 떨림 순간만. 로고 "다녀올게"(손글씨) + "Be Right Back". 메뉴: 새로시작/이어하기/설정/종료. 별도 TitleScene, 실시간 2D (영상 클립 미사용).
- **질문**: 타이틀과 깨어남(S-000) 사이 오프닝(초기 영상) 형식?
  - **결정**: **오프닝 시네마틱 생략.** "새로 시작" → 빗소리를 끊지 않고 바로 S-000 깨어남. 과거는 전부 게임 중 단서로 → 기억상실 몰입 극대화, 저비용.
- **질문**: S-000에서 '손목 시계' 발견 연출?
  - **결정**: **타이틀 시계 아트 1초 인서트 + "틱" SFX.** 타이틀↔깨어남 시각 직결("그 시계다"). 도입 1회 전용 컷(제약 '전용 UI 안 만듦'의 예외). 빗소리는 타이틀에서 끊김 없이 연결. S-000의 '쿼터뷰' 표기도 '탑다운'으로 정정.
- **질문**: S-001 도입 골목 — 시야 / 이동 / 환경음?
  - **결정**: 시야 = **부드러운 어둠 + 전당포 불빛 유도** (비전콘·손전등 등 본격 시야 메커닉은 첫 밤 레이드부터). 이동 = **걷기만**, 달리기는 이후 해금(시점 TBD) — 깨어난 직후 무력감 연출. 환경음 = **미니멀**(빗소리+발소리 위주). 카메라 = 부드러운 추적. 가방 획득 시 인벤토리 해금.
