# 스토리 스크립트 — 1지역 빌드 (구현)

> 게임 내 대사·연출·분기를 구현 수준으로 기술한 마스터 스크립트.
> **1지역(폐상가 교역 지구)까지만 포함.** 2지역 이후는 별도 문서로 확장.
>
> **이 문서 = "어떻게"(대사·씬·연출).** 스토리 구조·세계관·엔딩 설계는 → [story.md](story.md).

---

## 구현 제약


| 항목    | 제약                                                                           |
| ----- | ---------------------------------------------------------------------------- |
| 카메라   | 고정 탑다운 2D(Orthographic). 줌/패닝/앵글 변경 없음                                       |
| 캐릭터   | 탑다운 2D 스프라이트. 물건 주고받기 등 세밀 연기 불가                                             |
| NPC   | 고정 위치. 에스코트/이동 없음                                                            |
| 연출    | 화면 단위 이펙트만 (페이드, 플래시, 쉐이크, 색수차)                                              |
| 대화    | DialogueUI 사용. 전용 UI(시계 팝업 등) 만들지 않음                                         |
| 사운드   | `[BGM]`/`[앰비언트]`/`[SE]` 3분류로 각 씬 명시. 도입부는 BGM 최소(적막) + 환경음 위주                |
| 톤     | 검은 현상으로 붕괴한 세계. NPC는 기본 삭막·경계. 친절·호의는 관계(단계/호감도)를 쌓은 뒤에만. 첫 대면은 차갑게          |
| 대사 분량 | **전문(풀 스크립트).** 대화가 주고받으며 자연스럽게 흐르게 작성. 스토리 대화는 압축 금지 (반복 일일의뢰 등 기능성 대사만 짧게) |
| 선택지   | 기본 2개. 핵심 분기만 3개                                                             |


## 표기 규칙

- `[화면]` — 화면 이펙트 (페이드, 플래시 등)
- `[UI]` — HUD, 팝업, 튜토리얼
- `[게임]` — 조작 가능 구간, 전투, 파밍
- `[조건]` — 분기 조건
- `[선택지]` — DialogueUI 선택지
- `[말풍선]` — 머리 위 말풍선 (DialogueUI 아님 — 짧은 외침·혼잣말, 자동 소멸)
- `[BGM]` — 배경 음악 (없으면 "없음" 명시)
- `[앰비언트]` — 환경음 루프 (빗소리, 바람, 라디오 잡음 등)
- `[SE]` — 효과음 단발 (발소리, 타격, 문, 시계 틱 등)
- `[기술]` — 구현 방식 메모 (씬, 셰이더 등)
- `→` — 시스템 호출 (퀘스트, 아이템, 플래그)

**화자 표기**: 이름 미공개 NPC는 `???`로 표기 (예: 전당포 주인 = 본명 강무진, 서사 단계 3 공개 전까지 `???`). 설계 문서(story.md)는 본명 사용 가능, 게임 대사(이 문서)는 `???`.

## T-000. 타이틀 화면

```

[화면] 중앙에 멈춘 손목시계 클로즈업 (타이틀 전용 아트). 유리 위로 빗방울이 흐른다.
[화면] 초침은 정지. BGM이 1사이클 돌 때쯤 딱 한 번 "틱" 하고 미세하게 떨린다 — 시간 현상 복선.
[화면] 시계 뒷면에 각인이 있으나 김이 서려 읽히지 않는다 (→ S-000으로 이어지는 떡밥).
[화면] 로고 페이드 인: "다녀올게" (손글씨체) / "Be Right Back" (작은 영문 서브).

[사운드] 빗소리 앰비언트 루프 + 은은한 BGM 루프. 초침 "틱" SFX는 떨림 순간에만.
[기술] 별도 TitleScene. 실시간 2D (시계 스프라이트 + 빗 파티클 + 유리 김서림 셰이더). 영상 클립 미사용.

→ "새로 시작" → S-000 (프롤로그 — 별도 오프닝 없이 바로 깨어남, 빗소리 끊김 없이 연결)
→ "이어하기" → 세이브 로드 → 안전가옥 or 마지막 지점
```
