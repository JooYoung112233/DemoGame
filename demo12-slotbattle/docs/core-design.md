# Demo 12: 슬롯 배틀 — 코어 디자인

## 컨셉
슬롯머신 + 덱빌딩 + 전투 로그라이크.
슬롯 릴의 심볼이 곧 "덱"이며, 라운드마다 심볼을 추가/제거/업그레이드하여 빌드를 완성한다.

## 코어 루프
1. **슬롯 스핀** — 릴 3개 돌려서 심볼 조합 결정
2. **조합 판정** — 심볼 조합에 따라 전투 액션 생성 (공격/방어/버프 등)
3. **전투 적용** — 액션으로 적에게 데미지, 방어 등 적용
4. **라운드 클리어** — 적 처치 시 보상
5. **심볼 드래프트/강화** — 새 심볼 획득, 기존 심볼 업그레이드
6. → 다음 라운드 반복
