# Demo 12: 슬롯 배틀 — 코어 디자인

## 컨셉
슬롯머신 + 덱빌딩 + 전투 로그라이크.
슬롯 릴의 심볼이 곧 "덱"이며, 라운드마다 상점에서 심볼/아이템/조합강화를 구매하여 빌드를 완성한다.

## 코어 루프
1. **슬롯 스핀** — 릴 3개 돌려서 심볼 조합 결정
2. **조합 판정** — 심볼 조합에 따라 전투 액션 생성 (공격/방어/버프 등)
3. **전투 적용** — 액션으로 적에게 데미지, 방어 등 적용 (방어→HP 순서로 피해)
4. **라운드 클리어** — 적 처치 시 상점 진입
5. **상점** — 심볼 구매/조합 강화/아이템 사용/심볼 버리기(골드 소모)
6. → 다음 라운드 반복

## 방어 시스템
- 슬레이더슬 방식: 피해 → 방어에서 먼저 차감 → 남은 피해가 HP에 적용
- 방어는 **영구 유지** (턴마다 리셋 안 함), 스킬로 충전/소모
- 방어 획득량이 별도로 표시됨

## 적 공격 쿨타임 시스템
- 슬레이더스파이어 인텐트 시스템 참고
- 각 적은 고유 쿨타임(cooldown)을 가짐: 쥐(1), 슬라임(2), 박쥐(2), 고블린(2), 스켈레톤(3), 늑대(1), 오크(3), 흑마법사(4), 드래곤(3)
- 매 플레이어 턴 후 쿨타임이 1씩 감소, 0이 되면 공격 후 쿨타임 리셋
- 적 위에 "N턴 후 ⚔️공격력" 형태로 인텐트 표시
- 얼음(❄️) 심볼/빙벽 조합으로 적 쿨타임 증가(둔화) 가능

## 상점 시스템 (발라트로 참고)
- 라운드 클리어 시 무료 심볼 없음, 상점에서 구매해야 함
- 구매 가능: 개별 심볼, 아이템(HP회복/랜덤슬롯/랜덤조합), 조합 강화
- 심볼 버리기: 골드 소모하여 덱에서 제거
- 조합 강화: 같은 조합을 중복 구매할수록 효과 증가

### 2026-05-19 — 전투 시스템 대규모 리워크
- **요청 사항**:
  1. 적 공격 쿨타임: 슬스파식 인텐트 시스템, 각 적마다 N턴마다 공격
  2. 방어 영구 유지: 턴마다 리셋 안 함, 스킬로 충전/소모
  3. 심볼 확장: 10개→18개 (도끼, 폭탄, 번개, 얼음, 성벽, 약초, 생명력, 왕관 추가)
  4. 조합 확장: 8개→13개 (빙벽, 뇌전난무, 대폭발, 이중참격, 생명의축복 추가)
  5. 슬롯 인터랙티브: 1개씩 순차 공개, 각 릴 정지 시 이펙트
  6. HP바 애니메이션: 데미지/회복 시 프로그레스바 부드럽게 변화
  7. 전투 시각 피드백: 피격 시 화면 흔들림+플래시, 아이콘 표기 개선
