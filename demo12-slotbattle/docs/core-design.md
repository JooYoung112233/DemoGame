# Demo 12: 슬롯 배틀 — 코어 디자인

## 컨셉
슬롯머신 + 덱빌딩 + 전투 로그라이크.
슬롯 릴의 심볼이 곧 "덱"이며, 라운드마다 상점에서 심볼/아이템/조합강화를 구매하여 빌드를 완성한다.

## 코어 루프
1. **트리 맵 선택** — 다음 노드 선택 (전투/엘리트/상점/이벤트/보물/휴식)
2. **슬롯 스핀** — 릴 3개 돌려서 심볼 조합 결정 (유물로 리스핀 가능)
3. **조합 판정** — 심볼 조합에 따라 전투 액션 생성 (공격/방어/버프 등)
4. **전투 적용** — 액션으로 적에게 데미지, 방어 등 적용 (방어→HP 순서로 피해)
5. **노드 보상** — 전투 클리어 시 골드, 보물 노드에서 유물 획득
6. **상점** — 심볼/유물/아이템 구매, 심볼 강화/버리기
7. → Act 보스 처치 후 다음 Act로

## 맵 구조 (3Act 트리)
- **3개 Act**, 각 Act마다 슬스파식 트리 맵 (분기 선택)
- 노드 종류: 전투 / 엘리트(강적+좋은보상) / 상점 / 이벤트(랜덤) / 보물(유물) / 휴식(HP회복)
- 각 Act 끝에 보스 고정
- Act 1: 기본 적 (슬라임~박쥐), Act 2: 중급 (고블린~늑대), Act 3: 고급 (오크~흑마법사) + 최종보스 드래곤

## 유물(패시브 아이템) 시스템
- 영구 효과, 빌드를 정의하는 핵심 요소
- 획득: 보물 노드에서 3택 1 + 상점에서 골드 구매
- 유물 중복 시 효과 강화 또는 확률 증가
- 예시:
  - 🔄 **재회전 부적**: 턴당 리스핀 1회 가능 (중복→확률 증가)
  - 🎯 **집중의 렌즈**: 덱 내 같은 심볼 3개 이상 시 출현율 +50%
  - 🔗 **공명석**: 같은 종류 심볼 2개 나오면 3개째 효과 추가 발동
  - ⚡ **과부하 코어**: 콤보 발동 시 추가 스핀 1회
  - 🛡️ **가시 갑옷**: 방어 시 반사 데미지
  - 💰 **황금 손**: 금화 심볼 효과 2배
- 리스핀 연출: 유물 아이콘이 빛나면서 "리스핀!" 텍스트 → 슬롯 재회전

## 심볼 강화 시스템
- 개별 심볼 레벨업 (골드/재화로 강화)
- 강화 시 수치 증가 (+데미지, +방어, +회복 등)
- 상점 또는 전용 강화 노드에서 수행

## 방어 시스템
- 슬레이더슬 방식: 피해 → 방어에서 먼저 차감 → 남은 피해가 HP에 적용
- 방어는 **영구 유지** (턴마다 리셋 안 함), 스킬로 충전/소모
- 방어 획득량이 별도로 표시됨

## 적 공격 쿨타임 시스템
- 슬레이더스파이어 인텐트 시스템 참고
- 각 적은 고유 쿨타임(cooldown)을 가짐: 쥐(1), 슬라임(2), 박쥐(2), 고블린(2), 스켈레톤(3), 늑대(1), 오크(3), 흑마법사(4), 드래곤(3)
- 매 플레이어 턴 후 쿨타임이 1씩 감소, 0이 되면 공격 후 쿨타임 리셋
- 적 위에 "N턴 후 ⚔️공격력" 형태로 인텐트 표시
- 얼음(❄️) 심볼/빙벽 조합으로 적 쿨타임 증가(둔화) 가능

## 상점 시스템 (발라트로 참고)
- 라운드 클리어 시 무료 심볼 없음, 상점에서 구매해야 함
- 구매 가능: 개별 심볼, 아이템(HP회복/랜덤슬롯/랜덤조합), 조합 강화
- 심볼 버리기: 골드 소모하여 덱에서 제거
- 조합 강화: 같은 조합을 중복 구매할수록 효과 증가

### 2026-05-20 — 전투/맵/유물 대규모 리워크
- **요청 사항**:
  1. 도움말 UI 진입 불가 버그 수정 (H 변수 스코프)
  2. 리스핀 시스템 개편: 수동 리스핀 완전 제거 → 유물(재회전 부적)으로 자동 발동 (10%/개)

     - 중첩 시 확률: 1-(0.9^N) → 1개=10%, 2개=19%, 3개=27%
  3. 액션 프리뷰: 슬롯 결과 → 공격/방어/회복 수치 표시 1.2초 → 실제 적용
  4. 전투 템포 조절: 모든 딜레이 대폭 증가 (스핀→프리뷰→적용→쿨다운→적턴→대기)
  5. 유물 중첩(stacking): relics 배열에 중복 허용, count로 효과 스케일링
     - battle_drum: +5/개, ice_crystal: +1/개, vampiric_fang: +5hp/개, berserker_mark: +50%/개
     - golden_hand: 2^N배, phoenix_feather: 보유 수만큼 부활, thorn_armor: +3반사/개
  6. 맵 세로→가로 전환: 좌→우 수평 배치, 중앙 정렬
  7. 분기 최대 3갈래로 제한 (2~3 노드/층)
  8. 유물 8개 추가:
     - common: 무쇠 장화(매턴 방어+2), 행운의 동전(승리 시 골드+3)
     - uncommon: 불꽃 심장(매스핀 화상2), 거울 방패(방어→공격 전환), 영혼 등불(처치 시 최대HP+2)
     - rare: 혼돈의 오브(4번째 슬롯 효과), 시간의 수정(3턴마다 적 둔화)
- **선택**: 리스핀 확률 10%/개, 수동 리스핀 완전 제거
