# Demo 12: 슬롯 배틀 — 코어 디자인

## 컨셉
슬롯머신 + 덱빌딩 + 전투 로그라이크.
슬롯 릴의 심볼이 곧 "덱"이며, 라운드마다 상점에서 심볼/아이템/조합강화를 구매하여 빌드를 완성한다.

## 코어 루프
1. **슬롯 스핀** — 릴 3개 돌려서 심볼 조합 결정
2. **조합 판정** — 심볼 조합에 따라 전투 액션 생성 (공격/방어/버프 등)
3. **전투 적용** — 액션으로 적에게 데미지, 방어 등 적용 (방어→HP 순서로 피해)
4. **라운드 클리어** — 적 처치 시 상점 진입
5. **상점** — 심볼 구매/조합 강화/아이템 사용/심볼 버리기(골드 소모)
6. → 다음 라운드 반복

## 방어 시스템
- 슬레이더슬 방식: 피해 → 방어에서 먼저 차감 → 남은 피해가 HP에 적용
- 방어는 턴 종료 시 0으로 리셋
- 방어 획득량이 별도로 표시됨

## 상점 시스템 (발라트로 참고)
- 라운드 클리어 시 무료 심볼 없음, 상점에서 구매해야 함
- 구매 가능: 개별 심볼, 아이템(HP회복/랜덤슬롯/랜덤조합), 조합 강화
- 심볼 버리기: 골드 소모하여 덱에서 제거
- 조합 강화: 같은 조합을 중복 구매할수록 효과 증가
