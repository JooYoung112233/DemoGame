# 아트 필요 리스트 (임경민 형 전달용)

> 기준: demo10 "밤에만 열리는 도시" - 쿼터뷰 2D 생존 루팅 게임
> 정리일: 2026-05-27

---

## 1. 캐릭터

| 항목 | 상세 | 우선도 |
|------|------|--------|
| 주인공 스프라이트 | 4방향(상하좌우) 기본. 걷기/뛰기/대기 모션 | 최우선 |
| 주인공 장비 반영 | 방탄복, 단검/장검 등 착용 시 외형 변화 (최소 무기+방어구 1종씩) | 높음 |
| 손전등 들고 있는 상태 | 밤 탐험 핵심 비주얼. 플래시 ON/OFF 구분 | 최우선 |
| 웅크리기/포복 | 은신/암살 시스템 고려 시 필요 | 낮음 (폴리싱) |
| 적 - 낮(밴딧) | 인간형 적. 4방향. 기본 공격 모션 | 높음 |
| 적 - 밤(이상현상 몹) | 비인간형/유령형. 공포 느낌 | 높음 |
| NPC | 안전가옥 상인 등. 대기 포즈 1종이면 충분 | 중간 |

## 2. 맵 타일 & 건물 (아이소메트릭/쿼터뷰)

| 항목 | 상세 | 우선도 |
|------|------|--------|
| 바닥 타일 | 아이소 기본 타일. 아스팔트/콘크리트/잔디/실내바닥 등 바리에이션 | 최우선 |
| 벽 모듈 | 일자 벽, 창문 포함 벽, 문 포함 벽 → 조립식으로 건물 내부 구성 | 최우선 |
| 건물 외형 | 1층 구조 기준. 아파트/빌라/상가 외관 (낮은 건물, 캐릭 가림 방지) | 높음 |
| 건물 내부 | 1층만 구현. 방/복도/계단(막힌) 모듈 | 높음 |
| 랜드마크 건물 | 1스테이지 기준 특수건물 2개 (경찰서, 약국, 격납고 등에서 선택) | 중간 |
| 무너진/폐허 버전 | 정상 건물의 파손 바리에이션 | 중간 |
| 낮/밤 버전 | 같은 건물 라이팅/셰이더로 구분. 밤용 색감 조정 필요 | 높음 |

## 3. 오브젝트 & 프랍

| 항목 | 상세 | 우선도 |
|------|------|--------|

| 환경 프랍 | 버려진 차량, 가로등, 쓰레기통, 벤치, 풀/잡초 등 바리에이션 다수 | 높음 |
| 네온사인/간판 | 밤 분위기 핵심. 발광 효과용 이미지 | 높음 |
