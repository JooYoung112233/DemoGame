# 블랙마켓 & 도시 변이 시스템 기획

> Demo10 (Opening City) 중반 이후 해금 컨텐츠
> 상태: 아이디어 단계 (미구현)

## 목표

기존 "돈 → 장비 → 레이드 → 돈" 루틴이 식상해지는 문제를 해결.
매 출격의 동기를 "돈 벌러 감"이 아니라 **"오늘 밤의 도시를 읽으러 감"**으로 바꿔 리플레이성 확보.

---

## 1. 블랙마켓 (정보 거래)

플레이어가 블랙마켓 운영자 역할을 함.

### 핵심 메커니즘
- 밴딧에게 아이템을 팔면 **돈 대신 도시의 정보**를 받음
- 일반 상인(안전, 낮은 마진) vs 블랙마켓(정보 획득, 리스크)

### 정보 예시
- "오늘 밤 3구역 지하가 열린다"
- "그 건물 4층 벽 뒤에 뭔가 있다"
- "그 구역에 먼저 간 놈이 돌아오지 못했다"

### 핵심 긴장감
- 정보가 진짜인지 함정인지 모름
- 매 출격 동기가 "정보 확인"으로 바뀜
- "블랙마켓에 더 팔까?" — 돈은 되는데 필드가 점점 위험해짐

---

## 2. 밴딧 생태계

밴딧 = 단순 몹이 아니라 **나와 같은 원정꾼**.

### 행동 패턴
- 내가 판 아이템을 장착하고 필드에 등장
- 내가 안 간 건물을 먼저 털어감 → 가보면 이미 뒤집혀 있음
- 많이 팔수록 밴딧 무장 업그레이드 → 필드 난이도 상승

### 조우 상황
- 밴딧 시체 발견 → 뭐한테 죽었는지 단서 → 그 층에 뭔가 있다
- 같은 건물에서 마주침 → 싸울까, 무시할까
- "나만 이 도시를 탐험하는 게 아니다" → 세계가 살아있는 느낌

---

## 3. 도시 변이 (밤마다 구조 변화)

### 핵심
- 매 밤 열리는 건물 내부 구조가 달라짐
- 같은 건물인데 오늘은 왼쪽 막히고 오른쪽 열림
- 조건부 개방: "비 오는 밤에만 열리는 3층", "정전된 밤에만 보이는 문"

### 블랙마켓 연동
> 밴딧한테 아이템 팔았더니 귀띔해줌:
> "오늘 밤 그 백화점, 위층이 열린다더라. 근데 나 말고도 아는 놈 있어"
>
> → 정보를 믿고 가봤더니 진짜 새로운 층이 열려있음
> → 근데 밴딧도 와있음 → 경쟁 루팅 or 전투

### 비주얼 구현 (저비용)
- **문/벽 토글**: MapGenerator에서 "변이 포인트" 지정, 밤마다 문 타일 ↔ 벽 타일 스왑. 타일 1~2종 추가면 충분
- **흔적**: 기존 스프라이트 재활용 (적 스프라이트 눕히기, 반투명 오버레이)
- **분위기**: 밤마다 tint 색상 변경 (`setTint()`)으로 같은 맵 다른 느낌
- 새 씬/맵 불필요, MapGenerator에 변이 로직 함수 추가 수준

---

## 4. 잔해 시스템 (흔적)

- 이전 탐험에서 버린 아이템이 그 자리에 남아있음
- 밴딧이 다녀간 건물은 흔적 (뒤집힌 가구, 핏자국, 탄흔)
- 흔적 따라가면 시체 → 아이템 → 정보 메모 발견
- 같은 장소에 가도 "지난번 이후로 뭐가 바뀌었지?"가 항상 있음

---

## 핵심 루프

```
블랙마켓 (정보 거래)     도시 변이 (밤마다 구조 변화)
        ↘                    ↙
     "오늘 밤은 뭐가 다를까?"
        ↙                    ↘
  밴딧 동선/흔적          새로운 루트 발견
```

## "한 집만 더 털까?" 확장

| 기존 | 블랙마켓 추가 후 |
|------|-----------------|
| 돈 벌러 나감 | 정보 확인하러 나감 |
| 같은 장소 반복 | 밤마다 구조 변화 |
| 적은 장애물 | 밴딧은 나와 같은 존재 |
| 판매처 = 상인 | 블랙마켓 = 정보 + 리스크 |
| 난이도 고정 | 내 선택이 세계 난이도에 영향 |
