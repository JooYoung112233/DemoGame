## Phase 1: 전투 깊이 강화 (전략성 + 리플레이)

### 1-1. 연쇄 콤보 보너스
| 항목 | 내용 |
|------|------|
| 개요 | 연속 턴 콤보 발동 시 보너스 배율 증가 |
| 규칙 | 2연속 → ×1.5, 3연속 → ×2.0, 4연속+ → ×2.5 (캡) |
| 연쇄 끊김 | 콤보 미발동 턴에 카운트 리셋 |
| UI | 콤보 텍스트 옆에 "🔥×2" 표시, 연쇄 시 이펙트 강화 |
| 난이도 | ★★☆ (CombatResolver 수정 + UI 표시) |

### 1-2. 심볼 진화 시스템
| 항목 | 내용 |
|------|------|
| 개요 | 같은 심볼 3개 이상 보유 시 상점에서 진화 가능 |
| 비용 | 8~15G (심볼 등급에 따라) |
| 진화 예시 | 🗡️검 → ⚔️마검 (데미지 5→8, 관통 추가) |
| | 🛡️방패 → 🏰성벽 (방어 4→7, 아군 전체 +2) |
| | 🔥불 → 🌋화산 (화상3→6, AoE 추가) |
| | 💚포션 → 🧪만병통치 (회복4→8, 상태이상 해제) |
| 제한 | 덱에서 해당 심볼 3개 소모 → 진화 심볼 1개 획득 (압축) |
| UI | 상점에 "진화" 탭 추가, 조건 충족 심볼만 활성화 |
| 난이도 | ★★★ (symbols.js 진화 데이터 + ShopScene 탭 + 조건 로직) |

## Phase 2: 유물 확장 + 빌드 다양성

### 2-1. 추가 유물 (10종)

#### 보강형 (빌드 정체성)
| 유물 | 등급 | 효과 | 시너지 |
|------|------|------|--------|
| 🌊 파도의 고리 | uncommon | 같은 심볼 연속 출현 시 해당 효과 +30% | 심볼 집중 |
| 🎪 서커스 모자 | rare | 올디퍼런트 조합 발동 시 모든 수치 2배 | 다양성 빌드 |
| 💀 사신의 낫 | rare | 적 HP 10% 이하 시 즉사 | 마무리 |
| 🧲 자석 | uncommon | 해골 출현 확률 -30% | 안정성 |
| 📿 기도 구슬 | common | 회복 효과 +50% (중첩 가능) | 힐러 빌드 |

#### 리스크-리워드형
| 유물 | 등급 | 효과 |
|------|------|------|
| 🎰 도박꾼의 주사위 | rare | 모든 데미지 0.5~2.0배 랜덤 |
| 💔 피의 계약 | uncommon | 매 턴 HP -1, 공격 데미지 +3 |
| 🃏 조커 | rare | 해골이 나오면 랜덤 심볼로 교체 (자해 무효화) |
| 🌙 월광석 | uncommon | 홀수 턴 공격 2배, 짝수 턴 공격 절반 |
| ⚖️ 균형추 | common | 공격과 방어가 항상 동일하게 조정 (높은쪽→낮은쪽에 맞춤) |

### 2-2. 유물 시너지 세트
- 같은 유물 3개 = "완성" 보너스 (예: 재회전 부적 ×3 = 확률 27% + 리스핀 시 추가 데미지 +5)
- 특정 조합 세트: 🔥+❄️ = "원소 마스터" → 화상+둔화 동시 부여 확률

## Phase 3: 이벤트 + 콘텐츠 다양성

### 3-1. 이벤트 라운드 확장
| 이벤트 | 내용 | 리스크/리워드 |
|--------|------|--------------|
| ⚒️ 대장간 | 심볼 2개 합쳐 진화 심볼 1개 변환 | 덱 압축 기회 |
| 🔓 저주 해제 | 해골 1개 제거 가능 (유일한 기회) | 안전 |
| ⚔️ 시련 | 3턴 내 적 처치 → 유물 획득, 실패 → HP -20 | 고위험 고보상 |
| 🎁 미스터리 박스 | 3택: 유물/골드/심볼, 하나는 저주(해골 추가) | 도박 |
| 🏪 떠돌이 상인 | 희귀 심볼/유물을 HP로 구매 가능 | 체력↔자원 |
| 🪄 마법 샘 | 랜덤 심볼 1개의 효과 영구 +50% | 확정 보상 |

### 3-2. 히든 보스 / 챌린지
- Act 3 클리어 후 "진짜 최종 보스" 해금 조건 (특정 유물 세트 or 무데미지 Act 클리어)
- 주간 챌린지: 제한 조건 하에 클리어 (예: "방어 금지", "5턴 이내")

## 구현 우선순위 제안

### 즉시 (다음 작업)
1. **피니시 킬 연출** — 간단하고 체감 큰 폴리시
2. **연쇄 콤보 보너스** — 전략 깊이 즉시 증가
3. **HP 위험 경고** — 긴장감 연출

### 단기 (1~2일)
4. 추가 유물 5종 (보강형)
5. 적 특수 메커니즘 2~3종
6. 슬롯 트리플 매치 연출
7. Act 전환 연출

### 중기 (3~5일)
8. 심볼 진화 시스템
9. 이벤트 라운드 확장
10. 니어미스 연출
11. 보스 등장 연출

### 장기 (1주+)
12. 유물 시너지 세트
13. 히든 보스/챌린지
14. 주간 챌린지 시스템
