# 세계관 & 구역 서사

> 최종 수정: 2026-05-19

## 상위 서사

**계약+이익 하이브리드 길드**

- 길드는 도시/국가와 계약을 맺어 구역을 관리하되, 본질은 돈을 보고 움직이는 용병 집단
- 각 구역이 다른 수익 프로필 → "오늘은 어디로 벌러 가지?"가 매 턴 의미 있는 선택
- 3구역 모두 돌아야 성장 사이클 완성 (특수 소재 순환)

## 구역별 서사 & 동기

### Blood Pit — 도시 투기장 운영 계약
- **서사**: 도시가 투기장 운영을 길드에 위탁. 관중이 많을수록 수익
- **수익 모델**: 도박형 (고위험 고수익)
- **핵심 메커니즘**: 핏 게이지 = 관중 흥분도
  - 핏 낮음: 조용한 시합, 보상 적음, 안전
  - 핏 높음: 관중 흥분, 보상 2~3배, 적도 강해짐
  - 핏 MAX: 관중 난입! 보너스 몹 출현, 잡으면 대박
  - 핏 바닥: 관중 실망, 그냥 종료 (보상 없음)
- **플레이어 심리**: "한 판만 더, 이번엔 터진다"
- **특수 소재**: 혈정석 (용병 강화에 필요)

### Cargo — 약탈물 호송 계약
- **서사**: 위험한 약탈물을 호송하는 계약. 화물이 탈출하면 재앙
- **수익 모델**: 안정형 (화물 안전 인도 = 보수)
  - 화물칸을 많이 지킬수록 보수 ↑
  - 손상되면 배상금 차감
- **핵심 긴장**: 어떤 칸을 우선 방어할 것인가
  - 골드 화물칸(고수익) vs 일반 화물칸
  - 화물이 탈출하면 추가 적 출현
- **플레이어 심리**: "확실하게 벌자"
- **특수 소재**: 마법 동력석 (장비 제작에 필요)

### Blackout — 저주 저택 정화 의뢰
- **서사**: 저주받은 저택을 정화하는 의뢰. 정화할수록 보상+평판
- **수익 모델**: 일확천금형 (깊이 갈수록 고가 유물)
  - 적당히 나오면 안전하게 수익
  - 더 깊이 가면 전설급 유물, 대신 저주 위험
- **핵심 긴장**: 저주 감수하고 더 갈 것인가
  - 저주 레벨 상승 → 용병 영구 저주 위험
  - 탈출구를 찾아야 유물 회수 확정
- **플레이어 심리**: "전설템 나올 수도..."
- **특수 소재**: 저주 유물 (특수 엔챈트에 필요)

## 수익 포트폴리오 구조

```
BP(도박)  ─── 고위험 고수익, 변동성 큼
Cargo(운송) ─── 안정 수익, 예측 가능
Blackout(탐사) ─── 평소 보통, 가끔 잭팟
```

길드 경영 = 3가지 수익원을 적절히 배분하는 포트폴리오 관리

## 소재 순환

```
BP 혈정석 → 용병 강화 (훈련소)
Cargo 동력석 → 장비 제작 (제작소)
Blackout 저주유물 → 특수 엔챈트 (신전)
```

3구역 모두 돌아야 성장 루프 완성
