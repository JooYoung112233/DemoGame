# Opening City — 핵심 기획

## 개요
2D 탑다운 루팅 서바이벌 데모. "Opening City" 기획서를 참고한 MVP 프로토타입.
**검증 목표**: 루팅 루프(도시 진입→수색→위험 감지→탈출 판단)가 재미있는가?

## 핵심 루프
1. 🏠 안전가옥에서 출발
2. 🏚️ 폐허 도시 탐색 (건물 수색)
3. 📦 타르코프식 슬롯 인벤토리로 물자 관리
4. 🌙 밤이 오면 감염자 출현 — 위험 증가
5. 🚪 탈출 지점 도달 → 물자 정산 & 등급 평가

## 시스템

### 시간 시스템
- 낮: 60초 (안전하게 탐색)
- 밤: 120초 (감염자 출현, 시야 제한)
- 밤 3웨이브: 시간 경과에 따라 적 증가

### 시야 시스템
- 낮: 원형 시야 (반경 7타일)
- 밤: 부채꼴 시야 (90도, 7타일) + 뒤쪽 2타일
- 벽으로 시야 차단 (Bresenham 라인)
- 탐색한 타일은 어둡게 기억됨 (fog of war)

### 인벤토리
- 5×4 그리드 (20칸)
- 최대 무게: 30kg
- 아이템별 크기 다름 (1×1, 1×2, 2×1, 2×2)
- 무겁고 큰 아이템일수록 가치 높음

### 전투
- 최소한의 근접 전투 (클릭 = 공격)
- 적 접촉 = 데미지
- 안전지대에서는 데미지 없음
- **도망이 상책** — 전투는 최후의 수단

### 적
| 타입 | HP | 데미지 | 속도 | 시야 | 특징 |
|------|------|--------|------|------|------|
| 감염자 | 30 | 8 | 느림 | 4타일 | 기본 적 |
| 질주자 | 20 | 12 | 빠름 | 5타일 | 위험, 도망 추천 |
| 거수 | 60 | 15 | 매우 느림 | 3타일 | 높은 HP/데미지 |

## 안전구역 (거점)

### 컨셉
탭 메뉴가 아닌 **탑다운 이동 공간**. ExpeditionScene처럼 걸어다니며 오브젝트에 E키로 상호작용.
**뒷골목** — 좁은 골목에 컨테이너, 전당포 노점, 게시판이 늘어선 거점. 야외.

### 분위기
- 좁은 뒷골목/골목길, 양쪽 벽(건물 외벽)으로 막힌 구조
- 컨테이너가 창고 역할, 전당포는 판잣집/천막 노점 느낌
- 철조망/철창문이 골목 끝에 있고, 너머가 폐도시(레이드 구역)

### 오브젝트 배치
| 오브젝트 | 기능 | 상호작용 |
|---------|------|---------|
| 전당포 (NPC) | 퀘스트 + 아이템 매매 | E키 → 거래 UI 팝업 |
| 컨테이너 (상자) | 창고 — 아이템 보관 | E키 → 보관함 UI 팝업 |
| 게시판 | 존 선택 (원정지 정보) | E키 → 존 카드 UI 팝업 |
| 철창문 | 레이드 출발 | E키 → 선택된 존으로 출발 |

### 인벤토리 (TAB)
- TAB키로 어디서든 인벤토리 열기
- 타르코프식 구성: 좌측 장비 슬롯 + 중앙 캐릭터 + 우측 소지품 그리드
- 컨테이너 상자에서 아이템 꺼내 바로 장비 장착 가능
- 하단에 대형 장비 슬롯 (무기)

### 동선
```
골목 입구 ← [전당포] — [컨테이너] — [게시판] — [철창문] → 폐도시
```

### 맵 규모
- 좁고 긴 골목 (타일 기준 ~6×16 정도)
- 양쪽 건물 벽으로 막힌 일직선 구조
- 이동은 가능하되 탐험 요소 없음 — 순수 허브 공간

## 기획 결정 로그

### 2025-05-27
- **질문**: 안전구역 화면 구성 방식? (고정 배경+클릭 / 탑다운 이동 / 횡스크롤)
- **결정**: 탑다운 이동
- **근거**: ExpeditionScene과 동일한 조작감, 공간 몰입감

- **질문**: 전당포 기능 범위? (매매만 / 매매+장비 / 매매+수리+장비)
- **결정**: 퀘스트 + 매매
- **근거**: 전당포는 거래/의뢰 중심, 장비 장착은 별도

- **질문**: 레이드 출발 방식? (철창문→바로 / 철창문→존 선택 팝업 / 게시판+철창문)
- **결정**: 게시판에서 존 선택, 철창문으로 출발
- **근거**: 오브젝트 역할 분리, 게시판=정보, 철창문=출발

- **질문**: 안전구역 실내 vs 실외? (폐건물 내부 / 컨테이너 야적장 / 골목·뒷골목)
- **결정**: 뒷골목 (야외)
- **근거**: 좁은 골목에 컨테이너+전당포 노점 배치, 골목 끝 철창문 너머가 폐도시

- **질문**: 인벤토리/장비 UI 구조?
- **결정**: TAB키 → 타르코프식 (좌: 장비슬롯, 중앙: 캐릭터, 우: 소지품 그리드)
- **근거**: 컨테이너 상자에서 꺼내 바로 장비 장착 가능한 통합 UI
